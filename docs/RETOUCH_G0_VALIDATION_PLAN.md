## 3. 输入、参考与分组规范

所有正负例先准备 1024 最长边的主版本；512 版本从同一主版本和对应标记产生，
不算新的独立案例。缩放算法及边界规则在制作时记录并固定，不能按候选结果
选择更有利的版本。两个分支可共用同一源家族，但 D 与 H 集合永远不共用源家族。
相同肖像的换色、裁剪、镜像或换背景也不能伪装成独立源家族。

输入先转正并消除镜像得到 canonical RGBA8 sRGB 栅格。所有真值区域、参考图
和像素指标均在该栅格定义；方向测试将同一内容重新编码，再按相同规范回映。
禁止用候选输出的坐标、预测轮廓或保护区重新确定真值。

### EYE 参考制作

1. 选取满足限定输入域的肖像，以事先声明的目标眼制作轻度过亮光影正例，或
   对源肖像作独立的局部光影修饰以得到目标参考。具体作者方法在看候选前固定。
2. 参考只允许目标区内的局部光影变化；目标区外、眼裂、睑缘、睫毛、眉以及
   alpha 必须与源栅格相同。不能接受图像生成编辑造成的身份、几何或纹理漂移。
3. 冲突区域先保护；目标区边界与保护区在 G0 固定。明确单眼/双眼目标，不能
   把后来不达标的眼删掉。参考的通道变化须落在既有修饰上限内。
4. 完整查看源与参考：参考确有轻微光影改善，无环纹、暗槽、色带或塑料感。
   数字上离参考更近，不能代替参考本身合理。参考差异太小或造成几何改变时，
   在 G0 退回作者阶段，不进入算法比较。
5. 配对负例缺少应减弱的过亮目标，需在候选前确定；不可依据生产准入分数给
   源图贴正负标签。新目标不是旧平面残差、校准色块或既有候选输出的再包装。

### SEG 真值制作

1. 正例是有连贯可见边界的肤色哑光贴片；负例在相同位置具有连续皮肤。贴片
   与正常皮肤在实际输入上必须可区分，不能仅凭测试端隐藏的材质标签区分。
2. 在源图上独立确定完整物体轮廓、完整唇部、其他关键五官/背景保护区及皮肤
   评估区。皮肤评估区同时用于源与所有输出，不随自动排除结果缩小。
3. 物体必须有非空的内部核心区；皮肤区必须具有非零邻接亮度变化，且含有
   足够区域供已声明的平滑/锐化目标检验。达不到这些条件时先修输入设计。
4. 参考保护与正确蒙版控制可使用真值，但自动候选请求不得接触真值、参考图、
   ID、来源分组或期望标签。候选只看到图像及既有合法请求信息。
5. R03 的重复纹理拒绝例必须和正常皮肤负例有可观察上下文差异。若出现相同
   输入却要求一边原图退出、一边有效处理，直接判验收设计无效。

## 4. 测量定义

本节明确计算口径。阈值继续引用 R2 的 E1–E5、S1–S6，不在这里建立另一套数值。
所有分母和区域在候选前固定；空集合、零分母及非有限值为输入/测量错误，
不能计为正常退出、通过或被忽略的样本。

### 4.1 栅格、亮度与源精确

R/G/B/A 为规范化后 0–255 整数。EYE 亮度为
`Y = (2126 R + 7152 G + 722 B) / (10000 × 255)`，不在中间取整，不做线性光转换。
这与 R2 的 BT.709 sRGB code-value 口径一致。比较采用足够精度的求和，边界
判断不得因显示值四舍五入而改变通过状态。

SEG 邻接变化沿用已有纹理回归的加权亮度
`Yt = (77 R + 150 G + 29 B) / (256 × 255)`，不在中间取整；R2 先前未指定
SEG 系数，这里固定为既有测试口径，而非生产整数亮度的舍入版本。
两个亮度指标不得混用，也不把各自的百分比解释成材质或脂肪比例。

源精确是 RGBA8 相应通道逐值相等。保护条件按逐像素最大值/计数判定，
不能以均值接近零掩盖少量泄漏。所有 alpha 必须保持一致。

### 4.2 EYE 方向、强度与纹理

对每一预声明目标眼分别计算 ROI 内亮度绝对差的算术平均值；不把左右眼汇总
后用好的一侧抵消差的一侧。E1 分母是该眼 `MAE(Y(I), Y(T))`，至少达到 R2 的
最小源目标差；半强度和全强度都对**同一个全强度参考 T**计算改善。

E3 目标平均修饰量是 ROI 内 `Y(I) − Y(O)` 的平均值；每个被改像素还要检查
没有反向增亮及通道上限。半强度/全强度按同一源、同一区域比较，不在处理后
重新运行检测来改变测量区域。

高通为完整 canonical 亮度图减去其 3×3 等权 box 均值；图像外沿重复最近边界
像素，ROI 边界不截断邻域。辅助纹理比率为 ROI 内 `mean(abs(HP(O)−HP(I)))`
除以 `mean(abs(HP(I)))`。低纹理分母按 R2 单列视觉判定，不自动判通过。
测量高通只用于验收，不复制生产上睑准入/平面拟合/编辑器的评分。

### 4.3 SEG 物体与边缘带

在每个实际尺度的固定物体真值 O 中，距补集不超过 2 像素的内部区域为边缘带；
采用八邻域距离。其余为核心，核心必须非空。边缘带从真值生成，不能从预测
轮廓生成。至少 95% RGB 不变的条件用整数计数比较，禁止先把百分比取整。
所有变动同时满足 R2 的边缘位置与每通道上限；95% 不能豁免内部损坏。

### 4.4 SEG 邻接纹理方向

在固定皮肤 ROI 中，枚举两个端点都位于 ROI 的水平/垂直相邻像素对，每对只
计一次。变化指标为这些像素对的 `abs(Yt(p)−Yt(q))` 平均值。
平滑降低量为 `1−V(output)/V(source)`；锐化增加量为 `V(output)/V(source)−1`。
源指标非零、像素对集合非空是输入准入条件。平滑和锐化单独开启验证，不能
用两个参数互相抵消的组合取代各自的门槛。

### 4.5 SEG 支持覆盖与过度保护的可观测缺口

当前 [纹理实现](../BeautySDK/Sources/BeautyEffects/Render/BeautySkinTexturePipeline.swift)
只返回像素数组；public 输出不含最终支持蒙版。已有
[纹理回归](../BeautySDK/Tests/BeautyCoreTests/BeautySkinTextureHostProtectionTests.swift)
验证方向与保护，并未给新的支持覆盖指标提供独立接口。
因此 G0-C 不能以“有多少像素变化”代替 R2 的支持覆盖率。

后续验收器方案是在**隔离测试副本**中增加仅请求内的计数观察点：既有脸、颜色、
边缘、五官与排除条件全部通过后，且在平坦像素因小于量化阈值而不变之前，
记录可受处理的支持。生产源码、public API 与诊断不增加原始蒙版输出。
进入候选阶段后观察点必须对应候选的最终决策，不能由候选自报一个无关蒙版。

G0-C 必须先证明有/无该观察点的最终像素、错误和请求生命周期完全一致；
在正确蒙版、全排除、无排除等已知控制中计数符合预期。未完成这项验证时，
S3/S4 的覆盖字段标为 `unmeasured`，不能根据方向通过推定覆盖也通过。

定义 A0 为同一图像不使用新增自动排除时的既有最终可处理集合，A1 为加上
候选自动排除后的集合。A1 应为 A0 的子集，自动保护不能扩大原本不允许编辑
的区域。S3 覆盖分母是整个固定皮肤 ROI；S4 额外排除的分子是 ROI 中 A0 与
A1 的差集，分母也是整个 ROI。两者都与变色像素数独立。

SEG 完整 G0 已实施上述隔离 observer，并逐项证明其与 public CPU 输出一致。
它不补齐 EYE 或候选 G2 的全部后端覆盖。

## 5. 验收器控制矩阵

控制用于检查判据，不计自动候选，也不消耗算法开发版本预算。正确控制可
读取独立真值；候选不能读取。控制输出本身须符合输入/元数据条件。

| 控制 | EYE 预期 | SEG 预期 | 检查目的 |
| --- | --- | --- | --- |
| 正确参考/正确保护 | 对合格 T 的适用方向/保护检查通过，视觉确认参考合理 | 正确物体 + 唇保护且有效纹理的控制联合通过 | 标准不是自相矛盾、不可达 |
| 原图 no-op | 正例效果失败，负例按原图规则通过 | 正例皮肤方向失败 | 原样输出不能冒充效果 |
| 全图排除 | 等同 no-op，不获效果资格 | 物体保护通过但皮肤方向/覆盖失败 | 防止全停取得成功 |
| 整图调暗 | 保护区失败；即使参考距离下降也失败 | 关键区域保护失败 | 防全局改色冒充局部修饰 |
| 眼形位移 | 几何/关键区域失败 | 不用于纹理方向正例 | 防提睑/放大眼睛替代 |
| 磨平细节 | 纹理或视觉伪影失败 | 不用仅平滑方向高分豁免区域泄漏 | 防塑料质感或错误范围 |
| 注入环纹/暗槽 | 视觉伪影检查必须拒绝 | 不适用 EYE 伪影标准的替代得分 | 验证数字改善不足以掩盖缺陷 |
| 物体核心改动 | 不适用 | S2 核心保护失败，即使整体 95% 未变 | 防平均指标掩盖局部破坏 |
| 超出边缘变化上限 | 不适用 | S2 失败 | 验证容差不是任意泄漏许可 |
| 大面积误排除正常皮肤 | 不适用 | S4 失败 | 防“都像物体”的过度保护 |
| 目标/保护 mask 错位 | 对应源精确检查失败 | 对应保护/覆盖检查失败 | 验证方向/镜像坐标一致 |
| 伪造元数据或损坏输入 | 固定错误类别，不能报效果通过 | 同左 | 防环境/输入错误计为成功 |

每个适用控制须至少有一个固定输入使预期可观察；不能依赖一个根本没有纹理
或没有可变保护像素的输入去证明拒绝能力。正确控制达不到门槛时，先审计
参考/输入/指标；没有候选输出之前可更正明确的作者或测量错误并升级版本。
错误控制被接纳时，修的是验收设计，不能先推进算法再补测试。

## 6. 视觉检查和结果分类

EYE 按源、目标参考、半强度、全强度四项进行原尺寸全图与局部检查，统一缩放和
颜色管理。视觉检查逐案例记录“轻微改善 / 看不出改善 / 恶化”，以及环纹、
暗槽、色带、细节、眼形、左右失衡各项。不能根据候选编号或数字高低预填结论。
这里的独立指参考与判据不依赖候选实现；不伪称有第二名独立评审人。
SEG G0 对每例的源、全强度平滑及锐化控制检查全图构成与全部处理区原像素局部，
两尺度均检查，另核对物体边界与拒绝条件。保护区全像素精确比较补充视觉核对。
该上限控制用于证明方向/保护可同时成立，不签发自动候选的最终外观资格。

| 结果 | 含义 | 是否计效果成功 |
| --- | --- | --- |
| `pass` | 适用的方向、覆盖、保护、视觉与元数据联合通过 | 是 |
| `abstained` | 输入有效、实际输出按规定退出 | 否，保留在原正例分母 |
| `insufficient_effect` | 输出有效且保护通过，但方向或可见改善不足 | 否 |
| `hard_failure` | 保护、伪影、上限、元数据、非目标眼或状态恢复违约 | 否，该分支资格失败 |
| `invalid_fixture` | 缺文件、权限/摘要不符、标记错位或输入不可测 | 不进入成功率计算，整批不完整 |
| `infrastructure_failure` | 编译、依赖、后端或工具不能执行 | 不进入成功率计算，整批不完整 |
| `unmeasured` | 某必需指标或视觉检查未执行 | 不得通过 |

报告分母始终保留清单规定的逻辑案例数；不能因为上表后两类不计算效果比例
就从“总共需要完成的案例”中删除。控制的预期失败必须被工具准确识别；
算法输出的失败不能借用“控制预期失败”名义变成通过。

## 7. 冻结及复现设计

冻结前必须具备：内容/来源摘要、源家族和分组、目标眼与保护定义、拒绝理由、
两个尺度的可测性、控制矩阵结果、视觉记录及验收工具版本。只持久保存逻辑
身份、摘要与聚合字段；原始区域、图片和私有路径不写入记录。

工具需区分“清单存在”“文件实际就绪”“数据冻结”“候选已评估”，不允许一个
布尔完成值把这些合并。冻结后无故替换数据必须被摘要检查拒绝；正常重复执行
只能复用同一版本。留出输入可在 G0 检查可测性，不能用于候选调参或挑选赢家。
