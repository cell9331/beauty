# Beauty SDK Product Feature Plan

## 1. 产品定位

本 SDK 面向图片编辑、相机拍摄、短视频、直播、社交聊天、证件照、AI 写真等场景，提供类似美图秀秀、轻颜相机、醒图一类的美颜与人像精修能力。

核心目标：

- 支持实时预览与离线图片处理。
- 支持自然、可控、细粒度的人脸调整。
- 支持多档预设，一键美颜，也支持高级用户手动微调。
- 支持拍照、视频、直播流、人像图片编辑等多种输入场景。
- 作为 SDK 提供给 App 集成，功能模块可按需裁剪。

---

美颜 SDK 可以分为以下几个大模块：

# 3. 基础美颜功能

基础美颜主要解决皮肤质感、肤色、瑕疵、清晰度等问题。

## 3.1 磨皮

功能说明：让皮肤更平滑，减少毛孔、细纹、轻微斑点。

参数建议：

- 磨皮强度：0 ~ 100
- 保留皮肤纹理：0 ~ 100
- 人脸区域保护：开启 / 关闭
- 五官锐度保护：开启 / 关闭

产品注意：

- 不能把脸磨成塑料感。
- 鼻梁、眼睛、嘴唇、眉毛边缘需要保持清晰。
- 中高端方案需要支持“皮肤区域识别”，只对皮肤区域处理。

## 3.2 美白

功能说明：提升肤色亮度，让肤色更干净。

参数建议：

- 美白强度：0 ~ 100
- 肤色冷暖：冷白 / 自然 / 暖白
- 高光保护：开启 / 关闭

## 3.3 红润

功能说明：增加面部气色。

参数建议：

- 红润强度：0 ~ 100
- 红润区域：脸颊 / 全脸 / 自然分布

## 3.4 祛痘 / 祛斑 / 瑕疵修复

功能说明：去除皮肤上的痘痘、斑点、黑痣、细小瑕疵。

功能形式：

- 自动祛痘
- 手动点选祛痘
- 自动祛斑
- 局部修复笔

参数建议：

- 瑕疵识别强度：0 ~ 100
- 修复自然度：0 ~ 100
- 是否保留痣：开启 / 关闭

## 3.5 黑眼圈 / 法令纹 / 泪沟处理

功能说明：减轻疲惫感。

可调项目：

- 淡化黑眼圈
- 淡化泪沟
- 淡化法令纹
- 淡化额头纹
- 淡化眼周细纹

参数建议：

- 强度：0 ~ 100
- 自然度：0 ~ 100

## 3.6 清晰度 / 锐化

功能说明：增强五官、头发、轮廓清晰度。

参数建议：

- 清晰度：0 ~ 100
- 五官增强：0 ~ 100
- 头发增强：0 ~ 100
- 皮肤锐化保护：开启 / 关闭

# 4. 脸型重塑功能

脸型重塑是美颜 SDK 的核心模块之一。

## 4.1 瘦脸

功能说明：收窄脸部宽度。

可调项目：

- 整体瘦脸
- 左脸瘦脸
- 右脸瘦脸
- 下颌线收紧
- 腮帮缩小
- 颧骨收窄

参数建议：

- 瘦脸强度：0 ~ 100
- 左右对称：开启 / 关闭
- 人脸保护边界：0 ~ 100

## 4.2 小脸

功能说明：整体缩小脸部面积，同时保持五官比例自然。

参数建议：

- 小脸强度：0 ~ 100
- 五官跟随缩放：开启 / 关闭

## 4.3 窄脸

功能说明：主要压缩脸颊和脸部中段宽度。

适合场景：

- 圆脸
- 宽脸
- 镜头近距离畸变修正

## 4.4 V 脸

功能说明：让下巴更尖、脸型更接近 V 型。

参数建议：

- V 脸强度：0 ~ 100
- 下巴尖度：0 ~ 100
- 下颌收缩：0 ~ 100

## 4.5 下颌线优化

功能说明：让脸部轮廓更清晰。

可调项目：

- 下颌线清晰度
- 下颌宽度
- 下颌角收窄
- 下巴与下颌过渡自然度

## 4.6 颧骨调整

功能说明：调整面中部轮廓。

可调项目：

- 颧骨内收
- 颧骨柔化
- 颧骨高度微调

## 4.7 面部长度调整

功能说明：调整脸的纵向比例。

可调项目：

- 缩短脸长
- 拉长脸型
- 中庭缩短 / 拉长
- 下庭缩短 / 拉长

## 4.8 脸部对称修正

功能说明：改善左右脸不对称。

可调项目：

- 自动对称
- 左右脸宽度修正
- 左右眼高度修正
- 左右嘴角高度修正
- 左右脸轮廓修正

# 5. 眼部调整功能

眼部是用户最敏感、最常用的精修区域，需要细分能力。

## 5.1 大眼 / 小眼

功能说明：调整眼睛整体大小。

可调项目：

- 双眼整体放大
- 左眼单独放大
- 右眼单独放大
- 眼高调整
- 眼宽调整

参数建议：

- 大眼强度：-100 ~ 100
  - 负数：缩小眼睛
  - 正数：放大眼睛
- 左右同步：开启 / 关闭
- 眼球保护：开启 / 关闭

## 5.2 眼距调整

功能说明：调整两只眼睛之间的距离。

可调项目：

- 眼距拉近
- 眼距拉远
- 左眼横向移动
- 右眼横向移动

参数建议：

- 眼距：-100 ~ 100
  - 负数：眼距变近
  - 正数：眼距变远

## 5.3 眼睛上下位置调整

功能说明：调整眼睛在脸上的垂直位置。

可调项目：

- 双眼上移 / 下移
- 左眼上移 / 下移
- 右眼上移 / 下移

参数建议：

- 眼睛 Y 轴位置：-100 ~ 100

## 5.4 眼睛旋转 / 倾斜调整

功能说明：调整眼睛角度，让眼型更柔和或更有神。

可调项目：

- 左眼旋转
- 右眼旋转
- 眼尾上扬
- 眼尾下压
- 眼头高度调整
- 眼尾高度调整

适合做成：

- 灵动眼
- 下垂眼
- 猫眼
- 温柔眼

## 5.5 眼型调整

可调项目：

- 圆眼
- 杏眼
- 桃花眼
- 丹凤眼
- 下垂眼
- 猫眼
- 欧式眼型

实现方式：

- 可以作为高级预设，不一定全部开放为独立参数。

## 5.6 眼角调整

可调项目：

- 开内眼角
- 开外眼角
- 眼头拉伸
- 眼尾拉伸
- 眼角锐度

参数建议：

- 内眼角：0 ~ 100
- 外眼角：0 ~ 100
- 眼尾上扬：-100 ~ 100

## 5.7 卧蚕

功能说明：增强眼下卧蚕，让眼睛更有亲和力。

可调项目：

- 卧蚕增强
- 卧蚕阴影
- 卧蚕高光
- 卧蚕宽度

## 5.8 眼神光

功能说明：增加眼睛高光，让眼睛更亮。

可调项目：

- 眼神光强度

# 16. 多人脸处理

## 16.1 多人脸识别

功能说明：同一张图片或视频中识别多张脸。

能力要求：

- 支持最多 N 张脸。
- 支持主脸识别。
- 支持选择某一张脸单独调整。
- 支持所有人统一美颜。
- 支持不同人使用不同参数。

## 16.2 主脸策略

可选策略：

- 面积最大的人脸作为主脸。
- 距离画面中心最近的人脸作为主脸。
- 用户手动选择主脸。
- 首次识别的人脸保持跟踪。

# 21. 产品设计原则

## 21.1 自然优先

美颜不能只追求强度，应该优先保证自然。

建议每个参数内部都带自然度约束：

- 避免五官扭曲。
- 避免背景被拉伸。
- 避免脸部边缘变形明显。
- 避免多人合照中人物比例不一致。

## 21.2 参数可组合

用户常常不是只调一个参数，而是多个参数组合。

需要考虑：

- 磨皮 + 清晰度不能互相抵消。
- 大眼 + 眼距 + 眼尾上扬需要保持眼睛自然。
- 瘦脸 + 下巴 + V 脸需要避免脸型过尖。
- 妆容 + 滤镜需要避免颜色过饱和。

## 21.3 实时性能优先

作为 SDK，必须关注实时预览性能。

基础要求：

- 支持图片处理。
- 支持相机实时预览。
- 支持视频帧处理。
- 支持低端机降级策略。
- 支持不同分辨率输出。

## 21.4 可配置、可扩展

SDK 不应该把所有能力写死。

建议支持：

- 配置文件下发。
- 滤镜资源动态加载。
- 妆容素材动态加载。
- 参数预设动态加载。
- 功能模块按需启用。
