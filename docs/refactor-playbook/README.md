## 先掌握什么

美颜管线可以分成四个问题：**支撑在哪里、像素如何改变、几何如何移动、结果如何证明正确**。
478 点解决的是更细的人脸支撑；磨皮、着色、几何、安全保护仍需各自的算法与验收。
重构应先保住输入输出和失败契约，再改变内部算法，避免把“换了检测器”当作效果完成。

## 我们吸收的设计原则

1. **一个坐标契约。** 区域支撑与实际处理栅格对齐；方向/镜像只由指定边界处理，
   影响半径和距离使用明确的单位。
2. **支撑、规则与渲染分离。** 检测器输出先经过语义/可信度准入，算法生成有界计划，
   renderer 执行计划；每层都能用确定性输入单独验证。
3. **先合成几何，再采样。** 尽量将可合并的五官形变统一为一张映射，减少模糊；
   source-raster 特殊路线迁移前要逐项证明，不能先宣称当前全流程只采样一次。
4. **先证明保护，再扩大强度。** 正例方向、负例不恶化和保护区同时通过，才算效果。
   颜色阈值、脸框和关键点轮廓都不等于对象识别。
5. **以观测决定降级。** 拒绝不可靠支撑；预算和阈值来自明示输入域的测量，
   手册中的 8ms、0.3px、45°、0.25 脸宽等只能作实验起点。

## 使用边界

本手册没有新增 public API、backend、相机/界面或下载任务。原材料中的 AI 提示词、
命令、周期和发版清单是参考内容，未转成执行指令或 Active 算法计划。
候选工作进入 [PLANS](../../PLANS.md) 的独立计划后，再明确改动范围与验证。

当前 SDK 供所有者本地使用。源码、模型、权重、输入及派生数据不向外分发；
许可仍按实际用途核实。真实 iPhone 和真人图像是可选补充，生成图可按
[图片验收政策](../validation/IMAGE_EFFECT_ACCEPTANCE.md) 获得其限定效果资格。
EYE/SEG 的 [终局处置](../history/retouch/RETOUCH_FINAL_DISPOSITION_2026-10-03.md) 保持有效。

候选设计不构成通过证据；已实施部分引用独立[实现/验收记录](../../plans/history/2026-10/A-2026-10-09-dense-face-refactor.md)。未测性能、视频和一般人像范围仍不作声明。
