# 几何引擎：从控制点到统一映射

[返回入口](README.md)。dense静图已实现固定全画布逆网格；retained `Warp.metal`和Vision旧路线保留。语义脸面mesh/TPS/GPU原生网格仍为候选。

## 当前路线与重构目标

当前多个区域provider生成 [WarpControlPoint](../../BeautySDK/Sources/BeautyEffects/Warp/WarpControlPoint.swift)，
统一进入 [BeautyGeometryEffectPipeline](../../BeautySDK/Sources/BeautyEffects/Render/BeautyGeometryEffectPipeline.swift)。
dense路线按478点分布加密覆盖整张图的输出网格，每格固定两个三角。
局部位移在像素度量合成后统一限制位移/梯度，再用分片仿射映射采样；两backend共享CPU-owned阶段。
[实现契约](../DENSE_FACE_REFACTOR.md)说明全覆盖、保护行和充分无折叠条件。
旧Vision/retained Metal仍是局部影响点renderer：Metal最多256点，
facade无行限制超量计划走完整CPU容量路线，直接Metal/行限制超量typed failure。

重构目标是使每个效果产生可解释、可合并的位移计划，并证明统一映射的保护与稳定性。
当前 [GeometryConflictResolver](../../BeautySDK/Sources/BeautyEffects/Warp/GeometryConflictResolver.swift)
限制的是参数总强度；dense地图另在所有三角检查位移梯度并统一缩放，
二者分别承担参数冲突与实际映射安全。参数预算本身不等于无折叠证明。
现有特定水平内收路线有专用充分条件，不能推广为全部二维组合安全。

## 网格为何能逆向采样

对同一个三角形，源顶点为 `s0,s1,s2`，目标为 `d0,d1,d2`。
在目标三角形内求输出像素的重心权重 `b0,b1,b2`，
源位置就是 `b0·s0 + b1·s1 + b2·s2`。
Metal可用目标位置作为顶点位置、源位置作为UV插值；这是分片仿射逆向查询。

```text
当前帧源点 → 各效果位移 → 合并/限幅 → 合格的目标网格
                        ↓
           输出像素 → 目标三角重心坐标 → 源UV → 采样一次
```

“不散射源像素”消除了那类离散空洞，却没有自动保证整个输出都被覆盖。
需要源网格有效、目标网格覆盖、共享边一致、边界固定以及无退化/重叠；
`clamp_to_edge` 仅解决源采样越界，不能填补没有三角覆盖的输出。
所有vertex的齐次w取1时UV是这里需要的仿射插值；若扩展到3D则须另定义投影。

## 拓扑资源怎样形成

应先固定模型版本、语义顶点ID与运行时生成规则，再生成索引。
人脸语义约束决定眼睑/内外唇等边；图像边界与脸外过渡环负责全图覆盖。
MediaPipe自带脸面连接不覆盖整张照片，也不直接包含背景环和全部虹膜三角。

| 离线需要记录 | 为什么 |
| --- | --- |
| 顶点类别/稳定顺序/语义版本 | 检测点、插值点、锚点不能只靠裸数组下标默契。 |
| 三角索引、朝向、邻接和约束边 | 检查眼/唇边界、非流形边、交叉与局部退化。 |
| 画布与边界约定 | 像素边界 `[0,W]×[0,H]` 与像素中心 `[0.5,W−0.5]` 不混用。 |
| 资源版本、计数、哈希与索引宽度 | 读取前验证；超过UInt16范围必须拒绝或换明确格式。 |
| 几何与栅格覆盖验证 | 面积求和相等不足以证明没有洞或重叠；检查像素中心及边界。 |

普通 [SciPy Delaunay](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.Delaunay.html)
没有眼/唇约束边接口，也可能因数值问题遗漏输入点。
不能剔除小三角后就称覆盖完成：应移动/合并坏点、补点或重剖分并重新验证。
外环clip到边界可能产生重合点，要去重并维护语义映射。
原脚本导出的是计数header+索引，并未导出完整生成规则或达到这些条件。

固定索引的优点是避免每帧重新连接引起闪烁，但只在运行时源形态仍有效时成立。
闭眼、紧闭唇、侧脸或遮挡可导致源三角退化；此时应按预先定义的区域/拓扑策略退出，
不要在全量点上重新Delaunay或把异常点投回画布内掩盖问题。

## 位移计划怎样合并

每个功能至少定义：**可靠支撑、固定锚点、局部坐标轴、尺度、作用域、方向、权重、上限**。
先在同一源空间对所有功能求位移，再合成；眉眼距、鼻唇距等相邻部位共享预算。
建议按“参数cap → 单功能位移cap → 合成位移cap → 几何有效性”逐层检查。
脸宽/眼距只是尺度候选，缩短脸和收鼻的安全上限不能只共用一个8%常数。

边界锚点位移为零，脸外环平滑衰减，近轮廓更密。背景线条是否仍平直必须实测。
外环本质是分配局部拉伸，不会凭空补出被移走的皮肤、头发或背景。
语义mask限制像素着色与限制几何位移是不同操作；硬切位移场会破坏连续性，
warp图与原图混合又可能重影。保护要求要在输出空间定义并实际核验。

## 折叠保护的完整前提

对每个三角计算源/目标有向面积 `A0/A1`，在源有效后才使用面积比：

1. 先检查源点、索引、有限值、边交叉与 `abs(A0) > ε`；源本身不合格则撤销对应工作。
2. 将位移**先限幅一次**得到 `Δ`，再构建 `d(t) = s + t·Δ`；固定点保持源位置。
3. 检查同向、最小面积比及必要的边交叉/覆盖；单三角未翻不替代整网格有效性。
4. 从 `t=0` 的已验证状态向目标寻找安全候选，最终再次全量检查；找不到则当前帧无几何。

候选二分需满足从零到目标的安全区间前提。有向面积随t是二次函数，
一般叠加并不自动证明安全谓词全区间单调；“8次二分找到最大安全强度”不能无条件保证。
可求首次面积阈值交点、分段保守搜索或证明特定规则单调，然后验证最终候选。
原骨架跳过 `A0 == 0`、未拒NaN并默认t=0安全；这些都须先修正。
没有当前可靠跟踪时，也不要以“回退上一帧位移”替代安全退出。

## TPS/RBF 适合做什么

可以从少量有界控制点插值网格顶点位移，先在CPU完成小规模求解，再统一采样。
选择核、局部窗口和预分解策略前应对比现有局部规则；全图TPS和逐像素TPS
成本与背景影响较大，不作为当前候选默认，但这是项目选择而非数学禁令。

二维TPS典型系统含仿射项和约束，不能仅写 `(K+λI)w=v` 就称完整实现：

```text
[ K+λI  P ] [w] = [v]       P每行 = [1, x, y]
[ Pᵀ     0 ] [a]   [0]       f(x,y) = Σ wᵢ·U(rᵢ) + a₀+a₁x+a₂y
U(r) = r² log(r)，U(0)=0
```

λ≥0是可调平滑参数，良好独立控制点可取零；不是加正数就能消除共线、重复或数值病态。
只在控制点坐标/核/λ固定时缓存分解；检测点位置随帧变，不能沿用前帧矩阵。
局部窗口相乘会改变插值与边界导数，需重新检查固定锚点、连续性与折叠。
依据：[SciPy RBFInterpolator 的完整方程及可解条件](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.RBFInterpolator.html)。

## 径向放大的限幅如何理解

手册正向规则为 `dst = C + d·[1+a(1−t²)²]`，其中 `t=|d|/R < 1`。
径向导数是 `1+a(1−t²)(1−5t²)`；在放大域 `a≥0`，括号最小为−0.8，
因此孤立连续映射 `a<1.25` 时径向导数为正。
这是公式推导，不是实测；负向缩小还需下界，不能只检查a<1.25。

该结论不证明稀疏离散三角、两个眼部区域叠加或其他功能组合仍安全；仍需网格检查。
正向放大规则与手册的逆向缩放规则也不是同强度的严格互逆函数。
用脉冲、网格线、圆环等确定性图测宽高比、中心/边界、Jacobian与组合行为，再用肖像验收。
