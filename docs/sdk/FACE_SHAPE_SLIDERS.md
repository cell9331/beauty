# 脸型滑杆与连续轮廓

实现参考所有者的单参数美图截图及导入手册的脸型、位移场和保护区描述。
现行参数契约由本页、[DESIGN](../../DESIGN.md)与[taxonomy](../SDK_EFFECT_TAXONOMY.md)拥有，代码和测试用于核实。截图没有
数值；下面对齐中性位置、左右方向和连续强度，不承诺未知幅度或逐像素复刻。

## 宿主映射

`BeautyFaceShapeSlider` 接受 `0...1` 位置并返回参数快照；其他字段保留 normalized
值。超范围位置截断，非有限位置回到中性。端点对应既有安全 cap，避免中途触顶。

| 控件 / enum case | 字段 | 左 → 右 | 参数端点 |
| --- | --- | --- | --- |
| 脸宽 / `faceWidth` | `faceSlim` | 宽 → 窄 | −0.60 → +0.60 |
| 小脸 / `smallFace` | `faceSmall` | 大 → 小 | −0.45 → +0.45 |
| 太阳穴 / `temple` | `templeFullness` | 收 → 丰满 | −0.25 → +0.25 |
| 颧骨 / `cheekbone` | `cheekboneSlim` | 宽 → 收 | −0.25 → +0.25 |
| 下巴长短 / `chinLength` | `chinLength` | 长 → 短 | +0.35 → −0.35 |
| 尖下巴 / `chinTaper` | `chinTaper` | 尖窄 → 圆宽 | +0.25 → −0.25 |
| 下颌角 / `jawAngle` | `jawSlim` | 宽 → 收 | −0.45 → +0.45 |
| V 脸 / `vFace` | `faceVShape` | 中性 → 下脸收窄 | 0 → +0.50 |
| 面部流畅 / `contourSmooth` | `faceContourSmooth` | 中性 → 源边缘修整 | 0 → +0.25 |
| 发际线 / `hairline` | `hairlineHeight` | 上移 → 下移 | −0.25 → +0.25 |

双向控件中性为 `0.5`，V 脸与面部流畅为 `0`。宿主接线：

独立宿主的「下颌线」不再与「下颌角」共用 `jawSlim`。它直接映射新增
`jawlineShadow`：0…100 对应 0…0.25，左端原状、右端增强下颌下方阴影。
该字段不属于上述十项几何 enum；不修改采样坐标、不计几何预算，旧 `jawSlim`
与旧 JSON 缺 key 的默认零语义保留。源几何、皮肤佐证、已有明暗界限和保护
共同准入，证据不足原像素保持；与其它几何组合时只拒绝阴影，保留其它原行为。
实际效果和保护资格由现行脸型计划分别记录，不按有字段或有变化宣布美图等价。


六项新增 signed 字段保留 Codable key、零默认值与 cap。直接 `chinLength` 正值

## 八项连续场

脸宽、小脸、太阳穴、颧骨、下巴长短、尖下巴、下颌角与 V 脸共用
`BeautyContinuousFaceMap`。实测下轮廓、有效眼部和已注册外唇共同准入；粗代理
旧正向路线保持兼容，新增负向缺少已注册外唇时退出。

双眼建立像素局部坐标。Hermite轮廓的最近投影定义位移，源固定C1衰减形成连续窄带；小脸采用下脸解析inverse。太阳穴上方支撑属于二维轮廓延伸，不代表实测发际线。完整眼、外唇、观察鼻和眉的包围域及collars固定；存在但无效的鼻/眉支撑退出。上侧attachment保守几何reserve保护头部连接材料，不等于耳或头发分割。目标域外复制源字节；采样完整texel footprints也须避开保护域。alpha不修改，跨不同alpha的插值退出。

脸宽、太阳穴、颧骨在完整观察鼻眉支撑和不透明源像素可用时，额外要求源材料归属。皮肤须连接到独立源种子；未知材料、五官、头发/背景核心及几何attachment固定，完整source采样足迹也不能搬运它们。材料判断和距离场使用着色前的同相位sRGB源像素，采样及最终恢复使用当前阶段像素。已有但损坏或错位的源证明拒绝，不能回退到着色后重新分类。

该路线允许三字段及固定坐标的颜色操作；与其他几何、磨皮或锐化组合时退出。缺少完整观察支撑的兼容路线、其余连续字段及未测输入不获得该材料保护资格。保守拒绝或内部皮肤纹理变化不能替代轮廓方向、幅度和外观验收。

每轴129个基础节点再加入特征保护边缘，过近节点合并以避免病态cell。当前与同符号cap形态共同限制梯度Frobenius范数≤.45、位移≤轮廓像素宽的6%；除保留解析inverse的小脸外，单字段通过局部梯度投影避免一处collar削弱整条下颌，最终共同bound仍保留。姿态进一步减弱。核和cap形态不随档位移动；生成源控制已覆盖四分档，实际照片的非均匀幅度资格见下节。陈旧、无效或不足支撑退出，
已注册新路线不恢复旧点拉伸。映射不可编码，诊断只暴露尺寸和节点数。

CPU 与 Metal-selected 静图在已有 legacy/dense 采样之后、整体平移之前共享此
CPU-owned 采样，对应八项旧点不再执行。其他 dense 字段仍用原 map。两阶段
分别有界，不声称全部效果组合只有一次采样或共享单一 6% 总位移界。无新
shader、模型或 GPU API；像素缓冲路线不接入这一静图效果。

## 源轮廓修整

存在观察轮廓时，流畅由源像素修整阶段拥有；局部拒绝也不恢复 coarse/dense
代理点。旧宽域与亚像素采样都以原轮廓固定内20%/外6%的局部带，搜索到的色边
不扩大编辑域，完整水平采样足迹和alpha须先通过源资格。

宽域修整先建立固定cap场及零边界，逐cell四角检查Frobenius范数≤.45，合格后
按档位缩放；原`.05`数值现在用于cap残差准入，部分档位不再硬切残差。
亚像素注册保留原唯一强边≤1.5像素、fractional fallback≤.5像素的范围，逐行
限制横向位移导数≤.45并保留行内相位比例。这使水平inverse保持单调，不给该
注册分支声明完整二维Frobenius界。S8的规范化源曲线与原保护门保留。几何域
资格和注册校准仍不能替代发丝、耳部等完整材料保护与参考幅度验收。

## 验证与剩余边界

测试使用生成源固定标记，断言反向/四档单调、眼嘴/外围/alpha 精确保护、平滑
下巴不新增波纹、neutral/无脸/无效退出、重复性及公共 CPU/实际 Metal 一致性。
宽高、非零 extent、sRGB、旋转/镜像输出元数据和 typed failure/recovery 另有公共
断言。合成 dense carrier 不等于本次执行了 iOS/MediaPipe 推理。
