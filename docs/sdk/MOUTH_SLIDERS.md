## 宿主滑杆契约

`BeautyMouthSlider` 是参数值映射，不持有界面或编辑状态。八项几何控件使用
`0...1` 的滑杆位置，中性为 `0.5`；白牙中性为 `0`。`applying(position:to:)`
先归一化参数快照，再修改对应字段；`position(in:)` 为选择工具、撤销和恢复提供
反算。有限越界位置截断，非有限位置回到中性。端点覆盖既有安全 cap，控件之间
不复用参数。白牙算法不属于这次几何改动。

| 控件 / enum case | 参数字段 | 滑杆左 → 右 | 参数端点 |
| --- | --- | --- | --- |
| 大小 / `size` | `mouthSize` | 大 → 小 | +0.35 → −0.35 |
| 宽度 / `width` | `mouthWidth` | 窄 → 宽 | −0.35 → +0.35 |
| 上下 / `verticalPosition` | `mouthYPosition` | 下 → 上 | +0.25 → −0.25 |
| 倾斜 / `tilt` | `mouthTilt` | 逆时针 → 顺时针 | −0.25 → +0.25 |
| 左右 / `horizontalPosition` | `mouthXPosition` | 左 → 右 | −0.25 → +0.25 |
| M 唇 / `mShape` | `lipPeakDefinition` | 唇峰趋平 → 唇峰增强 | −0.25 → +0.25 |
| 丰唇 / `fullness` | `lipPlump` | 薄 → 厚 | −0.25 → +0.25 |
| 微笑 / `smile` | `smile` | 嘴角下弯 → 上扬 | −0.50 → +0.50 |
| 白牙 / `teethWhitening` | `teethWhitening` | 中性 → 增强 | 0 → +1 |

直接参数的 `mouthSize` 正值继续表示变大，`mouthYPosition` 正值继续表示下移；
helper 只反转这两个字段的滑杆方向。位置与旋转方向以方向归一后的图像为准，
其原点在左上、Y 轴向下。宿主的预览镜像应遵循既有元数据契约，不额外修改字段
符号。

```swift
parameters = BeautyMouthSlider.fullness.applying(
    position: sliderPosition, to: parameters
)
let restoredPosition = BeautyMouthSlider.fullness.position(in: parameters)
```

`smile`、`lipPeakDefinition`、`lipPlump` 新增负半区，三者归一化范围改为
`-1...1`，既有 Codable key、零默认值和正向 cap 保留。其他五个几何字段原本
已为 signed。组合强度按绝对值计入预算，负方向不会免于安全衰减；后端输入验证
与单字段封顶使用同一 signed 契约。

## 实测嘴部连续场

静图中，有真实外唇观测或 dense 支撑时由 `BeautyContinuousMouthMap` 拥有嘴部
八字段，不再叠加旧离散点拉伸。真实外唇、有效眼部与鼻部支撑以及 fresh 状态
共同准入；显式观测无效时退出，不借用粗代理继续形变。无实测外唇的既有粗代理
路线保留正向兼容，新三字段负向使用该路线已有位移的反向。

连续场以两侧嘴角建立像素坐标，按像素计算旋转，避免非方形图像把倾斜变成拉伸。
大小同时缩放宽高；宽度只改变横向尺度；上下、左右移动整嘴；倾斜在嘴部核心
使用刚性旋转。微笑以双侧对称的连续弯曲移动嘴角，正端向外展开并抬升，负端
向内收并下降；横纵分量使用同一嘴角权重，中央唇缝保持稳定。
左右移动直接沿方向归一图像的 X 轴，场的 Y 分量精确为零；嘴部局部坐标仍用于
尺度、上下与旋转。X 以固定局部保护域、图像坐标鼻眼保护域及外围的距离限定
位移，在两侧源嘴角原有非零双线性系数支撑的完整扫掠轨迹上准入共同幅度。解析
距离场的固定径向上下 profile 与内侧 terminal 连接保留共同材料平台、零域和
原梯度/位移界，不扩大刚性支撑或改用额外宽度补偿。每个滑杆半区的准入固定，
请求按强度连续缩放，姿态系数只计一次。材料嘴角保持等量移动；整个嘴唇的
可见纹理仍须单独复核，不能据此宣称精确刚性平移。径向上包络 profile 的一阶
连续结论只适用于其 terminal 连接处；实际图像场的其他距离和 min/max 分支
仍可能不光滑，不声明全局 C1。

M 唇与丰唇还要求真实内唇。M 唇正值增强两侧峰相对中央的高度差，负值使源唇峰
向较平缓的轮廓收敛，不把平唇强行变成倒置 M。丰唇改变外缘到内唇之间的厚度，
避免把张嘴或牙齿缩放当成唇厚变化。两项局部形变固定内口腔包围带、在嘴角前
衰减；缺失或无效内唇只关闭这两项，其余六项可继续使用有效外唇。X 的口腔内容
随整嘴移动；口腔零变化断言用于局部 M/丰唇，不作为 X 的保护要求。
正向丰唇的深度延伸覆盖安全衰减后的外唇边界，再饱和并向外围皮肤衰减。负向
收薄按距固定口腔、嘴角、鼻眼及既有外围的距离生成连续收缩场；源唇厚限制幅度，
但不把观测外缘当作实际可见唇色边界的终点。保护距离已进入场本身，避免重复
衰减压低收薄幅度。仅负向收薄细化两倍横纵网格，并以共边 scalar minorant 投影
固定端点，减少双线性插值在单元交界处额外占用梯度预算。滑杆半区强度 r 使用
连续单调的 r / (1 + 0.45 × (1 − r)) 响应，再计姿态一次；该校准保留中性和端点，
由实际可见厚度的四档响应验收，不把内部系数线性当成像素响应线性。最终仍检查
实际离散场的原梯度/位移界，不以连续公式的理论界替代。

M 唇幅度仍按可用厚度与源轮廓限制；负端在组织内部更早
完成同一趋平位移，使内于观测边界的可见唇缘也能响应。深度过渡按源定义端点
固定，不靠放大趋平目标制造倒 M。正端按源上唇可用组织量，将薄组织的外部
保护过渡从嘴宽的 25% 平滑缩短至 20%，保留相同峰值目标和精确保护域；
组织充足的源图保持原有正端结果。这个门控不随滑杆强度变化。

鼻眼保护域和场的外边界固定；过渡带连续衰减。源 alpha 原样保留，跨不同 alpha
的插值退出。当前场与同符号 cap 场共同限定梯度范数不超过 `0.45`，最大位移
不超过嘴宽的 `20%` 与脸部像素短边的 `6%` 中较小者；dense 姿态系数可以继续
减弱。单项限制沿同一滑杆半区保持固定，避免随强度增加而突然回退。左右、M 唇
与丰唇先分别准入，再对实际叠加场检查同一上限；组合预算保留姿态衰减一次。
解析 X 与其他嘴场叠加时使用实际子采样器的三角界，不套用仅对双线性单元成立的
梯度公式。
这避免这三项之间的另一项滑杆刚离开中性点，就用其整个端点预算改变已有编辑；
不将本轮修复扩称为全部八项任意组合的连续性保证。fresh dense 路线
保留嘴字段各自的 cap，以嘴场组合位移/梯度界限准入；非 dense 路线仍使用共享
绝对值组合预算。这些数值不承诺可见端点一定达到固定幅度。

CPU 与 Metal-selected 静图在共享几何阶段执行同一 CPU-owned 连续嘴部采样，
然后继续既有连续脸型/眼部场和整体平移；颜色阶段保留各后端原有顺序。没有新增
shader、GPU API、模型或权重。
静图连续嘴部场不形成实时视频、像素缓冲或端到端 GPU 性能承诺。
