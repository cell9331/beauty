# Retained source probes and causal investigations

The current implementation tests a blurred luminance residual against a fitted
plane, then applies bounded RGB corrections within a per-eye feather. That is
an **image-space proxy**, not a measurement of eyelid fat, tissue depth, or
volume. In the current frozen investigations, four natural-style generated
positives did not safely admit both eyes. One source with more visible fullness
had a *lower* residual score than its prior version. A controlled positive did
admit and pass numeric target/protection checks, but original-size review found
closed rings around both upper lids. Therefore neither a lower source threshold
nor a larger correction gain has evidence for a visual-quality claim.
In a separate, temporary package-only diagnostic on the existing generated
bulge fixture, eliminating all positive RGB corrections removed 123 brightened
proposal pixels but the visible dark ring persisted. Existing focused numeric
tests passed for that candidate; its visual result failed, so the change and
temporary test were removed. This does not isolate the ring's complete cause.

Before changing production behavior, freeze a qualified positive/negative
source pair, the eye and protected regions, neutral and typed-failure checks,
and an original-detail no-ring/no-worsening review. A candidate must preserve
both the intended directional change and the existing fail-closed behavior.
The owner's provisional callable API remains valid under its stated limits.

### Root-cause separation and independent oracle (2026-10-01)

The owner identified the repeated failure as an effect-development bottleneck,
not a runtime hang. Three distinct problems must be resolved separately:

1. **Ambiguous inference:** blurred luminance minus a boundary plane measures
   an image signal. Shape, lighting, reflectance and makeup can change that
   signal independently of upper-lid fullness. The bas-relief result above
   establishes this ambiguity under its assumptions; it does not prove that
   prior-based portrait editing is impossible. Changing a threshold cannot
   supply missing semantic evidence.
2. **Local contrast reversal:** before this repair the editor uses
   `delta = -clamp(1.8 * strength * residual, -16, 16)`, followed by Q16
   feathering. For an ideal smooth positive residual `r` and weight one,
   full-strength output relative to the reference is
   `r - min(1.8*r, 16)`. A shoulder with `0 < r < 16` becomes negative while
   a bright center with `r > 16` stays positive. This is a mechanism for a
   dark ring around a retained bright center. Soft `tanh` clipping retains
   the slope greater than one near zero, and suppressing brightening does
   not affect these positive-residual shoulders. Box averaging also spreads
   a dome into adjacent pixels, so merely capping the gain at one is not a
   sufficient no-halo proof.
3. **A self-scoring objective:** the previous half-strength test demands a
   smaller score from the same production relief analyzer used for admission.
   It has no lower bound penalizing overshoot. The ring counterexample's
   numeric assertions pass while its original-size output visibly fails.
   More tests of that same proxy cannot establish the intended appearance.

Artifact repair does not need to wait for a naturally styled matched pair
to pass the existing admission proxy. The deterministic dome/flat pair is
already an eligible input for this known artifact. Freeze its source-defined
regions, independent source-minus-flat direction and no-undershoot bounds,
radial shape checks, a nonzero improvement floor, negative identity and
existing protection/metadata assertions before evaluating a candidate.
Keep original-detail review. A safe candidate must also preserve the existing
texture and per-eye failure tests; a no-op cannot count as a repair.

Semantic discrimination and appearance qualification remain separate work.
Freeze labels independently of the production admission score, retain
rejected and false-positive sources, and vary lighting independently of the
intended lid shape. A better tonal operator alone does not prove fullness
recognition. Generated source pairs with unrelated changes outside the lids
cannot isolate shape from lighting. Neither the current no-model route nor
an edge-aware filtering paper provides an automatic generality guarantee.

The selected no-model repair retains that admission analyzer but uses a
complete 3×3 source tent neighborhood for the edit's shape guide. The larger
box's support-truncated averaging was unsuitable for guiding narrow peaks
near the support edge. A marker constrained by source headroom, the 16-level
cap and the final feather is reconstructed upward under this guide, then
scaled and quantized once. This uses the grayscale reconstruction concept
described by [Vincent (1993)](https://telin.ugent.be/~sanja/StudentProj/Literature/vincent-93.pdf);
the paper motivates the operator, while the SDK's independent output checks
establish the bounded result. It does not supply eyelid semantics.

Five source configurations and four strengths pass independent matched-flat
no-undershoot/no-bright-halo bounds, radial shape, meaningful central reduction,
protection and monotonic strength. Original-detail review of the preserved
384×384 reproducer at all four strengths no longer shows the prior closed
dark ring. The old integration source was an x-only bright ridge continuing
through the entire frame: it is now retained as an exact-output regression
at its original integration strength, while the integration positive has an
explicit two-dimensional source peak. The positive still must change final
composed pixels. These are generated-image tonal results, not tissue-volume
measurement or general portrait semantic qualification.

### Independent lighting follow-up (2026-10-01)

The source matrix now holds geometry and magnitude fixed while crossing three
base brightnesses and three affine-lighting settings. Together with the original
amplitude/geometry variants, 13 sources pass the same four-strength artifact
oracle; their matched flat and concave sources remain unchanged. Inputs are
checked for absent RGB clipping. This isolates finite lighting sensitivity
without claiming that base brightness spans skin chromaticities.

Replacing the remaining mixed-lighting production self-score with an identical-
shadow counterfactual exposes weak-strength loss: independent central removal
is `4.224%/9.729%` where the frozen minimum is `5%/10%`. The continuous field
was quantized down both before and after feathering. Choosing the nearest
actual Q16 correction fixes that bias only when constrained by both the full
source allowance and the full reconstructed correction. Candidates omitting
the latter cap fail three radial checks and are discarded. The fixed feasible
set makes requested strength a monotone nearest-value projection, preserves
the prior full-strength pixels, and keeps ties toward source. All four strengths
then pass the independent mixed-shadow bounds, and the negative remains exact.
The current implementation and validation details are in [DESIGN](../../DESIGN.md)
and [QUALITY_SCORE](../../QUALITY_SCORE.md). These earlier checks did not cover
live Vision or effect-specific orientation/mirror equivalence; the current
bounded-result section above records the later evidence and its limits.
