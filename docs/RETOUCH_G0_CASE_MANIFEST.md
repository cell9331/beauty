## 分组与状态

D 表示开发，H 表示留出，R 表示独立拒绝例。F-D01 与 F-H01 必须来自不同源家族，
不能通过改色、裁剪或镜像从同一肖像派生。EYE 和 SEG 可共用相同 F-D/F-H 家族，
但所有派生始终留在相同集合。拒绝例家族独立，支持注入只作已标明的故障控制。

所有正负例预定覆盖最长边 512/1024 两档和契约中的方向/镜像验证；这些变体
不增加逻辑案例数。R02 的极小主脸仍是在两档画布上的小主体，不是把输出尺寸
换成未定义的第三档。无脸和故障控制不要求具有正例 Vision 支持。

SEG 的 18 个独立源家族已核对权利、源与标记摘要、双尺寸输入和控制，
30 个逻辑案例通过 G0 后 frozen。正负例实际 Vision 与 public CPU 路径通过；
D01 补齐 G0 坐标控制。留出仅用于 G0 可测性检查，候选留出评估为零。
EYE 尚未准备。frozen 不是候选通过，也不替代 G2 的全案例方向/后端检查。

## 不计入这 60 个案例的检查

- 正确参考、no-op、全图调暗、全排除、几何/环纹/核心泄漏等验收器控制，
  从固定案例派生并另列结果，不增加独立样本数。
- 旧自然上睑与同色材质反例保留原身份、阈值和失败结果，不充作新留出样本。
- 原深肤色低对比唇源的自动修复回归单列，继续验证完整唇与对侧有效皮肤。
- 既有兼容、错误恢复、后端和完整 SDK gate 保留各自结果，不换算为效果成功率。
