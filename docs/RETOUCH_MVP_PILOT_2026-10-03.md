## 范围及证据边界

所有者在被明确告知实验可能失败后回答“允许”，授权小规模隔离验证。
协议见 [README](../scripts/experiments/retouch-mvp-pilot/README.md)，正式标准仍是
[R2 契约](RETOUCH_MVP_REQUIREMENTS.md)。本轮没有训练、模型下载、生产修改或默认展示恢复。

- EYE 使用一个既有授权生成肖像家族的受控光影正例，双眼分别评价；原始肖像
  和另一授权肖像作负例。独立参考为加入信号前的源图，不是算法输出或生产评分。
  1024 长边，不是新自然留出家族。
- SEG 是一个代码生成几何图家族：3 肤色 × 2 形状 × 2 尺度共 12 正例变体，
  另有 6 无贴片负例变体。不是 18 个独立家族。贴片有可见边界和细微表面纹理。
  r2 负例测量两侧脸颊，正例测量另一侧完整预定皮肤区。
- EYE 基线走 public CPU 路径，新候选使用 live Vision 眼支持。SEG 走固定脸框
  的内部 CPU 路径；它验证自动贴片候选的像素行为，不证明自然肖像脸检测、
  真实 Metal、方向/镜像或语义唇分割。
- 候选只收到源图及既有合法几何，不收到参考、真值区域、素材名或期待标签。
  纹理 observer 只注入临时副本，每次观测与无观测输出逐字节对照。

## 验收器结果与纠错

1. 最初沙箱尝试执行 0 测试，是构建环境失败；自动许可后的运行提供实际证据。
2. 首个 EYE 正确控制使用 25% 参考修饰，方向通过，但两眼高通变化
   12.60%/11.22% 超过 10%，因此停止在控制阶段，未运行候选。
3. 候选输出尚未产生时，将正确控制修饰量改为 12.5%；亮度误差降低
   12.68%/12.74%，高通变化 6.96%/6.57%，保护违例为零。没有修改验收阈值。
4. r1 控制 **2 tests / 0 failures / 0 skips**；SEG 包含 36 个正负/平滑/锐化比较。
   no-op、全排除、全局改色、物体核心泄漏、边缘超限和误排除均被相应判据拒绝。
5. r1 候选阶段，SEG 局部数值结果为 18/18；EYE 非正方形负例缩放后无法加载，
   执行未完成，整轮退出 2。这不是上睑算法失败，也不是联合通过。
6. r2 根据尺寸假设补充整数裁剪，并补强无贴片负例的双颊 ROI；旧源保留，
   不改写其失败含义。尺寸假设不充分，EYE 仍报 invalid_input，整轮仍退出 2。
   两份候选函数字节完全相同，只修输入/测量；r2 控制再次 **2/0/0**，36 个比较通过。
7. 只读 Core Image 预检确认根因是缩放边缘半透明：原图最小 alpha=1，缩放/
   裁剪后为 0.2763672，先延展边缘再缩放后为 1。r3 按此修复加载器，并在控制
   阶段实际加载第二负例。r1/r2 快照、执行不完整和算法摘要均保留。r3 控制
   实际 **2 tests / 0 failures / 0 skips**，全部输入可加载，36 个 SEG 比较通过。

有/无 observer 输出一致；neutral、无脸、全排除、错尺寸和后续请求恢复通过。
这是内部数组路径的支持计数验证，不替代完整 public typed-failure 或错误生命周期验收。
保护指标按逐像素检查，支持覆盖来自实际最终准入，未用变化像素数代替。

已查看原尺寸源图、独立参考、正确控制、错误暗槽控制及 SEG 源图。EYE 参考
可去掉作者加入的过亮信号，弱控制的可见区别很小；不能仅凭数字授予自然外观资格。
随后查看 EYE 半/全强度与基线、SEG 候选与基线的原尺寸实际输出。未看到可确认
的双眼共同改善；没有以“没看到明显大环纹”豁免另一眼零改善或数值细节超限。
SEG 在该几何图中保留了贴片纹理，基线会磨掉该纹理；这不是自然肖像视觉资格。
