## 实际机制与差距

S1 依赖低通梯度形成闭合边界，缩小后可能失去闭合；粗略脸框不能可靠约束所有
受保护区域。第二版减少了泄漏，但仍漏掉512尺度下的一例贴片，并改动部分五官
保护矩形或独立脸部包络之外的区域。

S2 改用局部 RGB 方差连通区域，并复用本次 Vision 已有的眼、外唇和脸轮廓。
第一版把正常平坦区域也当成整图退出理由；第二版限定其与可编辑脸颊域的交集，
恢复部分效果。仍存在定位包络不匹配、保守保护减少有效皮肤支持及误退出。
这是“自动定位足够准，同时保留足够有效处理”的联合缺口。四版失败不证明
所有无需训练的方法都无解，也不证明必须自行训练；它只否定本轮已运行方案。

每版输出逻辑及常数都在执行前登记：[S1-v1](../scripts/experiments/seg-development/S1-v1-registration.json)、
[S1-v2](../scripts/experiments/seg-development/S1-v2-PROTOCOL.md)、
[S2-v1](../scripts/experiments/seg-development/S2-v1-PROTOCOL.md)、
[S2-v2](../scripts/experiments/seg-development/S2-v2-PROTOCOL.md)。不再追加第五版。

## 验证与证据边界

- 基线测量及冻结开发控制实际执行14 tests / 0 failures / 0 skips；其中8个是
  G0控制，6个是自动测量。48项正确 host 控制通过，基线自动效果失败。
- 四个候选各执行6/0/0，分别收齐24输入摘要和48输出测量；运行器均因效果失败
  返回1。XCTest零失败只证明测量、输入和等价性检查完成，不代表算法通过。
- 实际 public CPU 请求不传 host 蒙版。候选不接收 ID、分组、标记或文件路径。
  A0/A1在冻结位置计数；有/无观察点、public 输出及重复输出逐字节一致，
  neutral、alpha、extent、sRGB 和输入 SHA 检查完成。S2复用已有观测，不新增检测。
- 接线前后两次基线153行逐项相同；S1-v1 导出修正前后72行相同。源树及冻结
  契约摘要校验通过，生产算法、既有测试、旧失败及 G0 冻结未修改。
- 视觉诊断查看了基线/S1 的 D01 整图、S1-v2 的 D02/D03 变化区、S2-v1 的 D06
  正例及 S2-v2 的 D02负例/D03正例，后两者按1024原始细节对照原图、平滑、锐化。
  因数值已拒绝，没有签发完整视觉资格，也未以局部肉眼检查覆盖像素失败。
- 未做本候选的拒绝集、旧完整低对比唇回归、Metal、完整方向/镜像、G2/G3或
  生产集成；这些是未验证项，不能借用 G0 控制或旧1076/0/0替代。

首次基线构建因适配文件缺少 BeautyDetection import 执行0测试，属基础设施失败；
补 import 后重跑，未改算法。另一次基线复核图被同名 host 控制图覆盖，数值
有效但原图不作视觉证据；加 automatic 前缀重跑后保持全部数值一致。原记录和
源码保存在 revisions/r1、r2、r3；S2所用接线源码在 revisions/r4。一次审批等待
超时未启动子进程，获准重试后执行；没有把它记为效果评估。

持久材料仅为代码、摘要、逻辑 ID、聚合数值；媒体、标记和原始日志不入库。
[结果索引](../scripts/experiments/seg-development/results/index.json)绑定所有回执及使用的源码快照。

收尾静态核对：2,111个既有保护文件哈希不变，生产/测试/归档目录无新增文件；
6份结果回执的288条自动输出测量、4份候选登记和源码快照绑定一致；17份当前
文档的186个本地链接可解析。SDK-only boundary与 `git diff --check` 通过。
60例状态仍为SEG 30 frozen、EYE 30 not_prepared，16项需求均未误勾完成。

## 当前处置和可继续工作

SEG用完原2方法×2版本预算，保持未完成且停止此轮研发，不接入生产、不消耗
候选留出资格、不通过降低阈值续试。再次研发须另立新假设和范围，不能用一般
“继续”隐式重置预算。已有 host 并集蒙版保持可用，不冒充自动识别成果。

EYE独立保留原预算（E1-v1已用1方法/1版本），需先完成自身 G0 的输入和独立
光影参考，不能直接恢复旧去脂。当前库存批量工具可独立推进，不依赖 SEG 成功。
整个里程碑仍0/16需求完成，后续入口为[现行计划](../plans/active/A-2026-10-03-v1-25-retouch-repair.md)。
