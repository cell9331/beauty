## 重要说明

1. 文中的数值（限幅、半径、强度、阈值、耗时预算）均为**起始参考值**，必须在你的关键点模型、相机、目标机型上实测调参。
2. code/ 下的代码是**设计骨架**，用于说明数据流和关键算法，未在真机上完整编译、联调，不能直接当成品使用。
3. 数据集与预训练模型的商用授权（dlib 68 点模型、300-W、CelebAMask-HQ、部分 InsightFace 模型等）请上线前逐项核实，文中只做风险提示。
4. docs/01 中的编号是 dlib/iBUG 68 点；478 点编号见 docs/12。
5. `code/gen_topology_478.py` 只在合成数据上验证过流程，请用真实的规范人脸 obj 生成并检查预览图。
