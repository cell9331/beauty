# 05 功能：眼睛 / 眉毛

通用：眼睛是最敏感的区域，**任何变形都要保持眼型比例**；点位少时形变会出棱角，必须加密（眼睑样条）。
可行性标记同 docs/04。

## 眼睛通用规则

- 以**眼中心**为锚（保持不动或轻微位移）。
- 内眼角、外眼角、上睑、下睑**成组联动**，不要单点拖拽。
- 单眼独立计算（左右眼点位、姿态权重分别处理）。
- **眨眼衰减**：EAR 低于阈值时强度平滑降到 0。
- **侧脸衰减**：远侧眼强度按姿态降低，近大远小的透视会被放大。
- 眼周区域需要**更密网格**，眼睑线加密 3–4 倍。
- 位移作用后检查**眼睑线是否交叉**（上睑低于下睑）。

## A. 眼睛

| 功能 | 做法 | 限幅/注意 | 68点 |
|---|---|---|---|
| **大小** | 以眼中心径向放大（见 docs/02 第 7 节），眼周点同步 | a ≤ 0.5；R≈眼宽 1.5–2 倍；闭眼降强度 | ✅ |
| **眼距** | 两眼整体沿水平轴向外/内平移，刚体 + 外缘衰减 | ≤ 瞳距 5%；别压到鼻梁 | ✅ |
| **上下**（眼位） | 整个眼睛沿竖直轴平移 | ≤ 眼高的 30%；眉-眼距要联动 | ✅ |
| **眼尾上扬** | 外眼角上移，内眼角不动，上下睑按到外眼角的距离线性加权 | 幅度小；闭眼需衰减 | ✅ |
| **眼高** | 上下睑远离/靠近，眼宽不变 | 上睑上移受眉毛距离限制 | ✅ |
| **长度** | 内外眼角水平方向拉长/缩短，上下睑随之 | 避免拉到鼻梁、太阳穴 | ✅ |
| **提肌**（上睑提升/睁眼幅度） | 上睑中部上提，形成更"开"的眼型 | 太大像瞪眼；闭眼衰减 | ⚠️（需上睑加密点） |
| **眼瞳大小** | 虹膜/瞳孔局部放大，用虹膜 mask（478 点含虹膜）限定范围 | 不能超出眼睑；需要保持眼白可见 | ❌（68 点无虹膜） |
| **眼神矫正** | 3D 眼球重定向 / gaze redirection 模型 | 需训练模型，难度高，延迟大 | ❌ |
| **眼睑下至**（卧蚕、下眼睑） | 下睑中部轻微下压/外凸，配合轻微提亮卧蚕 | 与眼袋/泪沟的位置容易混淆 | ⚠️ |
| **倾斜** | 整个眼睛绕眼中心旋转 | ≤ 5°；左右眼方向对称 | ✅ |
| **内眼角** | 内眼角点内/外移（开内眼角） | 幅度小，易出现眼头"撕裂感" | ⚠️ |
| **外眼角** | 外眼角点外/下移（开眼角） | 与眼尾上扬冲突要联合预算 | ✅ |
| **对称** | 左右眼大小、位置、倾斜向平均值靠拢，强度可调 | 完全对称会假，强度上限 50% | ✅ |
| **祛红血丝** | 巩膜 mask 内降低红色饱和度、轻微提亮 | 必须排除虹膜/瞳孔/睫毛；mask 精度要求高 | ⚠️（需眼白 mask） |
| **去脂（眼袋/眼部脂肪）** | 下眼睑下方皮肤用低频取样提亮/平滑；轻微位移上提 | 与黑眼圈、泪沟区分；过度导致"假面感" | ⚠️ |

### 眼睛专项坑
1. **只拖外眼角**：眼型扭曲。必须内/外眼角、上下睑联动。
2. **眨眼时变形**：大眼在闭眼瞬间拉扯眼睑。用 EAR 衰减。
3. **睫毛、眼线**：形变时睫毛被拉长，看起来像"毛刺"。放大系数限制，并在眼周加密网格。
4. **眼镜**：镜片折射使眼睛位置与镜框不一致，眼镜框被一起扭曲。检测到眼镜时降强度，或用眼镜分割做保护。
5. **高光（反光点）位置**：大眼后高光位置也被放大，会显得瞳孔放大不自然。可单独保持高光。
6. **美瞳/瞳孔变色类功能**：需要虹膜 mask，不要用颜色阈值。
7. **眼神矫正**：如果不能训练模型，建议放弃，不要用 2D 简单位移冒充。

## B. 眉毛

> 眉毛的难点不是形变本身，而是**移动后原位置要被擦除、新位置要被画出**。

通用做法：
1. 眉毛 mask（分割或 17–26 点多边形外扩）。
2. 在源空间用**周边皮肤低频取样**填补原眉毛区域（眉毛移走后留下的"皮肤"）。
3. 位移眉毛区域（局部 warp）。
4. 粗细/浓度的调整用 mask 内的亮度/不透明度混合。

| 功能 | 做法 | 注意 | 68点 |
|---|---|---|---|
| **上下** | 整个眉毛沿竖直轴平移 | 限制不侵入眼睛；必须做原位置填补 | ✅ |
| **粗细** | 眉毛上下缘沿法线外扩/内收 | 内收过多时眉毛变线，外扩要补眉毛纹理 | ✅ |
| **长短** | 眉头/眉尾点沿眉毛走向伸缩 | 延长部分需要"画眉"（取眉毛颜色延伸）；缩短部分要填补皮肤 | ⚠️ |
| **间距** | 两眉整体水平靠近/远离 | 与眉头间距、眼距联动 | ✅ |
| **眉头间距** | 仅眉头点水平移动，眉形相应平滑 | 眉头位于眉心，易与鼻梁高光混淆 | ✅ |
| **倾斜** | 眉毛绕中点旋转 | ≤ 8°；左右眉方向对称 | ✅ |
| **眉峰** | 眉峰点上移/外移，形成挑眉形状 | 过度像"生气脸"；与倾斜联合预算 | ⚠️（需眉毛加密点） |

### 眉毛专项坑
1. **原位置残留**：眉毛移走后留下"鬼影"。必须先用周边皮肤填补，再 warp。
2. **眉毛稀疏/淡眉**：分割和 mask 不稳定；要用关键点多边形兜底。
3. **刘海遮挡眉毛**：关键点被刘海干扰；降强度或关闭。
4. **眉毛与眼睛联动**：眉毛下移到眼睛，需要碰撞保护（最小间距）。
5. **颜色**：加粗/延长时的新增眉毛需要匹配原色；用 mask 内眉毛平均色。
6. **纹理**：延长时眉毛发丝纹理不连续；可沿眉毛方向拉伸取样。
