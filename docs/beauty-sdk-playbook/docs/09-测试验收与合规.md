# 09 测试验收与合规

## 1. 测试数据集（自建，覆盖面决定上线质量）

| 维度 | 覆盖 |
|---|---|
| 肤色 | Fitzpatrick I–VI 全覆盖 |
| 年龄/性别 | 儿童（若产品涉及需额外合规）、青年、中老年；男/女 |
| 姿态 | 正脸、侧脸 ±30°/45°/60°、仰头、低头、歪头 |
| 表情 | 微笑、大笑、张嘴说话、眨眼、闭眼、皱眉、鬼脸 |
| 遮挡 | 眼镜（含反光）、墨镜、口罩、刘海、帽子、胡须、手遮脸、麦克风 |
| 光照 | 逆光、强光、暗光、混合光源、彩色灯光 |

每个维度保存**固定序列视频**，用于回归对比。

## 2. 量化指标

| 指标 | 说明 | 参考目标（需自行标定） |
|---|---|---|
| 静止抖动 | 静止时渲染后五官特征点的 RMS 位移 | < 约 0.3px（1080p） |
| 运动延迟 | 关键点相对真实脸的滞后帧数 | ≤ 1 帧 |
| 帧耗时 P95 | 单帧总耗时 | 低于帧预算 |
| 掉帧率 | 低于目标 fps 的帧占比 | < 1% |
| 三角翻转率 | 翻转三角数 / 总帧数 | **= 0** |
| 热状态 | 10–30 分钟持续运行 | 无 serious 以上 |
| 内存峰值 | | 稳定无增长（泄漏） |
| 形变回归 | 固定输入下输出 SSIM/PSNR 与金图对比 | 超阈值需人工确认 |
| 闪烁度 | 相邻帧输出差分在静止场景的幅度 | 低于阈值 |

## 3. 人工评审

- **参数极值矩阵**：每个参数 0/50/100，以及若干组叠加的极值截图。
- **自然度打分**：外部评审员（含目标用户群）盲评，对比原图/竞品。
- **A/B 对比**：新旧版本并排视频。
- **专项**：眼睛、嘴、轮廓三处放大 1:1 看细节。

## 5. 授权与合规

### 5.1 数据集与模型授权（上线前逐项核实）
- **dlib 68 点预训练模型**：训练数据 iBUG 300-W 存在使用限制，商用有风险。
- **300-W、CelebAMask-HQ、FFHQ、WFLW** 等数据集：许可条款各不相同，不少限制非商用，需逐一阅读。
- **预训练模型**（InsightFace 等）：部分仅限研究；MediaPipe 模型一般为 Apache-2.0，但仍应以实际发布版本的许可为准。
- 自训模型：自有数据采集需**知情同意**与合法来源，标注外包需保密与合规条款。

### 5.2 隐私与法规
- 人脸属**生物识别/敏感个人信息**：
  - 尽可能**本地处理**，不上传原始人脸图像与关键点。
  - 若上传（如云端渲染、埋点），需明确告知、取得同意，最小化收集，脱敏。
- 按所在地区法规处理：个人信息保护法（中国）、GDPR（欧盟）、部分美国州生物识别法（如 BIPA）等。具体适用请咨询法务。
- 苹果 App Store 隐私标签与审核要求：如实声明人脸/相机数据用途。
- 未成年人：若面向未成年人，需额外合规（家长同意、限制强度、不提供过度修饰）。

### 5.3 产品伦理
- 默认"自然"档，不默认高强度。
- 提供"一键关闭""原图对比"。
- 避免对特定人群（肤色、种族、年龄）有系统性偏见的调色或形变。
- 直播/社交场景：部分平台要求标注"已使用美颜/滤镜"，按平台规则处理。

## 6. 发版门禁

发版前必须通过：
1. docs/07 自查清单全部勾选。
2. 固定视频序列回归无新增翻转、抖动在阈值内。
3. 最低端机型 P95 帧耗时达标、30 分钟热状态无 serious。
4. 授权与隐私清单已由负责人签字确认。
