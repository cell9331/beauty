# 07 坑点总表与自查清单

按类别汇总。开发和评审时逐项对照。每条格式：**现象 → 原因 → 对策**。

---

## A. 坐标系 / 平台

| # | 现象 → 原因 | 对策 |
|---|---|---|
| A1 | 点画在错误位置、五官镜像 → Vision 左下原点 / Metal 左上 / NDC y 向上 / 前置镜像 / 设备方向混用 | 内部统一"像素、左上、未镜像"；输入输出各转换一次；写画点测试 |
| A2 | 大眼变椭圆 → 在归一化坐标算圆形距离，忽略宽高比 | 距离在像素空间或宽高比校正空间计算 |
| A3 | 边缘出现半像素偏移/发虚 → 像素中心 0.5 约定混用 | 全局约定采样坐标；单元测试 |
| A4 | 图像边缘拉出黑边/拖尾 → 采样越界 | `clamp_to_edge`；边界点位移=0 |
| A5 | 颜色偏灰/偏色 → 视频范围/全范围、P3 与 sRGB、gamma/线性混用 | 明确色彩管线；调色在线性或 Lab 空间；输出匹配预览色彩空间 |
| A6 | 8bit 带状/色阶 → 多 Pass 反复量化 | 中间纹理 RGBA16F，或合并 Pass |
| A7 | 竖屏/横屏/拍照方向错 → 方向与 EXIF 未处理 | 输入端归一化方向；照片读 EXIF |

## B. 关键点 / 稳定性

| # | 现象 → 原因 | 对策 |
|---|---|---|
| B1 | 静图正常、视频抖 → 每帧点位有噪声 | One Euro + 局部坐标系 + 位移二次平滑 |
| B2 | 转头拖影、五官粘旧位置 → 固定 alpha 滤波；推理延迟 | beta 自适应；同步推理或外推；时间戳对齐 |
| B3 | 帧间闪烁 → 每帧重新 Delaunay，拓扑变化 | 离线预生成索引，运行时固定 |
| B4 | 整张图崩 → NaN/越界点未校验 | 校验+修复；低置信度渐隐关闭 |
| B5 | 丢脸/找回时跳变 → 强度硬切 | 200–300ms 渐隐渐入 |
| B6 | 多人脸互相干扰 → 滤波状态串脸 | 稳定 ID 跟踪、独立状态 |
| B7 | 眨眼时眼睑被拉扯 → 未做 EAR 衰减 | 眼闭合时形变强度降到 0 |
| B8 | 张嘴大笑嘴型崩 → 内唇点抖动、强度未衰减 | 内唇强滤波；张嘴度调制 |
| B9 | 戴眼镜、口罩、刘海、手遮挡时崩 → 点位不可靠 | 检测遮挡并降强度；手遮挡用分割取消位移；口罩关闭嘴/鼻功能 |
| B10 | 大侧脸形变失真 → 远侧点同权重 | 姿态衰减；>60° 关闭几何形变 |

## C. 形变几何

| # | 现象 → 原因 | 对策 |
|---|---|---|
| C1 | 参数拉满畸形 → 无限幅 | 单点限幅 + 多参数联合限幅 |
| C2 | 画面撕裂/折叠 → 三角翻转 | FoldoverGuard，二分降强度 |
| C3 | 远处也被带动 → 无距离衰减 | smoothstep 衰减，ROI 限制 |
| C4 | 眼型扭曲 → 只拖外眼角 | 内外眼角、上下睑联动 |
| C5 | 背景直线弯曲 → 外环太近/位移外溢 | 外环 0.2–0.3 脸宽；人像分割压低边界位移 |
| C6 | 轮廓外出现鬼影/断层 → mask 硬切，或把"背景不动"理解为 mask 外位移为 0 | 位移场延伸到轮廓外并平滑衰减；不用硬 mask 裁剪位移 |
| C7 | 图像模糊、锯齿 → 多次重采样、最近邻 | 全流程一次重采样；双线性 |
| C8 | 出现黑洞/孔隙 → 正向映射 | 网格光栅化（inverse）或逐像素反向查询 |
| C9 | 棱角感 → 顶点太稀疏，曲线被折线逼近 | 加密顶点（样条插值） |
| C10 | 效果很假 → 参数×固定偏移，线性 | 空间权重+非线性映射+联合预算；"自然档"默认 |
| C11 | 发丝、耳朵、眼镜被拉扯 → 轮廓邻近物体被一起 warp | 头发/眼镜分割做权重衰减 |
| C12 | TPS 震荡/波浪 → 无正则、控制点少 | 加 λ；限制半径 |

## D. 皮肤与颜色

| # | 现象 → 原因 | 对策 |
|---|---|---|
| D1 | 塑料脸、蜡像脸 → 高频全丢 | 高低频分离，保留部分高频，微弱 grain |
| D2 | 眉毛/睫毛/发丝糊 → mask 未排除 | 皮肤 mask 排除五官、头发；羽化 |
| D3 | 过曝死白 → 整体 gain | 曲线+高光压缩；Lab/线性空间 |
| D4 | 肤色偏灰偏黄 → 只调亮度 | 同步控制 a/b；多肤色测试 |
| D5 | 暗光噪点放大 → 噪点被当纹理 | 噪声估计；去噪或提高低频比重 |
| D6 | 唇色盖掉唇纹 → 直接叠色 | Lab 保留 L，混合 a/b |
| D7 | 白牙像烤瓷 → 过度提亮 | 降 b*，L 微升，限幅，保留阴影 |
| D8 | 红润变醉酒 → 全脸加红 | 局部权重、联动预算 |
| D9 | 锐化放大噪点/光晕 → 无门限、半径大 | 门限；亮度通道；强度联动磨皮 |
| D10 | 眉毛移走后留鬼影 → 未填补原位置 | 先做皮肤填补再 warp |

## E. 性能 / 功耗

| # | 现象 → 原因 | 对策 |
|---|---|---|
| E1 | 掉帧 → 单帧超预算 | 磨皮降采样；合并 Pass；half；模型量化；隔帧检测 |
| E2 | CPU 占用高 → 像素回读/CPU warp | 全程 GPU，不回读 |
| E3 | 首帧卡顿 → 懒创建 pipeline | 初始化预创建 pipeline state |
| E4 | 内存涨、卡顿 → 纹理频繁创建 | 纹理池、`MTLHeap` |
| E5 | 画面撕裂/闪 → CPU/GPU 争用 | 3 帧 in-flight + semaphore |
| E6 | 崩溃/花屏 → `CVMetalTextureCache` 生命周期 | 命令缓冲完成前持有 CVBuffer |
| E7 | 发烫降频 → 持续满负荷 | 监听 `thermalState` 动态降级，带迟滞 |
| E8 | 延迟累积 → 推理队列堆积 | 只保留最新帧，丢旧帧 |

## F. SDK 工程

| # | 现象 → 原因 | 对策 |
|---|---|---|
| F1 | 运行时找不到 metallib → 资源 bundle 路径 | `makeDefaultLibrary(bundle:)`；SPM/CocoaPods 资源配置 |
| F2 | 符号冲突 → 带入 OpenCV/protobuf 等 | 静态链接+隐藏符号+前缀，或不用 |
| F3 | 缺模拟器 slice → XCFramework 未包含 | 打 device + simulator slice；以真机为准 |
| F4 | 线程竞态 → API 线程模型不明 | 明确队列与线程安全；文档化 |
| F5 | 接口难演进 → 暴露内部类型 | 对外 ObjC/C 稳定接口；结构体+版本号 |
| F6 | 包体过大 → 模型、资源 | 量化、压缩、按需下载、加密 |
| F7 | 照片与视频效果不一致 → 两套模式未区分 | 拍照走高分辨率路径，参数/降级策略独立 |

## 评审自查清单（每次发版前）

- [ ] 画点模式在前/后置、四个方向、镜像下正确
- [ ] 静止 10 秒五官无可见抖动
- [ ] 快速转头无明显拖影、无五官飞出
- [ ] 所有参数拉满 + 叠加拉满，不崩、无翻转
- [ ] 眨眼 / 张嘴 / 大笑 / 皱眉不崩
- [ ] 侧脸 ±45°、±60° 表现符合预期
- [ ] 眼镜、口罩、刘海、手遮挡有降级
- [ ] 背景直线（门框）弯曲在可接受范围
- [ ] 多人脸互不干扰
- [ ] 丢脸、找回无跳变
- [ ] 最低目标机型 P95 帧耗时达标，10 分钟无明显降频
- [ ] 肤色 I–VI 的样本调色都自然
- [ ] 首帧无卡顿，内存稳定
- [ ] 三角翻转率 = 0
