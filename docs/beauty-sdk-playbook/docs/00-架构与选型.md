# 00 架构与选型

## 1. 三件事撑起 80% 功能

1. **人脸关键点 / 分割**：回答"脸和各部位在哪"。
2. **GPU 像素处理（Metal）**：磨皮、调色、锐化、局部上色。
3. **网格变形（Warp）**：用关键点驱动图像形变，实现"瘦、大、长、短"。

难点不在某个算法，而在：**稳定性（不抖）、自然度（不假）、性能（不烫）、边缘情况（不崩）**。

## 2. 固定管线（顺序不可随意调换）

```
Camera(BGRA/YUV) → CVMetalTextureCache 零拷贝 MTLTexture
  │
  ├─ [异步] 检测/跟踪 → 关键点(带时间戳、置信度)
  │
  ▼ CPU：关键点层
  校验修复 → 局部坐标系 One Euro 滤波 → 姿态/眨眼/张嘴状态
  → 生成扩展点 + 外环点 → 参数→目标点(位移规则+限幅+姿态衰减)
  → 三角翻转检测(翻转则降强度) → 强度门控(丢脸渐隐渐入)
  │
  ▼ GPU：单个 command buffer
  P1 磨皮(高低频 + 皮肤mask)
  P2 美白/红润/祛红血丝/唇色/白牙/眉毛擦除填补(源空间，mask相乘)
  P3 统一网格 Warp(全流程唯一一次几何重采样)
  P4 轻锐化/可选颗粒
  → 预览 / 编码 / 拍照
```

**为什么上色在 warp 之前**：mask 是用当前帧的源关键点算的，在源空间完全对齐。先 warp 再上色，要把 mask 一并变形，容易错位。

**为什么只允许一次几何重采样**：多次重采样会累积模糊并放大畸变。

## 3. 关键点来源选型

| 方案 | 点数 | 优点 | 缺点 | 建议 |
|---|---|---|---|---|
| dlib 68 点 | 68 | 易上手，教程多 | CPU 慢、抖动大；预训练模型基于 iBUG 300-W，授权限制商用（请核实） | 仅原型 |
| Apple Vision `VNDetectFaceLandmarksRequest` | 76 | 免费、免模型、系统级优化 | 点位固定、稳定性一般、无完整 3D 姿态矩阵 | MVP |
| MediaPipe Face Landmarker | 478 | 点密、含面部变换矩阵(姿态)、Apache-2.0、有 iOS SDK | 需做坐标适配，包体增加 | **主力推荐** |
| 自训 106 点 | 106 | 完全可控 | 数据/标注/调优成本高 | 有算法团队再做 |
| ARKit Face Tracking | 面网格 | 3D 精度高 | 要求 TrueDepth 或较新芯片；占用相机会话，不适合作为通用 SDK 底座 | 仅作特殊场景 |

**68 点的天然局限**：无额头/发际线/头顶、无虹膜与瞳孔、无牙齿。功能表中"发际线、额头、颅顶、头包脸、眼瞳、眼睑下至、内外眼角细调、白牙"在 68 点下做不了或做不好。路线：MVP 用 68，P1 起迁移 478。

## 4. Warp 方案选型

| 方案 | 说明 | 结论 |
|---|---|---|
| **加密三角网格 + 顶点位移 + 光栅化** | 顶点位置=目标点，UV=源点；每个输出像素由硬件插值得到源坐标，天然 inverse warp，无空洞 | **主方案** |
| 局部径向缩放/平移(Gustafsson 液化) | 眼睛放大、局部推移，简单鲁棒 | 作为"生成顶点位移"的规则之一 |
| TPS / RBF | 少量控制点平滑插值到大量点 | **CPU 对网格顶点插值**，不在 shader 逐像素算 |
| 全图 TPS | 开销大且拉扯背景 | **禁止** |
| 逐像素位移图(Displacement Map) | 位移场渲染成 RG16F 纹理再采样 | 可选；叠加多特征位移时更灵活，需注意分辨率与插值 |

## 5. 平台层必备能力

- AVFoundation：采集、前后置、方向、镜像、`videoOrientation`
- `CVPixelBuffer`、`IOSurface`、`CVMetalTextureCache`（零拷贝）
- Metal：顶点/片段着色器、Compute、多 Pass、纹理池、`MTLHeap`、Frame Capture
- 推理：CoreML / MNN / ncnn / TFLite Metal delegate / MediaPipe Tasks
- 线程：相机队列 → 推理队列（只保留最新帧）→ 渲染队列

## 6. 自研 vs 采购的建议

关键点与分割模型训练成本高。常见策略：**关键点用 MediaPipe 或商用库，渲染与变形自研**。这样核心效果可控，又不必一开始背上数据与标注成本。分割模型（皮肤、嘴唇、牙齿、头发）可后续逐步替换为自训或商用。
