# 04 功能：脸型 / 整脸 3D 塑颜 / 比例

通用约定（见 docs/02）：位移在**人脸局部坐标系**下定义；单位为"脸宽/瞳距比例"；所有项受**联合限幅、姿态衰减、翻转检测**约束。
"68点可行性"：✅ 可行 / ⚠️ 勉强（需扩展点或加密）/ ❌ 需 478 点或额外模型。

> 限幅数值为**起始参考**，需实测。

---

## A. 脸型

### 1. 脸宽
- **做法**：轮廓点（0–16 中靠两侧的 1–5、11–15）沿"指向脸中心"的方向内收；也可整体水平缩放。
- **权重**：钟形，颧骨下至下颌角最大；近耳（0/16）和下巴尖衰减。
- **限幅**：单点 ≤ 脸宽 5%–8%。
- **坑**：均匀内收会让下巴突然变尖；耳朵、头发、耳饰被拉扯；侧脸远侧要降强度。
- **68点**：✅

### 2. 小脸
- **做法**：轮廓相对脸中心整体缩放（含下巴），可略带下庭权重。
- **限幅**：缩放 ≤ 5% 量级。
- **坑**：和脸宽/V脸叠加会超限，必须联合限幅；缩太多五官相对变大，显得"头小"。
- **68点**：✅

### 3. V 脸
- **做法**：下颌线下半段（约 5–11）向内收，下巴点（8）上提并轻微内收；下颌角处衰减。
- **坑**：下巴尖得怪异；下颌转折消失显得像"锥子脸"；嘴角附近肌肉被拉扯。
- **68点**：✅（但下颌细节有限）

### 4. 面部流畅（脸颊/轮廓平滑）
- **做法**：对轮廓点沿轮廓曲线做平滑（曲率限制），消除轮廓凹凸；位移沿法线方向，幅度很小。
- **坑**：过度会把下颌角抹没；注意不要把头发边缘拉出。
- **68点**：⚠️

### 5. 太阳穴（丰太阳穴）
- **做法**：需要**太阳穴区域点**（眉尾外上方）。68 点无此点，用外眼角、眉尾、轮廓上端（0/16）外推生成扩展点；向外轻微"鼓"位移（径向放大）。
- **坑**：容易与头发混淆；头发遮挡时效果不自然；位移要小。
- **68点**：⚠️（扩展点）

### 6. 颧骨
- **做法**：颧骨点（轮廓 1–3 与外眼角下方生成的扩展点）内收（"削颧骨"）。
- **坑**：与脸宽重叠，须联合限幅；过度造成凹陷感。
- **68点**：⚠️

### 7. 下颌角 / 下颌线
- **做法**：下颌角点（约 4–5、11–12）向内上收；下颌线（5–11）平滑。
- **坑**：下颌角位置因人而异，68 点只是近似；侧脸时这条线几乎和背景重合，位移容易带出背景弯曲。
- **68点**：⚠️

### 8. 下巴长短
- **做法**：下巴点（8）及周边沿竖直轴移动，高斯衰减；同步轻微联动下唇下方区域。
- **限幅**：长度变化 ≤ 下庭长度 10%。
- **坑**：抬头/低头时轴向变化，须用局部坐标系；下巴缩短时颈部与脖子衔接出现拉伸。
- **68点**：✅

### 9. 尖下巴
- **做法**：下巴点附近（7–9）向中线收，下巴点轻微下移。
- **坑**：与 V 脸叠加过度；侧脸时失真。
- **68点**：✅

### 10. 发际线
- **做法**：需要**发际线点**。68 点没有，必须用扩展点：沿面中线向上外推（约眉心到下巴的 0.3–0.4）并配合**头发分割**确认真实发际线位置。位移沿竖直轴上/下移动。
- **坑**：推发际线下移时需要"长出"头发纹理，难；上移要"露出"额头皮肤，需要皮肤填补；有刘海时不可用。
- **68点**：❌（建议 478 点 + 头发分割）

### 11. 去双下巴
- **做法**：下颌线下方、颈部上端区域向上、向内收（位移场）；颈部分割限定范围。
- **坑**：脖子与衣领边界被拉扯；低头时双下巴本来就明显，强度要随俯仰角调整。
- **68点**：⚠️（需下颌下方扩展点）

### 12. 去双下巴 Pro
- **做法**：在 11 的基础上，加**颈部/下颌下方分割 + 纹理补全**（把"肉"的阴影压低，用周边皮肤取样）；可加阴影重绘。
- **坑**：补全纹理不自然；要和磨皮、肤色一致。
- **68点**：❌（分割网络）

## B. 整脸 / 3D 塑颜

### 对称
- **做法（简化）**：用关键点沿面中线镜像，计算左右偏差，位移向对称方向靠拢。强度只往对称方向走一小段。
- **做法（3D）**：3DMM 重建，在 3D 模型上做对称，再按姿态重新投影。
- **坑**：真人脸本就不对称，完全对称显得假；侧脸时左右点深度不同，二维镜像失真。
- **68点**：⚠️（二维简化）；3D：❌

### 上下 / 左右 / 倾斜（整脸位移与旋转）
- **做法**：整脸内容整体平移/旋转（相对画面），或旋转五官位置的"相对排布"。注意这类参数不是"整张图平移"，而是脸内部五官相对位置的变化。
- **做法（3D）**：在 3D 人脸模型上旋转/平移再投影。
- **坑**：五官整体位移后，外轮廓需要同步，否则脸被撕裂；3D 重建不准确时会出现"面具感"。
- **68点**：❌（建议 3DMM 或 478 点 + 变换矩阵）

> **3D 塑颜路线**：MediaPipe 478 点（含伪 3D 坐标）+ 面部变换矩阵，可以先做到"准 3D"；真正可商用的 3D 塑颜需要 3DMM（BFM/FLAME）拟合 + 纹理映射，工程量大，建议 P2 之后。

## C. 比例

> 比例类功能影响"头/脸/五官"之间的比例，依赖额头与头顶的信息，68 点基本不够。

| 功能 | 做法 | 难点 |
|---|---|---|
| 小头 | 头部（脸+头发+颅顶）整体缩放，背景需保持 | 需**头发/人像分割**，否则头发被拉；肩部边界补偿 |
| 头包脸（头部相对脸部更大） | 头部外缘（颅顶、头发）外扩，脸部不变 | 需头发分割，头发边缘伪影 |
| 颅顶 | 颅顶点（额头上方）上提/下压 | 需颅顶点（扩展点），头发遮挡 |
| 额头 | 额头区域上下伸缩，发际线联动 | 需额头点与头发分割；刘海遮挡 |
| 中庭（鼻区高度） | 鼻底（鼻基点）上下移动，联动眉-鼻-嘴间距 | 与鼻/嘴功能叠加须联合限幅 |
| 人中 | 鼻底到上唇间距伸缩，鼻/唇联动 | 上唇形状变化，注意牙齿露出 |
| 下庭 | 嘴到下巴间距伸缩，联动下巴长度 | 与下巴长短重叠，共享预算 |
| 短脸 | 三庭整体纵向压缩（竖直轴缩放） | 眼睛/嘴同步缩放需保持形状，只缩间距不缩五官 |

**比例类通用原则**
- 先定义"三庭"边界（发际线—眉心、眉心—鼻底、鼻底—下巴），再按比例分配位移。
- 位移作用于"间距"而非单个点，避免五官形状被压扁。
- 所有比例项合并后统一限幅。

---

## 三项通用坑（本类别）

1. **轮廓外的背景补偿**：脸型变化大，一定要有外环；背景弯曲时检查外环距离。
2. **侧脸**：远侧轮廓与背景边界贴合，形变最容易出错。强度按姿态衰减，>60° 关闭。
3. **头发/耳朵/眼镜**：轮廓附近这些东西随之扭曲，看起来假。头发分割做权重衰减，是中后期必做。
4. **叠加爆炸**：脸宽 + 小脸 + V脸 + 颧骨 + 下颌角 + 尖下巴，同时拉满会严重畸形。总位移预算必须由联合限幅控制，UI 上提供"一键自然"预设。
