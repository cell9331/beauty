# 10 里程碑路线图

假设：2–3 名工程师，使用现成关键点库（MediaPipe 或 Vision），不自训关键点模型。周期为参考，请按团队实际调整。

## 功能优先级

| 级别 | 功能 |
|---|---|
| **P0** 先做可用版本 | 磨皮、美白、红润、锐化；大眼、瘦脸、小脸、V 脸、下巴长短；鼻子大小/鼻翼 |
| **P1** | 其余脸型（颧骨、下颌线、面部流畅）；眼睛全套（眼距、眼尾上扬、内外眼角等）；眉毛全套；嘴唇与牙齿（唇色、白牙、嘴型） |
| **P2** | 太阳穴、发际线、额头、颅顶、头包脸、小头；去双下巴 Pro；眉毛移动填补；眼瞳大小；祛红血丝；去脂 |
| **P3**（长期） | 3D 塑颜、对称（3D）、整脸上下左右倾斜（3D）、眼神矫正 |

## 里程碑

| 阶段 | 周期 | 内容 | 验收 |
|---|---|---|---|
| **M0 管线** | 1–2 周 | 相机 → 零拷贝 → Metal → 屏幕；坐标系封装与单测；调试叠加层；性能打点 | 前后置/方向/镜像下画点位置准确；空载 60fps |
| **M1 美肤** | 2–3 周 | 美白、锐化、磨皮（高低频 + 降采样 + 引导上采样）；粗皮肤 mask | 近景无塑料感；iPhone 低端机 30fps |
| **M2 关键点稳定** | 1–2 周 | 点位校验修复；One Euro + 局部坐标系；丢脸渐隐渐入；姿态/EAR/张嘴度 | 静止不抖；快速转头不拖影 |
| **M3 网格 Warp** | 2–3 周 | 离线拓扑工具；外环与边界锚点；FoldoverGuard；大眼、瘦脸 | 参数极值不崩；背景不歪；翻转率 0 |
| **M4 扩展五官** | 4–6 周 | 脸型、眼、鼻、眉、嘴全套参数；联合限幅；姿态/眨眼衰减；加密顶点 + TPS/RBF | 侧脸、表情、遮挡场景稳定 |
| **M5 分割类** | 2–3 周 | 皮肤精细分割；唇色、白牙、眼瞳、祛红血丝 | 边缘自然；多肤色测试通过 |
| **M6 性能与发热** | 贯穿 + 2 周专项 | 降级策略；纹理池；热控；机型矩阵测试 | 最低机型 P95 达标；30 分钟无 serious |
| **M7 SDK 化** | 2–3 周 | XCFramework、接口稳定性、文档、示例 App、License | 第三方宿主集成无冲突 |
| **M8 高阶** | 长期 | 发际线、额头、去双下巴 Pro、3D 塑颜 | 按业务需求逐项评估 |

## 关键决策点

| 时间点 | 决策 | 依据 |
|---|---|---|
| M2 结束 | 是否从 68/76 点迁移到 478 点 | 抖动指标、功能清单（P1 起需要） |
| M3 结束 | Warp 方案是否稳定（网格 vs 位移图） | 翻转率、性能、背景弯曲 |
| M5 开始 | 分割模型自研 / 采购 | 授权、精度、延迟、成本 |
| M6 | 是否引入人像分割保护背景 | 背景弯曲用户反馈 |
| M8 | 是否投入 3D 重建 | 业务价值与人力 |

## 风险与应对

| 风险 | 应对 |
|---|---|
| 关键点抖动长期无法收敛 | 尽早换更稳的点位模型；加强滤波；位移二次平滑 |
| 低端机性能不达标 | 提早建立降级档位；预算分配尽早实测 |
| 自然度难调 | 引入设计/视觉评审，建立"自然档"预设与参数曲线调校流程 |
| 数据与模型授权问题 | 上线前授权审计；预留替换模型的接口 |
| 高阶功能（3D、眼神）工程量失控 | 分层交付，先用近似方案占位，保留回退 |
