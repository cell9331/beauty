## 共同测量约定

所有位移定义为源到目标的前向对应 `D(p)=p_target-p_source`；x 向右、y 向下，负 dy 表示上提。单位是**对齐后的截图像素**，不是原始相机像素。所有端点跨度均为实际配对之差，未除以二推断单端强度。

截图编码尺寸为 1170×2532，共同照片测量裁区为 1170×1570，排除状态栏、滑杆、工具栏和底部背景保护浮层。面部流畅另排除发顶的会员提示及邻域。脸部、保护区和剖面根据这张源图的空间分区选取，仅适用于本次测量。

原图为同一内容的 1728×2304 素材。只在效果区外的发顶、天空及远侧背景纹理拟合全局相似变换，保留空间分区留出点。原图到截图的缩放约 **0.9437–0.9438**，伴随水平裁切，不能用 1170/1728 的整图宽度比例代替。只将原图重采样到共同网格一次；截图保留原像素网格，不做局部可变形对齐。

独立复核的原图配准留出集合有 152–333 个初始对应，包含少量错误特征匹配；全部留出残差 P95 为 **0.73–1.17 px**，每集合 1–3 个残差超过 3 px，其中存在明显错配，未把它们隐去后再称全点精度。截图间估计相似变换接近恒等，前两项保守稳定区域约 94.7% / 97.1% 的像素完全相同，故没有再次重采样。外侧背景仍有少数像素随局部效果移动，不能据此声称背景严格固定。

原图与截图的显示对应成立，不等于原图已被证明为编辑器共同零态。第三项内部眼鼻口与原图接近，也未看到前两项几十像素运动整体残留的模式；这支持“未观察到明显累积”，但没有编辑历史或中性截图，不能排除小幅隐藏调整。第三项结论因此保留条件。

## 交叉检查及边界

主场采用全分辨率 DIS 光流，检查前后向闭合，并在半分辨率独立重估后换回相同像素单位。弱纹理皮肤和下巴内部的稠密场属于平滑估计，不能把其格点数当成独立观测。

独立方法按源图纹理及空间格网取点，以局部模板搜索对应；未使用稠密场初始化或一致性筛选。主模板半径 14 px，另用半径 20 px 复查，初始搜索 ±96 px；没有接受点触及搜索边界。筛选依据为源纹理、相关峰唯一性、匹配相似性及反向闭合。移动点与静止点单列，避免背景淹没运动误差。方法间差异是交叉证据，不是真值误差。

稠密方法在零变化控制中返回零场；已知 (+37,−23) px 平移控制的误差 P95 为 0.12 px。独立模板方法同类控制约 0.05 px。这只核对符号和量级，不能外推为真实局部形变、弱纹理区域或全部照片的精度保证。

本轮局部验证覆盖：输入与控件核对、全局配准留出残差、前后向闭合、第二尺度、独立纹理匹配、控制实验及报告引用。没有修改 SDK 或宿主，没有运行 SDK 测试、构建或模拟器回归。

本目录只保留聚合观察及可被后续证据推翻的机制假设。对照图、带符号热图、标明窄带位置的横纵剖面、实际对应及逐像素场只留在本次本地工作区，不写入持久文档。仅凭这些截图不能识别闭源算法、网格拓扑、关键点体系或中间档响应。
