# 02 小脸

共同单位、方法和输入限制见[分析入口](README.md)。本项测量 **IMG_2020 左端 → IMG_2021 右端**，不把端点跨度拆成两个等幅单端。

## 测得的运动

与脸宽相比，本项的重心更低：两侧下半脸内收，嘴部及下巴明显上提，上半脸保持较稳定。部分颈部也发生位移。

| 观察区 | 本次聚合结果 | 证据限制 |
| --- | --- | --- |
| 双眼核心窗口 | 共 29 个接受纹理点，模长 P95 约 0.1 px | 本次局部近静止，不代表整片眼周严格固定 |
| 嘴部核心 | 22 个接受点，dy 中位数约 −14.0 px | 支持嘴部上提，不能由此称嘴整体刚性平移 |
| 左 / 右脸颊 | 接受点 dx 中位数约 +14.8 / −15.6 px | 分别为 16 / 4 个点，采样覆盖不同 |
| 两侧下颌 | 稠密估计同时内收和上提，局部水平约 20–30 px | 轮廓纹理稀疏，独立点只覆盖部分区域 |
| 下巴中心 | 稠密估计 dy 中位数约 −28.3 px；较宽下巴窗仅 1 个接受纹理点，dy 约 −28.8 px | 单点兼有横向运动，不能代表中心或完整下巴；弱纹理内部仍为估计值 |
| 中央颈部 | 4 个接受点中有上移，最大模长约 15.3 px；稠密窗口 dy 中位数约 −9.9 px | 独立点与场窗口覆盖不同，不能当作同一统计 |

横剖面在较低位置的内收更强；纵剖面的上移向下巴增强，再向颈部下方衰减。发顶和双眼附近接近零。不能声称“只动脸，颈部完全保护”。

## 能支持的最小解释

**事实 → 假设：**上半脸近静止，下半脸向内、向上收拢，并向颈部延伸，优先支持“以较高区域为稳定过渡的下半脸二维收拢场”。水平内收和竖直缩短需要分别描述，作用范围及幅度不必相同。

**排除依据：**将整张脸围绕一点统一缩小会同时改变双眼位置与间距，不能解释本次眼部近静止而嘴部上移约 14 px；仅用脸侧水平推拉也无法解释下巴和颈部的竖直分量。脸宽的场不能只乘一个强度直接复用：两者在眼部、嘴部、下巴及颈部的响应比例不同。

**未知量：**现有证据不能确定是否存在某个内部缩放核心，也不能确定它的中心、精确形状和外部过渡函数。尚不能把局部收拢等同于全脸相似缩放。需要中性和中间档图，才可测响应是否线性、正负两端是否等幅以及保护边界如何变化。

## 本项验证

独立模板匹配接受 **726/899** 个候选。主要拒绝为峰不唯一 142 个、低纹理 24 个、低相关 4 个、闭合失败 3 个；无搜索触边。

模长大于 2 px 的接受点有 **188** 个，其模长 P95 为 **23.1 px**，最大为 **30.6 px**；稠密面部估计最大约 38.2 px，不能把这个估计峰称为已有独立纹理点证实的最大值。移动点与稠密场的向量差异 P95 为 **1.34 px**，最大差异约 7.06 px；个别下颌点在较大模板下发生错峰，保留该不一致，不以光流过滤。模长不超过 1 px 的 513 个点，方法差异 P95 为 0.13 px。

前后向闭合小于 1.5 px 的面部格点约 99.2%；其中闭合 P95 约 0.36 px，全/半分辨率差异 P95 约 1.39 px。结论以方向、空间分布和有纹理区域为主，不对弱纹理内部作亚像素保证。
