# 同肤色物体自动保护：有限可行性验证与处置（2026-10-03）

## 结论与当前状态

一次新候选预算已用完并被拒绝。通用、无排除蒙版的同肤色非皮肤物体自动辨认仍**未完成，暂停续作**；本次研究处置可以完成，不代表该能力实现。生产算法、公开 API 和常规 SDK 测试均未修改。正确显式二值排除蒙版继续精确保留其指定像素；新反例同时显示，粗略五官保护域不能保证覆盖全部低对比唇缘。

原 15 项二维控制及皮肤平滑/锐化已有的限定输入验收不变。本次不提升任何 taxonomy 行，不启动模型、训练或去脂研发。去脂仍为 `suspended`、默认隐藏、保留显式兼容。

## 冻结的范围与判据

所有者批准后，先在计划冻结以下条件，再运行结果：

- 不透明 sRGB、64×64、单脸测试观测；两种肤色和低对比细纹，平滑和锐化各四个组合。观测由 Testing SPI 提供，不声称 live Vision 自然照片辨识。
- 两种物理解释的完整图像、元数据及脸支撑完全相同；右脸颊分别是皮肤或复制其可见外观的印刷覆盖物。独立 oracle 的材质标签不传入自动请求。
- 皮肤正例：平滑后目标邻接亮度变化至少降低 20%；锐化至少增加 10%。物体负例：目标 RGB 必须源精确，同时对侧皮肤达到效果门槛。
- 眼、唇、背景和 alpha 保护、neutral identity、重复、extent/色彩空间与 RGB 改变量上限同时成立，不能用停掉所有处理达到保护。
- 当前无蒙版公开路径为基线；正确显式蒙版为控制。唯一新候选在测试内检测 4 像素周期及 2 像素反相，扩大拒绝域；它仅读取源图，不使用 oracle 标签或目标 ROI。
- 最多一个候选，结果后不更改输入、阈值、ROI 或保护断言。矛盾可见输入或正负例不能同时通过时，拒绝一般自动识别承诺并结束续作。

## 实际结果

| 路径 | 正常皮肤目标方向 | 同色物体源精确 | 完整冻结保护 | 处置 |
| --- | --- | --- | --- | --- |
| 当前无蒙版基线 | 通过 | 失败，物体被处理 | 深肤色低对比唇缘失败 | 不具备通用自动保护资格 |
| 唯一周期纹理候选 | 失败，正常皮肤也停止处理 | 通过 | 同一唇缘失败 | 拒绝，不接入生产 |
| 正确显式物体排除蒙版 | 通过，对侧皮肤仍有效 | 通过，所有被标记像素与源一致 | 同一未被标记唇缘失败 | 指定像素契约继续有效；完整新输入不合格 |

相同材质解释输入/输出的检查通过。三条路径在深肤色输入下，各对平滑、锐化出现一次唇区源精确断言失败，共六处；浅肤色组合及局部方向/物体谓词通过。粗略脸相对唇域没有覆盖这份源图全部唇缘，而低对比颜色/邻域守卫允许处理域外边缘。本轮没有扩大保护域或移除反例。主机若需要这些已知唇缘像素精确保留，须将它们也纳入显式排除蒙版；这属于既有指定像素契约，不是本轮另一次“已修复”验收。

原 SDK 测试宿主运行新挑战 **4 tests / 6 assertion failures / 0 skips**；原显式蒙版回归独立通过 **4/0/0**。将同一 Swift 源逐字冻结到独立临时包后，复现仍为 **4/6/0，退出 1**。这是保留的失败验收，不是 expected failure，也不是全量门禁通过后可覆盖的结果。输出的 `local_joint=pass` 只指蒙版目标与对侧方向；完整保护仍失败。

## 根因与解决路径

这是**可辨识性不足**：相同完整可观察输入要求同一区域既有效改变又精确不变，任一只读该输入的确定性规则都无法保证两种语义同时正确。单看颜色、脸框或规律纹理不足以提供这里缺失的材质信息；本次周期拒绝也误停了真实皮肤正例。

可落地的当前方案是主机提供正确的 `BeautyTextureExclusionMask`，包含其知道必须保留的物体或五官像素；对不满足现行准入/保护条件的输入，主机也可关闭纹理处理。扩大自动能力需另行明确能从输入观察到的差异及有限域正负例，再授权新研究。此结论不说明所有物体都不可识别、不证明模型必需，也不保证模型能解决完全相同的观测歧义。
