# 位移测量细则

在实际分析原图/参考图、计算位移或制作剖面图时读取。
选择足以分辨本次假设的方法，下面是决策依据，不是每轮都执行的完整测试矩阵。

## 输入与配准

1. 确认同一内容与状态，区分原始素材、共同零态、左端、右端和已累积其他调整的截图。
2. 记录编码尺寸与可见照片边界；比较截图时不能把工具栏匹配当作照片配准成功。
3. 只用可信稳定区域估计全局相似变换；出现透视差异时先解释来源，再决定是否需要更复杂的全局模型。
4. 稳定纹理至少覆盖不同方位。留出点的误差比训练内点数更能说明剩余对齐误差；必要时比较两个独立稳定区域的变换。
5. 显示适配可能是“先放大再裁切”，不能直接按整图宽高比例换算。统一网格只重采样一次。

不得通过可变形对齐、局部回正或以效果区自身拟合全局变换来提高匹配率。
若稳定区之间也存在不可解释的局部运动，应先标记输入不满足单效果比较，而不是强行解释成该控制的作用。

## 坐标与可辨识量

将源→目标的向量定义为 `D(p)=q-p`，声明 x/y 正方向和显示中的符号转换。
报告“对齐后的截图像素”或其他实际单位，不冒充原始相机像素。
像素中心、图片 extent 和归一化纹理坐标须一致；显示图的缩略尺寸不改变原测量单位。

只有两个端点时，可直接测的是低端→高端对应。
即使两幅视觉上对称，也不能把总位移、总转角或相对倍率自动除二，称为两个单端效果。
原图只有在确认为共同零态且对应可靠时，才约束中性拆分。

对于同一个中性源点 p：

```text
p_low = F_low(p)
p_high = F_high(p)
V_pair(p_low) = F_high(p)-F_low(p)
```

不同映射的坐标域必须先对应，再比较向量。
扩张还需区分端点相对倍率与中性强度：在线性核心中
`lambda=(1+b_plus)/(1-b_minus)`，相同 lambda 不唯一确定 `b_plus+b_minus`。

## 稠密场、稀疏匹配和不确定性

稠密场可通过适当的光流或其他对应估计取得。保留 `dx`、`dy`，不要只存模长。
检查前后向闭合及按场重采样后的纹理重合。重建好只能支持对应关系，不能自动识别内部算法。

当边界或平台是关键结论时，换一种尺度、窗口或另一方法复测，比较的应是关键区域与剖面。
若估计边界随平滑窗口明显移动，应给范围，不能给小数级确定边界。
弱纹理区域可以显示稠密估计，但要标注其依据不足，不能用填充格点数量冒充独立样本数。

独立的局部纹理检查可使用特征对应、局部块匹配等适当方法：

- 根据源图纹理和空间分区取点，覆盖峰值、固定区、衰减与关键保护区。
- 搜索范围覆盖候选最大位移及裕量；峰值贴近边界时扩展后重测，不默认它是真正最大值。
- 用本方法自身的纹理强度、峰值唯一性、反向闭合等判据筛选。
- 不使用待核验的稠密场初始化或一致性过滤后，再把结果称为独立精度验证。
- 保留跨方法不一致的结果和拒绝计数，用它们定位方法适用域。

“通过本方法判据的匹配点，与另一方法的差异 P95”是方法间差异，不能称真值误差。
必须单列移动点统计；全部点的分位数可能被大量静止背景主导。
独立匹配中观察到的最大位移也只是这些匹配点的最大值，不等于连续场全域最大值。

## 剖面和几何特征

在对照图上标出取剖面的位置，注明坐标、窄带宽度和中位数/其他聚合方式。
邻近纹理点可以辅助检查曲线，但应注明它们不一定恰好位于剖面上。
对多个特征分别观察：核心幅度和方差、水平/垂直正交残差、沿长度的强度变化、峰位、
上下边界的过渡、外围回零位置，以及独立保护窗口。

以一致定义报告过渡宽度，例如 10%→90%。不要把这个宽度当完整支持半径。
对完整三次 smoothstep，10%→90% 约为全过渡宽的 0.6084；
该换算只适用于这条候选曲线，乘上保护或其他权重后仍须重新测完整场。

拟合刚性运动时，同时看角度、尺度、点对距离与残差的空间分布。
有限旋转必须检查两个位移分量；只用“头上尾下”不足以区分旋转与局部竖直推拉。
对“固定”结论检查一段区域和其误差界，不能只固定一个控制点或依据插值结果。

## 最小控制与输出

根据关键风险选零变化、已知平移、局部场或旋转控制，核对坐标符号、尺度和运动量级。
由小幅垂直控制测出的误差，不能外推到大幅水平位移、旋转或弱纹理边界。
仅靠数据不能稳定估计的量应保留为未知，说明哪种新增观测能辨识它，而非承诺调参必能解决。

输出图应可直接审阅：对齐输入、水平/垂直场、横纵剖面、可靠对应点、单位与跨度。
对零位移与非零位移使用明确标尺；多图统一色标便于比较，单图色标则应覆盖其有效范围。
热图是几何量的可视化，不是颜色处理结果，也不等于对象分割。
只保留允许的汇总；图像、点位、密集场及中间脚本留在本次本地工作目录。
