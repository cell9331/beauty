# 从测量推导技术方案

在用户要求把位移分析转成技术文档或实施假设时读取。
方案应帮助实现者选择并验证机制，不要求反推到闭源产品的唯一内部公式。

## 用可审查的判断组织推导

先写能由输入支持的事实，再提出低自由度候选，说明能够推翻它的对应或剖面。
保留对竞争假设的简短排除依据和真正未知的量，不写未经测量的精确参数。

| 问题 | 需要的证据 | 容易误写的结论 |
| --- | --- | --- |
| 整体平移还是局部伸缩？ | 沿特征长度的位移、点对距离、刚性残差 | 有变化就算平移 |
| 扩张还是整体抬高？ | 锚线两侧的方向、离锚线距离与位移关系 | 只看上边缘 |
| 旋转还是两端分别推拉？ | 完整 dx/dy 与近刚性对应 | 只看反向升降 |
| 哪些区域固定？ | 独立固定窗、纹理对应与噪声界 | 尾部弱就强制为零 |
| 是否复现？ | 独立检查点、作用范围及实际输出保护 | 有限变化、安全或测试数量证明外观 |

少量可靠证据应优先排除错误路线。只有残差有稳定空间规律时才增加参数，
不要为追随光流噪声堆局部控制点，也不要用更多工程完整性弥补目标机制未确认。

## 明确前向场与渲染方向

给每项定义源图、局部轴、锚点、几何尺度、正负方向和零值。
分开定义内部运动规律与外围支撑：平台、沿长度的递增/递减、局部峰形、有限旋转等
是内部模型；连接静止皮肤的连续衰减是另一组需要拟合的参数。
支撑区域包含随动皮肤，不等同于毛发/眼睛等二值语义蒙版。

所有公式注明是前向 `F_u(p)=p+D(p,u)`，渲染则求目标 q 对应的源 p。
一次 `p=q-D(q,u)` 一般只是近似，不能默认等于真实逆映射。
选择固定点迭代时，须满足相应的梯度收敛条件并核验逆残差；采用网格时检查覆盖与全局无重叠。
原图在最终逆映射下采样一次，避免反复变形上一次输出或混合两份错位图像遮接缝。

有限旋转包含两个分量。内部旋转的行列式为 1，不意味着与外围恒等混合后的整个场也安全。
`J_F=I+∇D` 要包含全部空间权重的导数；只看控制点或内部仿射部分会漏掉边界压缩。
仅有正行列式不独立保证全局一一映射，稀疏采样的最大梯度也不是全域导数上界。

## 标定与假设分开

每个数值注明是实测、从指定公式推导、待拟合量，还是初版设计选择。
把像素位移按已明确定义的几何长度归一化，角度和比例单独处理。
没有参考长度测量时，不编造无量纲系数；尺度迁移也需要独立验证。

端点总差不自动约束中性拆分。选择对称响应时应明确它是设计假设，
不能把幅度、转角或相对倍率直接除二叫作实测。
候选字段的比较须按同一源点生成端点映射，再转到观测场的源网格。
前后端权重、支撑或模型变动时，重新检查哪些参数仍可由现有数据识别。

## 每项文档需要回答的问题

按内容组织，通常包含：

1. 这组参考测到了什么，支持哪一种可被推翻的机制假设？
2. 最小需要哪些可靠几何，坐标、单位、锚点与符号是什么？
3. 位移公式与响应函数怎样计算，内部与外围如何连接？
4. 幅度、作用区域和尺度怎样标定，哪些量还不能确定？
5. 怎样保护独立指定的区域，怎样处理退化几何、无折叠和逆解失败？
6. 从几何准备到原图采样的实现步骤是什么？
7. 用什么独立位移和实际像素正负例证明这项效果，而不是证明调用链成功？

多项调整各自一文件，公共坐标和采样数学集中在入口，局部只解释差异。
公式评审和合成数值自检可以证明推导的一致性，不能代替实际效果验收。
用户只要文档时不改实现、不提升效果资格、不隐式创建研发或模型任务。

## 本项目的按需示例

公共定义见[眉毛位移方案](../../../../docs/eyebrow-displacement/README.md)。
需要某种机制时只读对应示例：

- [上下](../../../../docs/eyebrow-displacement/vertical-position.md)：平台与上下非对称过渡。
- [粗细](../../../../docs/eyebrow-displacement/thickness.md)：锚线、扩张与端点倍率可辨识性。
- [长短](../../../../docs/eyebrow-displacement/length.md)：固定眉头、中外段伸缩及待拟合的尾侧衰减。
- [间距](../../../../docs/eyebrow-displacement/spacing.md)与[眉头间距](../../../../docs/eyebrow-displacement/head-spacing.md)：由沿长度的剖面和归零位置区分控制。
- [倾斜](../../../../docs/eyebrow-displacement/tilt.md)：有限旋转、左右符号与不确定的中心位置。
- [眉峰](../../../../docs/eyebrow-displacement/peak.md)：局部峰值、内外侧不对称衰减。

这些是先前数据支持的候选参数化示例，不是新输入的标定常数，也不是现有实现的替代权威。
