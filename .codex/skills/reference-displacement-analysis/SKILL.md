# 参考图位移分析

先测清参考效果，再选择机制。先回答“图上哪些位置怎样移动”，再回答“怎样用最小模型复现”。
优先用能区分候选机制的测量缩小问题，避免在未确认目标时投入接线、调参或大量工程验证。

## 适用边界

- 以用户提供的图片、授权的本地输入和当前测量为依据。功能名称、现有参数或代码结构不能证明参考机制。
- 用户要求独立推导时，不读既有实现、旧算法方案或历史实验来决定本轮机制；需要接入代码时另按授权范围核对。
- 用户指定只分析位移，就围绕几何取证，不增加颜色分析；热图颜色只编码位移。不要把某次“下颌线改变明暗”的样本变成所有功能的分类规则。
- 分析、写方案和实施是不同交付。分析请求不自动授权改 SDK/宿主、下载模型或重开已关闭路线。
- 遵守当前会话工作约定、[项目入口](../../../README.md)和当前图片证据约定；原像素、实际点位、蒙版、逐像素位移及私有路径不进入持久文档。

## 分析顺序

### 1. 固定能回答的问题

盘点原图、截图、控制名、滑杆位置、尺寸和可见照片区域。先看缩略总览，再核对关键图的原始细节。
确认图片是否来自同一源、是否存在裁切/缩放、其他效果是否可能累积；有“原图”不代表已证实它是共同零态。
缺少中性参考时仍可分析端点差，不能据此虚构单端强度或中间档响应。

在运行测量前写清坐标方向、像素单位、源/目标、拟合区域、保护观察区和待检验假设。
不要把某一张截图上的剖面位置、眉长或固定半径写成所有新输入的常数。

### 2. 对齐，只消除拍摄或显示差异

裁出共同照片区域，排除文字、工具栏、滑杆及覆盖层。
在效果区外、空间分布充分的稳定纹理上拟合全局平移/旋转/缩放；保留独立稳定点检验残差。
不能用局部可变形配准把待测效果消掉。稳定区已同网格时保留原字节，避免重复重采样。
原图只重采样到统一网格一次；报告留出残差与实际尺度，不能只报拟合内点率。

### 3. 测场，再用独立对应检查

测量前向二维位移 `D(p)=p_target-p_source`，分别保留水平和垂直分量。
稠密光流适合发现平台、峰形和衰减线索；弱纹理处的平滑填充不是独立观测。
结合前后向闭合、另一尺度或方法、局部纹理对应，选择最小充分的交叉检查。

局部对应的搜索范围要覆盖最大候选运动并留裕量；匹配落在搜索边界时先扩大搜索核对。
独立检查点按源纹理或空间分区选择，不按“与稠密场一致”筛选，再报告方法间差异。
分别统计移动点和静止点；大量零位移背景不能稀释移动区域的误差。报告接受数及主要拒绝原因。

需要实际测量时读[测量细则](references/measurement.md)，不预设必须使用某个库、模型或固定参数。

### 4. 用空间规律区分机制

先看两个分量和剖面，再提出最简单、可被独立对应推翻的模型：

| 测得的规律 | 优先检验的假设 |
| --- | --- |
| 主体位移近恒定，外围回零 | 平台平移及连续支撑 |
| 锚线两侧反向移动，随离锚线距离变化 | 局部扩张或压缩 |
| 沿特征长度递增、递减或局部归零 | 受锚点约束的伸缩/局部平移 |
| 两端反向升降，同时有相符的横向分量 | 有限二维旋转 |
| 内部有局部峰值，向两端减弱 | 局部 bump 及独立边界包络 |

检验幅度、作用范围、平台/峰位、过渡宽度、正交残差和保护区。
“尾部较弱”不等于“尾部严格固定”；“外围归零”不等于“特征端点归零”。
整体刚性假设应由成对距离或刚性拟合残差支持，不能只凭最大位移或热图观感。

用简短的“事实 → 假设 → 排除依据 → 未知量/下一项辨别测量”组织结论。
证据不足时收窄结论并完成已有数据支持的部分，不用更多自由参数掩盖未知量。

### 5. 需要技术方案时再推导

明确源坐标、局部轴、符号、尺度和作用区域，写出前向场 `F(p)=p+D(p,u)`。
把测得的幅度/剖面与自行提出的函数、对称假设、安全预算分开；不得把候选公式说成闭源算法真相。
按同一源点比较端点映射，不能逐点相减不同坐标网格上的场。
检查连续性、保护、完整梯度/Jacobian 和逆映射，再规定从原图单次采样。

写公式或实施说明时读[从测量到技术方案](references/implementation.md)。
多项调整需文档交付时，每项单独文件，共享坐标/采样约定集中定义；不复制整套通用约定到每篇。
未要求实施时，到可审阅的方案与验证方法为止，不自行开算法执行计划。

## 输出与核验

展示图优先采用“对齐原图与端点对照 + 位移热图 + 有坐标标记的横纵剖面”。
曲线注明窄带聚合或插值，叠加可靠的邻近纹理点；区分估计曲线与实际对应。
图例交代正方向、单位与端点跨度。色标和坐标范围应覆盖相关运动，不能截掉峰值而不标注。
保留方向信息；只画模长会掩盖粗细两侧的反向运动或倾斜的旋转特征。

有运行工具的需要才建立本次临时工作目录，先检查可复用的 Python/图像计算环境。
已知平移、局部场或零变化控制用于核对符号与测量能力；控制实验的误差不能外推成其他机制的精度。
文档只保留允许的聚合数、公式及适用范围，不依赖会消失的会话临时路径。
仅分析或文档改动不触发全 SDK/模拟器回归；验证本次测量、公式、引用和文件格式即可，其他门禁按项目规则与实际影响选择。
