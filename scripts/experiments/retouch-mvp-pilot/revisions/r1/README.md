# R2 小规模开发预检（2026-10-03）

所有者已明确允许有失败可能的小规模可行性验证。该授权允许验收器、输入和
隔离候选实施；不等于完整里程碑开工、生产接入、训练或模型下载。
本预检遵循 [R2 数值契约](../../../docs/RETOUCH_MVP_REQUIREMENTS.md)，不是完整 G0。
正式 60 例清单仍全部未准备，未读取任何 H 留出样本。

## 看候选输出前固定的范围

- EYE：复用已授权生成肖像作开发诊断家族，1024 长边；在独立作者的椭圆内
  加入峰值 16/255 的四次亮度隆起，以原始肖像为独立参考。双眼均为目标，
  每眼源目标 MAE 至少 4/255。原图和另一已授权平睑肖像作负例。
  这是可控光影信号，不作为未经构造的自然效果或独立留出证据。
- SEG：一个代码生成图家族的 3 肤色 × 2 形状 × 512/1024 两尺度贴片正例；
  3 肤色 × 两尺度无贴片负例。贴片有可见边界及细微表面纹理，另一侧皮肤
  保持纹理；同一模板的派生不能计为独立家族。使用固定脸框的内部测试路径，
  不据此宣称自然肖像 Vision 检测或自动唇分割已通过。
- EYE 先测试现有 public CPU 基线，再试一个局部低频残差衰减候选：仅从输入
  与 live Vision 合法眼支持估计边界背景，减弱平滑后的正残差，强度 0/.5/1。
  不向候选传参考、作者区域或期待标签。
- SEG 先测现有纹理基线，再试一个闭合边界连通域候选：低通梯度形成边界，
  有界紧凑内域扩张为自动排除，附保守嘴部区；输入只有图像与既有合法脸框。
  同时检查保护、皮肤方向、实际处理支持和负例过度排除。
- 本轮每分支只运行一个新方法的一个版本（记入正式每分支 2×2 总预算）；
  编译/测量错误修复不算候选版本，但必须未改变算法、真值或数字。若效果失败，
  本轮停止该候选，不在同一数据上不断调参。基线不计新方法预算。

## 测量与隔离

先单独执行 controls，再冻结源文件摘要并执行 candidates。正确参考/正确蒙版
须通过适用数值门槛；no-op、全排除、全局改色、对象核心泄漏、边缘超限、
过度排除等错误控制必须被拒绝。控制失败时不得启动候选。
EYE 的原尺寸视觉检查独立记录；数字通过不能自动签视觉通过。

隔离 SwiftPM 副本仅给纹理函数增加请求内 observer，位置在最终所有排除条件
之后、量化阈值之前。每次检查有/无 observer 的输出完全一致，并对全排除、
无脸、neutral、错尺寸和恢复作检查。掩码不输出，只报告聚合覆盖。
生产 Sources/Tests/Package 和既有失败实验原字节保持不变。

运行器保留有界子进程输出于内存，超时中止进程组；只公开聚合 JSON、已知错误
类别和新测试行号，不持久保存原始日志。图片仅保存于被 Git 忽略的本地审阅区。
退出 0 只表示当前 stage 通过；候选数值失败退出 1，执行/测量错误退出 2。
小预检成功仍需完整 G0、正式开发/留出、视觉和集成门禁；失败仅否定本候选，
不推断所有无模型路线均不可能。
