# SEG 正式 G0 输入与控制准备

当前步骤只制作/核对正式输入和控制；不运行 S1-v1 或其他自动候选，不访问自动
候选的留出结果，不改生产代码。上睑 E1-v1 保持停止。标准来自
[初版契约](../../../docs/RETOUCH_MVP_REQUIREMENTS.md)和
[G0 设计](../../../docs/RETOUCH_G0_VALIDATION_PLAN.md)。

先验证 D01 源家族的实际 Vision 支持、两个尺度与正确保护控制可测，再制作
D02–D06；开发六家族已制作，留出和拒绝集合未制作，不能声称 30 个案例就绪。每个新肖像独立生成，不把换色、缩放
或裁剪冒充不同家族。持久清单只保存逻辑身份、来源类型、内容/标记摘要和聚合。

输入作者先观察未加工肖像，独立标出双颊测量区、贴片位置及关键保护区；私有
标记只存在本地忽略目录。正例在 1024 主版本上代码绘制肤色哑光贴片，真值是
作者几何轮廓，不读算法预测。配对负例保留未加贴片的同一源栅格。贴片颜色
由被覆盖源区域的 RGB 均值加固定 8 code-value 构成，表面加入固定幅度 1 的
细微格纹；无候选输出参与作者选择。
关键保护包括完整双眼/眉/唇的作者矩形，以及独立描绘的保守脸部包络以外全部
像素，覆盖背景、头发、颈部和衣服。补全脸外保护未改变皮肤 ROI、贴片或源像素。

512 版本从 1024 主版本以逐通道 2×2 box 均值、四舍五入生成；alpha 保持 255。
物体真值采用源块 any，皮肤测量区采用 all；边缘带按实际尺度重新构造。
两个尺度都是同一逻辑案例，不能重复计入正例分母。

正确控制允许使用作者真值，只允许固定皮肤评估区参与处理，其他区域以 host
排除蒙版保护；它是证明标准可达的控制，不是自动功能。真正候选以后仍不得
读取真值。实际 public CPU 输出与相同源/live Vision 脸框的隔离观察路径须
逐字节一致；observer 在最后准入后、量化之前计数。处理支持不得用变化像素数代替。
观察路径使用同一参数 resolver，保留 public 强度 1 对应的实际安全上限，不能
直接构造 effective strength 1。初次检查因此产生的 8 个等价性失败保留在 r1
快照及进展记录；不改输入、区域、阈值或生产实现。

控制检查 S3 的 50% 支持、20% 平滑下降、10% 锐化增加，物体和保护区、alpha、
元数据、neutral、repeat、错网格 typed failure 与恢复。no-op、全排除、关键
保护泄漏、核心泄漏、超限边缘、大面积误排除须被拒绝。控制不达标先留下
G0 缺口，不修改阈值，不开始自动候选。

单源运行：`python3 -B scripts/experiments/seg-g0/run.py D01`；
开发集合：`python3 -B scripts/experiments/seg-g0/run.py development`。
每源独立 XCTest，另有 25% 过度排除、50% 支持边界及平坦输入测量控制。
开发集合预期 7 tests、24 条输入摘要和 48 条效果控制；缺条、重复、零测试、skip
均不能通过。r3 的批量复核图命名未带家族导致覆盖；r4 为每个家族保存独立输出，
其修正不改变输入像素或已有数值结果。历史运行器快照保留原依赖布局含义，
重放须在临时副本恢复同级 helper 布局，不能直接在 revisions 目录执行。

仅使用本地忽略输入；输出有界、只返回聚合。完整记录和当前样本状态在
[SEG G0 进展](../../../docs/SEG_G0_PROGRESS_2026-10-03.md)。
