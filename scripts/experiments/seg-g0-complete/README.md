# SEG 完整 G0 输入与控制

承接 [开发输入控制](../seg-g0/README.md)，独立补齐留出与拒绝集合，不修改该记录。
本目录只运行已知正确 host 控制和故障控制，**不包含自动候选**。G0 完成不等于
G1/G2 通过，留出输入的可测性检查不消耗候选的一次留出资格评估。

固定 18 个源家族：D01–D06 开发、H01–H06 留出，分别配对正负例；R01–R06 为
独立拒绝家族，合计 30 个逻辑案例。17 个肖像分别独立生成，R01 是代码生成
的无脸棋纹。原肖像、区域和渲染图只在忽略目录中使用，持久文件仅身份/摘要/聚合。

D 输入与作者标记原字节承接上一轮，H 使用相同制作规范：1024 主源、512 box
派生；贴片为源区域 RGB 均值 +8、固定 ±1 格纹；独立 superellipse 真值与完整
皮肤 ROI 不由候选产生。三档肤色×均匀正面/柔和侧光，形状按原清单预定。
作者矩形保护完整眼眉唇，保守脸部包络外全部保护。观察器使用原 resolver，
执行 public CPU + 实际 Vision，逐像素核对方向、覆盖、保护、元数据和错误恢复。

拒绝样本：R01 无脸；R02 独立肖像缩到 64×64 放在 1024 画布中心（512 同步减半）；
R03 重复印刷条从画布左边跨入脸内，轮廓被画布截断；R04 生成的手接触并遮挡
脸颊，接触区肤色相近；R05 哑光条跨唇并延伸到画布右边；R06 大面积不透明
遮挡覆盖主脸。R03/R05/R06 作者矩形和取色区先独立固定，R03 为 ±6 格纹，
其他为平面哑光。它们与正常皮肤有可观察上下文差异，不制造相同输入矛盾标签。
拒绝正确控制是公开路径的全排除/源精确参考，不是自动拒绝能力；单像素破坏
必须被源精确 oracle 拒绝。源家族与派生从不跨 D/H/R 集合。

额外控制：no-op、全排除、关键保护/核心/边缘泄漏、整图调暗/磨平、物体保护
蒙版水平错置、大面积误排除、支持阈值边界、平坦输入、损坏/空/透明输入和恢复。
D01 的正负/双尺寸/双效果还各覆盖八方向×镜像，验证实际输出与 upright 控制
逐字节一致；共 128 个方向效果比较。这是 G0 坐标控制，G2 入选案例仍须自身
完整方向和真实 CPU/Metal 证据。元数据错误控制拒绝伪造颜色空间与平移 extent。

运行 `python3 -B scripts/experiments/seg-g0-complete/run.py all`。
也可按 `development`、`holdout`、`rejection` 或单个家族 ID 执行。
全量期望 20 XCTest（18 个家族 + 2 个工具控制）、48 个正负输入栅格摘要、96 项
纹理控制、12 个拒绝栅格控制、8 个方向汇总与1个输入错误汇总。任何缺失、重复、
skip、零测试或实际失败均不通过。成功运行之后仍须视觉复核与摘要冻结才能签 G0。
超时 600 秒、子进程输出最多 16 MiB 仅保存在内存；对外只输出固定聚合与新测试行号。

数字、分母、冻结和候选预算仍由 [R2](../../../docs/RETOUCH_MVP_REQUIREMENTS.md)拥有。
不下载模型、训练、接入生产、恢复旧去脂或签发全量 SDK/设备/商业资格。

回执通过隔离目录中的原子聚合 JSON 传递，不从可能交错的 XCTest 标准输出解析；
目录随运行清理，只把固定允许字段复制到最终回执。r1 在回执形成前失败，未计通过；
原源码及失败摘要保留在 revisions/r1。输入、指标、阈值和候选均未改变。
