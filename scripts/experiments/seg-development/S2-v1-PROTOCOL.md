# S2-v1：局部平坦度与实测五官保护

登记于 S1-v2 拒绝后、任何 S2 执行前。方法1已用完两版；这是方法2第1版。
新依据是局部 RGB 方差连通区域，不使用方法1的梯度闭环。候选只接收当前像素、
尺寸、脸框及同一次 Vision 请求已有的脸轮廓、双眼和外唇观测；不再检测一次，
不接收独立标记、案例 ID、分组或路径。无新模型、权重、依赖或网络。

固定规则（scale = max(1,width/512)）：

- 三通道分别计算半径 2×scale 的局部方差，全部 ≤2.25 为平坦像素。
- 四连通域面积至少全图 0.0004，紧凑度 ≥0.50，宽高跨度至少 6×scale；
  有效域包围框扩张 6×scale 后保护。只选择中心位于实际脸框内的域。
- 该面积域超过全图 0.035、中心不在内缩脸轮廓或落入扩张唇区时整图退出；
  合格区域超过8块时整图退出。这些只是假设，尚不证明六个拒绝案例可退出。
- 脸置信度 ≥0.8、框宽高 ≥0.2、轮廓12–32点、外唇8–32点、两眼各6–32点且点
  有限。缺失则整图退出。闭合轮廓边界内缩脸宽0.035。
- 编辑带 u∈[.12,.42]或[.58,.88]、v∈[.43,.62]，并在实测双眼最低点下方
  脸高0.04。外唇包围框向四周扩张脸宽/高0.08，区域内一律保护；原生产准入继续生效。

上述内部域不替换冻结评估 ROI。开发12逻辑例、24尺度、48比较及全部硬门槛
不变。先重跑同一 G0 控制，核对新增观测传递不会改变基线；候选与原生产纹理
仍只改一次性副本，实际 public CPU 输出须与观察路径逐字节一致。

本轮只做开发筛选；若失败最多还有 S2-v2，禁止 S1-v3 或第三种方法。
不读留出/拒绝媒体。数值成功后仍须视觉、拒绝与旧完整唇回归，方可选定 G1。
