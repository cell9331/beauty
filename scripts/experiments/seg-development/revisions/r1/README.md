# SEG 冻结开发集的自动候选验证

只读取 G0 已冻结的 D01–D06 正负例及独立标记；不加载 H 留出或 R 拒绝图。
保持 [R2](../../../docs/RETOUCH_MVP_REQUIREMENTS.md) 数值、原图、ROI、尺度及 G0
测量函数原字节不变。候选与计数观察点仅进入一次性 SwiftPM 副本；生产源码、
既有测试和 G0 证据只读。实际 Vision + public CPU 请求没有 host 蒙版。

## 先登记的方法、顺序和选择规则

1. `baseline`：现有纹理输出，不新增保护。先执行冻结 G0 开发控制，再测基线。
2. `S1-v1`：原预检低通梯度 + 闭合连通域 + 紧凑度/有界面积 + 矩形扩张，附原
   保守嘴区。函数逐字节来自只读预检；不根据自然肖像或留出改变常数。它已经
   占用一个方法/一个版本，本次补齐正式开发评估不把同一实现算成新版本。
3. 若失败，记录具体保护/覆盖/方向及视觉问题，停止该版本。新假设及输出逻辑
   须先登记、另存文件并计入原2方法×2版本预算，再执行；不以验收器修正为名
   改算法。不因基线失败删除输入或扩大容差。

数值筛选按全部12逻辑案例、24尺度栅格及48效果比较报告：每例两尺度、平滑与
锐化都通过才计联合通过。六正例至少四例且覆盖三肤色/两光照，六负例全部通过，
任何保护硬失败均拒绝。正例全图源精确记退出而非成功。此处数值通过仍须视觉、
拒绝集与旧完整唇回归等检查，才可签 G1/选择送留出版本；运行器不提前签 G1。

## 观察与自动边界

候选独立文件仅接收当前 canonical RGBA8、尺寸与实际脸框，不接收标记、ID、
分组或文件系统。隔离纹理函数在既有有效脸/参数/预算检查后生成自动排除，
下游处理逻辑不改。已有显式 host 蒙版控制旁路自动候选。零参数不运行候选。
测试观察点使用冻结 G0 同一位置；测 A0 时仅禁用隔离候选，A1 是实际自动输出。
有/无观察点、实际 public 输出与重复输出逐字节等价；先核对每个源栅格 SHA。

XCTest 断言执行、输入、元数据和等价性；算法结果用冻结测量记录，单独决定效果
退出码：0仅为本开发子集的数值门槛通过，1为完整测量后的效果失败，2为执行或
回执不完整。不能把6个测量测试执行成功报告为6个效果通过。

先运行 `python3 -B scripts/experiments/seg-development/run.py baseline`，再运行
`python3 -B scripts/experiments/seg-development/run.py S1-v1`。前者还执行8个冻结
控制测试，后者只执行6个开发家族测量。全量开发回执须有24个输入摘要、48项
自动结果；基线另有81行 G0 聚合。丢行/重复/skip/零测试均拒绝。
所有源树、G0 契约/工具与当前候选/验收器版本都校验摘要；基线控制未通过不得
执行候选。子进程限600秒/16MiB内存日志，私有图只进入忽略目录；持久结果仅聚合。
未执行实际 Metal、正式留出、G2/G3 或生产集成，不修改原去脂状态。
