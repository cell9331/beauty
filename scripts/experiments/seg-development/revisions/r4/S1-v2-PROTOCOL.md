# S1-v2：闭合边界与保守脸颊处理域

登记于读取 S1-v1 开发结果后、运行本版本之前。S1-v1 在真实 Vision 支撑下
眉部/脸侧保护泄漏，部分贴片边界未闭合而漏保护；原版本拒绝且不改写。
这是方法1的第2个输出版本，用完该方法的两版本预算。

新假设：先对同一低通梯度边缘作半径 `2 * max(1,width/512)` 的方形闭运算，
补短缺口，再用原有面积/紧凑度/边界接触筛选和 `8 * scale` 包围框扩张。
原半径、梯度门槛、面积和紧凑度常数保持不变。闭运算先膨胀再腐蚀，图外按非边缘。
此规则不读作者物体或皮肤 ROI；根据开发失败修输出逻辑计为候选版本。

同时只在实际脸框内的两块保守脸颊带允许编辑：横向相对位置 `[.14,.39]`
或 `[.61,.86]`，纵向 `[.44,.60]`。其余均自动保护；已有颜色、边缘、眼唇等
生产准入仍进一步约束。不把这两块内部计算域当作评估 ROI，不移动独立区域。
如果收紧范围造成固定 ROI 覆盖<50%、负例额外排除>25%或方向不足，原样判失败。

只运行原冻结开发12例、两尺度、双效果，选择门槛及所有关键保护不变。
若失败，停止 S1；下一类方法必须有不同依据和独立登记，不再用 S1-v3 调参。
