# S2-v2：按实际脸颊交集限定平坦域退出

登记于 S2-v1 完整开发测量后、S2-v2 执行前。方法2第2版，SEG 总预算最后一版。
S2-v1 48项比较无保护硬失败，但多数正常脸整图退出，正例1/6、负例2/6联合通过。
新假设：不在可编辑脸颊内的平坦区域不应触发这一路线退出；扩张的唇保护区
用于禁止编辑，不等于物体实际跨唇。

只调整 S2-v1 的平坦连通域准入/退出，其他常数、五官保护和冻结验收完全不变：

- 面积筛选后，先计算连通域与候选五官保护后脸颊域的交集，至少6×scale²像素，
  且占该连通域至少10%，才认为是本处理域可见的遮挡候选。交集不是 oracle ROI。
- 原面积上限0.035及中心位于内缩脸轮廓的条件保留；仍不满足则整图退出。
- 跨唇退出仅在上述有效连通域有像素落入实测外唇包围框时触发；原扩张0.08的
  唇保护区继续禁止编辑，不能减少保护来增加处理量。

只使用冻结开发集，所有候选退出都须按原门槛记分；禁止删除困难例、改变参考、
补第三类方法或 S2-v3。开发失败即停止 SEG；通过也只允许按原 G1 补齐视觉、
固定拒绝与旧唇回归，再选择一次留出评估。未运行拒绝/留出前不声称其可通过。
