# Requirements: Beauty v1.25 上睑外观与皮肤语义修复

**Defined:** 2026-10-03
**Status:** planned; 0/16 verified requirements.
**Source request:** 所有者明确要求查论文和开源实现，将去脂与通用同肤色物体
识别纳入新的修复里程碑；取代先前排除这两项的范围建议。
**Core value:** 所有者能在有依据的静图适用域取得有效、局部且受保护的效果，
对证据不足输入得到安全退出，而非错误处理或无依据的效果承诺。

## Active requirements

### 范围与研究准入

- [ ] **RSC25-01**: 所有者可核对冻结的输入域、独立目标/保护 oracle、开发与留出输入、效果下限、覆盖/拒绝标准及预算；完全同观测而反标签的输入不得被许诺为可自动区分。
- [ ] **RSC25-02**: 所有者可取得候选代码、权重、数据来源、依赖、版本/摘要、实际用途和本地执行可行性的逐项准入记录；未通过许可或环境检查的候选不得进入生产依赖或成为强制完成条件。

### 自动皮肤、遮挡与五官保护

- [ ] **SEG25-01**: 所有者可比较既有守卫基线与最多两类解析/遮挡/提示分割候选，得到原尺寸像素保护与皮肤效果的独立结果，而非仅论文分数或模型 IoU。
- [ ] **SEG25-02**: 所有者在冻结且有可观察证据的同肤色物体类别域，能经无主机目标蒙版/点击的自动路径保持物体源精确，同时有效平滑/锐化目标脸部皮肤；辅助提示结果单列，不计自动成功。
- [ ] **SEG25-03**: 所有者对未知、含糊、越界、遮挡证据不足输入能得到预先规定的保守退出，显式排除优先级不受自动结果覆盖；正例必须达到冻结覆盖下限，不能全停取得通过。
- [ ] **LIP25-01**: 所有者在冻结的深肤色低对比唇缘及新增姿态/边缘正负例域，无主机唇蒙版也能完整保护唇部，同时保留有效皮肤处理；不得靠改变唇 oracle 或扩大保护到全部皮肤结项。

### 上睑饱满外观

- [ ] **EYE25-01**: 所有者可核对新的可证伪外观假设与独立目标参考/结构标准，区分上睑饱满外观、光照、化妆、眼袋和黑眼圈；普通眼/皮肤解析与生产亮度残差不得当作目标真值。
- [ ] **EYE25-02**: 所有者在冻结的无提示自动适用域，能得到可控的上睑饱满外观减弱，并同时通过双侧目标、自然风格负例、细节保留、无环纹/暗槽/色带及完整保护检查；局部调暗或安全 no-op 不足以满足本项。
- [ ] **EYE25-03**: 所有者既有字段、零值、Codable 与显式调用保持兼容；新效果不得借用眼高、提睑、眉移动或其他效果取得通过，未通过 EYE25-02 前继续默认隐藏且资格不提升。

### 集成与工程库存

- [ ] **INT25-01**: 所有者可通过现有静图路径使用通过验收的自动保护与上睑编辑；已验证主机并集蒙版持续工作，自动/辅助/原图退出分别报告，其他效果的保护不被纹理蒙版偷偷扩大声明。
- [ ] **INT25-02**: 所有者在资源缺失、超限、损坏、支持无效和随后有效请求中得到明确 typed failure 或既定安全退出，诊断不含原始蒙版/像素/几何/私有路径，无请求间状态泄漏或隐式网络。
- [ ] **BAT25-01**: 所有者可使用新的 SDK-owned 批量验证入口，依据当前默认清单核对实际案例身份，基线 98 默认/99 注册，去脂仍默认排除；显式兼容单独检查，旧 75 项 wrapper 与冻结证据只读。
- [ ] **BAT25-02**: 所有者能从批量结果区分效果失败、基础设施失败、缺失/重复案例与成功；成功必须核对实际输入/输出和固定 oracle，不能仅靠 exit 0 或动态发现后自我认定库存完整。

### 最终验收与一致性

- [ ] **VFY25-01**: 所有者可复现适用尺寸/extent、八方向与镜像、sRGB/alpha、neutral/repeat、双脸选择、无脸/禁用/跳帧与失败恢复；CPU 和真实 Metal-selected 执行分开计数，配置枚举不能替代执行证据。
- [ ] **VFY25-02**: 所有者取得最新代码实际执行的 archive-first 全量 SDK gate：非零测试、零失败、零 skip、全部必选 opt-in；既有失败实验保留身份，另报新候选结果，不重签旧回执。
- [ ] **DOC25-01**: 所有者可从当前计划、taxonomy、产品/架构/安全/可靠性与功能列表核对每项范围和结果；仅两条自动效果需求实际通过后才按完整目标结项，研究完成、辅助成功或隐藏功能不算算法完成。

## Definition of done

全部 16 项必须有各自可复现证据并通过，尤其 SEG25-02 与 EYE25-02 均为
自动效果条件。状态百分比只统计本里程碑，不表示全部 SDK 泛化资格。
Phase 100 先冻结数值、视觉和资源门槛；本文件不是未校准的数字承诺。
已有同源纹理方向门槛为平滑邻接变化降低至少 20%、锐化增加至少 10%；
新输入域须独立提前校准。不能用模型高分、只有变化像素或全图原样代替。

每条研究路线至多两类候选，每候选最多两轮实现。耗尽预算而未通过时停止
该分支并保留失败；其他独立工程项可推进。本里程碑不得自动标记 completed，
须由所有者明确决定追加新假设或调整范围。任何范围调整都保留原未通过项。

## Future / conditional work

- 数据采集、训练、微调、蒸馏：本次不授权；若预训练与无模型候选均不足，
  提出单独用途、许可证、数据、预算与目标方案。
- Core ML / 移动端转换：仅在候选已选、许可通过、实际运行域确定后单独定义；
  不把 CUDA 演示或 Mac 可运行性推导为 iOS 通过。
- 完全同观测的矛盾语义：保留歧义反例；新增点/框/蒙版/参考图是额外信息，
  后续辅助路线成功也不满足无提示自动需求。

## Out of scope

| 项目 | 原因 |
| --- | --- |
| 真实脂肪组织/体积测量、医疗或手术效果 | 当前任务是照片外观修饰；照片亮度并非组织测量 |
| 任意物体、任意光照/姿态、任意肖像零错误保证 | 未定义可辨识信息和覆盖证据，不能作为可兑现完成条件 |
| UI/App、实时视频、3D/NeRF 生产集成、新 GPU backend/shader | 保持 SDK-only 静图主线，候选论文不自动扩大工程范围 |
| 外部分发、商业质量、设备性能承诺 | 所有者本地用途；真实设备/真人输入仍仅可选补充 |
| 第三方网络图像编辑、自动下载资源 | 本地隐私边界；研究阅读不授权上传或隐式取资源 |
