## Goal and pre-edit acceptance

Make the existing `upperEyelidFullnessReduction` relief edit measurably stronger
on an eligible, deterministic convex upper-lid input while preserving the
existing fail-closed, source-owned still-image boundary. Use the v1.21 bounded
v4 implementation at the start of this milestone as the **frozen baseline**;
measure it and the candidate with the same source, support, strength, composer,
and metric. Do not choose a new fixture or threshold after seeing candidate
output.

- **Positive signal:** At strength 0.5, the composed central convexity score
  measured by the existing independent source/after `ReliefModel.analyze`
  path must be at most 35% of the source score **and** improve the normalized
  source-to-output score by at least 10 percentage points compared with the
  frozen baseline. The source score must exceed the current applicability
  minimum. A changed-pixel count or uniform darkening is not sufficient.
- **Negative signal:** Planar illumination and crease-only inputs stay
  source-exact; missing, malformed, closed, occluded, low-confidence, or
  unsupported eyes remain independent source-exact no-ops. The supported
  peer's output must not depend on the rejected eye.
- **Target:** Only independently approved upper-eyelid brow-to-lid support
  pixels may change. Edits must remain spatially nonuniform and retain source
  high-frequency detail; do not move eye aperture, lashes, iris/sclera, crease,
  eyebrow, or face geometry.
- **Protected regions:** Every pixel outside the approved per-eye hard support,
  the other eye if rejected, the eye/lash/iris/sclera and brow/crease guards,
  background, and all alpha bytes remain source-exact. Existing Q16 feathering,
  immutable-source composition, duplicate/collision-to-source behavior, and
  `±16` per-channel ceiling remain. The existing generated continuity ceiling
  (adjacent correction jump ≤5) and texture-energy ratio (≥0.98) may not
  regress. Dimensions, extent, orientation/mirroring, color space, and metadata
  remain unchanged.

The fixed positive comparison starts with the in-memory convex relief fixture
in `BeautyUpperEyelidFullnessEditorTests`; protected-region, continuity, and
texture checks use the existing independent safety fixtures. Add a public
still-image pixel oracle for both facade entries. Repeated runs must be byte
identical. Record only aggregate measurements in durable evidence; raw pixels,
masks, landmarks, image outputs, and private fixture locators stay local.

**Pre-edit baseline check (2026-09-24):** At strength 1 this fixture already
yielded source score `9.3623085`, output score `0.9999072`, ratio `0.1068013`.
That near-floor result cannot discriminate a useful incremental change. Before
any production edit, the same fixture at strength 0.5 yielded source score
`9.3623085`, output score `4.2480761`, ratio `0.4537424`. The fixed v1.24
target is ratio `≤0.35` (and thus at least 10 percentage points below the
frozen `0.4537424` baseline); the full-strength fixture remains a safety and
nonuniformity check. Only these aggregate values persist.

The frozen production baseline is repository HEAD
`20adcdfcb92a3b7e79fcc27333e8fec85374e274` with
`BeautyUpperEyelidFullnessEditor.swift` SHA-256
`e53315723615e3766b99faad283840a8b647f26d67cf5150eb693594de844adb`.
The added half-strength target test failed at `0.4537424` on the unchanged
production baseline before the gain edit. Independent review later found that

correction values at strength 0.5. This review-driven repair occurred after
the first candidate test, and final qualification reruns the strengthened
oracle. Public fixture guards and paired/single-eye pixel comparisons were
also strengthened after review.
