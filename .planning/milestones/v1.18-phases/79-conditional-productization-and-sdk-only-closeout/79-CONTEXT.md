# Phase 79 Context

## Objective

Materialize the failing Phase 78 branch and close v1.18 as an SDK-only
milestone. The public effect remains absent, generic mechanics remain
non-authorizing infrastructure, and the current CPU/GPU/metadata contracts are
verified without introducing a new backend or product surface.

## Locked decisions

- The Phase 78 recommendation `mechanics-only-not-promotion` is authoritative
  for this closeout. No public field, renderer case, preset key, route, SPI,
  resource, or documentation claim may bypass it.
- `BeautyParameters` remains exactly 61 fields, the bundled catalog exactly
  five neutral presets, and `BeautyExampleRenderer` exactly 74 cases.
- `去脂` remains `future` and the `眼睛` branch remains `partial` in the
  SDK-owned taxonomy. The package-only Phase 76/77 mechanics are not a public
  control or efficacy claim.
- Existing canonical input, alpha/extent/color metadata, deterministic
  request-local failure isolation, CPU oracle, selected GPU behavior, typed
  `.metalUnavailable`, and retained `Warp.metal` remain unchanged.
- The closeout records exact absence and nonclaims; it does not manufacture a
  genuine bundle, blinded review, device evidence, commercial approval,
  packaging, shipping, launch, or release-readiness claim.

## Out of scope

The passing 62/5/75 product branch is not selected. UI/Demo, realtime/video,
transparent input, HDR/gain maps, new algorithms, new Metal/GPU APIs, and
physical-device validation remain outside this SDK-only closeout.
