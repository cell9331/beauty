# v1.2 Archive Replay

The v1.2 HTML package is archive-only. Use this sequence from the repository
root:

```bash
python3 scripts/archive-legacy-ui.py verify --output archives/legacy-ui
TMP_DIR=$(mktemp -d /tmp/beauty-v1.2-replay.XXXXXX)
python3 scripts/archive-legacy-ui.py restore --output archives/legacy-ui --destination "$TMP_DIR/legacy-ui"
node "$TMP_DIR/legacy-ui/meituxiuxiu/html/offline-check.mjs"
```

Open the restored files locally for historical inspection. Do not create a
`meituxiuxiu/` or `BeautyDemo/` tree in the active SDK repository. The retained
PNG captures are under `.planning/evidence/v1.2/`; two historical visual gaps
are documented in `11-VERIFICATION.md` and are not current SDK pass evidence.
