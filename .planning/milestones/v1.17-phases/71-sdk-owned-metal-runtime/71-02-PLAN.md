<threat_model>
Security posture: OWASP ASVS Level 1 applies. Any HIGH finding is blocking and
must be mitigated before this plan can complete.

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Internal policy/request → Metal executor | Package callers select an unexposed execution policy and pass validated carriers. |
| CIImage/CVPixelBuffer → byte/texture bridge | Framework-backed input is converted into bounded request-local RGBA8/BGRA data. |
| Metal executor → shared result boundary | Only matching output kind, dimensions, metadata flags, and bounded counts may publish. |
| Metal failure → CPU reference | A failed GPU transaction must not silently invoke or credit CPU work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-71-05 | Tampering | Internal `.metal` request policy | mitigate | Keep policy and executor package-only; preserve public configuration/parameter/preset inventories and run schema scans. |
| T-71-06 | Information Disclosure | Image/texture bridge and diagnostics | mitigate | Use transient bounded carriers, explicit sRGB conversion, aggregate-only result diagnostics, and no raw framework/object output. |
| T-71-07 | Denial of Service | Metal backend conversion/dispatch | mitigate | Reuse request limits, checked row/byte arithmetic, one dispatch, and runtime cleanup before result publication. |
| T-71-08 | Fail-open/Repudiation | Executor error routing | mitigate | Typed terminal errors, exactly-one invocation tests, and static rejection of CPU fallback/retry tokens. |
| T-71-SC | Tampering | Package installs | accept | No package-manager install or dependency change occurs in this plan. |
</threat_model>
