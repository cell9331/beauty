## Trust Boundaries

| Boundary | Description |
|---|---|
| Public BeautyConfiguration → engine factory | Integrator-controlled execution policy selects a package-owned executor. |
| Engine → backend request | Request policy and transient input cross the internal backend boundary. |
| Host Metal availability → public initializer | Framework/device capability determines whether explicit GPU construction can proceed. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
