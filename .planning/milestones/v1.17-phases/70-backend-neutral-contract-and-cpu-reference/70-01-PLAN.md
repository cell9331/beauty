Security posture: OWASP ASVS Level 1 applies. Any HIGH finding is blocking and
must be mitigated before this plan can complete. No package installation,

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Host input → backend request | Untrusted image/frame metadata, dimensions, format, alpha, and normalized parameters enter the contract. |
| Detection/support → backend request | Package-only support crosses transiently; raw values cannot enter result diagnostics or durable owners. |
| Backend result → facade | Output and typed errors cross back with only bounded aggregate diagnostics. |
| Source/test output → owner docs | Only fixed contract statements and aggregate status may persist. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-70-01 | Tampering | Request/result contract | mitigate | Checked dimensions, metadata, canonical carrier, output-kind, and normalized-plan invariants reject malformed requests before execution. |
| T-70-02 | Information Disclosure | Diagnostics and owner docs | mitigate | Non-Codable request-local support plus aggregate-only diagnostics and path/raw-data scans. |
| T-70-03 | Elevation of Privilege | Backend policy | mitigate | Package-only `.cpu` policy, no public config mutation, and no fallback/retry semantics. |
| T-70-04 | Denial of Service | Input boundary | mitigate | Existing finite dimension/pixel ceilings, checked storage arithmetic, bounded aggregates, and fail-closed rejection. |
| T-70-SC | Tampering | Package installs | accept | No package-manager install or dependency mutation occurs in this plan. |
</threat_model>
