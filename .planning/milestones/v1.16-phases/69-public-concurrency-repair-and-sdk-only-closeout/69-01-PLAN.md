| Caller payload → public result | Arbitrary caller/framework output crosses the generic type boundary. |
| Result → concurrent task | A result is transferred to another task and must satisfy Swift's static sendability contract. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-69-01-01 | Elevation of Privilege | `BeautyResult` generic conformance | mitigate | Use conditional `Sendable` constrained by `Output: Sendable`; remove arbitrary unchecked conformance. |
| T-69-01-02 | Information Disclosure | Concurrency test evidence | mitigate | Assert only fixed values/aggregate fields; do not persist payload internals, paths, or image/support data. |
| T-69-01-SC | Tampering | SwiftPM dependencies | accept | No package installation or external dependency is introduced; existing package graph is unchanged. |
</threat_model>
