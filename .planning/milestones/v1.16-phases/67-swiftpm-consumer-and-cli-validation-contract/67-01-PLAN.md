| Boundary | Description |

| Integration fixture → local package | An independent manifest selects which project product and targets are consumable. |
| Generated pixels → public SDK | Synthetic bytes cross the same public still-image facade used by a host. |
| Checker → child processes | Shell launches SwiftPM/compiler output that must remain bounded and non-authoritative. |

| T-67-02 | Information Disclosure | Consumer diagnostics | mitigate | Emit one fixed aggregate line; prohibit pixels, paths, raw errors, and fixture locators. |
| T-67-03 | Denial of Service | Consumer checker child | mitigate | Use a bounded capture, fresh scratch directory, cleanup trap, and fail on nonzero/oversized output. |
| T-67-SC | Tampering | SwiftPM dependency resolution | mitigate | Permit exactly the repository-local BeautySDK path dependency; no remote package install is authorized. |
</threat_model>
