## Artifacts this phase produces

- `WarpControlPoint`: internal `Equatable`, `Sendable` value with normalized `source`, `target`, `radius`, `strength`, and `falloff`.
- `WarpControlPointProvider`: provider protocol for deterministic geometry output.
- `LandmarkGeometryHelper`: helper for center, bounds, distance, and directional movement in normalized image coordinates.
- `FaceShapeWarpProvider`: provider for `faceSlim`, `faceSmall`, `faceVShape`, and `jawSlim`.
- `ChinWarpProvider`: provider for `chinLength`.
- `GeometryConflictResolver`: compound weakening policy for overlapping face-shape points.
- Tests proving caps: `faceSlim 0.60`, `faceSmall 0.45`, `faceVShape 0.50`, `jawSlim 0.60` or a documented value no greater than `faceSlim`, and `chinLength 0.35`.
- Warning code `combined_geometry_weakened` or final equivalent stable code.
