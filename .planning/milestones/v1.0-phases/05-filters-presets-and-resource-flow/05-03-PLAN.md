## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Public SDK resources -> Demo UI state | Demo must present only facade-visible, validated resources and keep missing resources friendly. |
| User interactions -> `BeautyParameters` snapshot | Slider and chip interactions must normalize into immutable SDK snapshots without hidden state layering. |
| Resource failure -> user-facing copy | Copy must be redacted and must not clear current parameters. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-05-03-01 | Tampering | Preset application | mitigate | `applyPreset(_:)` replaces the full represented snapshot and tests assert every displayed field syncs. |
| T-05-03-02 | Information Disclosure | Resource failure UI | mitigate | Empty/error state copy is fixed and redacted; tests reject paths, raw framework errors, internal target names, and JSON payloads. |
