<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Bundled JSON -> SDK values | JSON resources must be decoded, schema-checked, and ID-validated before becoming `BeautyPreset` values. |
| Resource IDs -> resource loader | IDs are untrusted identifiers and must never become arbitrary filesystem paths. |
| Resource failures -> public errors | Failures crossing the SDK facade must be typed and redacted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-05-01-01 | Tampering | `BeautyResourceManifest` and preset JSON | mitigate | Enforce `schemaVersion == 1`, positive content versions, conservative ID validation, and manifest reference validation. |
| T-05-01-02 | Information Disclosure | Resource error descriptions | mitigate | Use `BeautyError.resourceNotFound` and `BeautyError.presetDecodeFailed` with existing redaction; tests reject raw paths. |
| T-05-01-03 | Elevation of Privilege | Resource ID traversal | mitigate | Treat IDs as identifiers only; load fixed bundled resources through `Bundle.module`; tests include traversal-like IDs. |
| T-05-01-SC | Tampering | Package installation surface | accept | This plan adds no package-manager dependency or external resource download. |
</threat_model>
