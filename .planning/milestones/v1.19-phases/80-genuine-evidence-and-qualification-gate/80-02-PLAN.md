| filesystem entries → admitted assets | Traversal, symlinks, replacement, and TOCTOU may substitute private evidence. |
| manifest/review values → durable schema | Sensitive key/value injection may smuggle paths, prose, geometry, or identity. |
| subprocess → validation record | Raw child stdout/stderr can leak paths or content. |
| contract/review/baseline hashes → decision | Tampering can detach the decision from the frozen rubric/editor. |
| mechanics/generated inputs → evidence weight | Spoofed classification could promote non-genuine data. |
| decision/public tree → Phase 81 | Fail-open logic or public drift could activate the effect without authorization. |
