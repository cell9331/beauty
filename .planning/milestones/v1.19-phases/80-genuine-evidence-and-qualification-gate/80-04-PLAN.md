## Trust Boundaries

| Boundary | Description |
| --- | --- |
| environment locator → evaluator | The locator is untrusted and must never be emitted. |
| manifest relative assets → file descriptors | Traversal, symlink, replacement, size, hash, and TOCTOU attacks can substitute evidence. |
| asset/metric/category rows → aggregates | Duplicate, missing, reordered, or borrowed rows can hide a failing fixture/category. |
| evaluator stdout/temp files → summary | Raw private results and paths must be reduced and deleted. |
| rights/metric hashes → later review | Tampered admission could cause review of a different candidate. |
| generated origin → genuine weight | Origin spoofing could convert mechanics to evidence. |
| admission pass → public activation | Bundle admission alone is insufficient; review and final binding remain mandatory. |
