## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Bundled resource JSON -> `BeautyResources` | Manifest and preset JSON are data inputs and must be schema-validated before use. |
| Resource identifier -> bundle lookup | Logical IDs must not become arbitrary filesystem paths. |
| Current bundled resources -> final ledgers | Evidence for bundled metadata filters must not be overstated as external package support. |
| Resource tests -> security evidence | Tests must verify behavior instead of relying only on policy text. |

| T-25-02-01 | Tampering | `BeautyResourceManifest.isValidResourceIdentifier` | mitigate | Run focused resource tests and keep conservative identifier validation plus traversal-like ID rejection. |
