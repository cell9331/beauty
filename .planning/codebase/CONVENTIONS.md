# Coding Conventions

**Analysis Date:** 2026-06-10

## Naming Patterns

**Files:**
- Swift source files currently use PascalCase: `BeautyDemoApp.swift`, `ContentView.swift`.
- Root contract documents use uppercase descriptive names: `ARCHITECTURE.md`, `PRODUCT_SENSE.md`.
- Long-form docs use numbered snake_case names: `docs/04_development_spec.md`.
- GSD generated map files use uppercase names under `.planning/codebase/`.

**Functions:**
- Current Swift code has no standalone functions.
- Future Swift APIs in contracts use Swift camelCase examples such as `processImage`, `processFrame`, and `reset`.

**Variables:**
- Current Swift code has only `body` computed properties generated by SwiftUI.
- Future public model fields in `DESIGN.md` use lower camelCase such as `preferredProcessingSize`, `maximumFaceCount`, `skinSmoothing`, and `filterIntensity`.

**Types:**
- Swift types use PascalCase: `BeautyDemoApp`, `ContentView`.
- Future SDK types in root contracts use the `Beauty` prefix for public/domain models: `BeautyEngine`, `BeautyParameters`, `BeautyConfiguration`, `BeautyError`.
- Target names are PascalCase: future `BeautyCore`, `BeautyRender`, `BeautyDetection`, `BeautyEffects`, `BeautyResources`, `BeautySDK`.

## Code Style

**Formatting:**
- No explicit SwiftFormat, SwiftLint, `.editorconfig`, or formatting config exists.
- Current Swift files use Xcode default formatting with 4-space indentation.
- Current source is minimal and generated by Xcode.

**Linting:**
- No lint tool is configured.
- Xcode build settings enable many compiler warnings in `BeautyDemo/BeautyDemo.xcodeproj/project.pbxproj`.
- No standalone lint command exists.

## Import Organization

**Order:**
1. Framework imports at top of file.
2. Declarations below imports.

**Current examples:**
- `BeautyDemo/BeautyDemo/BeautyDemoApp.swift` imports only `SwiftUI`.
- `BeautyDemo/BeautyDemo/ContentView.swift` imports only `SwiftUI`.

**Path Aliases:**
- None.

**Future boundary rule:**
- `BeautyDemo` should import only `BeautySDK` from the SDK package, never internal targets such as `BeautyCore`, `BeautyRender`, `BeautyDetection`, `BeautyEffects`, or `BeautyResources`.
