# v1.22 post-closeout status and tool audit — 2026-09-23

## Question

Can the completed Phase95 closeout simply be rerun and re-signed after the
2026-09-23 face-mapping repair, while preserving the historical receipts?

## Findings

1. **Historical completion remains valid for its signed snapshot.**
   `95-COMPLETE.json` records input digest
   `56d33c8d9ddfbd6899287feeac501139d6ea1bac05250ca8982fa861482ed6f0`.
   The milestone ledger reports 7/7 phases, 33/33 plans and 11/11 in-scope
   requirements. Later changes do not retroactively erase that result.
2. **The current tree is not covered by that receipt.** The present input
   digest is `2d19ba0347e147ef8c11e8992319b95e034debfda16f435752432d8efa2a37d7`.
   Compared with the original binding, exactly six normative files differ:
   `VisionFaceDetector.swift`, its test, `DESIGN.md`, `PRODUCT_SENSE.md`,
   `SECURITY.md`, and `RELIABILITY.md`. `verify-complete` returns
   `review_missing_or_stale`. The separately recorded 938/0/0 gate does not
   supply new portrait or independent-review credit.
3. **The existing closeout command is one-time.** `phase95-genuine-gate.py`
   rejects an existing `95-CLOSEOUT-BINDING.json` or
   `95-CLOSEOUT-CHECKS.json` before executing. `run-clean-65-portrait.sh`
   writes classification to the existing `95-CLEAN-65-REPORT.json` path.
   `phase95-closeout-evidence.py` publishes receipts exclusively and its
   `finalize` destination is the existing `95-COMPLETE.json`. The old evidence
   is required to remain immutable. Direct rerun/re-sign is therefore not a
   valid next action.
4. **Scope decision is separate from status.** There is no active milestone
   or automatic requirement to reopen v1.22. If the owner needs the same
   Phase95 completion claim for the current code, a separately scoped,
   append-only evidence path and fresh independent reviews/portrait gate are
   required first. If not, the mapping fix remains a verified post-closeout
   repair and the next milestone can be chosen without claiming the old
   receipt covers current code.

## Disposition

Correct the current administrative wording that treated renewed review and
closeout identity as an unconditional next step. Keep the Phase95 contract,
receipts, original portrait report and archived evidence unchanged. No new
effect qualification, device result, or distribution claim is made.
