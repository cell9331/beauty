# v1.18 Post-Archive Milestone Re-Audit

## Verdict

`gaps_found`. The selected failing public-absence branch is still the safe
runtime/product outcome: `去脂` is not public, `眼睛` remains partial, and the
SDK surface remains 61 fields, five presets, and 74 renderer cases. The prior
audit nevertheless overstates requirement closure and cross-phase wiring.

This report is a new post-archive review. It does not edit or replace the
immutable archived audit or phase evidence.

## Highest-Priority Findings

### 1. Phase 75 closed two requirements contrary to its own gate

`75-02-PLAN.md` says to leave `EVID-01` and `EVID-02` pending when no complete
rights-approved local bundle is available. No such bundle was supplied, yet
`75-02-SUMMARY.md`, `75-VERIFICATION.md`, and archived `REQUIREMENTS.md` all
mark both complete. The contract/evaluator mechanics are real, but the
requirement disposition is internally inconsistent. The strict
original-intent score is therefore 14/18, not the historical 16/18.

### 2. Phase 78 to Phase 79 is document-token coupling

`check_phase79_closeout_boundaries.py` reads the mutable
`78-VERIFICATION.md` and searches for three strings. It does not invoke the
candidate decision program or validate a machine-produced decision report and
contract hash. Current absence is correct, but the checker does not prove that
the materialized branch came from the actual Phase-78 decision.

### 3. Phase 76 support never reaches the Phase 77 editor end to end

`detectWithUpperEyelidSupport(...)` is called only by detection tests.
`BeautyUpperEyelidFullnessEditor.edit(...)` is called only by editor/safety
tests, which manually construct support resolutions. The individual mechanics
are green, but the archived audit's observation-to-composition flow does not
exist as a caller or integration test.

### 4. Phase 78 does not bind its baseline to Phase 77 mechanics

The Phase-78 script names `deterministic-editor`, but does not execute or hash
Phase-77 code/output evidence. Its frozen evaluation values are caller-supplied
booleans. Missing genuine evidence still correctly produces no promotion, but
this is not a promotion-safe candidate binding.

### 5. The archived Phase-79 gate is not location-independent

After archival, its live mode still resolves `.planning/phases/...` and now
fails with 24 missing-artifact reasons. This is a reproducibility defect in
the audit tooling, not a reason to reactivate or edit archived evidence.
