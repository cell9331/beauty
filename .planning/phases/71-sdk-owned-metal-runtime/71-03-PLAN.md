<threat_model>
Security posture: OWASP ASVS Level 1 applies. Any HIGH finding is blocking and
must be mitigated before this plan can complete.

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Active source tree → static preflight | New runtime/backend code must remain in authorized SwiftPM target paths and resource ownership. |
| Preflight → mandatory wrapper | Aggregate gate status controls whether consumer/oracle/full-child work can run. |
| Implementation → owner docs | Only measured, privacy-safe runtime facts may become durable contract text. |
| Host Metal availability → evidence | Unavailable hosts must be explicit and cannot lend success to GPU behavior or parity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-71-09 | Tampering | Runtime source/target placement | mitigate | Regular-file ownership checks, authorized shader inventory, target/import scans, and forbidden-target mutation self-tests. |
| T-71-10 | Information Disclosure | Static logs and owner docs | mitigate | Bounded temporary logs, fixed aggregate markers, privacy scans, and no raw framework/raster/path persistence. |
| T-71-11 | Denial of Service | Preflight/wrapper execution | mitigate | Bounded command output, finite focused filters, fail-closed positive execution, cleanup traps, and existing no-skip transcript limits. |
| T-71-12 | Repudiation | Availability classification | mitigate | Emit separate `metal_available`/`metal_unavailable` status and never count unavailability as GPU success. |
| T-71-SC | Tampering | Package installs | accept | No package-manager install or dependency change occurs in this plan. |
</threat_model>
