<threat_model>
Security posture: OWASP ASVS Level 1 applies. Any HIGH finding is blocking and
must be mitigated before this plan can complete.

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Caller/request dimensions → Metal allocation | Untrusted dimensions and byte carriers can trigger GPU allocations. |
| SDK runtime → Apple Metal device/queue/library | Platform availability and resource creation can fail or return unusable objects. |
| Command encoding/completion → SDK result | Command status and synchronization determine whether output may be published. |
| Runtime bytes → tests/ledgers | Raster bytes and framework detail must remain transient and aggregate-only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-71-01 | Tampering | `BeautyMetalRuntime` allocation/dispatch | mitigate | Validate finite dimensions, checked RGBA8 arithmetic, pixel ceilings, texture usage, and bounded thread-grid before allocation/encoding. |
| T-71-02 | Information Disclosure | Runtime result/test observations | mitigate | Keep device objects, textures, command buffers, and bytes request-local; publish only typed errors and bounded lifecycle counts. |
| T-71-03 | Denial of Service | Command queue and resource scope | mitigate | Use one bounded dispatch, explicit command completion, finite input ceilings, and unconditional cleanup on all exits. |
| T-71-04 | Availability/Fail-open | Missing Metal device or pipeline | mitigate | Return `.metalUnavailable`/typed terminal errors; never invoke CPU fallback or report GPU success. |
| T-71-SC | Tampering | Package installs | accept | No package-manager install or dependency change occurs in this plan. |
</threat_model>
