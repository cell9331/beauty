# Plan 04-01: Add Public Metadata and Result Contracts

## Phase Goal

**As a** SDK host and Demo user, **I want to** preserve input metadata and receive safe detection summaries, **so that** orientation, mirroring, and face-state degradation can be diagnosed without leaking sensitive geometry.

<objective>
Create the public metadata/result foundation for Phase 4.

Purpose: PIPE-05 needs explicit orientation and mirroring metadata, while PIPE-07 needs no-face and partial-face state to be visible as structured, redacted result metadata.
Output: Public `BeautyInputMetadata`, `BeautyInputSource`, `DetectionAvailability`, `DetectionDegradationReason`, `BeautyDetectionSummary`, additive `BeautyResult` metadata, and metadata-aware `BeautyEngine` result overloads.
</objective>
