## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vision framework -> BeautyDetection | OS-provided face observations and errors enter SDK internals. |
| BeautyDetection -> BeautyCore public summary | Internal face geometry is reduced to public availability, counts, timings, and reason codes. |
