## Artifacts this phase produces

- `CoordinateSpace`: internal `BeautyDetection` enum for `visionNormalized`, `imageNormalized`, `imagePixel`, `textureUV`, `preview`, and `mirroredPreview`.
- `CoordinateMapper`: deterministic transform utility using `BeautyInputMetadata`, image extent, and optional preview extent.
- `CoordinateMapper.MappingError`: internal error mapped to public `DetectionDegradationReason.mappingFailed`.
- `ImageNormalizedPoint` and `ImageNormalizedRect` or equivalent internal value types with top-left origin.
- `CoordinateMapperTests`: synthetic point/rect matrix tests.
- `FaceObservationMappingTests`: tests proving Vision observations are normalized before face selection.

| T-04-03-02 | Information Disclosure | Mapped face geometry | mitigate | Keep all mapped coordinates internal to `BeautyDetection`; static source checks reject public point/rect/landmark APIs. |
| T-04-03-03 | Denial of Service | Invalid extents or mapper errors | mitigate | Return typed mapper errors and map them to `mappingFailed` degradation reasons. |

</threat_model>
