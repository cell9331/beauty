## Trust Boundaries

| Boundary | Description |
| --- | --- |
| environment locator → local evaluator | Private bundle/review locations are untrusted, ephemeral inputs and must never enter durable output. |
| manifest/review JSON → canonical records | Untrusted keys, values, types, duplicates, encodings, and non-finite numbers cross into hashes and decisions. |
| relative asset record → filesystem descriptor | Traversal, symlink, replacement, oversized, and TOCTOU content crosses into evidence admission. |
| private child/process output → repository evidence | Child errors, stderr, paths, transcripts, and sensitive values must be reduced to normalized aggregate reasons. |
| review/baseline hashes → promotion decision | Tampered rubric, review, semantic contract, evaluator, source/evidence baseline, or public surface must fail closed. |
| generated/mechanics evidence → genuine qualification | A spoofed admission mode must never gain genuine weight. |
| decision → later public phase | Anything except the exact passing decision must preserve 61/5/74 and block Phase 81. |
