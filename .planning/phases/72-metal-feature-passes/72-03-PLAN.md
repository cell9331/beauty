<threat_model>
Security posture: OWASP ASVS Level 1 applies. Any HIGH finding is blocking and
must be mitigated before this plan can complete.

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Provider units → composition owner | Request-local teeth/sclera proposals are validated, owned, and reduced to one canonical carrier. |
| Canonical composed carrier → Metal backend | Only immutable RGBA8 bytes and six bounded aggregate counters cross the executor boundary. |
| Metal failure → result publication | A terminal GPU error must not publish partial output or suppress independent CPU-owned siblings. |
| Active source/owners → feature preflight/wrapper | Static and archive-first gates decide whether package feature evidence may proceed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-72-09 | Tampering | Local-retouch composition ownership | mitigate | Keep `BeautyLocalRetouchCompositionOwner` as the sole proposal/collision owner; Metal receives only its canonical output and aggregate summary. |
| T-72-10 | Information Disclosure | Local-retouch payloads, tests, and docs | mitigate | Reject raw masks/proposals/landmarks/pixels/locators in static scans; use generated in-memory fixtures and aggregate-only diagnostics. |
| T-72-11 | Fail-open | Per-unit failures and GPU terminal errors | mitigate | Preserve owner-local sibling continuation, typed terminal backend errors, no partial publication, no retry, and recovery/resource-counter assertions. |
| T-72-12 | Tampering/Denial of Service | Feature preflight and wrapper ordering | mitigate | Bounded temporary logs, mutation-tested scope/cleanup/privacy checks, exactly-once preflight invocation, and zero-failure/zero-skip transcript accounting. |
| T-72-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installation or dependency change is part of this plan. |
</threat_model>
