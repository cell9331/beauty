# 山根自动测量最小验收范围复核

结论：**NOSE-02 不要求对单张照片取得 certified worst-case detector error。**
把它设成必要前提，会把当前二维图像效果验收扩大成未要求的检测器认证问题。
但这不允许把检测点当作无误差物理真值，或用任意内部纹理运动代替宽度。

本次仅读现有需求、Phase93 CONTEXT、当前执行口径、语义澄清、forward 语义评审、
公开 mesh 索引评审及 correlated-change 定义；未读私图、执行模型或联网。
这是范围复核，不是测量批准、效果通过或新执行许可。

## 原始契约与后来选用的充分条件

[NOSE-02](../../REQUIREMENTS.md)要求原 root ROI 内可检测的缩窄、控制独立性、
保护区、cap 与 fail-closed。[Phase93 CONTEXT](../93-distinct-nose-bridge-and-root-repairs/93-CONTEXT.md)
要求 source-side anatomical justification；它没有要求个体真实骨宽或检测器零误差。
[forward 语义评审](95-ROOT-FORWARD-SEMANTIC-REVIEW.md)允许结构位置或有依据的宽度标记，
要求保留定位不确定性。[当前语义澄清](95-ROOT-SEMANTIC-CLARIFICATION.md)没有把
“认证的最坏误差界”列为产品必须取得的证书。

该澄清中“预测器本身不提供 certified bound”应解释为不能作这种保证，不能反向
推导“没有 certified bound 就不得自动完成”。区间计算的保守性是相对于明确、
经验证的测量模型；它不等于对所有现实照片与隐藏解剖解释给出无条件数学保证。

| 必须保留 | 可版本化替换的测量选择 |
| --- | --- |
| 原 source、ROI、全图宽单位、16 Q16、所有 siblings 与保护/目标变化谓词 | 16 个行中心、12/16 覆盖、特定支持长度和等权对象属于具体方案；改变时必须明确新聚合含义，不能只修改旧最低行数 |
| source 先确定具有宽度意义的左右结构/标记，输出不重选对象 | 绝对物理解剖外边界、人工标注、特定 Vision 或 mesh 方法都不是唯一方式 |
| 定位与像素对应的不确定性有依据且进入最终计算 | 全外侧仿射背景、固定拟合噪声、半像素区间、固定搜索范围都不是天然产品常数 |
| 不借无关部位或内部纹理制造 root 缩窄 | segment 两端严格同侧是已试方案的保守充分条件，不是普适解剖定理；不能因其失败直接撤销，替代规则仍需独立反例依据 |
| 实际输出像素、neutral identity、全部比较、重复性与元数据 | 特定模板、source 定位器、水平/二维对应算法可以替换；模型必须适用于被比较的实际路径 |

历史定义及其失败不变；上表不是对当前冻结实现的即时豁免。

## 最小有效自动测量定义

1. **Source 语义注册。** 在看任何输出前，以冻结的通用规则形成宽度标记及其
   不确定集合 H。左右标记须表示同一山根可见形态的两侧，或经过独立验证、
   确实定义该形态宽度的标记。ROI 内、网格相邻、镜像、置信分高或可追踪本身
   都不充分。保留适用的内/外候选解释；不要求枚举不可观察的任意隐藏解剖。
2. **同一位置的实际像素对应。** Source、neutral、candidate 和全部 siblings
   使用同一 H、cohort 与权重。对同一 source 位置 s 测 forward 位置 f(s)，
   再计算参考宽度减 candidate 宽度。可使用已审查的 shared-source 差分，避免
   将同一位置误差当两份独立误差重复扣除；不能用场的意图供应正效果。
3. **保守全比较。** 对每个适用解释保留完整位置/对应区间，先按冻结权重汇总
   有符号宽度变化，再按全图宽转换 Q16。Source 与 neutral 的收缩下界均须
   达到16；每个 sibling 的总体有符号差区间与零的距离均须达到16。原目标变化、
   保护、元数据等仍为 conjunction。未知角色、缺失必需对应、固定外形而仅内部
   收缩、纯光度变化、共同平移或复制 sibling 不能通过。

上述定义需要一个可执行、预先确定并独立验证的模型，不需要每张照片的一份
绝对物理真值证书。有限测试也不能被描述成已证明所有照片的最坏误差界。

## 固定公开 mesh 候选能否取得资格

**可以作为自动注册的语义先验，不能仅凭候选索引直接成为宽度真值。**
公开资产/静态索引关系已经独立核对，不应反复重做。尚缺的是候选与实例可见
山根形态的联系，以及足以支撑该联系的定位/歧义处理。

可执行路线是：固定模型及候选链提供初始语义位置，source-only 的可见形态检查
决定哪些轮廓/标记解释仍适用，并形成位置区间或候选集合；随后实际像素追踪
这些 source 位置。若 source 可见的外侧解释仍合理，不能因内侧候选更易移动而
将其舍弃。若预测落在内部纹理、眼区或不可见区域，则扩展合理不确定性或弃权，
不能靠缩小窗口或换链取得通过。

这里可采用经过独立真值验证的条件化误差模型与实例适用性检查，无需要求
预测器发布单照片的 certified worst-case 误差。特别应区分：

- mesh 预测偏差；
- 从 source 可见结构定位标记的不确定性；
- 栅格量化和实际 output 对应误差。

不能把第三项的半像素误差冒充第一项。也不能把人为设置的搜索半径、平均误差
或重复推理稳定性直接命名为保证包含真实边界的区间。若 mesh 只作语义提示而
最终位置由 source 可见证据确定，可以避免让预测器独自承担精确边界定位任务。

## 下一步收敛到一个实现

在依赖恢复期间即可实现一个 source-only 注册器接口，先用生成的预测输入测试，
将内/外候选、可见性/部位判断、定位集合和失败理由放在同一版本中。生成器须
独立声明真实轮廓；预测输入另加受控偏移、错误内侧链、遮挡及强内部纹理。
正例应能取得有用集合，固定外轮廓/移动内部纹理必须失败；不能仅证明预测输入
与自己复制的索引一致。之后接入同一个已绑定模型，验证运行与实例适用性。

一次测量修订集中完成这套注册、实际像素对应、完整 sibling/保护比较和已有
独立评审/driver 接入，不为每个设计假设再建立一条循环批准链。若具体 source
不能满足这个已验证模型，则记录明确的不可用原因；不能承诺已有照片必然通过。

当前没有有效 source 注册或新效果通过。这是仍需实现/执行的证据缺口，不是
等待所有者标注，也不是要求取得检测器的普适数学认证。
