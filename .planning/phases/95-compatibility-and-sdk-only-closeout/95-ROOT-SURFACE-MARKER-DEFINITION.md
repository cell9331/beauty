# 山根顶部表面标记跨度：操作定义

日期：2026-09-22。状态：实现用定义，尚无原图效果通过信用。本文件只定义测量对象、
source cohort 与解释边界；不是测量准入凭证，不新设审批链，不覆盖历史观察。
本次核对仅使用公开 canonical 模板及文献，没有读取私有人像。

## 1. 为什么不再要求每行存在最外侧亮度边缘

山根顶部宽度、山根基底宽度和鼻翼宽度不是同一个量。2020 年的原始研究将
glabella-radix 的顶部宽度对应眉鼻美学曲线，将基底宽度对应鼻侧面与面颊的交界；
其外观评价也包含美学曲线的间距变化。因此，顶部变窄而基底不动，不能自动被
判为没有山根整形效果。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7671270/)

人体测量的鼻根宽度另有双侧 maxillofrontale（mf–mf）定义，与鼻翼宽度分开。
该定义帮助澄清概念，但不能据此把任意 MediaPipe 索引称作已验证的 mf 点。
[鼻部二维测量原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10000550/)

本项目本次采用的量是：**原山根 ROI 内，原图固定的上鼻背双侧表面标记之间的
水平跨度变化**。这是用于局部图像整形的顶部外观几何代理，不是物理骨宽、整个
鼻侧基底宽度或医学 mf–mf 测量。标记不必落在可见亮度跳变上，也不能由最暗
像素、最强内部纹理或输出效果反向挑选。

关键点约束局部图像变形具有现成实践：面部变形研究采用语义关键点与 MLS 做
鼻等部位缩小，TikTok 的 Face Stretch 使用面部模板关键点控制局部比例。
这些来源支持工程方法，不证明本项目具体索引具有官方解剖命名。
[算法原始论文](https://arxiv.org/abs/1910.13671)、
[TikTok 官方实现说明](https://effecthouse.us.tiktok.com/learn/guides/workspace/objects/face-effects/face-stretch)

## 3. 固定 source cohort

以下规则必须在读取各效果输出前执行；只使用原 source 的检测结果、既有 ROI
和既有眼区排除信息。模型、原 source、坐标转换及 ROI 身份沿用受审查的读取链。

1. 每条链有两段，段序号 `s = 0, 1`。每段取16个固定中点参数
   `t_j = (j + 0.5) / 16 = (2j + 1) / 32`，其中 `j = 0..15`。
   在左右两条链的对应段上分别做二维线性插值：
   `p(side,s,j) = (1-t_j) * vertex(side,s) + t_j * vertex(side,s+1)`。
   两侧同一 `(s,j)` 构成一对，共32对；不重复段端点。
2. 模型坐标通过既有、已修正半像素约定的转换进入 canonical 全分辨率图像。
   不在512缩略图宽度上报告效果量，不把图像左右误作人的解剖左右。
   本次源图评分前的实现修订：每侧插值点的 Y 按 `floor(y+0.5)` 固定为最近
   整数像素行，然后沿同一条原 mesh 段重新求该 Y 的 X；超出段端点则整个
   几何注册不可用，不外推。这避免把分数行的二次图像插值冒充真实 sampler。
   所选对仍由原固定参数决定，不按输出或纹理质量移动/重选；若不同参数落到
   相同栅格位置，保留全部原参数权重，不去重后重新均分，也不算独立观察。
3. 对每个原图标记中心 `(x,y)`，定义闭合支撑框
   `P = [x-11,x+11] × [y-11,y+11]`。这给21像素跟踪窗口留下插值支撑余量；
   它是跟踪支撑边界，不是检测器位置误差证书。
4. 只有左右两个 `P` 都完整位于**原有**山根 ROI 内、原图范围内，并且都与
   既有向外取整/扩张的眼区排除矩形没有交集时，才保留这一对。接触排除框边界
   也算有交集。复用既有 expanded-eye 定义，不再另选一套眼框或更窄排除范围。
5. 两侧源图 X 跨度须至少8像素，这是预先固定的最小可分离标记跨度。
   source 裁剪后保留全部合格对，稳定顺序为 `(s,j)`；至少4对才可尝试评分。
   少于4对报告 `unavailable`，不能缩小窗口、排除框或按同图结果重选链来凑数。
   4对是此跟踪测量的最小支撑规则，不是原产品要求或新的12/16行替代硬指标。
6. 注册对象随后冻结。各输出不能重新检测后挑点、按残差删除不利对，或只留下
   效果大的采样。任一已注册对无法可靠跟踪时，该次完整测量不可用；不能按剩余
   点重新归一化后签发通过。

32对是预先固定的模板采样密度；它们相邻且相关，不能视为32次独立统计观察。
source 裁剪所得 cohort 只定义原 ROI 内可观察的该段表面，不能外推到眉部、整个
鼻背或被排除区域。保留的 pair 数量不改变该声明范围。

## 4. 实际效果量与输出对应

对保留的 `N` 对标记，权重固定为 `1/N`。令 `w(role,i)` 为同一对源图表面位置
在对应角色的**实际输出像素**中跟踪得到的右侧横坐标减左侧横坐标；两侧身份在
source 固定，不能逐输出重新排序以掩盖交叉。

`D(role) = (1/N) * Σ [w(role,i) - w(candidate,i)]`。

先在像素单位传播定位/跟踪误差并形成有符号区间，再使用**原 canonical 全图宽**
归一化为 Q16。维持原16 Q16门槛：source、neutral相对于candidate的收缩下界
至少16；三个原 sibling 各自差区间到零的距离至少16。原比较对象、ROI、目标信号、
保护区、metadata、确定性和失败拒绝要求均保留。

不能用变形 provider 计划移动的控制点来填入 `w`。水平 sampler 只用于确已满足
水平采样条件的路径；存在纵向位移的 sibling 必须使用适用的二维对应。使用二维
跟踪时，需要支撑、残差、前后向一致性和不可用分支；跟踪 API 返回成功本身不够。
[OpenCV 官方跟踪正确性说明](https://docs.opencv.org/4.x/d4/dee/tutorial_optical_flow.html)

模型预测只能提出源图语义表面位置，不能单独提供亚像素对应精度。误差与接受
规则应通过独立已知变形的生成输入验证；不得把重复运行一致冒充真实定位误差界。

## 5. 必须覆盖的独立反例与解释边界

- 已注册表面标记与其支撑不动，只有内部斑点或暗度质心移动：不能通过。
- 几何不变，仅照明、阴影、肤色或高频纹理变化：不能获得收缩信用。
- 已知真收缩应被检测；零变化、扩张、共同平移、左右交叉和阈值附近正反例
  应给出正确结果；同一冻结标记必须用于全部 sibling 比较。
- 错误先验、遮挡、重复纹理歧义、支撑越界或任一输出跟踪失败应拒绝；不能
  因有32个密集点而平均掉系统性偏差。
- 顶部语义表面带实际收缩、外侧基底保持不动，可以符合本定义。反例若只因
  “最外边没动”便拒绝，实际又换回了基底宽度。相反，仅内部纹理变动不能
  因重新命名为顶部而获得通过。

生成验证能够证明给定语义表面与采样模型下的测量行为，不能证明任意自然照片
的绝对解剖真值。本方法的最终声明限定为既定 owner-local 输入、原 ROI 与上述
顶部表面跨度；不增加临床测量、通用检测、商业视觉质量或外部分发资格。
