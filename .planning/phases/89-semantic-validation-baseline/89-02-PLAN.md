## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Local fixture privacy | Authorized portrait bytes enter canonical decode but only aggregate opaque summaries may leave the request. |
| Path/input admission | Caller paths and every discovered image/output are untrusted until regular-file, descendant, inventory, freshness, decode, and dimension checks pass. |
| Report leakage | The JSON encoder is an allowlist boundary between request-local image data and ignored aggregate evidence. |
| Threshold manipulation | Verdicts consume only the pre-frozen manifest integers and generated boundary tests; live measurements cannot modify thresholds. |
| Stale/missing output | Fresh-run window, exact inventory, atomic write, and distinct infrastructure status prevent stale or partial credit. |
| Transcript persistence | Comparator output is fixed aggregate status; raw errors and child output are forbidden. |
| Owner-only evidence | Report claims are limited to owner-local automated still-image semantic validation. |
