# Plan 01-01: Create Swift Package Target Structure and Public Facade

<objective>
Create the buildable `BeautySDK` Swift Package skeleton with required internal targets and a public facade target so downstream plans can add models, engine behavior, and tests inside a stable package graph.
</objective>

<user_story>
As a host app developer, I want to import a local `BeautySDK` package product, so that SDK integration starts from the same facade boundary a real app will use.
</user_story>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| Internal targets become the integration API | medium | Add facade import smoke test and keep Demo/import scans in later verification. |
| SDK targets accidentally depend on SwiftUI/UIKit | medium | Create SDK targets without UI imports and include static scans in verification. |
| Package manifest omits required modules | high | `BeautySDK/Package.swift` must declare all required internal targets and test targets. |
</threat_model>
