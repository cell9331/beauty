# Plan 01-04: Add Foundation Package Tests and Build Verification

<objective>
Close Phase 1 by broadening and running the foundation verification suite, proving every Phase 1 requirement and context decision is covered, and recording build/test/static-scan evidence in the repository ledger.
</objective>

<user_story>
As a maintainer, I want automated evidence that the SDK foundation works through the public facade, so that later phases can build on a stable package contract.
</user_story>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| A requirement is planned but untested | high | Map SDK-01 through SDK-07 to test or static-scan evidence. |
| Demo accidentally imports internal SDK targets | medium | Run forbidden import scans before completion. |
| SDK targets gain UI dependencies | medium | Run SwiftUI/UIKit scans against SDK source targets. |
| Verification claims success despite local Xcode destination failure | medium | Use explicit simulator destination when building Demo; otherwise record exact failure. |
</threat_model>
