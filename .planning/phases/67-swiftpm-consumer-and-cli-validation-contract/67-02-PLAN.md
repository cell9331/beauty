<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments → renderer | Untrusted flags select local inputs, cases, backend token, and output destination. |
| Local image files → public SDK | Files are enumerated and decoded before bounded public processing. |
| Renderer → filesystem/report consumer | Generated PNGs and JSON become disposable machine-readable evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-04 | Tampering | Argument/case/backend selection | mitigate | Strict single parser, exact case membership, CPU-only token, duplicate-value rejection, and no silent fallback. |
| T-67-05 | Information Disclosure | Diagnostics and JSON report | mitigate | Sorted allowlisted fields and bounded relative labels; prohibit paths, pixels, masks, landmarks, coordinates, framework errors, and private metadata. |
| T-67-06 | Tampering | Generated output matrix | mitigate | Atomic write, re-open/decode, byte-count/dimension checks, exact expected basename inventory, and reconciled counts before exit 0. |
| T-67-07 | Denial of Service | Input enumeration/rendering | mitigate | Regular supported-extension inputs, duplicate-stem preflight before writes, existing SDK dimension/pixel ceilings, and local per-unit failure accounting. |
| T-67-SC | Tampering | Package/source dependencies | mitigate | Use only existing Apple frameworks and the local public BeautySDK product; no package install is introduced. |
</threat_model>
