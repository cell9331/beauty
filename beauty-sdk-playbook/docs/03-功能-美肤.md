# 03 功能：美肤（磨皮、美白、红润、皮肤锐化）

所有美肤操作都在**源空间**完成，位于 warp 之前。都依赖**皮肤 mask**，先讲 mask。

## 0. 皮肤 mask

| 方案 | 精度 | 成本 | 说明 |
|---|---|---|---|
| YCbCr/HSV 阈值 + 脸部多边形 | 粗 | 极低 | MVP 可用；肤色多样性下易漏、易误（木头、衣服） |
| 关键点多边形（脸部区域）− 五官多边形 | 中 | 低 | 简单稳定；头发、胡须、眼镜边界不准 |
| 人脸解析分割网络（BiSeNet 类，量化） | 高 | 中 | 皮肤/眉/眼/鼻/唇/牙/发/颈，推荐中期上 |

**必须排除**：眼睛（含睫毛）、眉毛、嘴唇、鼻孔、牙齿、头发、眼镜框、胡须。
**必须羽化**：边缘做 3–8px（随脸尺寸）的软过渡，否则磨皮边界出现"脸上一圈"。
**时域稳定**：分割结果逐帧会闪，做轻度时域平滑，或用关键点多边形约束分割结果。

## 1. 磨皮

**目标**：去除瑕疵、肤色不均，保留皮肤质感。

**做法：高低频分离（行业标准）**
1. 低频 L = 保边平滑（导向滤波 / 双边 / 表面模糊）。
2. 高频 H = 原图 − L（纹理、毛孔）。
3. 输出 = L + α·H（α 控制纹理保留，0.3–0.7 常用）。
4. 用皮肤 mask 混合回原图。

**性能做法**
- 在 1/2–1/4 分辨率做滤波，再用**引导上采样**（joint bilateral upsampling）回全分辨率。
- 导向滤波用 box filter 实现（O(1)），Compute Shader 或 `MPSImageBox`。
- 滤波半径**随脸尺寸自适应**（例如脸宽的 1–2%），不要固定像素。

**强度映射**：非线性。前段（0–50）缓、自然；后段（50–100）陡、夸张。给用户"自然区/夸张区"。

**坑**
- 塑料脸/蜡像脸：α 太小或滤波太强。保留部分高频，可叠加极弱颗粒（grain）。
- 眼睫毛、眉毛、发丝被磨掉：mask 排除不干净。
- 磨皮边界明显：mask 未羽化。
- 痘痘/斑点/痣被误当纹理保留或被当噪点抹掉：磨皮与**祛斑/祛痘**是两件事。祛斑可单独做（局部检测 + 周边取样修补），不要靠加大磨皮解决。
- 暗光高 ISO 噪点：噪点会被当成纹理放大。先估计噪声强度，噪声大时提高低频比重，或先轻度去噪。
- 硬件差异：iPhone 前置与后置噪声、锐化风格不同，需分别调参。
- 8bit 反复量化：中间纹理用 RGBA16F，或把磨皮+调色合并到少数 Pass。

**验收**：近景 1:1 放大看——毛孔仍有但均匀、嘴角法令纹仍在但变淡、没有"水彩感"。

## 2. 美白

**做法**
- 在 **Lab 的 L 通道** 或 **线性空间** 用曲线提亮，**只作用于皮肤 mask**。
- 曲线：提亮中间调，对高光做 shoulder 压缩，防止过曝死白。
- 保持色相：只改 L，或同时按比例调整 a/b 防止偏灰。
- 可选：轻度降低黄/青偏色（b* 微调）。

**坑**
- 整体 gain 提亮 → 高光溢出，鼻尖脸颊"一块白"。
- 在 gamma 空间直接加亮度 → 暗部发灰、色偏。
- 肤色较深人群被提亮后偏灰、失真：需要**按肤色自适应**（统计 mask 内 L 均值，自适应曲线），并用多肤色样本（Fitzpatrick I–VI）验证。
- 曝光自动变化时，美白效果跟着跳：用 mask 区域亮度做归一化。
- 同时叠加滤镜/LUT 时顺序影响效果：先美肤再滤镜。

## 3. 红润

**做法**
- Lab 的 **a\*（红绿）通道**小幅提升，局部在脸颊/鼻翼/下巴权重更高（用关键点画高斯权重）。
- 或叠加"腮红"层：柔光/叠加混合，色相偏珊瑚粉，权重图用关键点生成。
- 作用于皮肤 mask，**不要碰唇、眼**。

**坑**
- 全脸加红 → 像过敏、喝醉。
- 与美白叠加 → 肤色偏粉红。联合限幅。
- 不同肤色需要不同的目标色相，不要写死一个颜色。

## 4. 皮肤锐化（含锐化/清晰）

**做法**
- USM 或**高反差保留**，仅作用于**亮度通道**。
- 加**噪声门限**：低于阈值的高频不放大。
- mask：全脸或五官重点（眼睛、眉毛、唇边缘权重更高），皮肤大面积弱锐化。
- 放在 warp 之后（P4）补偿重采样模糊；磨皮之后的微弱"补质感"可在 P1 内部做。

**坑**
- 放大噪点、颗粒。
- 与磨皮互相抵消：磨皮去纹理，锐化又加回来，两者强度需联动。
- 锐化光晕（halo）：半径与强度过大。
- 视频中锐化会放大帧间噪声闪烁；限制强度并做时域稳定。
