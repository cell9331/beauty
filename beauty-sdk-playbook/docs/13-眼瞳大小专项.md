# 13 眼瞳大小（虹膜放大）专项

## 1. 先界定"眼瞳大小"
- 美颜里的"眼瞳大小"通常指**放大黑眼珠（虹膜 + 瞳孔）**。478 点只有**虹膜**点（468/473 中心，469–472/474–477 环），**没有瞳孔点**。
- 瞳孔单独放大（深色眼睛里瞳孔与虹膜几乎不可分）需要额外的瞳孔检测，作为可选子模式（见 §6），默认不做。

## 2. 算法：源空间"反向径向重映射 + 开口 mask + 保护带"
**不要**用网格 Warp 做：网格位移会连带移动眼睑、睫毛和周围皮肤。
做成**独立的局部重映射 Pass**，只允许在"眼睑开口 ∩ 窗口半径内"采样，其余像素直接拷贝。

### 2.1 输入量
| 量 | 来源 | 稳健处理 |
|---|---|---|
| 中心 c | 468 / 473 | One Euro 滤波；眨眼时不可靠，由门控关闭 |
| 半径 r0 | 环点到 c 的距离 | 取**水平点对**距离/2 为主（上下点常被眼睑遮），中位数 + 时域平滑；夹取到眼宽的约 0.15~0.26 倍；离群时退回眼宽先验 |
| 开口 mask A | 上睑链 + 下睑链闭合多边形 | centripetal Catmull–Rom 平滑 → 光栅化 R8 → **腐蚀**（避开睫毛/睑缘，约眼宽 4–8%）→ SDF 羽化 |

> 注：4 个环点**不足以做一般椭圆拟合**（至少需要 5 个点），所以用圆（半径来自水平点对）；竖直点对仅在开口充分时才参与估计纵横比。

### 2.2 反向映射函数 g（输出半径 → 源半径）
设放大倍数 s ≥ 1，保护带 m（以 r0 为单位，建议 0.6–1.0），R = (s+m)·r0：

- r ≥ R：g = r（恒等）
- r ≤ s·r0：g = r / s（虹膜**均匀放大**，纹理与瞳孔形状不变形）
- s·r0 < r < R：**三次 Hermite**，起点 (s·r0, r0)、斜率取割线 Δ=(R−r0)/(R−s·r0)，终点 (R, R)、斜率 1
  → 与窗口外 **C1 衔接**，巩膜带被平滑挤压，不出现环形接缝。

数值验证（numpy，s∈[1,1.6]、m∈{0.4…1.5}）：**映射处处严格单调（最小导数 0.625 = 1/1.6），不折叠**；虹膜边界精确映射到 r0。

### 2.3 合成
```
p_src = c + (p − c) · g(|p−c|) / |p−c|
p_src 若落在开口外（被眼睑遮住的虹膜上部）→ 沿射线向 c 收缩，最多 4 次，直到落回开口内
out(p) = mix( src(p), src(p_src), w )   其中 w = A(p) · strength
```

## 3. 如何保证"其他区域完全不变"
| 层级 | 做法 | 保证 |
|---|---|---|
| ① 支持域 | 窗口外 `r ≥ R` 或 `A(p)=0` 或 `strength=0` → **直接拷贝** | 保护区逐位不变（合成测试：最大误差 0.0） |
| ② 开口 mask | 腐蚀 + 羽化，只覆盖眼白+虹膜可见区；睫毛/眼线/眼睑/皮肤权重为 0 | 不改眼睑形状与睫毛 |
| ③ 采样夹取 | 源位置在开口外则收缩回开口内 | 不把眼睑/睫毛"吸"进虹膜 |
| ④ 空间限幅 | `s ≤ min(1.3, 0.9·d_corner / r0)`，`d_corner` 为虹膜中心到最近眼角的距离 | 看向侧面时自动减弱，不溢出眼白 |
| ⑤ 门控 | blink（`eyeBlink*`）、偏航角、丢脸门控；闭眼时开口面积→0，自然关闭 | 闭眼/侧脸不变形 |
| ⑥ 时序 | c、r0 用 One Euro；s 做斜率限制 | 无闪烁、无呼吸感 |
| ⑦ 回归测试 | s=1 或 strength=0 时全图 diff≈0；保护区 diff=0；金图 SSIM/ΔE | 自动化守住"不变" |

## 4. 与其他功能的顺序和预算
- 本 Pass 在**源空间**，位于磨皮、调色之后，**网格 Warp 之前**；虹膜随后被眼睛大小等几何功能整体搬运。
- 这是**唯一允许的第二次采样**，且严格限制在眼睑开口内；窗口外零改动，所以不会累积模糊。
- 与"眼睛大小"（网格径向放大）会叠加放大虹膜：共享一个"眼部放大预算"，联合限幅。

## 5. 质量增强（可选）
1. **极坐标展开**：把虹膜按 (θ, r) 展开为纹理，缺失的被遮挡扇区用对称/低频填充，再按新半径回贴，比射线夹取更自然，成本略高。
2. **保留光照**：重映射后只替换高频，低频亮度仍取原图（保住上眼睑在虹膜上的投影）。
3. **反光点（catchlight）**：阈值检出高亮小块，按原大小/原相对位置重新叠加（Screen），避免反光点被一起放大。

## 6. 瞳孔单独放大（可选子模式）
在虹膜内部再加一个节点：`(s_p·r_p, r_p)`，其中 r_p 为瞳孔半径（需检测，约 r0 的 0.3–0.5，因人/光照而异）；虹膜边界 r0 处映射保持恒等，**虹膜外缘不动**，只改变瞳孔占比。需要瞳孔分割或阈值检出，深色虹膜上不可靠，默认关闭。

## 7. 常见错误
| 错误 | 后果 |
|---|---|
| 用网格 Warp 放大虹膜 | 连眼睑/皮肤一起动 |
| 用整只眼的径向缩放 | 眼白、睫毛被拉伸 |
| 不做开口 mask | 虹膜"长"到眼睑和皮肤上 |
| 不夹取采样源 | 眼睑/睫毛被采进虹膜 |
| 放大后不给保护带 | 虹膜边缘与巩膜出现硬接缝 |
| 不限制 s | 看向侧面时虹膜溢出眼角 |
| 用 4 个环点做椭圆拟合 | 欠定，结果不稳 |
| 眨眼时仍处理 | 半闭眼时虹膜扭曲 |
