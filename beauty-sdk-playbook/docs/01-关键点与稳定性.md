## 2. 坐标系约定（所有坑的源头）

内部统一约定：**像素单位、左上原点、未镜像、与传感器图像对齐**。

| 来源 | 原点/单位 | 转换动作 |
|---|---|---|
| Vision | 左下、归一化 | y 翻转并乘宽高 |
| Metal 纹理 | 左上、归一化 uv | 内部像素 / 尺寸 |
| Metal NDC | 中心，y 向上，[-1,1] | 仅在渲染时转换一次 |
| UIKit | 左上、点(pt) | 仅在显示层处理 |
| 前置相机预览 | 通常镜像 | 在未镜像空间计算，最后再镜像 |
| 设备旋转 | 方向变化 | 由 `AVCaptureConnection` 或自己维护旋转矩阵，只在输入处理一次 |

**要求**：输入端转换一次、输出端转换一次，中间不再混用。必须有"在图像上画出 68 点"的调试模式，并在各方向、前后置、镜像下逐一验证。

**宽高比陷阱**：任何"圆形影响半径"必须在像素空间或宽高比校正后的空间计算。在归一化坐标里直接算距离，大眼会被拉成椭圆。

## 3. 点位校验与修复

每帧先校验：

1. 是否 NaN / 无穷。
2. 是否超出图像范围较多。
3. 脸框尺寸是否异常（过小、突变）。
4. 整脸置信度。
5. 与上一帧相比的位移是否远超运动模型（疑似误检）。

处理：
- 个别点异常：用上一帧在局部坐标系下的位置恢复，或用相邻点插值。
- 整脸置信度低：**强度在 200–300ms 内渐隐到 0**；恢复时同样渐入。不要硬切，硬切会有"啪"一下的跳变。
- 疑似换人/ID 变化：重置该人滤波状态，避免从旧状态"拉"过去。

## 4. 防抖：One Euro Filter + 局部坐标系

### 为什么不用固定 alpha 的 EMA
EMA 平滑系数固定，静止时想压抖就要调小 alpha，结果快速转头必然拖影；调大 alpha 又压不住静止抖动。One Euro 的截止频率随速度自适应：慢时强滤波，快时弱滤波。

### 局部坐标系滤波（最佳实践）
1. 用相似变换（平移+旋转+缩放，Procrustes）把当前关键点对齐到"标准脸"。
2. 在标准脸坐标下对每个点（或其残差）做 One Euro 滤波。
3. 把滤波结果变换回图像坐标。

好处：刚体运动（头在动）与点位噪声被分离，滤波不会误伤头部运动，拖影显著减少。

### 调参顺序（One Euro 论文推荐）
1. `beta = 0`，调 `minCutoff`，直到**静止**时五官不抖。
2. 逐步增大 `beta`，直到**快速转头**不拖影。
3. 坐标建议用瞳距归一化后调，更换分辨率不必重调。

### 再加两层保险
- **位移二次平滑**：对最终位移（目标点−源点）再做轻度时域平滑。参数突变、姿态突变时位移仍可能跳。
- **参数变化限速**：用户拖滑杆时，内部强度按斜率限制变化，避免画面突跳。

## 5. 延迟与对齐

关键点推理需要时间。若用第 N−1 帧的点处理第 N 帧画面，快速运动时五官会"粘"在旧位置。方案（按优先级）：

1. 推理足够快（如 ≤8ms），同步等当前帧结果。
2. 异步推理 + 匀速模型外推一帧。
3. 每 N 帧检测一次，其余帧用轻量跟踪（光流或 ROI 内小模型）。

**保留时间戳**：关键点结果带上对应帧的时间戳，渲染端按时间戳对齐，不要靠"最近的结果"。

## 6. 姿态、眨眼、张嘴状态

- **姿态**：MediaPipe 的变换矩阵可直接得 yaw/pitch/roll。68 点可用 `solvePnP`（需要 3D 标准脸点与相机内参近似）。无姿态时，用左右眼宽度比、鼻尖相对两眼中点偏移做近似。
- **眨眼 EAR**（Eye Aspect Ratio）：眼睑垂直距离/水平距离。眼闭合时，大眼等眼部形变强度降到 0。
- **张嘴度**：内唇上下距离/嘴宽。张嘴时，嘴型调整降强度；白牙 mask 才有内容。
- **大侧脸**：>45° 开始按 `cos` 类曲线衰减远端形变；>60° 直接关闭形变，只保留肤色处理。

## 7. 多人脸

- 每张脸独立：滤波器、位移、mask、强度门控。
- 需要稳定的脸 ID 跟踪（IoU + 点位距离），否则滤波状态串脸。
- 数量上限（例如 5），超出按脸面积排序。
- 脸之间网格区域重叠时，按脸权重混合位移，或限制其中一方。

## 8. 检测 + 跟踪节奏

| 场景 | 建议 |
|---|---|
| 高端机 | 每帧检测+点位推理（可异步） |
| 中低端机 | 每 2–3 帧检测，其余帧跟踪 |
| 发热降级 | 降低检测频率与输入分辨率 |

推理输入分辨率不必等于渲染分辨率：1080p 画面可缩到 ~320–480 短边做检测，点位再映射回原图。
