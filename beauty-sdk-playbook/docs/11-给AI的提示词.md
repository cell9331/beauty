# 11 给 AI 的提示词

用法：先发"总提示词"，再按模块逐个让 AI 实现。生成的代码必须用 docs/09 的调试开关和测试集验证，尤其是**坐标系、翻转保护、滤波调参**三处。

---

## 一、总提示词

```
【角色与目标】
你是 iOS 图形与计算机视觉工程师。请用 Swift + Metal(MSL) 实现基于人脸关键点的实时几何美颜
（大眼、瘦脸、瘦鼻、嘴型），目标 1080p/30fps，GPU 渲染。不使用深度学习生成模型/GAN，只做几何形变。

【输入】CVPixelBuffer 视频帧 + 关键点数组(68点，可扩展至478点)，带时间戳与置信度。

【固定管线，顺序不得更改】
1 关键点校验：NaN/越界/低置信度点用上一帧局部坐标插值修复；整脸置信度过低时形变强度在300ms内渐隐至0。
2 防抖：转换到人脸局部坐标(相似变换对齐标准脸)，使用 One Euro Filter(minCutoff、beta可配置)，滤波后变换回图像坐标。
  禁止固定alpha的EMA。
3 扩展点：生成额头扩展点；生成脸外扩张环点(轮廓点沿外法线外扩约0.25脸宽，位移恒0)；加入图像四角与边中点(位移恒0)。
4 目标点计算：位移=强度×基准尺度(瞳距/脸宽，非像素)×局部坐标轴方向×smoothstep空间权重×姿态权重(yaw/pitch衰减)
  ×眨眼/张嘴权重，再做单点限幅与多参数联合限幅。
5 翻转保护：计算所有三角形有向面积，出现翻转则二分降低总强度直至无翻转，最多迭代8次。
6 渲染：使用【固定、离线预生成的三角索引表】(禁止每帧Delaunay)，顶点位置=目标点(NDC)，UV=源点，
  Metal渲染管线单次绘制并双线性采样，天然inverse warp。全流程只允许一次几何重采样。
7 后处理：位移场在轮廓外扩张带内平滑衰减至0；轻微锐化补偿重采样模糊。

【形变规则】
- 瘦脸：轮廓点沿指向脸中心方向内收，钟形权重，近耳与下巴尖衰减，下颌拐点限幅。
- 大眼：以眼中心为锚，内外眼角及上下眼睑同步径向放大；正向公式 dst = C + d*(1 + a*(1-(r/R)^2)^2)，a<1.25，
  距离在像素空间计算(处理宽高比)；闭眼(EAR低)时强度降为0。
- 瘦鼻：鼻翼点向中线收，鼻梁锚点不动，近鼻尖偏移大，近眉心近似0。
- 嘴：嘴角沿局部水平轴移动，上下唇垂直缩放，唇中心稳定；张嘴时降低强度。
- TPS/RBF 仅在 CPU 对【网格加密顶点】插值位移(必须带正则项lambda)，禁止在shader中做全图或逐像素TPS。

【必须处理的坑】
坐标系(Vision左下/Metal左上/NDC/镜像/设备方向)统一为内部"像素、左上原点、未镜像"；宽高比；0.5像素偏移；clamp-to-edge；
多人脸独立滤波与独立位移；眨眼与张嘴衰减；大侧脸衰减(>60°关闭几何形变)；
异步推理只保留最新帧；纹理池；pipeline state初始化预创建；CVMetalTextureCache生命周期；3帧in-flight信号量。

【模块划分】
LandmarkPreprocessor / OneEuroFilterBank / MeshTopology(离线数据) / DisplacementSolver(参数→目标点) /
FoldoverGuard / WarpRenderer(Metal) / MaskBuilder / DebugOverlay。

【调试开关】绘制关键点(滤波前/后)、网格、mask、位移向量场、翻转三角；关闭形变；单独关闭任意模块。

【交付】完整可编译代码 + 参数默认值表 + 每个模块的单元测试(坐标变换、翻转检测、滤波收敛) + 性能测量点(os_signpost)。

【禁止】每帧重建三角剖分、全图TPS、CPU像素级warp、正向像素散射映射、两次几何重采样、硬二值mask直接裁剪位移。
```

## 二、分模块提示词（按需追加）

### 1. 关键点预处理
```
请实现 LandmarkPreprocessor 与 OneEuroFilterBank：
- 输入：[SIMD2<Float>] 关键点（像素，左上原点）、时间戳、置信度。
- 先 Procrustes 对齐到标准脸，在标准脸坐标下对每个点做 One Euro 滤波，再变换回图像坐标。
- 异常点(NaN/越界/突变)用上一帧局部坐标恢复；置信度低于阈值时输出 gate(0..1) 并按300ms斜率渐变。
- 提供 reset()；多人脸时按 faceID 维护独立状态。
- 附单元测试：静止噪声下输出方差下降 >80%；阶跃输入下收敛时间在阈值内；NaN 输入不污染状态。
```

### 2. 网格与拓扑
```
请写一个离线 Python 工具(scipy.spatial.Delaunay)，在标准脸上生成三角索引表：
- 顶点=主关键点+加密点(眼睑/唇/轮廓样条插值)+额头扩展点+外环点+图像边界锚点。
- 剔除内角<15°或面积过小三角；保证眼、嘴内部有三角；检查覆盖无空洞/重叠。
- 输出 indices.bin(UInt16) 与顶点生成规则的说明；附可视化脚本。
Swift 侧只读取索引表，运行时仅更新顶点坐标。
```

### 3. 位移求解
```
请实现 DisplacementSolver：输入滤波后点、姿态(yaw/pitch/roll)、EAR、张嘴度、用户参数；输出所有顶点目标位置。
- 建立局部坐标系(原点=两眼中点，x=两眼连线，尺度=瞳距)。
- 每个功能定义：锚点、作用点集、方向向量、smoothstep权重、限幅；累加后做联合限幅(总位移≤脸宽8%)。
- 少量控制点通过 TPS(U(r)=r^2 log r, 带 lambda 正则)插值到加密顶点。
- 实现 FoldoverGuard：有向面积检测+二分降强度。
- 每个功能独立开关，附单元测试(极值参数无翻转、对称输入对称输出)。
```

### 4. 渲染
```
请实现 WarpRenderer(Metal)：顶点缓冲(dstNDC, srcUV)+索引缓冲，单次 drawIndexedPrimitives，
fragment 线性采样 clamp_to_edge；3帧 in-flight；输出到 RGBA16F 纹理；
pipeline state 初始化预创建；调试模式输出网格线框与翻转三角高亮。
```

### 5. 美肤
```
请用 Metal Compute 实现磨皮：降采样(1/2~1/4)→导向滤波(box filter 实现)→引导上采样；
高低频分离输出 = L + α·H；皮肤 mask 羽化混合；半径随脸宽自适应；
附美白(Lab-L曲线+高光压缩)、红润(Lab-a 局部权重)、亮度通道锐化(带噪声门限)。
```

## 三、AI 输出验收清单

让 AI 交付后，逐条检查：

- [ ] 没有每帧 Delaunay
- [ ] 没有全图 TPS，TPS 只在 CPU 对加密顶点做
- [ ] 全流程只有一次几何重采样
- [ ] 坐标转换集中在一处，有单测
- [ ] 距离计算考虑宽高比
- [ ] 位移用脸尺度归一，不是固定像素
- [ ] 有联合限幅与翻转检测
- [ ] 有眨眼/张嘴/姿态衰减
- [ ] 有丢脸渐隐渐入
- [ ] pipeline state 预创建，无每帧分配
- [ ] 调试开关齐全
- [ ] 有单元测试与性能打点
