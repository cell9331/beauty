# 14 "下颌线"是阴影层，不是形变（对美图秀秀效果图的逆向分析）

## 1. 结论
对"原图 vs 美图秀秀·脸型·下颌线 100%"两张图做了像素级对齐与差分，结论：

| 项 | 结果 |
|---|---|
| 几何形变 | **基本没有**。SIFT + RANSAC 相似变换内点 3090/3125（99%）；稠密光流在下巴/脸颊/嘴区域平均位移仅 0.1–0.25 px，属于重采样噪声 |
| 亮度变化 | **只发生在下颌线下方的脖子上**：一条紧贴下颌轮廓的新月形变暗带，脸面、额头、背景、衬衫的亮度比均 ≈ 0.99–1.00 |
| 结论 | 该档位的"下颌线"= **下颌线下方的轮廓阴影（contour shading / 修容）**，让下颌线更清晰、下颌更显利落；下颌角、V 脸、尖下巴在同一界面里是另外的几何项 |

> 局限：只有一张图、一个强度（100%）、一次截图（有显示缩放与色彩管理），看不到对方代码。下面是**从像素测量得到的现象 + 我的实现推断**，不是对方算法的确切描述。图见 `jawline_analysis.png`（右图发丝处的紫色斑点是重采样噪声，不是效果）。

## 2. 测得的阴影特征（脸宽≈640px 的截图尺度下）
| 特征 | 测量值 | 解读 |
|---|---|---|
| 起点 | 紧贴下颌轮廓，脸面一侧比值 ≈ 0.997 | **单侧**：只在轮廓外（脖子侧）加，不压脸 |
| 中线峰值 | 亮度比 ≈ 0.90（原图本身在此处已有自然投影，叠加后再 −10%） | 峰值不夸张，靠范围和一致性出效果 |
| 下颌角附近 | 最暗可到约 0.76–0.88 | 两端略深，增强"下颌转折" |
| 衰减长度 | 轮廓向下约 150px ≈ **0.2–0.25 倍脸宽**；约 100px 处仍有 ~4% | 平滑衰减（类似 smoothstep/高斯尾） |
| 侧向边界 | 在颈部两侧遇到头发处截止 | 被**颈部/皮肤 mask 或头发 mask 裁剪** |
| 衬衫领口 | 基本不变 | 衰减在领口前结束，且被 mask 排除衣物 |
| 颜色 | 通道比值 R 0.884 / G 0.908 / B 0.949：**红通道降得最多，偏冷、略去红** | 不是灰度乘法；更像"冷灰/紫灰阴影色"的叠加（具体混合模式无法从一张图判定） |
| 通道回归 | 斜率≈1.05、截距随通道为负（R≈−28 / G≈−16 / B≈−6） | 近似**按通道的减法式偏移**，而非 ×k；样本纹理方差小，仅作参考 |

## 3. 在我们的 SDK 里怎么做（478 点）
### 3.1 数据
- **下颌折线**：`contourR/contourL` 的下颌段（约 93→132→58→172→136→150→149→176→148→152→377→…→323），Catmull–Rom 平滑（见 docs/12）。
- **脸宽 W**：`|234 ↔ 454|`（像素）。
- **颈部 mask**：人像/皮肤分割中的"身体皮肤" − 脸部多边形；排除头发、衣物；Guided Filter 细化边缘。

### 3.2 阴影场（GPU，一个全屏/ROI Pass）
```
d  = 到下颌折线的单侧有符号距离（仅脖子侧为正，脸侧 = 0）；用 36 段折线解析求最小距离，或 JFA
dn = d / W
s(dn) = (1 − smoothstep(0, L, dn))^γ          L ≈ 0.22，γ ≈ 1.2   （起始值，目视调）
u  = 沿下颌弧长的归一化位置 ∈ [0,1]
a(u) = lerp(1.0, 1.25, smoothstep(0.55, 0.9, |2u − 1|))   // 两端略深（下颌角附近）
mask = neckMask × (dn > 0)
```
### 3.3 着色（避免灰度乘法，保证偏冷）
在 **Oklab** 中：
```
L'  = L · (1 − k·s·a·mask)            k ≈ 0.10–0.14（UI 100% 时，对应中线 −10% 左右；以"原图已有投影"为基础叠加）
a*' = a* · (1 − 0.35·k·s·a·mask)       // 红向分量多收一点 → 偏冷、去红（对应实测 R 降得最多）
```
也可用"向冷灰阴影色 Soft Light/Linear Burn 混合"，但**推荐 Oklab 的原因**：参数可解释、跨肤色稳定、不会因混合模式在不同肤色上表现不一致。

### 3.4 约束与门控
| 项 | 做法 |
|---|---|
| 位置 | 源空间、**网格 Warp 之前**：阴影贴着下颌轮廓，随后与 V 脸/下颌角的形变一起被搬运，二者天然同步 |
| 姿态 | 抬头→脖子露出更多，阴影区放大；低头→下颌盖住脖子，强度和范围按 pitch 衰减；大偏航时远侧衰减 |
| 张嘴 | 下颌折线随 jaw 下移，阴影跟随；`jawOpen` 大时减弱，避免阴影压到嘴下 |
| 时序 | 折线点已滤波；`k`、`L` 做斜率限制；SDF 边缘抖动会表现为"阴影闪烁"，必须稳定 |
| 保护 | 脸面不动（单侧）；头发/衣物被 mask 排除；多人脸各自计算 |
| 与"去双下巴 Pro"的关系 | 同一阴影场、**符号相反**：去双下巴要压低颏下阴影，下颌线要加阴影。两者共享"净阴影预算"，避免互相抵消或叠加过头 |

### 3.5 常见坑
| 坑 | 后果 |
|---|---|
| 把阴影画到脸面一侧 | 下巴发脏、脸变黑 |
| 灰度乘法 | 脖子发灰发脏，与肤色不协调 |
| 阴影不被 mask 裁剪 | 压到头发、衣领 |
| 衰减太短或太长 | 太短像描边，太长像脏污 |
| 折线点抖动 | 阴影边缘闪烁 |
| 低头/抬头不调 | 低头时阴影压到下巴 |
| 与去双下巴并存时不联动 | 效果互相打架 |

## 4. 对本方案其他文档的修正
- 之前我把"下颌线"归为**几何形变**（轮廓平滑）。依据上面的测量，更合理的拆分是：**下颌线 = 轮廓阴影（光度层）**，**下颌角 = 几何形变**。已同步改 `478点完整方案.md`、`docs/04`、`docs/12`。
- 这说明一个通用原则：**"显脸小/显下颌利落"并不全靠形变**，很多功能是"光影重塑"。值得做一个通用的 **ShadingField（轮廓阴影/高光场）** 模块，复用于下颌线、鼻梁高光、山根、颧骨、卧蚕、颏下阴影。

## 5. 从截图界面读到的其他信息（推测）
- **"背景保护"开关**：说明其几何形变配合了**人像分割保护背景**，与我们方案中的外环衰减 + 人像分割一致。
- **"整体 ▾"**：看起来是"整体/左/右"之类的分区调节入口（仅凭 UI 推测）。
- 功能项并列出现"下颌角 / 下颌线 / V脸 / 尖下巴 / 发际线 / 去双下巴 Pro"，与我们的功能表一致，也佐证了其中既有几何项也有光影项。
