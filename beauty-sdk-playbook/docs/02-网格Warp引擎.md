# 02 网格 Warp 引擎

## 1. 核心思想

- 构建一张**覆盖全图**的固定拓扑三角网格。
- 每个顶点有**源位置**（关键点/锚点在当前帧的位置）和**目标位置**（源位置 + 位移）。
- 渲染时：顶点位置 = 目标位置（NDC），顶点 UV = 源位置（归一化纹理坐标）。光栅化后每个输出像素的 UV 由硬件线性插值得到，直接去源图采样。
- 这就是 **inverse warp**：遍历输出像素找源坐标。**天然无空洞**。

> 禁止"正向映射"：把源像素散射到目标位置会产生黑洞和孔隙。

## 2. 顶点集合

| 类别 | 数量参考 | 位移 |
|---|---|---|
| 主关键点（68/478 的子集） | 68+ | 由参数产生 |
| 加密点（眼睑、嘴唇、轮廓之间用样条插值） | 50–150 | 由 TPS/RBF 或规则插值 |
| 额头扩展点 | 5–9 | 视功能（额头、发际线）而定，否则 0 |
| **外环点**：轮廓点沿外法线外扩 0.2–0.3 脸宽 | 16–24 | **恒 0** |
| **图像边界锚点**：四角 + 边中点（可再加密） | 8–16 | **恒 0** |

### 为什么需要外环
瘦脸时轮廓内缩，原来的轮廓位置要用外侧像素补上。没有外环，空出来的地方只能硬拉背景或留空。外环到轮廓之间的三角形承担"背景补偿拉伸"。

- 外环**太近**：背景（门框、墙角）弯曲明显。
- 外环**太远**：带动大片背景。
- 需要强背景保护：叠加人像分割，在人像边界附近对位移再乘一个权重。

## 3. 拓扑离线生成

在"标准脸"（平均脸，点位对齐）上做 Delaunay，**离线一次**，写入资源，运行时只读。

离线步骤：
1. 在标准脸上取全部顶点（含加密点、外环、边界）。
2. Delaunay 三角剖分。
3. 过滤坏三角：面积过小、最小内角过小（如 <15°）。
4. **约束**：眼、嘴内部必须有三角（张嘴/眨眼时有内部结构）；眼睛区域不让三角横跨眼睑闭合线（可手动指定约束边）。
5. 检查全图覆盖，无空洞、无重叠。
6. 导出索引数组 `indices: [UInt16]`。

运行时：**每帧只更新顶点坐标，不重建索引**。每帧重做 Delaunay 是最常见的错误：拓扑变化导致闪烁，还浪费性能。

> 参考脚本：`code/gen_topology.py`。

## 4. 位移计算（CPU）

输入：滤波后的关键点、姿态、状态（眨眼/张嘴）、用户参数。
输出：所有顶点的目标位置。

流程：
1. 建立**人脸局部坐标系**：原点取两眼中点，x 轴=两眼连线方向，y 轴=垂直于 x（指向下巴），尺度=瞳距或脸宽。
2. 每个功能定义：**锚点（不动）**、**作用点集**、**方向向量**（局部坐标轴）、**空间权重**（smoothstep 衰减）、**限幅**。
3. 每个功能的位移累加到对应顶点。
4. **联合限幅**：同一顶点被多个功能影响时，总位移不得超过预算（例如 ≤ 脸宽的 8%），超过则按比例缩放。
5. **姿态权重 × 眨眼/张嘴权重 × 强度门控**。
6. 少量控制点通过 **TPS/RBF** 插值到加密顶点（见第 6 节）。
7. **翻转检测**（见第 5 节）。

> 位移单位用"脸尺度的比例"，不要用固定像素。否则人脸离镜头远近不同，效果不一致。

## 5. 三角翻转保护（FoldoverGuard）

位移过大或多个功能叠加，会使某些三角形有向面积变号（折叠），画面出现撕裂/扭曲。

每帧：
1. 计算每个目标三角形的有向面积（与源三角形符号比较）。
2. 若出现翻转或面积比 < 阈值（如 0.1）：把总强度乘以 t（0..1），二分搜索 t，直到无翻转。
3. 最多迭代 6–8 次，仍失败则直接关闭当帧形变（或回退到上一帧位移）。
4. 在调试模式高亮翻转三角形。

## 6. TPS / RBF 的正确用法

**不要**在 shader 里对每个像素计算 TPS。**要在 CPU 上对网格顶点做插值**：

- 控制点：少量（如大眼：眼周 6–8 点 + 若干锚点）。
- 目标：把控制点位移插值到加密顶点（几十到几百个）。
- 核函数：TPS 用 `U(r) = r² log r`；RBF 可用高斯或多二次。
- **必须加正则项 λ**（解 `(K + λI) w = v`），控制点少或噪声大时防止过拟合出现震荡。
- 规模小（几十点），在 CPU 用 Accelerate 解 LU 即可；或在**标准脸坐标系**里预先分解矩阵，运行时只做乘法。
- **方向**：直接拟合"目标→源"的映射更方便 inverse，也可用"源→目标"位移加到顶点上。网格方案采用后者。

> 影响半径：每个 TPS/RBF 区域用 smoothstep 限制半径，半径外位移衰减到 0。

## 7. 径向局部缩放（大眼等）

Inverse 形式，距离在**像素空间**计算：

```
d = p - C;  r = |d|;  t = r / R
if r < R:  k = 1 - s * (1 - t²)²;  src = C + d * k
```

- C：眼中心，R：影响半径（眼宽 ×1.5~2），s：强度。
- r=R 处 k=1，与外部无缝衔接。
- **s < 1 可保证映射单调、不折叠**（r·k(r) 的导数 1 - s(1-t²)(1-5t²) 在 s<1 时恒正）。
- 实用上限建议 s ≤ 0.4。

**在网格方案里**不是在 fragment 中逐像素算，而是对**加密顶点**用"正向"形式求目标位置（光栅化会自动完成逐像素的反向查询）：

```
d = v - C;  r = |d|;  t = r / R
if r < R:  g = 1 + a * (1 - t²)²;  dst = C + d * g      // v 是顶点的源位置，同时作为 UV
```

- 正向形式的单调条件是 **a < 1.25**，实用上限建议 a ≤ 0.5（对应眼睛中心约放大 1.5 倍）。
- 顶点必须足够密（影响半径内至少 ~20 个顶点），否则线性插值会把平滑曲线"折"成多边形，可见棱角。
- 仍需配合第 5 节翻转检测。

## 8. 渲染要点

- 一个 `MTLRenderPipeline`：顶点缓冲 `dstNDC`、`srcUV`、索引缓冲。
- Fragment：`sampler(filter::linear, address::clamp_to_edge)` 采样源纹理。
- 单次绘制全网格。
- 输出到 RGBA8 或 RGBA16F 纹理，再送到锐化 Pass。
- **边缘羽化**：几何上靠外环衰减自然过渡；如需额外保护，可在 fragment 内按"到人像 mask 的距离"混合原图与 warp 图。

> 参考：`code/MeshWarp.metal`、`code/DisplacementSolver.swift`。
