# 08 性能与工程化

## 1. 帧预算（参考值，需实测）

| 目标 | 单帧总预算 | 建议分配 |
|---|---|---|
| 30 fps | ~33ms | 关键点推理 ≤8ms（异步）；GPU 渲染 ≤8–10ms；其余留余量应对抖动和发热 |
| 60 fps | ~16ms | 关键点推理隔帧；GPU ≤6ms；降级开关更激进 |

**原则**：预算按 P95 帧耗时，而非平均值；留 30–40% 余量应对发热降频。

## 2. 线程模型

```
相机队列(serial) ──最新帧──▶ 推理队列(serial, 仅保留最新帧)
        │                          │ 关键点(+时间戳)
        └──────────帧──────────▶ 渲染队列(serial) ◀── 关键点
```

- 推理积压时**丢旧帧**，不要排队。
- 渲染队列取"时间戳最接近当前帧"的关键点结果（或外推）。
- 所有可变参数通过线程安全的"参数快照"传入，每帧读取一次，避免半更新状态。

## 3. GPU 最佳实践

| 项 | 做法 |
|---|---|
| 零拷贝 | `CVMetalTextureCache` 创建纹理，避免 CPU 拷贝 |
| 资源池 | 纹理池 + `MTLHeap`，不要每帧创建 |
| in-flight | 3 帧 in-flight，`DispatchSemaphore` 控制 |
| Pipeline | 初始化时预创建全部 pipeline state；变体用 function constants |
| 精度 | 能用 `half` 就用 `half`；中间纹理视质量需求用 RGBA16F |
| 合并 Pass | 调色类（美白/红润/唇色/白牙）合并到一个 Pass；减少带宽 |
| 降采样 | 磨皮等模糊类 1/2–1/4 分辨率 |
| MPS | `MPSImageGaussianBlur` / `MPSImageBox` 等已高度优化，可直接用 |
| 回读 | 禁止 CPU 回读像素（除非拍照输出） |
| 分析 | Xcode GPU Frame Capture、Instruments（Metal System Trace、Time Profiler、Thermal State） |

## 4. 推理优化

- 输入缩放：检测/关键点输入短边 ~320–480，再映射回原图。
- 模型量化：FP16 常是安全选择；INT8 需要重新验证精度（关键点抖动会受影响）。
- 运行时：CoreML（可走 ANE）、MNN/ncnn/TFLite Metal delegate；用 Instruments 看是否真的跑在 ANE。
- 检测+跟踪：每 N 帧检测，其余帧用跟踪；跟踪失败回退检测。

## 5. 热管理与降级

监听 `ProcessInfo.processInfo.thermalState`，并结合帧耗时 P95：

| 状态 | 动作 |
|---|---|
| nominal | 全功能 |
| fair | 降低检测频率；关闭次要效果 |
| serious | 降分辨率；关闭加密网格；磨皮降采样更激进 |
| critical | 仅保留肤色处理或关闭美颜；提示用户 |

降级与升级之间加**迟滞**（例如持续 5–10 秒再切换），避免来回抖动。

## 6. 内存

- 峰值内存：纹理池大小受分辨率影响；拍照 12MP+ 注意单纹理限制与中间纹理数量。
- 拍照路径可分块（tile）处理或降采样滤波再上采样。
- 监听内存警告：释放非必要缓存。

## 7. SDK 打包与接口

| 项 | 建议 |
|---|---|
| 形态 | XCFramework（device + simulator slice），同时提供 SPM 或 CocoaPods |
| 资源 | metallib、模型、拓扑表放入 framework bundle；`makeDefaultLibrary(bundle:)` |
| 符号 | `-fvisibility=hidden`；静态依赖加前缀；避免与宿主 App 冲突 |
| 接口 | 对外提供 ObjC/C 稳定接口，Swift 友好封装；参数用结构体+版本号 |
| 线程 | 文档化回调队列、线程安全保证 |
| 状态 | 提供 `reset()`、`pause()`、`release()`；前后台切换时释放 GPU 资源 |
| 输出 | 支持 `CVPixelBuffer` 输入/输出（直播推流、编码用），支持 `MTLTexture` 输入/输出（自渲染） |
| 授权 | License 校验在非渲染线程，失败降级为"无美颜" |
| 日志 | 分级日志；性能打点用 `os_signpost` |
| 版本 | 语义化版本；模型版本与 SDK 版本解耦 |

## 8. 照片 vs 视频

| 项 | 视频 | 照片 |
|---|---|---|
| 目标 | 低延迟、稳定 | 画质 |
| 分辨率 | 720p–1080p | 12MP+ |
| 关键点 | 滤波+跟踪 | 单帧精检，可用更大模型 |
| 磨皮 | 降采样滤波 | 全分辨率或高质量降采样上采样 |
| 降级 | 动态降级 | 不降级，可耗时更长 |
| 注意 | 帧间一致性 | EXIF 方向、色彩空间（P3） |

## 9. 持续监控

- 线上埋点（脱敏）：帧耗时分布、热状态分布、降级触发率、崩溃率。
- 机型矩阵：最低端支持机型 + 主流机型 + 最新旗舰。
- 回归：每次提交跑固定视频序列，比较帧耗时、抖动指标、翻转率。
