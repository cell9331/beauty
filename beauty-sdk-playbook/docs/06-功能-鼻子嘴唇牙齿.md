# 06 功能：鼻子 / 嘴唇与牙齿

可行性标记同 docs/04。

---

## A. 鼻子

通用规则：
- **鼻梁中轴线是锚**，鼻梁点（27–30）基本不动。
- 位移方向使用局部坐标轴：水平收缩沿 x 轴向中线，提升沿 y 轴向上。
- 鼻翼、鼻孔、鼻底是一个整体，调整鼻翼时要**保持鼻孔形状**。
- 侧脸时鼻子本身就是轮廓的一部分，变形会明显改变侧脸轮廓。>45° 强度要降。

| 功能 | 做法 | 限幅/注意 | 68点 |
|---|---|---|---|
| **大小** | 以鼻中心（鼻尖与鼻翼之间）径向缩放，整体变小/变大 | 缩放 ≤ 8–10% | ✅ |
| **鼻翼** | 鼻翼外侧点（31、35 及外扩点）向中线收缩；靠近鼻尖偏移更大，靠近眉心几乎不动 | ≤ 鼻宽 12%；注意鼻孔不被压扁 | ✅ |
| **鼻尖** | 鼻尖点（30、33 附近）整体缩小/上翘/前后（2D 上表现为上下） | 上翘过度像猪鼻；与人中联动 | ⚠️ |
| **鼻梁** | 鼻梁两侧向中线收，视觉上变窄变挺 | 过度像"竹竿"；需配合阴影高光增强立体感 | ⚠️（点少） |
| **山根** | 山根（两眼之间、27 附近）区域加高/加宽：提亮高光+轻微位移 | 2D 位移效果有限，主要靠明暗 | ⚠️ |
| **提升**（鼻子上提） | 整个鼻子沿竖直轴向上，人中联动变短 | 与中庭/人中联合预算 | ✅ |

### 鼻子专项坑
1. **2D 变形做不出"挺"的立体感**：鼻梁、山根的"高度"本质是明暗。业界常见做法是在 warp 之外叠加**高光/阴影**（鼻梁高光、鼻翼阴影），用关键点画高斯权重图，柔光混合。
2. **鼻孔变形**：收鼻翼把鼻孔挤变形。给鼻孔区域更低的位移权重，鼻孔 mask 单独保护。
3. **鼻翼收缩影响脸颊**：位移半径过大，带动脸颊、法令纹。影响半径限制在鼻周。
4. **鼻环、鼻钉**：被变形扭曲，难处理，接受轻微失真。
5. **侧脸**：近侧鼻翼的轮廓被背景吃进去，拉扯背景。降强度。
6. **仰头/低头**：鼻底透视变化，位移轴要随姿态。

## B. 嘴唇与牙齿

通用规则：
- 嘴部由**外唇、内唇、嘴角**组成，保持三者结构一致。
- 嘴角沿水平轴移动、上下唇沿垂直轴缩放，**嘴唇中心点稳定**。
- **张嘴度**影响：张嘴时降低嘴型强度；牙齿 mask 才有内容。
- 嘴内网格需要内部三角（张嘴时内部点与外唇联动）。

| 功能 | 做法 | 限幅/注意 | 68点 |
|---|---|---|---|
| **大小** | 以嘴中心径向缩放（外唇+内唇） | ≤ 10% | ✅ |
| **宽度** | 嘴角（48、54）水平向外/内，唇线平滑过渡 | 嘴角靠近脸颊肌肉，位移半径适中；过度会撕裂 | ✅ |
| **微笑** | 嘴角沿"斜上外"（沿颧骨方向）移动，唇线上弯，可联动脸颊轻微上提 | 不要只拉嘴角，要同步上下唇弧度；强度小 | ⚠️ |
| **上下** | 整个嘴沿竖直轴平移 | 与人中/下庭联合预算；牙齿露出 | ✅ |
| **左右** | 整个嘴沿水平轴平移（修正歪嘴） | 小幅，≤ 嘴宽 5% | ✅ |
| **倾斜** | 整个嘴绕中心旋转 | ≤ 5° | ✅ |
| **M 唇** | 上唇中线（51 附近）下压，唇峰（50、52 附近）上提，形成 M 形 | 过度显得"人造嘴"；强度小 | ⚠️（需上唇加密点） |
| **丰唇** | 上下唇向外径向放大（局部缩放），嘴角位置保持 | 放大超过 15% 明显失真；牙齿露出会被遮挡 | ✅ |
| **唇色** | 嘴唇 mask 内，在 **Lab/HSL 保留 L**，改 a/b 与饱和度；叠加弱高光 | 保留唇纹；mask 边缘羽化；排除牙齿/舌头 | ✅（mask 用唇点多边形，更精细需分割） |
| **白牙** | 牙齿 mask 内：Lab 的 **b\* 降低（去黄）+ L 微升** | 限幅防"烤瓷牙"；闭嘴时 mask 为空 | ⚠️（牙齿 mask） |

### 唇色细节
- 色彩混合顺序：**先去除原唇色偏差 → 再叠加目标色**，避免原本很红的嘴叠加后过饱和。
- 高光保留：对高亮区域降低着色强度。
- 质感可选：哑光/滋润/金属，只需要调整高光和饱和度曲线。
- 嘴唇 mask 边界：边缘用 2–4px 羽化，避免"涂到皮肤上"。

### 白牙细节
- **牙齿 mask 构建**：用内唇多边形（60–67）作为外边界，再用颜色阈值（亮度较高、饱和度较低）剔除舌头、口腔暗部。有分割网络更好。
- **去黄**：在 Lab 里降低 b*（黄），而不是单纯加亮。
- **局部归一化**：以 mask 内平均亮度做基准，避免曝光变化时跳。
- **不要把牙缝、牙边的阴影抹掉**：保留高频，只改低频颜色。

### 嘴唇与牙齿专项坑
1. **张嘴时内唇点不稳定**：说话、大笑时内唇点最抖。内唇点用更强滤波，或用外唇点推算。
2. **牙齿位移**：嘴型调整后，牙齿区域跟随位移，但牙齿本身不要被拉伸（水平位移权重较小）。
3. **丰唇遮挡牙齿**：放大后唇会盖住牙齿，需要对上下唇向外缩放，不是向内。
4. **唇色溢出到牙齿/皮肤**：mask 精度不够；唇线 mask 需要二次细化（沿唇线法线收缩 1–2px）。
5. **口红/唇膏原有妆容**：叠加后色偏，需要先估计原唇色再做目标映射。
6. **微笑功能**：真实微笑会带动脸颊、眼角（鱼尾纹）、法令纹。只拉嘴角会显得"皮笑肉不笑"，要联动脸颊上提；但联动半径过大会带动法令纹，需调。
7. **戴口罩**：嘴部功能必须自动关闭，否则对口罩进行变形。
