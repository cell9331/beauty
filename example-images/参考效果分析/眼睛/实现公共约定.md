# Shared geometry and rendering conventions

**Status: proposed mathematics for review, not SDK implementation or reference-effect qualification.** The [eye index](README.md) defines the measured inputs and evidence limits. Each feature file separates observed displacement from its candidate field. No model download, SDK change, or algorithm execution project is authorized by this analysis.

## Coordinate domains and endpoint identity

All reported observations are forward displacements `D(p) = q − p`, with image x right and y down, in native aligned **screenshot-photo pixels**. They are not original-camera pixels. “Image-left” and “image-right” identify screen position, not anatomical laterality. The eleven paired studies map the observed left slider endpoint into the observed right endpoint. The controls show no numbers; neither endpoint is assigned a numeric value or a neutral-relative strength.

Paired-study figures label coordinates from the photo-crop origin; the S0 → 去脂 figure explicitly uses full native screenshot coordinates. Their vector units and signs agree, but their coordinate origins differ. Local manifests own the origin conversion. Convert positions before merging point arrays or comparing profile locations across these figures.

For a paired study, the candidate family uses `s ∈ [0,1]`, with `F_0(p)=p` on the **observed left-endpoint source** and `F_1` approximating the observed right endpoint. This is an analysis interpolation domain, not a proposed UI calibration. The separately aligned photograph S0 used for 去脂 is source-relative and is not certified as an application neutral.

If a later implementation uses a certified common neutral image, compare endpoints by the same neutral source point:

```text
p_left = F_left(p)
p_right = F_right(p)
V_pair(p_left) = F_right(p) − F_left(p)
```

Do not subtract arrays of fields with different source grids. Observed endpoint spans cannot be halved into single-endpoint strengths. In an expansion core, an observed relative gain `(1+b_right)/(1+b_left)` does not identify both neutral-relative gains. Intermediate response, bilateral equality, and symmetry about zero remain unmeasured.

## Input-specific geometry

Freeze all geometry in the source domain before evaluating a field. For each eye use a reliable source center/reference `c`, a positive reference length `L` (for example, an independently localized canthal distance), a unit tangent `e_t` from nasal to temporal side, and a unit inferior normal `e_n`. The basis is orthonormal; it need not have the same handedness for both eyes. Define:

```text
t(p) = dot(p−c,e_t)/L         grad_t = e_t/L
n(p) = dot(p−c,e_n)/L         grad_n = e_n/L
F_s(p) = p + D(p,s)
```

The source-defined sampling windows in this study are inspection geometry, not validated landmark detectors, semantic masks, or reusable support radii. No image-coordinate center or actual correspondence is embedded in aggregate Markdown. Local evidence figures mark the actual profile positions. A new photograph requires its own reliable geometry and scale; screenshot amplitudes are not transferred as fixed pixels.

## Internal motion and surrounding support

Separate the internal motion `r(p,s)` from a compact, continuous envelope `w(p)`:

```text
D(p,s) = w(p) r(p,s)
w(p) = P(p) H(t(p)) K(n(p))
grad_w = H K grad_P + P K H'(t) grad_t + P H K'(n) grad_n
J_F = I + w J_r + r (grad_w)^T
```

`P` is a smooth protection/ownership factor, not an unverified hard segmentation mask. Every transition derivative belongs in `grad_w`. With multiple protection factors, apply the product rule to each one. Source geometry is frozen; a normal direction that varies with p also contributes its derivative. The feature files specify departures from this common constant-basis model.

A possible **design choice**, not a measured kernel, is a plateau followed by a smoothstep falloff. For `z=(|t|−a)/(b−a)` with `0≤a<b`, set `H=1` inside a, `H=1−3z²+2z³` in the transition, and `H=0` beyond b. Then `dH/dt = (−6z+6z²) sign(t)/(b−a)` inside the transition and zero outside it. Separate nasal/temporal or superior/inferior widths may be introduced only when corresponding evidence supports them. A true C1 plateau handles the absolute-value origin without a cusp. A compact bump can instead use a smooth squared elliptical radius; its center, core, and edge must be fitted or explicitly left unknown.

Support includes skin that follows the adjustment. Its edge cannot be inferred from an eye/iris binary outline or from the smoothing footprint of optical flow. An apparent weak tail is not an exact fixed endpoint. Protection must be assessed with separate source-selected stationary texture observations, including regions with few accepted matches.

## Full-field safety and inverse mapping

Translation, scaling, and finite rotation can all create compression in their support transition. A rigid core having determinant one says nothing about the blended boundary. Evaluate the complete `I+grad_D`, including support/protection derivatives and overlaps. A positive determinant at sampled pixels alone proves neither a global derivative bound nor global injectivity.

One conservative sufficient design condition is a verified global Lipschitz bound `sup ||grad_D||₂ ≤ κ < 1`. Then `F` is injective by the distance bound `||F(p)−F(q)|| ≥ (1−κ)||p−q||`, and the fixed-point inverse is contractive when the domain/coverage conditions also hold:

```text
p_0 = q
p_(k+1) = q − D(p_k,s)
check ||F_s(p_k) − q|| against the rendering tolerance
```

One step `p=q−D(q,s)` is only an approximation. If contraction is unavailable, use a separately checked inverse or a mesh with coverage and non-overlap checks. A numerical grid maximum is an estimate; it is not the analytic supremum used above. Preserve bounds through the full support, all active controls, and the image boundary.

For combined controls either define a sum on a shared frozen source grid and test the sum, or declare an ordered composition and apply the chain rule `J_(G∘F)(p)=J_G(F(p))J_F(p)`. Do not assume the effects commute, share ownership, or remain safe when combined. Inverse maps run in reverse order. The final renderer samples the **original source once** using the composed inverse. Repeatedly warping the previous raster or blending misregistered originals is not the specified rendering method.

On degenerate/unreliable geometry, invalid ownership, unsafe support, inverse failure, or missing source coverage, preserve the original affected pixels and return an explicit failure/no-op result. Do not silently clamp a few nodes and claim the field passed. These are implementation requirements for a future candidate, not tests performed on this repository's SDK.

## What would qualify a candidate

First fit a small internal model against independent source-selected moving correspondences; then test its decay against separate stationary/protection samples. Use both vector components, upper/lower and nasal/temporal partitions, and pairwise geometry for rigid claims. Keep accepted disagreements and report matching rejection counts. Do not filter points by agreement with the candidate or the dense field being assessed.

Match the observed endpoint transformation on its own source grid, not just the visible maximum. Validate contour/texture agreement in actual output, signs, support, orthogonal residual, inverse closure, and protected areas. Synthetic controls validate the measuring method on those controls; formula review validates mathematics. Neither establishes reproduction of the proprietary effect, new-photo generalization, neutral response, or SDK quality.
