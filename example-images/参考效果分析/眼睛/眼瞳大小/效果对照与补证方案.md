## Minimum evidence-completion plan

The smallest useful plan is conditional. Reuse the existing pair first; acquire new captures only for questions that this pair cannot answer. Do not start another parameter search while collecting the missing evaluation evidence.

### 1. Freeze the present implementation and audit missing observations

Preserve both actual output variants, configuration identities, source/reference identities, the original partition, rejection reasons and failed outcomes. Review source texture/anatomy **without the candidate overlay** before attempting new correspondences. Classify the missing iris/lower-lid evidence as excluded by the partition, rejected as ambiguous, obscured, or absent. Do not silently move old fit points into holdout or reduce the guard/matching rules to obtain coverage.

**Minimum output:** a coverage matrix for each eye: iris material, visible iris boundary, upper lid, lower lid, nasal sclera, temporal sclera; moving texture, transition and quiet observations. Keep the old matrix unchanged and label any supplement as a new, prospective same-photo check. Adequacy is coverage and identifiability of the proposed field, not an invented point quota.

### 2. Obtain the missing same-photo checks, if the pixels contain them

Use unused, independently identifiable source texture for lid/scleral material correspondence. Select and freeze the source regions, fit/evaluation role and non-overlapping observation footprints before matching or seeing candidate residuals. Keep evaluation annotations out of any refit. Retain ambiguous, contradictory and failed matches instead of snapping them to the predicted field. An independent reviewer should inspect correspondence uncertainty without candidate predictions.

Independently annotate **visible** iris/limbus arcs and upper/lower lid contours, with occluded segments excluded and edge uncertainty recorded. Compare transported visible contours and signed normal residuals separately from material-point dx/dy. Boundary agreement can test the visible size/shape shortfall; it cannot prove iris-interior material motion, expose a hidden iris boundary or justify assuming a circle. Repeat/blinded annotation supplies uncertainty for this contour task, not a universal pixel tolerance.

**Minimum decision:** can the unchanged candidate explain reliable new lid/visible-boundary observations within independently established uncertainty? A persistent structured residual should reject or narrow the candidate. Same-photo supplements can test this pair only; they cannot become unseen-photo qualification. If usable texture is absent, stop this attempt and proceed directly to step 4 rather than relaxing matching.

### 3. Capture one controlled state sequence for G01

On one unchanged authorized source, use a fresh import and the reference application's actual reset/off operation. Record the app/version, source identity, display extent, selected tool, all other active settings and the real control readout/state. Capture **reset → left endpoint → reset → right endpoint → reset**, preserving the native photograph grid. The repeated reset checks isolate state drift/accumulation; use stable photo texture, not UI elements, to verify alignment.

This is the minimum sequence for endpoint/reset isolation. If the goal includes the product response curve, add recorded intermediate states on the actual available branch(es), selected in advance to distinguish the candidate response models, then return to reset. Neither a screen midpoint nor the name “reset” alone proves that the image is an unedited neutral: compare the repeated reset outputs and recorded sibling state. If the application exposes no verifiable off/reset, retain an endpoint-only contract. Do not invent an unavailable negative branch or a symmetric endpoint split.

**Minimum decision:** a verified repeatable reset and corresponding endpoint material maps can address neutral decomposition. Intermediate response remains unqualified until intermediate captures discriminate it. An unexplained reset-repeat difference blocks control isolation.

### 4. Add one evidence-bearing source only when required

If the existing image cannot supply iris material or independent lower-lid evidence, choose the next authorized source specifically for visible iris detail, observable upper/lower lid texture and nasal/temporal scleral transitions. Retain natural occlusion instead of assuming complete iris anatomy. Use the controlled sequence above and prospectively select the evaluation regions before candidate inspection. Keep this photograph out of tuning if it is the held-out applicability check.

One new source is the next evidence increment, **not a claim of generalization**. If it supplies none of the missing observations, record that failure instead of accumulating nominal image counts. Wider partial-occlusion/closed-eye applicability and production ownership remain later gates; existing synthetic refusal tests do not replace those photographs.

### 5. Decide before fitting again

From reliable new correspondence/contour uncertainty and the intended output scale, freeze per-region comparison criteria and coverage requirements **before** optimization. Keep photographic budgets separate from the unchanged inverse, ownership, alpha and contraction restrictions. Fit only the declared training evidence, then evaluate the frozen candidate once against untouched evidence; keep failures visible. If the field remains unstable or the held-out residual has structure, narrow/reject the hypothesis rather than adding unconstrained parameters.

The immediate deliverable is sufficient evidence to decide the current pair/model, not an automatic production calibration. Default/host promotion remains blocked until the applicable effect, response, safety and composition gates pass. This review specifies no new center, radius, gain, kernel parameter, latency budget or numerical acceptance threshold.
