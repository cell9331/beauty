# Outer canthus: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad temporal-direction agreement; response and support unqualified.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1949 → IMG_1950` supports temporal-corner/sclera motion outward, with quieter nasal side and iris interior. Active-corner horizontal travel is roughly 6–12 px; dy is smaller and nonuniform. Plateau/bump and orthogonal behavior remain uncertain. See [evidence](分析链路.md).

## Active implementation

The nominal inverse field is pure image-x: `side*.0465*span*u*outerCornerWeight*shapeWeight`. It uses a horizontal plateau/return, aperture-height vertical fade and interior-weighted iris preservation, with RGB/local geometry registration. An additional `.93` response gain is applied after component admission. See [local frame](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L644), [weight](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L694) and [response gain](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L379).

## What differs

Main outward direction and locality agree. The [candidate](实现方案.md) leaves local axes, orthogonal motion, peak/plateau and decay to observation; current image-x, fixed plateau widths, vertical fade and post-admission gain choose them explicitly. These are not independently calibrated to this pair. Small dy does not by itself justify adding a vertical parameter.

## Qualification and missing discriminator

No same-pair actual Swift baseline is recorded. Actual admitted full-vector corner travel, interior/transition follow motion and independently quiet areas must be scored separately before judging the fixed gain or support.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
