## What the supplied evidence supports

The label indicates a visual intention. It does not establish which pixels change, how vessels are distinguished from other eye structures, whether geometry changes, or whether the output preserves iris, pupil, eyelid, and skin appearance. A menu name is not evidence for a color transform, a segmentation method, a learned model, or any particular internal mechanism.

The outdoor original is a same-content source candidate. It cannot replace the missing applied target, and the existing iris-size or canthus pairs cannot supply that target either. See the [input inventory](../输入清单.md) for the batch's selected controls and limitations.

## Minimum additional evidence

Capture an explicit unchanged/off state and a visibly applied state on the same photograph, preserving crop, scale, other adjustments, and background-protection state. Record the selected control, any strength, and any per-eye scope. Add neutral and endpoints if a slider exists. An unchanged repeat is useful for identifying display and encoding differences.

Use an authorized photograph with enough resolved scleral vessel detail to test the intended change. A low-resolution or already clear sclera cannot establish effectiveness or a general absence of effect. Preserve the original files and document their encoding and color-profile relationship if a later appearance study is undertaken.

## What geometry can and cannot establish

Stable external alignment and local correspondence can test whether the sclera, iris, or lid boundaries move. They can identify a geometric component or establish that no motion is resolved at the measurement scale. They cannot quantify redness reduction, vessel suppression, color preservation, or whitening quality. Low optical flow is not evidence that a redness effect failed, and optical-flow magnitude is not a redness metric.

A color/appearance study would therefore need a separately defined scope, valid source/target states, color handling, vessel-detail criteria, and protected-region checks. Those measurements have not been added to this geometric task merely because the feature name suggests color. No color formula, model route, mask, or measured redness result is claimed here. The control is covered as an evidence gap; its effect analysis remains pending.
