## What the supplied evidence supports

The name supplies a product intention, not measured behavior. A less prominent under-eye contour might arise from geometric movement, altered illumination or contrast, texture replacement, or a combination. The label and icon cannot choose among these explanations, establish a support boundary, or demonstrate preservation of lower lashes and cheek texture.

No target with a documented change of this control is available. The outdoor original is a same-content source candidate, but it does not create an effect pair or certify the state of other adjustments. The [input inventory](../输入清单.md) describes the available endpoint comparisons.

## Minimum additional evidence

Capture an explicit unchanged/off state and an applied state of this control on the same photograph. Keep display crop, scale, other controls, and background protection fixed. Record any strength and per-eye setting. Include neutral and both available endpoints when the UI provides a slider, or a documented before/after transition when it provides an action or toggle. A repeated unchanged capture helps quantify display and encoding variation.

The input should resolve the lower-lid margin, under-eye contour, and nearby skin texture without UI overlays. If the current photograph has little visible under-eye structure, add a suitable authorized input before drawing a negative conclusion about the feature.

## How the new evidence would discriminate mechanisms

Stable-region alignment and independent local texture correspondences can test whether the under-eye structure moves. Consistent contour and texture displacement would support a geometric component. A visual difference with stable texture positions would not justify reporting a deformation field as the explanation. Weak skin texture must remain an uncertainty rather than being filled with optical-flow estimates and counted as independent evidence.

If the measured change is predominantly appearance, define the intended brightness, color, and texture questions separately before expanding the study. The current geometric analysis does not automatically authorize a color-processing study or a model-based retouching route. No reduction strength, formula, mask, or reference-match claim can be reported from the current menu-only evidence; effect analysis remains pending.
