# Eye vertical position: migration plan

Planning date: 2026-10-17. **Status: planned only; no implementation or test execution.** [Shared sequence and gates](../改造计划.md) · [Evidence gaps](../证据缺口.md) · [Current item evidence](README.md)

## Current behavior and change decision

Current behavior is a nearly rigid core translation along image-down with a shared normalized coefficient and continuous surrounding falloff.

Preserve translation. Treat image, face and individual-eye inferior directions as explicit competing contracts; the near-frontal reference does not by itself choose one for head roll.

Current change location: [BeautyContinuousEyeMap.swift](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L718); inspect only the term and shared helpers actually affected.

## Ordered tasks

1. Measure current same-source core translation, core distances, orthogonal residual and upper/lower decay. Fit each eye first; test whether a shared source-scale normalization explains the bilateral pixel difference.
2. Use G10 captures to distinguish image-down from face/eye-local directions. Synthetic rotated inputs test a chosen covariance rule only; they cannot certify the reference product's rule.
3. If the target selects a different direction, isolate that axis conversion in the position term, preserving zero, sign, strength identity and independent sibling terms. Refit falloff only where source-texture evidence requires it.

Use the shared C0 comparator before fitting; C1 field/inverse rules and C2 ownership/composition apply only to changes actually selected. Do not silently change centered slider, serialized scalar or unavailable-host semantics. A field-coefficient change must be evaluated through the actual admitted forward/relative map, including pose and safety scaling.

## Minimum verification and exit

Existing test locations to select from after identifying the exact changed dependencies: [BeautyContinuousEyeWarpTests.swift](../../../../BeautySDK/Tests/BeautyEffectsTests/BeautyContinuousEyeWarpTests.swift), [BeautyEngineEyeSliderTests.swift](../../../../BeautySDK/Tests/BeautyCoreTests/BeautyEngineEyeSliderTests.swift)

Frozen core translation/rigidity, selected-axis covariance, orthogonal residual and separate brow/bridge/skin observations pass. Exercise the position path and directly affected common-axis/sibling cases only.

Add feature-specific source-selected reference-vector/contour or color oracles where existing synthetic tests cannot establish the target. Freeze criteria before optimization. Keep mechanical safety, reference appearance, API compatibility and eventual host availability as separate gates. Execute only relevant methods and directly affected shared paths; no full SDK/device regression follows automatically.

## Evidence gate and stop condition

Open dependencies: [G01](../证据缺口.md#g01), [G02](../证据缺口.md#g02), [G10](../证据缺口.md#g10), [G14](../证据缺口.md#g14). The register states which decisions are blocked and which independent work can advance.

No production axis change or unilateral gain correction merely because the candidate uses a local normal. Leave the current contract explicit while G10 remains open.

A failing candidate remains a recorded failure. Preserve valid exterior/peer behavior and explicit local identity/refusal when ownership, inverse or source coverage fails; never hide a failed target behind a revived wrong-mechanism fallback. New raw correspondences/pixels remain local under the existing retention boundary. This plan does not enable the tool, acquire a model or change code.
