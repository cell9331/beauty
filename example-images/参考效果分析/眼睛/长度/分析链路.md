## Observed pattern and core geometry

The nasal and temporal portions of each eye move apart horizontally. Vertical displacement is substantially smaller. The active core changes horizontal extent, unlike the approximately uniform horizontal vector of the spacing control.

Dense horizontal P1–P99 spans −9.54 to +8.69 px / −8.51 to +10.39 px. Vertical P1–P99 stays roughly within ±0.90 px in these eye windows. In source-defined cores, 10 independent points per eye give horizontal affine gains 1.154/1.156 and vertical gains 1.028/1.020. Rigid-fit P95 residuals 7.36/6.47 px fall to 0.91/1.10 px for affine fits. This supports tangential stretch; small orthogonal effects remain measurable.

## Independent verification and method limits

Primary template matching selects the strongest source texture in spatial cells without a flow seed. A 19 px template searches ±64 px, with expansion to ±96 px for a boundary peak. It checks contrast, NCC ≥0.78, a separated competitor margin ≥0.025, and independently matched reverse closure ≤1.5 px. These are analysis choices, not application parameters. 273/381 candidates pass; rejections: 70 low-texture, 19 ambiguous, 1 reverse-closure, 17 edge, 1 reverse-ambiguous. No accepted search-boundary point is treated as a measured maximum.

The remaining 16 accepted points lie between those classes. These differences are not truth errors; all accepted disagreements remain. DIS uses a fine-scale estimate; Farneback is a second dense method with a larger averaging window. Their disagreement can reflect smoothing and capture differences, particularly at sharp lid transitions. Do not average it away or interpret a smooth field as hundreds of independent skin observations.

Source-defined protection windows give independent NCC checks: brows: 58 accepted, magnitude P95 0.057 px; nose: 30 accepted, magnitude P95 0.067 px; left-cheek: 13 accepted, magnitude P95 0.108 px; right-cheek: 2 accepted, magnitude P95 0.095 px. Small counts supply correspondingly weak coverage. Distributed stable photo texture is checked independently in the shared registration audit. Near-zero dense output alone is not proof of protection.

## Fact → hypothesis → exclusions → unknowns

**Fact:** The nasal and temporal portions of each eye move apart horizontally. Vertical displacement is substantially smaller. The active core changes horizontal extent, unlike the approximately uniform horizontal vector of the spacing control. **Candidate:** Use a tangential expansion core about a fitted source reference, with separate continuous skin falloff. Test a single axial gain first; do not lock either canthus merely because it is an anatomical endpoint.

**Excluded as sufficient explanations:** A whole-eye translation cannot explain opposite horizontal signs within one eye. A full 2D size change would also produce the prominent superior/inferior pattern seen in the size sample; this pair has much smaller vertical motion. A rigid rotation is inconsistent with the horizontal distance increase and weak vertical pattern.

**Unknown / next discriminator:** The effective center, exact nasal/temporal asymmetry, core extent and support edge are not identified uniquely. Independent sparse cores are small and approximate; affine gains are endpoint-relative summaries, not an internal algorithm coefficient. Additional source-selected transition points and intermediate settings would test linear stretch against a canthal-bump mixture.
