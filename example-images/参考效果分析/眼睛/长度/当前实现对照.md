# Eye length: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad tangential-stretch agreement; pivot and interior attenuation unqualified.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1934 → IMG_1935` supports opposing inner/outer motion and increased horizontal extent. Independent horizontal gains are approximately 1.154/1.156; vertical gains 1.028/1.020. Center, exact support and small normal motion remain uncertain. See [evidence](分析链路.md).

## Active implementation

The nominal local-tangent inverse contribution is `.066*u*horizontalX*aperturePreservation`, transformed into image axes and multiplied by the common shape envelope. Its pivot uses bounded source-RGB aperture evidence or geometry; horizontal distance saturates. See [term and interior attenuation](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L610) and [image transform](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L713).

## What differs

Tangential separation agrees. The [candidate](实现方案.md) starts with an affine tangential core and separate falloff; current source-derived pivot, saturation and smooth interior attenuation can make the actual core nonuniform. None is yet proven inconsistent with the matched reference. Small image-y motion does not alone establish a missing normal term: a rotated tangent itself produces image-y motion.

## Qualification and missing discriminator

No same-pair actual Swift baseline is recorded. Ideal unattenuated `.066` gives relative ±endpoint gain about 1.1413, broadly comparable with the observed scale but not an acceptance result. Same-material tangential gain, orthogonal residual and transition observations would distinguish the remaining choices.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
