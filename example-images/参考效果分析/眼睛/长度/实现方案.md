# Eye length: candidate field

**Status: proposed mathematics only.** This does not identify proprietary internals, implement the SDK, or qualify reproduced appearance. Read the [evidence chain](分析链路.md) and [shared definitions, derivatives, safety and sampling](../实现公共约定.md).

## Minimum geometry and source domain

Use a tangential expansion core about a fitted source reference, with separate continuous skin falloff. Test a single axial gain first; do not lock either canthus merely because it is an anatomical endpoint. Freeze reliable source eye geometry: center/reference c, positive scale L, nasal-to-temporal tangent e_t and inferior normal e_n. The common definitions provide t,n and all normalization derivatives. For this pair s=0 is the observed left-endpoint image and s=1 the right-endpoint mapping, not a neutral-to-positive control. Set the candidate response to zero at s=0 and fit its endpoint value; choosing a linear response between them would be an unmeasured design choice.

## Forward map and full Jacobian

```text
r(p,s) = b(s) dot(p−c,e_t) e_t
D(p,s) = w(p) r(p,s)
J_r = b(s) e_t e_t^T
J_F = I + w b(s) e_t e_t^T + r (grad_w)^T
```

Use the common compact support/protection product and its complete derivative. Smoothstep is only one possible design kernel. The measured optical-flow window and a binary eye/iris mask do not define w. Fit any superior/inferior or nasal/temporal asymmetry from the source-matched transition, not from the control name. If geometry or directions vary spatially rather than remaining frozen constants, their derivatives also enter J_r.

## Calibration, scope and protection

Fit the relative tangential gain and a source reference c from core correspondences; only the tangential coordinate of c matters here. Do not simultaneously claim a unique pivot and an unrelated free tangential translation. The observed core gain near 1.15 is a hypothesis-fitting target for this endpoint pair, not a default or a signed neutral gain. Reassess orthogonal residual before allowing a small normal term.

The interior eye, both canthal regions and following skin can move. The brow, bridge and remote cheeks should remain outside the active support. A hard iris or lid mask would cut across following texture. Nasal and temporal transition widths are fitted separately only if evidence requires their difference.

The effective center, exact nasal/temporal asymmetry, core extent and support edge are not identified uniquely. Independent sparse cores are small and approximate; affine gains are endpoint-relative summaries, not an internal algorithm coefficient. Additional source-selected transition points and intermediate settings would test linear stretch against a canthal-bump mixture.

## Future evaluation sequence

1. Admit reliable source geometry and ownership; retain identity on degenerate or uncertain inputs.
2. Fit the internal model with independent moving correspondences, then determine support using separate decay/protection observations. Preserve accepted outliers and residual structure.
3. Evaluate the complete Jacobian and any multi-effect overlap; establish a valid inverse/coverage strategy. A safe core or positive sampled determinant alone is insufficient.
4. Solve q=F_s(p), check the inverse residual, and sample the original source once. Use the common explicit identity/failure result for unsafe support, failed inverse or uncovered targets.
5. Compare output contours, texture and protected regions against the actual endpoint mapping on the same source points.

Require opposite tangential signs within each eye, an independently supported horizontal distance increase, weak but honestly reported normal residual, and the observed decay. Similar-looking endpoint length with a translated iris or fixed wrong canthus rejects the field.

The zero/translation/expansion/rotation controls reported at the [eye index](../README.md) qualify the measuring method only on their own synthetic cases. No actual candidate output has been rendered or accepted in this task.
