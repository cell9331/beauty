# Lower-eyelid lowering: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad downward/local behavior agreement; peak and support remain unresolved.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1941 → IMG_1942` supports downward motion concentrated toward the outer lower lid. Inner/central and much upper texture are quieter. The primary mobile NCC/DIS P95 disagreement is 12.33 px; denser/template checks did not qualify the peak or precise dx. See [partial evidence](分析链路.md).

## Active implementation

The nominal inverse field is `(0,.083*span*u*lower)`. `lower` combines minimum orbital/protection distance, central guard, outer cutoff, upper-trace sampling clearance and `.60*irisRadius` core clearance through a ramp/softened plateau. RGB-qualified local aperture evidence can adjust its registered frame. See [clearance](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L57) and [lower-lobe field](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L657).

## What differs

The [candidate](实现方案.md) follows a measured lower-lid curve with a local-inferior C2 bump; the current field uses image-y and a different distance/support construction. Direction and locality broadly agree. The code's upper-trace clearance is a protection gate, not an implementation of that proposed lower-lid center curve. Neither the candidate bump nor a larger amplitude is established by the unresolved peak.

## Qualification and missing discriminator

No same-pair actual Swift vector/raster baseline is recorded. This comparison identifies structural choices, not an accepted peak mismatch. More reliable mobile lower-lid/transition correspondences are needed before tuning amplitude or width; extra stationary background cannot fill that gap.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
