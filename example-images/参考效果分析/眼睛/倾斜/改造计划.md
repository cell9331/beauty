# Eye tilt: conditional implementation change plan

**Original status: plan only, 2026-10-17.** Subsequent [T1/T2 execution and directed validation](实施与验证.md) retains the existing production formula; the real-reference acceptance gate remains unqualified. T3–T6 are still conditional. No new tilt parameters were selected. Follow the [overall plan](../改造计划.md), [implementation audit](../实现差异统计.md), [measured evidence](分析链路.md) and [finite-rotation candidate](实现方案.md). Shared coordinate, inverse, protection and sampling rules remain in [the common conventions](../实现公共约定.md).

The first deliverable is a trustworthy comparison of the current implementation with the observed endpoint map. A rewrite is conditional: keep the implementation if that comparison satisfies the frozen fit criteria. If it fails with a repeatable, spatially structured core residual, test a finite rigid core with independently determined support. This plan does not select the proprietary application's internal algorithm.

## Evidence and current behavior

The observed left-to-right endpoints lower the outer side and raise the inner side, with mirrored signs between eyes. The upper/lower horizontal component also reverses. Source-selected core correspondences favor a finite rigid map over vertical-only shear. Smaller-template fits give approximately 8–9 degrees of mirrored endpoint rotation, with matching/template sensitivity; pairwise distances support approximate rigidity. Stationary surrounding skin is outside that core. Exact angle, pivot, independent translation, support and neutral response remain unresolved.

The current [continuous field](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L687) already has both components. It uses `k=.069*u*side`, a source-defined shifted pivot, saturation of the vertical coordinate, a dy-only upper-region attenuation and a smaller outward attenuation, then [orbital/protection weighting](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L717). [Raster sampling](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L958) uses destination-grid inverse offsets. A change cannot be justified merely by the absence of explicit `sin`/`cos` or by comparing `.069` with the measured endpoint angle.

## Ordered implementation steps and decision gates

### T1 — Freeze a comparison contract before modifying the field

Record the G14 evaluation configuration using the authorized local reference pair. Keep source geometry fixed during each comparison. Define image x-right/y-down, endpoint order, source/target domains, core and transition partitions, independent protection windows, fitting versus held-out correspondences and the available template sensitivities. Selection and rejection must depend on source texture/matching reliability, never on agreement with the candidate. Score each eye separately and retain accepted disagreements.

Freeze limits for full-vector residual, core rigidity, protected-region movement, inverse closure and numerical coverage from matching/control sensitivity and the intended rendering tolerance. The existing measured residuals and synthetic-control errors are context, not automatic pass thresholds for all points or images. Do not tune the thresholds after a candidate is seen. If the local reference records or reliable partitions are unavailable, complete the synthetic comparator and report the real-reference gate as unresolved; do not replace them with invented correspondences.

**Exit:** a reviewable aggregate comparison contract, with explicit uncertainty and no raw positions in tracked documents. G01 and G06 may remain unresolved, but their permitted hypotheses must be recorded.

### T2 — Establish the current inverse-to-forward and endpoint baseline

Implement a reusable test/local-analysis comparator before introducing a new tilt formula. For current inverse sampling, write:

```text
B_u(q) = q - d_u(q)                  # target q -> immutable source p
solve B_u(Q_u(p)) = p               # forward map of the same material p
left  = Q_left(p)
right = Q_right(p)
V_pair(left) = right - left
```

Equivalently, on the left endpoint's grid solve `B_right(q_right)=B_left(q_left)`. Check solve residuals and coverage; do not subtract two destination-grid arrays at identical indices and call the result a source-forward endpoint map. The comparator must account for the actual admitted lattice, interpolation, pose factor and clipping/failure policy, not only the unweighted algebraic core.

For a real reference with no certified neutral source, record the frozen source-frame and endpoint replay assumptions explicitly. The current signed SDK endpoints are an existing product contract, not recovered reference neutral strengths. A conditional replay can reveal model-shape residuals, but it cannot close G01 or establish production neutral calibration. A direct observed-span candidate instead maps the observed left source to the right target and must retain that different interpretation.

Verify comparator sign/domain correctness with identity, known finite rotation plus translation and the ideal linear rotational inverse field. In that ideal field, the same-source ±endpoint map can rotate by `2*atan(k)`; at `.069` its magnitude is about 7.89 degrees. Single-endpoint scale factors can cancel in that pair. This is a derived ideal control, not a correction to the measured angle or a qualification of the current saturated/attenuated field.

On independent source-defined core points, compare current output against reference vectors using both dx and dy. Report finite-rigid and affine fit residuals, signed angle sensitivity, spatial residual structure and pairwise-distance changes on the same accepted points. Report transition/protection statistics separately; stationary skin must not dilute a moving-core error. Compare actual rendered texture/contours as well as the admitted coordinate map, so a raster or interpolation failure remains visible.

**Decision:** if the current same-source endpoint map satisfies the frozen, qualified core and support criteria, retain its production formula and add the missing comparator/regression evidence. Do not rewrite it for mathematical style. If correspondence sensitivity cannot distinguish the alternatives, retain the current implementation and leave the mechanism decision open.

### T3 — Diagnose the smallest failing component

Proceed only if T2 has a qualified failure. Partition residuals across upper/lower, inner/outer and core/transition regions. Test the explanatory effect of the existing vertical-coordinate saturation and dy-only attenuation in isolated local candidates. Removing either requires repeatable full-vector or pairwise-geometry evidence; the current upper attenuation must not be deleted merely because a rigid formula looks simpler.

If the core passes and only the transition/protection fails, keep the core and change only the independently measured envelope. If only angle/translation differs within an otherwise rigid core, investigate the permitted response/frame hypothesis first. Do not absorb uncertain neutral calibration into an unrecorded change of the slider curve. Add shear/stretch parameters only after a low-parameter rigid map demonstrably fails beyond the retained matching sensitivity.

**Exit:** a documented residual-to-change argument naming the smallest production component that needs replacement, or a stop decision retaining current behavior.

### T4 — Conditionally implement a finite rigid core and separate support

Reuse the candidate mathematics rather than treating its sample values as defaults. Freeze a convenient reliable source reference `c` and local scale/support axes. Fit `theta` and `b` from the allowed independent core set:

```text
r_s(p) = (R(s*theta) - I) * (p-c) + s*b
F_s(p) = p + w(p)*r_s(p)
J_F = I + w*(R(s*theta)-I) + r_s * grad(w)^T
```

Here `s=0..1` describes the observed endpoint span for reference fitting. It does not redefine public neutral or prescribe signed endpoint angles. Fix `c` by an explicit source convention and fit `b`, or separately test a no-translation pivot hypothesis. Do not claim both are uniquely measured. Do not set two single-endpoint angles to half of 8–9 degrees and label that split observed. Any later signed production response must be declared as an existing or separately qualified design choice under G01.

Use a genuine constant rigid core where the evidence supports one; fit its continuous return to identity from independent transition/protection observations. Follow skin outside the eye outline. Keep iris/lids together in the qualified core. Do not freeze the iris, impose canthal zeros, import a measurement ellipse as a mask or normalize overlapping eye weights without evidence. A different upper/lower support can explain peripheral asymmetry without applying a one-component attenuation throughout the rigid core.

Fit core parameters before support and score held-out points after each decision. Retain the current geometry and protection admission wherever compatible. A proposed plateau that cannot fit inside safe, owned source coverage is a refusal, not permission to move brows/bridge or clamp away a failed transition.

### T5 — Adapt the candidate to the existing inverse-lattice contract

An exact finite forward core must not be pasted into the existing destination-offset slot unchanged. On the rigid plateau, the inverse is analytic; across the blended support, solve and check the complete inverse. Convert to `d(q)=q-F_inverse(q)` only after that check. Reuse the existing lattice/rendering route where the converted map meets its domain, gradient and coverage contract. Include every support/protection derivative and bilateral overlap in safety evaluation. A determinant of one in the core does not qualify the transition.

Check both the mathematical candidate and the final admitted/interpolated map. Admission must not silently turn a proposed rigid endpoint into an unmeasured scaled/sheared one while the result is still reported as a passed fit. If bounds attenuate it, rerun the same frozen comparator on that actual result. Preserve source pixels on unsafe support, invalid ownership, uncovered targets, failed inverse or malformed geometry under the existing fail-closed route.

Keep grids/source geometry stable through zero and tiny sibling strengths. Reuse the shared sampling contract; do not create an extra tilt raster pass or repeatedly sample previously tilted pixels. Summing a converted tilt inverse offset with sibling inverse offsets is the existing composition convention, not proof of a composed source-forward model. Record that limitation and test the directly affected overlap cases; reserve a broader composition replacement for G13.

### T6 — Integrate only the qualified change and retain compatibility

Compare baseline and candidate under the same frozen criteria, including protected regions and actual raster output. Activate the new tilt component only if it passes both the reference and local safety/compatibility gates. Preserve the existing public field, cap, slider polarity, encoding/decoding and zero behavior. Inactive tilt must leave sibling-only outputs unchanged; an infinitesimal tilt must not rescale or abruptly admit another organ field.

Keep a source-controlled baseline and aggregate before/after results so the tilt-only change can be reverted independently. A validation failure means retain/revert the current tilt component or preserve identity on refused local geometry according to the existing ownership contract. It must not trigger per-pixel mixing between old/new mechanisms, a legacy point fallback or a silent change to unrelated controls. No permanent public algorithm switch is required by this plan.

## Stop conditions and completion report

- Stop the rewrite if the qualified current endpoint comparator passes, or if uncertainty cannot distinguish the models. Preserve the baseline and record the measured limit.
- Stop calibration if neutral/response or pivot/translation assumptions cannot be separated. Finish the identifiable observed-span comparison without claiming a neutral-calibrated SDK result.
- Stop production integration on full-vector/rigidity, inverse/coverage, protection or compatibility failure. Reduce scope to the passing diagnostics; do not loosen G14 after seeing the failure.
- Keep raw images, actual correspondence positions, masks, dense fields and private input paths in ignored local material only. Tracked output contains aggregate counts/residuals, formulas, decisions and reproducible synthetic tests.

The eventual report must distinguish unchanged baseline, a qualified tilt-only change and unresolved evidence. State exactly which local measurements and tests ran, their inputs/coverage, and which claims remain open. The linked execution record supplies the subsequent baseline results; neither document supplies a reference-effect qualification.
