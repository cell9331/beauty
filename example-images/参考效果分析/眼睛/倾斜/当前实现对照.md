# Eye tilt: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Actual conditional baseline mismatch measured; production formula retained.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1945 → IMG_1946` supports mirrored finite rotational cores with both vector components. Precise pivot, support and neutral decomposition remain unresolved. The latest [current-map execution record](实施与验证.md) supersedes the old audit's statement that the current core had not been measured.

## Active implementation

The nominal inverse core has `k=.069*u*side`, shifted source pivot, transverse-coordinate saturation, dy-only upper/outward attenuation and orbital protection. It has **both dx and dy** and does not apply the iris-preservation multiplier to tilt. See [actual term](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L687). It is not an exact finite-rigid plateau; absence of explicit sin/cos is not itself a defect.

## What differs

The actual fixed-observed-left endpoint replay now provides a concrete difference. Primary core vector median/P95 errors are **1.419/3.309 px** on 51 image-left points and **1.984/2.673 px** on 58 image-right points. Reference/current descriptive angles are −8.650°/−7.297° and +8.491°/+7.281°.

Current core pair-distance changes are not uniformly worse than the reference estimates. The difference contains centroid/component offset, angle and transition shape; it cannot uniquely select a change to saturation, upper attenuation, pivot, detector frame or response. These descriptive angles are not new production parameters. Ideal linear ±endpoint algebra gives about 7.89° for `.069`, but does not replace measurement of the actual admitted map.

## Qualification and missing discriminator

The latest record contains actual field/raster replay, all 3,737 frozen points resolved, local stable/protection observations and 30 historical directed passes. It is conditional on one observed-left carrier, not a certified neutral. Retrospective partitions and absent independent fit criteria leave reference acceptance unqualified. The production formula was retained, with no safety relaxation or replacement parameters selected. The other nine non-iris controls do not inherit these tilt results.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
