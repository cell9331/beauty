## What the supplied evidence supports

The supplied batch establishes a menu entry only. It contains no qualified before/after pair for this feature and no documented change of this control. The same-source outdoor original does not resolve the missing target or establish the feature's neutral state. See the [input inventory](../输入清单.md).

The label does not identify what is equalized. Candidate observables could include eye opening, length, height, canthal orientation, position, or an appearance measure. The label also cannot establish whether one eye is the reference, both eyes move toward an average, or the effect follows another target. Perspective and head pose can produce image-space differences even without a corresponding anatomical asymmetry; these cannot be silently treated as a correction objective.

## Minimum additional evidence

Capture the same photograph before and after selecting and applying the control. Keep framing, crop, scale, other controls, and background protection fixed. Record every visible state or strength and any choice of reference eye or scope. If there is a slider, capture neutral and endpoints; if there is only an action or toggle, capture its explicit before/after states.

Use a photograph with visible but clearly resolved left/right eye differences. If the UI permits choosing a reference side, capture both choices from the same initial state. This is the smallest useful extension for distinguishing a fixed-reference operation from a symmetric adjustment. A near-symmetric face alone may produce a weak result and would not prove the feature inactive.

## How the new evidence would discriminate mechanisms

Align with stable external texture and measure both eyes independently. Compare the source-to-target change in each eye's dimensions, orientation, and position using consistently defined local axes. One quieter eye with the other approaching its geometry would support a reference-side hypothesis. Both eyes moving toward a shared result would support a different hypothesis, whose target still needs measurement. A reflected screenshot is not a valid substitute for an observed output.

Separate image-space equalization from any claim about anatomy or pose correction. No averaging rule, mirroring formula, fixed side, or symmetry guarantee is justified by the present evidence.
