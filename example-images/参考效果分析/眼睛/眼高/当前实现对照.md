# Eye height: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad normal-expansion agreement; anchor and attenuation unqualified.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1932 → IMG_1933` separates upper/lower texture, predominantly vertically, with a larger upper lobe and smaller horizontal motion. Dense vertical gains around 1.51/1.50 differ from sparse estimates around 1.45/1.68; gain and anchor precision remain unresolved. See [evidence](分析链路.md).

## Active implementation

The nominal local-normal inverse term is `.200*u*shapeQ.y*aperturePreservation*heightAlong`, where `heightAlong=max(0,1-(localX/(.52*span))²)²`. The normal coordinate is centered on the observed aperture midpoint and saturates. Source-contour-interior attenuation and the common orbital envelope further modify it. See [attenuation and term](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L610).

## What differs

The reference supports expansion but does not establish the exact midpoint anchor, fixed lateral quartic zero, interior attenuation or superior/inferior split. The [candidate](实现方案.md) leaves these to observation. The attenuation is smooth and contour-interior weighted, not a hard iris mask. Local-normal motion can have an image-x component. An asymmetric observed lobe does not by itself prove the current coefficient wrong; geometry/protection also introduce asymmetry.

## Qualification and missing discriminator

No same-pair actual Swift baseline is recorded. An ideal unattenuated central ±endpoint inverse coefficient `.200` gives a relative gain of 1.5, but this does not qualify actual output. Matching-method sensitivity prevents selecting a precise replacement gain from the current study.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
