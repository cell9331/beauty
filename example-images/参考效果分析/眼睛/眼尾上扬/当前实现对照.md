# Outer-eye tail lift: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad outer-upward agreement; full-vector mechanism remains ambiguous.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1943 → IMG_1944` shows upward temporal motion, quieter inner texture and much smaller horizontal motion. The existing analysis has not excluded a rotation around a nasal pivot with same-core rigidity/pair-distance evidence. See [evidence](分析链路.md).

## Active implementation

The nominal inverse term is pure image-y: `d_y=-.066*span*u*outer*aperturePreservation*shapeWeight`, with `outer=smooth((outward-.08)/.92)^1.5`. Outward distance uses source pupil/visible pivot and eye geometry. Iris attenuation is contour-interior weighted. See [outward frame](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L639), [term](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L684) and [weight](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L717).

## What differs

The [candidate](实现方案.md) proposes a compact bump while retaining a pivoted-rotation alternative. Current increasing-outward weighting, exact zero image-x and interior attenuation are different choices. The measured small dx alone does not prove an implementation bug or calibrate another component. Quiet inner texture does not exclude a near-nasal pivot.

## Qualification and missing discriminator

No same-pair actual Swift baseline is recorded. A common accepted core set, full-vector residuals, rigid/pair-distance checks and independently observed falloff are needed to distinguish the current lift, bump and pivoted rotation. The current evidence supports locality/direction more strongly than a unique formula.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
