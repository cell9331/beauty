## Observed pattern and core geometry

The eyes separate: image-left moves left, image-right moves right. Each core has a nearly constant horizontal vector while surrounding skin returns toward zero. This differs from the two opposing horizontal lobes inside each eye under length adjustment.

Source-defined cores contain 10/11 independent correspondences. Median dx is −26.96/+25.58 px; P10–P90 is −27.16 to −26.83 / +25.12 to +25.71 px. Median dy is +0.14/+0.02 px. Core rigid-fit P95 residuals are 0.29/0.44 px, and local gains are close to one. The two core translations increase their relative separation by about 52.54 px in this observed pair; this is not a neutral-relative distance.

## Independent verification and method limits

Primary template matching selects the strongest source texture in spatial cells without a flow seed. A 19 px template searches ±64 px, with expansion to ±96 px for a boundary peak. It checks contrast, NCC ≥0.78, a separated competitor margin ≥0.025, and independently matched reverse closure ≤1.5 px. These are analysis choices, not application parameters. 256/380 candidates pass; rejections: 68 low-texture, 31 ambiguous, 5 reverse-ambiguous, 2 low-ncc, 1 reverse-closure, 17 edge. No accepted search-boundary point is treated as a measured maximum.

The remaining 0 accepted points lie between those classes. These differences are not truth errors; all accepted disagreements remain. DIS uses a fine-scale estimate; Farneback is a second dense method with a larger averaging window. Their disagreement can reflect smoothing and capture differences, particularly at sharp lid transitions. Do not average it away or interpret a smooth field as hundreds of independent skin observations.

Source-defined protection windows give independent NCC checks: brows: 58 accepted, magnitude P95 0.057 px; nose: 30 accepted, magnitude P95 0.067 px; left-cheek: 13 accepted, magnitude P95 0.108 px; right-cheek: 2 accepted, magnitude P95 0.095 px. Small counts supply correspondingly weak coverage. Distributed stable photo texture is checked independently in the shared registration audit. Near-zero dense output alone is not proof of protection.

## Fact → hypothesis → exclusions → unknowns

**Fact:** The eyes separate: image-left moves left, image-right moves right. Each core has a nearly constant horizontal vector while surrounding skin returns toward zero. This differs from the two opposing horizontal lobes inside each eye under length adjustment. **Candidate:** Use separately calibrated temporal translation plateaus with continuous periocular support. A shared normalized response is a later hypothesis; the two measured pixel amplitudes are not forced equal.

**Excluded as sufficient explanations:** An axial length change has opposite signs within each eye; this pair has a constant core direction. A global face-width or camera-scale transform would move stable forehead/hair/nose texture, which remains on the native grid. A canthus-only bump would leave the iris quiet, contrary to the translating core.

**Unknown / next discriminator:** The compact support, bridge-side overlap/protection, bilateral amplitude relation and response between endpoints remain unmeasured. Farneback agrees well in the core, but retained moving-point disagreement has a P99 tail of 4.77 px; a good median does not qualify every transition. More independent nasal/temporal boundary texture is needed to fit falloff.
