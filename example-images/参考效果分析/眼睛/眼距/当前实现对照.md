# Eye spacing: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad core-translation agreement; axes and bridge decay unqualified.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1936 → IMG_1937` supports outward near-rigid core translations: median dx −26.96/+25.58 px and near-zero dy. Relative inter-eye separation increases about 52.54 px; this is neither a single-eye amplitude nor a neutral-relative measurement. See [evidence](分析链路.md).

## Active implementation

The nominal inverse term is `(side*.0828*visibleSpan*u*spacingWeight,0)` in image axes. A larger envelope uses radii about `1.12*span/.85*span`, a `.30*span` transition, feature protection and a source-fixed zero midline. Spacing requires an admitted disjoint eye pair. No iris attenuation multiplier is applied to this translation. See [support](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L594), [pair admission](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L285) and [term](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L720).

## What differs

The [candidate](实现方案.md) proposes separately observed translation plateaus and source-local temporal axes. Current code chooses image-x, a shared normalized gain and a predefined bilateral midline/bridge strategy. Those are identifiable structural choices, but the frontal pair does not prove a rotated-axis rule or a different normalized gain. Its quiet core does not determine the complete bridge transition.

## Qualification and missing discriminator

No same-pair actual Swift baseline is recorded. Actual endpoint translations and bridge-side decay need separate scoring; stationary bridge pixels must not dilute moving-core error. Pose-axis qualification remains a separate missing reference.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
