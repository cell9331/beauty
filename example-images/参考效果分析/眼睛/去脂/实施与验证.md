## Exact limited hypothesis

The general [candidate](实现方案.md) uses a curved source-lid projection and varying superior normal. Implementing that without qualified geometry would hide unknown ownership/projection assumptions. This first experiment is only its **straight source-frame special case**, with a constant explicitly supplied superior direction.

For source point `p`, center `c`, supplied frame columns `x,n`, radii `rx,ry`, amplitude `a >= 0` and source-relative progress `t`:

```text
v       = [x n]ᵀ (p − c)
B(z)    = (1 − z²)² for |z| < 1; otherwise 0
W(p)    = B(v.x/rx) B(v.y/ry)
D_t(p)  = t a n W(p)
F_t(p)  = p + D_t(p)
∇D_t    = t a n ⊗ ∇W
```

Both bump derivatives are included. `∇n = 0` is true only for this special case; it does not justify dropping normal/projection derivatives from a future curved field. Source superior may rotate with the supplied frame, rather than being an assumed negative screen-y. The current upright photo frame is not a transferable pose estimator.

With `M = max |B′| = 8/(3√3)`, a conservative global bound is:

```text
||∇D_t|| <= t a ||n|| M (||x||/rx + ||n||/ry) = kappa
```

The code retains actual supplied axis values, rounds the bound outward and requires `kappa < 1`. Rectangle support is bounded with `[x n]⁻ᵀ`, including both handednesses; an ellipse approximation or near-unit axes treated as exact would be incorrect. The bound is a sufficient inverse certificate, not a fitted feature cap. Refusal under it is not proof that the actual field folds.

For a certified field, fixed-point inversion must meet the explicit residual/iteration policy. Original pixels are sampled once through that inverse. The entire input must be exactly opaque; transparency is a whole-request refusal, including zero progress, rather than flattening or a successful no-op. Every changed destination and all four source taps must satisfy bounds/ownership/alpha checks before RGB sampling. Failure discards the affected region transactionally; an independent valid disjoint peer may remain. Support overlap or protected-support collision refuses rather than multiplying by an unproved spatial mask.

All source centers, widths, amplitudes, ownership and solver settings are explicit research inputs. Synthetic test constants are not photo defaults. Source-relative `t=0` means identity of the supplied source; neither `t=1` nor half progress is an established reference slider setting. No `a/L`, endpoint split or response coefficient is fixed for production.
