# Inner canthus: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad nasal-direction agreement; small normal motion and support unqualified.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

`IMG_1947 → IMG_1948` supports nasal-corner/nasal-sclera motion toward the nose, with quieter iris interior and temporal side. Supplementary active-corner coverage is only one point per eye; small dy and the exact plateau/bump remain unresolved. Iris fringe is not uniformly fixed. See [evidence](分析链路.md).

## Active implementation

The nominal inverse field is pure image-x: `(-side*.102*span*u*innerWeight,0)`. The weight uses minimum orbital/protection distance, nasal-side and vertical extents, `.70*irisRadius` core clearance and protectionFade. See [core clearance](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L658) and [field](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L704).

## What differs

The main direction and quiet opposite side agree. The [candidate](实现方案.md) leaves local axes, a small normal component and plateau/bump shape to fitting. Current exact zero image-y, fixed core clearance and ramp widths are unqualified implementation commitments. Sparse small orthogonal observations do not establish a calibrated correction or prove zero-dy wrong.

## Qualification and missing discriminator

No same-pair actual Swift baseline is recorded. Reliable corner/adjacent-sclera texture over core and transition, along with source-axis orientation and retained uncertainty, is needed to separate tangential motion from an additional normal component.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
