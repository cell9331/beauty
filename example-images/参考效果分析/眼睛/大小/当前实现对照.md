# Eye size: reference versus current implementation

[Shared current-code contracts and eleven-control summary](../十一项当前实现对照.md) · [Feature overview](README.md)

Reviewed 2026-10-17 against the current working files, including uncommitted changes. **Broad mechanism agreement; calibration and support unqualified.** This review changes no SDK/host behavior and runs no new measurement, build or test.

## Reference facts

The observed pair `IMG_1928 → IMG_1929` supports two-dimensional core expansion. Independent core gains are approximately 1.13/1.11 horizontally and 1.17/1.15 vertically across the two eyes. The study does not uniquely determine slight anisotropy, center or support. See the [evidence chain](分析链路.md) and [candidate](实现方案.md).

## Active implementation

The observed-eye route uses the local canthal tangent/normal. Its nominal inverse term is `.063*u*(horizontalX, shapeQ.y)`, then transformed to image axes and multiplied by orbital/protection weight. The horizontal pivot comes from bounded source-RGB aperture refinement or the geometric fallback; the vertical reference is the observed aperture midpoint. Distances saturate beyond fixed core/transition extents. See [field](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L621) and [image transform](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousEyeMap.swift#L713).

## What differs

The broad expansion agrees. Current pivots, saturation and envelope are fixed implementation choices; the candidate leaves them to independent fitting. They have not been shown wrong by an actual admitted-map replay on this pair. An ideal unattenuated `.063` inverse coefficient yields a relative ±endpoint gain of about 1.1345, so comparing `.063` directly with a measured 13% expansion is invalid. Actual weighting/admission can change that gain.

## Qualification and missing discriminator

No same-pair actual Swift vector/raster baseline is recorded. Existing analytic-aperture response tests are not this photo comparison. The remaining discriminating evidence is same-material core gain/anisotropy and separately observed transition/protection, using the actual admitted map.

Numerical constants above describe existing code or measured aggregates; they are not replacement defaults. See the shared comparison for inverse/forward domains, strength polarity, admission and source-sampling limits.
