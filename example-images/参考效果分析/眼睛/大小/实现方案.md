# Eye size: candidate field

**Status: proposed mathematics only.** This does not identify proprietary internals, implement the SDK, or qualify reproduced appearance. Read the [evidence chain](分析链路.md) and [shared definitions, derivatives, safety and sampling](../实现公共约定.md).

## Minimum geometry and source domain

Start with a locally isotropic expansion core and a separately fitted continuous envelope. A distinct horizontal/vertical gain is a competing refinement only if independent residuals consistently require it. Freeze reliable source eye geometry: center/reference c, positive scale L, nasal-to-temporal tangent e_t and inferior normal e_n. The common definitions provide t,n and all normalization derivatives. For this pair s=0 is the observed left-endpoint image and s=1 the right-endpoint mapping, not a neutral-to-positive control. Set the candidate response to zero at s=0 and fit its endpoint value; choosing a linear response between them would be an unmeasured design choice.

## Forward map and full Jacobian

```text
r(p,s) = b(s) (p−c)
D(p,s) = w(p) r(p,s)
J_r = b(s) I
J_F = I + w b(s) I + r (grad_w)^T
```

Use the common compact support/protection product and its complete derivative. Smoothstep is only one possible design kernel. The measured optical-flow window and a binary eye/iris mask do not define w. Fit any superior/inferior or nasal/temporal asymmetry from the source-matched transition, not from the control name. If geometry or directions vary spatially rather than remaining frozen constants, their derivatives also enter J_r.

## Calibration, scope and protection

Fit c and the endpoint gain using independent core correspondences, then fit decay using other correspondences. Avoid treating a center and a free translation as independently identified parameters. The approximate 1.12–1.14 dense relative gain is a sample-specific diagnostic, not a default. If systematic anisotropy survives template/selection sensitivity, replace bI by b_t e_t e_t^T + b_n e_n e_n^T and refit both components.

The iris, sclera, lids, canthi and following skin participate in the observed expansion. A fixed eyelid or iris-only binary mask would contradict the measured support. Protect brows, nose/bridge and remote cheeks using independent windows; do not use a semantic eye outline as the support boundary.

The exact reference center, support shape, plateau edge, and small anisotropy remain unidentified. Core gains are endpoint-relative fits, not neutral strengths. Additional source-selected correspondences across the upper/lower and nasal/temporal transitions would distinguish an isotropic core from an anisotropic or non-linear core.

## Future evaluation sequence

1. Admit reliable source geometry and ownership; retain identity on degenerate or uncertain inputs.
2. Fit the internal model with independent moving correspondences, then determine support using separate decay/protection observations. Preserve accepted outliers and residual structure.
3. Evaluate the complete Jacobian and any multi-effect overlap; establish a valid inverse/coverage strategy. A safe core or positive sampled determinant alone is insufficient.
4. Solve q=F_s(p), check the inverse residual, and sample the original source once. Use the common explicit identity/failure result for unsafe support, failed inverse or uncovered targets.
5. Compare output contours, texture and protected regions against the actual endpoint mapping on the same source points.

Check the sign change in both components, near-equal core gains only to the precision supported by independent points, distance increase, and stationary outer skin. A reproducible anisotropic residual would reject the simplest isotropic core; a moving brow or seam would reject the fitted support.

The zero/translation/expansion/rotation controls reported at the [eye index](../README.md) qualify the measuring method only on their own synthetic cases. No actual candidate output has been rendered or accepted in this task.
