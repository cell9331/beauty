## 已测约束与待定量

中央纹理支持低端到高端约 15.7–15.8° 的顺时针相对转角，中央成对距离基本保留。外围必须归零，且同半径不同方向的响应不同，不能采用只依赖圆形半径的统一旋转衰减。

本轮没有共同中性输入。端点相对角不能除二用作正负单端标定；中性中心、`θ(u)`、核心边界及二维过渡宽度仍是待拟合量。若首版采用对称滑杆响应，应明确记为产品设计选择，并通过新增中性与中间档复测。

## 最小几何与前向场

准备可靠的口唇中心候选 `c`、口裂切向 `e_t`、指向下唇的法向 `e_n`、口唇尺度 `L` 及上下唇/嘴角外围。局部基 `Q=[e_t,e_n]` 保持正向；以 `r=Qᵀ(p-c)` 表示源点，x 向局部右、y 向局部下。

定义二维光滑角度包络 `w(r)∈[0,1]`：中央纹理核心取 1，外围及明确保护区取 0，过渡带至少一阶连续。它包含随动皮肤，不等同于唇色分割。上下与两侧宽度由各方向剖面分别拟合，不能从本次截图取固定像素半径迁移到所有脸。

前向候选为：

```text
φ(r,u) = θ(u) w(r)
Rφ = [[cosφ, -sinφ], [sinφ, cosφ]]
F_u(p) = c + Q Rφ(r,u) r
D(p,u) = F_u(p)-p
```

`θ>0` 表示顺时针。核心 `w=1` 时是有限二维旋转，自动保留两个位移分量与核心距离；外围 `w=0` 时返回恒等映射。使用完整正弦/余弦，不用 `dy∝x` 的单分量近似代替本次约 16° 的相对转角。

这只是足以解释核心证据的最小模型。先检验其外围残差是否有稳定空间规律，再决定是否增加中心漂移或其他自由度；不要追随单个错误对应设置局部控制点。

## 支撑、Jacobian 与逆解

`w` 需同时满足嘴形支撑和保护观测。以光滑二维嘴部邻域构造初值，可按沿口裂位置改变上下过渡宽度；不能只为了与静止鼻下相接就任意压窄过渡。

以下在局部坐标中定义 `Ω=[[0,-1],[1,0]]`。`θ` 对空间为常数时：

```text
J_F = Rφ + θ (Rφ Ωr)(∇w)ᵀ
det J_F = 1 + θ (∇w)ᵀ Ωr
```

该式包含包络的全部一阶导数。核心 `det=1` 不能证明过渡区安全；非等向 `w` 的梯度可引起额外压缩。逐项联合评估整个支撑和保护边界，保留正行列式、最小奇异值与全局无重叠预算；失败时减弱强度或放宽允许的过渡，不能在保护区外硬截断位移。

已对一个任意的无量纲二维包络，在 `θ=-0.28、0、0.28` 的各 4,000 个合成点上交叉检查该解析式：Jacobian 与有限差分的最大分量差小于 `3.4×10⁻¹⁰`，数值逆解的最大回代残差小于 `4.6×10⁻¹⁶`。这些设计参数不来自参考图；检查只核对公式与该合成例的一致性，不证明一般包络的全域无折叠或真实效果合格。

各向异性包络下，目标点的半径通常不足以直接确定其源点角度，`q-D(q)` 也不是精确逆。使用带残差检查的逆解或已验证的无重叠网格，按公共约定回采原图一次。几何不可靠、支撑与保护无法同时满足或逆解失败时，按公共失败策略返回该项恒等结果。

## 实现次序与可推翻条件

1. 在同一中性源坐标准备口唇几何、尺度和独立保护区；先确保核心几何稳定。
2. 用独立纹理拟合核心旋转与候选中心，比较刚性、平移和相似模型残差；保留外围点，不以拟合好坏反向筛点。
3. 仅以可解释的横纵剖面拟合二维包络，核验鼻下、脸颊、下巴及邻近皮肤，不将弱纹理光流填充当边界真值。
4. 按同一中性源点生成两个端点映射后比较相对场，验证完整 Jacobian、全局覆盖及逆解，再从原图采样。
5. 在独立源纹理上核对方向、转角、距离保留、嘴角与上下缘横向分量、外围归零；以真实输出对齐端点作外观复核。

如果中央出现可靠而显著的成对距离变化，或有限旋转拟合在两种独立对应上都保留成片系统残差，应推翻纯旋转核心。若外围在同一方向呈现无法由角度衰减解释的径向运动，再检验额外变形；现有外围误匹配与光流不稳定不足以单独授权增加该项机制。

本轮仅完成测量和公式推导，未生成算法执行计划，也未做 SDK、宿主或模拟器回归。
