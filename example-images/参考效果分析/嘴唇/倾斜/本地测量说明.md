# 倾斜本地测量说明

本次材料为 **IMG_1965.PNG 与 IMG_1966.PNG**，方向为前者到后者。输入照片保留在既有嘴巴参考目录，不改原件。端点截图共同网格上的原像素用于测量；不是原相机像素，也没有建立共同零态。

本地可审阅图见[位移证据](证据/位移证据.png)。共享的本地测量目录保留主测量脚本、配准与分区汇总、前后向场和另一尺度的场；`controls_qc/` 保留本项独立控制脚本、零变化/已知平移/局部旋转控制汇总，以及 SIFT、旋转模板的原始对应。图像、实际对应点和逐像素场沿现有规则留在本地，不写入持久 Markdown 或强制提交。

复测应依次执行：

1. 核对输入身份、配对方向与共同照片区域，先确认独立稳定留出点仍支持恒等对齐。
2. 运行主测量，保留普通 NCC 的接受与拒绝记录、前后向闭合及另一尺度差异。
3. 用同一源纹理运行零变化、`(+23,-17)` px 平移和核心 14° 顺时针局部旋转控制，核对符号及各方法适用域。
4. 运行独立 SIFT 互反描述子匹配、旋转模板穷举搜索；按源中央与外围分区报告模型和活动点差异，不用 DIS 或拟合残差筛掉不一致点。
5. 重新生成证据，核对角度、分量方向、图例和统计数量与[分析链路](分析链路.md)一致。

记录中的 SIFT 控制包含一次大误匹配，普通 NCC 在旋转控制也明显失效；重测不得只保留成功百分位而删除最大误差。两种独立方法对真实中央转角的相符，是当前有限旋转假设的主要支持；它不证明外围流场或参考产品内部机制。

本次验证范围为输入对齐、三类合成控制、真实倾斜对应、核心几何拟合，以及候选 Jacobian 的有限差分与合成逆解自检；没有运行 SDK 测试、构建或模拟器回归。
