# 上下：分析链路

## 输入与对齐

2026-10-16，`IMG_1963.PNG` 为滑杆左端源图，`IMG_1964.PNG` 为右端目标图。选中名称为“上下”，两端位置清楚，没有可读数值。原截图均为 1170×2532，照片构图相同；没有共同中性原图，切项是否清零也未证实，只分析配对低→高差。

测量前约定 `D(p)=p_high−p_low`，画面向右为 `+dx`、向下为 `+dy`，单位为截图像素。公共照片裁区排除 UI 和覆盖层；效果区外的分散稳定纹理用于相似变换拟合与独立留出检验，嘴部不参与消除全局差异。保护观察分开查看眼、鼻、外侧双颊和颏；参见[公共约定](../实现公共约定.md)。

稳定 SIFT 对应 2049 个，1366 个拟合、683 个留出。尺度约 1、转角约 0；留出残差中位和 P95 均小于 0.001 px，最大也小于 0.001 px；稳定区原字节一致率为 100%。因此保留共同原网格，不重采样，不通过可变形配准消除目标移动。

## 平台资格与竞争模型

按源图色素和空间范围选择 45 个已接受点，平移中位向量为 `(−1.34,−20.28)` px；整体残差中位 0.32、P95 13.63 px。上半部分 9 点含慢速过渡和可能的上缘皮肤，不能将此集合直接当全嘴唇刚体。对全 45 点做仿射会出现约 0.90 的垂直奇异尺度，但这混合了平台与衰减，不能据此声称嘴唇整体压缩。

从相同源图条件中预先按下半部再选 36 点，不按运动大小或光流一致性筛选：

| 检查 | 结果 |
| --- | --- |
| 平移向量中位数 | `(−1.344,−20.345)` px |
| 平移残差 | 中位 0.25、P95 0.57、最大 0.75 px |
| dy 分布 | P05～P95 为 −20.63～−19.92 px |
| 源点距大于 20 px 的点对距离比 | 中位 0.999、P05～P95 为 0.993～1.012 |

点对检查由 36 点形成 575 对，彼此相关，不是 575 个独立观测。它支持下半部近似平移与距离保持，不能升级成全嘴部刚性证明。上缘独立点少，需要更密纹理对应区分唇上缘是否同属平台、过渡是否进入皮肤，以及是否存在细小形变。

| 事实 | 候选或竞争排除 | 未知/反证 |
| --- | --- | --- |
| 中央和下部近恒定向上，点对距离大致保持 | 局部二维平移平台优先 | 若源选平台内留出点出现稳定位置相关残差，须收窄平台或修改内部模型 |
| 左右 dy 均同号，横向不呈反向内外移 | 旋转和水平伸缩不能解释主运动 | 全唇微小转动尚不能仅凭方向排尽，但无须先加入旋转参数 |

| dx 约 −1.3 px | 保留二维平移向量 | 局部轴、姿态关系与是否恒定比例需新增观测，不强制 dx=0 |

## 独立核验与不确定性

NCC 尝试 750 点、接受 246 点，拒绝为低纹理 408、歧义峰 83、反向闭合 9、峰值不足 3、搜索边界 1。搜索半径 72 px；贴边点改用 120 px 后不再贴边，仍因歧义拒绝，未加入接受数。

| 点组 | 数量 | DIS/NCC 差异中位数 | 差异 P95 |
| --- | ---: | ---: | ---: |
| 移动（NCC 模长≥1 px） | 84 | 0.37 px | 1.62 px |
| 静止（NCC 模长<1 px） | 162 | 0.03 px | 0.62 px |

以上为方法间差异，不是真值误差。色素全子集方法差异中位 0.32、P95 0.78 px，覆盖范围有限，不能代替移动点全统计。低纹理拒绝很多，不以稠密格点数量补充独立样本。

唇邻域前后向闭合中位 0.13、P95 1.03 px；全尺寸与半尺度差异中位 0.41、P95 1.46 px，尺度差异只统计主场闭合小于 1 px 的像素。上部闭合 P95 达 1.83、尺度差异 P95 达 1.69 px；下部闭合 P95 0.33 px，更稳定。由此只能给平台与衰减的范围线索，不能精确确定完整支持或 10%→90% 过渡宽度。

眼窗、外侧双颊窗原字节全部相同；眼窗不在 NCC 采点范围内，没有眼部独立 NCC 证据。鼻窗 34 点 dx/dy 中位约 0，dy P05～P95 为 −0.19～+0.02 px，整个鼻窗并非字节全同。颏窗 30 点 dy 中位 −0.03、P05 −2.33、最小 −4.22 px，证明上侧皮肤随动，不能报告整个下巴固定。

只有端点，不能测中性拆分、滑杆线性或所有人脸的运动范围。下一项有区分力的补充是上唇缘的独立纹理对应、共同零态与至少一个中间档，而不是直接增加自由参数。
