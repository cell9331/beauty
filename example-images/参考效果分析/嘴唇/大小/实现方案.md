# 大小：候选实现方案

2026-10-17 实施更新：本页保留原候选推导；当前 SDK 实现、幅度/支撑设计与限制统一见[SDK改造记录](../SDK改造记录.md)，实际验证和待所有者验收项见[人工验收](../人工验收.md)。下文“未实施”指原测量阶段。

状态：**测量支持的候选，尚未实施或获得外观验收**。本轮低→高表现为二维收缩；不把“大小”二字推定为高端放大，也不声称下面是美图秀秀的唯一内部公式。

## 最小模型

沿用[公共坐标、权重与逆采样约定](../实现公共约定.md)。在本次配对源网格中，以源嘴部几何给出收缩中心 `c`，先用画面水平和垂直轴描述实测；新姿态的局部轴必须另行核验。令 `r=p−c`，`W(p)` 为嘴唇核心近 1、外围连续归零的支撑。

```math
K=\alpha e_xe_x^T+\beta e_ye_y^T,
\qquad D_{pair}(p)=W(p)K(p-c),
\qquad F_{pair}(p)=p+D_{pair}(p).
```

`α<0、β<0` 表示本次低→高内收，核心相对倍率分别为 `1+α、1+β`。首先检验 `α=β` 的等比约束；只有留出点显示可重复的轴向残差，才放开二者。`c` 由源几何初始化，再用独立纹理残差校核，不能把某个截图坐标当作所有照片的常数。该模型目前不增加逐点控制或旋转参数。

本次色素子集给等比倍率约 0.884；分轴拟合约为水平 0.877、垂直 0.923。它们是低→高相对拟合，受采点和随动边缘影响，尚不足以固定通用参数。等比模型 P95 残差 7.79 px，不能直接以“最小模型”名义忽略；若收缩核心的空间留出残差仍大，则应拒绝严格等比并核验分轴或支撑的具体原因。

支撑应覆盖嘴角、上下唇及其随动皮肤；鼻底与颏侧过渡可不同宽。不能用色素二值蒙版截断场，也不能将颏上侧观察到的随动误标为泄漏后强制归零。外围范围、平台边缘与过渡宽度均待拟合，不从本张图的固定半径迁移。

## 标定和滑杆边界

可直接标定的是 `F_pair: low→high`。如为研究预览定义 `τ∈[0,1]`，可选 `D(p,τ)=τD_pair(p)`；这是人为线性插值，`τ=0` 只是本配对低端，并非已证明的产品中性值。不能把总位移或收缩率除二，分别写成两个实测单端强度。

真正宿主滑杆需要共同中性源和多个中间档再标定 `F_low、F_high` 及响应函数；若以中性坐标建模，应按同一源点计算 `F_high(p)−F_low(p)`，再转到低端源网格比较。缺少嘴宽、唇高的独立尺度测量时，不将截图像素幅度转换为通用无量纲常数。

## 连续性与安全约束

候选完整导数为：

```math
J_F=I+WK+[K(p-c)]\otimes\nabla W.
```

核心倍率为正只约束内部，不能替代外围权重导数和完整映射检查。权重须至少连续且在接回恒等处导数平顺，检查收缩中心、嘴角与上下过渡的 Jacobian、覆盖和全局重叠；阈值是后续设计预算，不冒称本次实测安全界。退化或被遮挡的源几何、支撑与保护区冲突、逆解不收敛时应减弱或拒绝该项。

最终渲染按公共约定求真实逆映射，从原图单次采样。`p=q−D(q)` 只能是初值，不能直接视为逆解；不能反复变形上一档输出。

## 实施前可审阅的验证

1. 在同一低端源上生成预测高端，独立比较两侧 dx、上/下 dy 的符号和沿长度、上下方向的剖面，报告移动点误差，不能用静止背景稀释。
2. 比较等比和分轴模型在空间留出纹理上的残差。若加入分轴参数仅降低训练残差，仍保留等比的未知状态；若两者均不能解释残差，则重新检查核心和支撑，而非堆更多局部峰。
3. 核验眼与外侧双颊固定，鼻纹理接近静止；对颏上侧单独允许连续随动，再检查更远处归零，不能声称整个下巴固定。
4. 同时检查完整 Jacobian、逆残差、纹理拉伸和边缘接续。用单独的已知二维收缩与零场控制核对方向和采样能力；合成控制不能替代实际参考复现。

当前未知包括共同零态、精确中心、严格等比资格、支撑过渡与多档响应。完成这些检查前，本方案仍只是一条可被当前对应推翻的候选路线。
