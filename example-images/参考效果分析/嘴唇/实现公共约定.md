# 嘴唇位移分析的公共约定

本文保留 2026-10-16 测量阶段的原始范围与结论。2026-10-17 后续实施另见[SDK改造记录](SDK改造记录.md)和[人工验收](人工验收.md)。

本轮日期：2026-10-16。范围是当前本地截图的位移取证与候选模型，不是 SDK 实施或参考外观验收。输入清单、功能状态见[入口](README.md)。

## 输入、网格与可辨识量

16 张截图均为 1170×2532。每张使用相同照片矩形 `[0,142,1170,1750)`，得到 1170×1608 的照片网格，排除顶部状态栏、底部工具条、滑杆、“背景保护”及对比按钮。坐标原点为裁剪照片左上，x 向右、y 向下，单位为截图照片像素，不是相机像素。展示缩放不改变测量单位。

每项以滑杆最左截图为源、最右截图为目标。截图未显示数值，不记为 ±100。宽度和丰唇截图显示“整体”模式；没有这些控制其他子模式的证据。没有独立原片或可确认的共同零态；切换控制时是否重置、其他调整是否累积均未知。每对内部稳定区一致，支持当前状态下的端点比较，不能证明所有控制均从同一中性状态出发。

观测场为 `V(p_low)=p_high-p_low`。若以后定义中性源 p 的两个映射，必须比较：

```text
p_low = F_low(p)
p_high = F_high(p)
V(F_low(p)) = F_high(p) - F_low(p)
```

不得直接相减不同源网格上的场，也不得自动把总幅度、总角度、相对倍率除二作为单端实测。中间档、响应对称性和多控制次序仍不可辨识。

## 只消除显示差异的对齐

稳定区域覆盖照片上部头发、背景及下部两侧纹理；排除可能随动的中央下半脸。SIFT 对应按空间顺序每三点留一，余点用 RANSAC 拟合全局相似变换，留出点不参与拟合。每组拟合点 1365–1368，留出点 683–684。八组留出残差 P95 均小于 0.001 px，全部留出点的最大残差小于 0.007 px；这些很小的数值只说明同网格输入的数值一致性，不代表局部变形测量有同等精度。

八组稳定拟合掩区的 RGB 字节均 100% 相同，拟合变换也接近恒等。因此保留裁剪后的原字节，不进行全局重采样，更不做局部可变形配准。不能用嘴部本身拟合全局变换，把效果消掉。

## 主测量和交叉检查

- 主场使用灰度 DIS medium，分别计算低→高、高→低；以源坐标插值反向场得到闭合差。另在半宽半高图独立估计，放回原网格、位移乘二后比较。半尺度与主场同属光流家族，不是独立真值。
- 基础独立 NCC 在源图固定空间分区尝试 750 个位置，29×29 模板、±72 px 搜索。源模板灰度标准差至少 5，峰值至少 0.90，排除峰周围 5 px 后的次峰差至少 0.012，整数反向闭合不超过 1.5 px。亚像素峰只在本法峰附近抛物线细化。没有使用主场初始化、搜索中心或一致性筛选。
- 搜索触边的候选另以 ±120 px 重查，仍触边或未通过自身判据者不纳入接受集。倾斜有一例扩大后仍触边，明确保留为拒绝，不能解释为真实最大运动。左右、微笑补充较小模板和更密源分区，方法与统计各自在分项记录；补查没有额外有效触边点。
- 活动点定义为该独立方法位移模长≥1 px，其余为近静止点，分别统计与 DIS 的差。阈值仅是本轮统计分组，不是产品死区。模板相互重叠，接受点数不等于统计独立样本量。
- 倾斜补充互反 SIFT 与可旋转 NCC；丰唇补充允许尺度变化的模板。专门方法的自身筛选、接受/拒绝和不确定性见各项。不能用普通 NCC 失败来证明局部没有运动。

光流的闭合合格不独立保证对应正确。低纹理区的平滑值仅是估计，不能用大量格点提高证据等级；重建图的差也只检查对应，不识别内部算法。每项保留方法不一致及拒绝统计，不把方法差称为真值误差。

## 证据图的读法

每项主图含同网格端点、分别编码 dx/dy 的有符号热图、带坐标的横纵剖面。红为正、蓝为负，热图颜色仅表示位移。色标覆盖显示窗口的全部主场分量，不截峰；灰色表示前后向闭合差>1 px，不能读成静止。

主剖面使用 11 px 窄带中位数，实线只画窄带至少一半闭合合格的区段，虚线为半尺度估计。附近独立对应点保留原横/纵坐标，不伪装为恰好在剖面上；二者差异可能来自邻近位置和局部梯度。剖面坐标只是本次检查位置，不能变成未来输入的固定参数。丰唇的灰区、倾斜的失配段需结合专项证据；不从断线补出确定场。

## 候选场的共同数学

各项公式均为自行提出、可被观测推翻的候选，不声称美图秀秀采用同一公式。以可靠嘴角/唇缝几何定义中心 c，`e_h` 沿源嘴部横轴，`e_v` 始终取与 e_h 正交且朝照片下方的方向，形成正交矩阵 `E=[e_h,e_v]`。屏幕+y仅定义观测符号，不自动等于局部 e_v。用源嘴宽 W 作为水平尺度，另用可辨的上下唇厚度描述纵向范围；本轮像素幅度不直接迁移到其他脸。

```text
z = Eᵀ(p-c)
F_u(p) = p + D(p,u)
D(p,u) = w(p) v(p,u)
J_F = I + w ∇v + v (∇w)ᵀ
```

`w` 是内部平台与外部静止皮肤之间的二维连续支撑，不等同于唇部二值分割。可用内核为 1、外界为 0、过渡采用 `S(t)=1-3t²+2t³` 的 C1 包络作为初始设计；具体边界、上下不对称及 10%→90% 宽度仍要由可靠纹理重新拟合，不把光流回零处当作精确支撑边界。若另外相乘保护权重，应对乘积求完整导数。约束区应在静止证据与随动皮肤之间留出过渡，不把鼻底和颏部整块强制为零来迎合名称。

统一检查整个支撑内的完整梯度、最小奇异值、行列式和边界覆盖；核心仿射/旋转安全不代表连接后的场安全。设计上可要求 `sup||∇D||₂≤κ<1`，但必须获得含所有包络导数的有效上界，稀疏网格最大值不能替代证明；仅 `det(J_F)>0` 也不独立保证全局一一映射。退化或不可靠几何应减少幅度或输出恒等，并将其与参考效果资格分开。

渲染按目标 q 求源 p：`F_u(p)=q`。若满足收敛条件，可迭代 `p_(k+1)=q-D(p_k,u)`，并核验逆残差、越界和停止条件；一次 `q-D(q,u)` 只是近似。网格法另检覆盖、重叠与完整边界。只在最终逆映射下从原图采样一次，不逐次变形上一张输出，也不混合两张错位图像掩盖接缝。多项组合必须重新检查整个组合映射，不以每项单独安全代替组合资格。

## 本轮验证边界

零变化、已知二维平移与局部旋转控制核对了符号和对应方法的适用域；其误差不外推为丰唇大幅伸缩或弱纹理区精度。各项完成当前图片测量、候选公式/引用/隐私边界检查；未改 SDK、宿主或模型，未跑 Swift 构建、模拟器、真机或全功能回归。中性拆分、中间强度、其他人脸、张嘴/露齿、遮挡、尺度迁移和组合效果均未获验证。
