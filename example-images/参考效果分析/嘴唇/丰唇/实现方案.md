## 最小可推翻模型

本组支持的最低复杂度解释是：以唇缝附近为弱运动带，上、下两侧沿脸部竖轴扩张，下侧强于上侧，沿唇宽连接到静止皮肤。选择全局脸部竖轴而非逐点唇缘法线，是因为可靠下唇对应的水平分量远小于竖直分量；是否需要小幅 dx 仍由后续留出对应判断。

源图建立正交局部坐标 `(s,y)`，横轴沿两嘴角方向，竖轴朝下。以源唇缝曲线 `m(s)` 定义 `t=y−m(s)`；几何来自当前输入。`L` 是当前嘴角跨度，幅度与支撑宽度需相对 L 标定，不能直接沿用参考截图像素。

下面定义前向场，所有函数均作用于实现选定的同一源坐标。若用于中性→端点映射，应先取得相应中性输入，不能把本组低端点自动当作已证实中性：

```text
F_u(p) = p + D(p,u)
D_s = 0
D_y = A(u) W_s(s) W_t(s,t) b(t) t
b(t) = b_up + (b_down − b_up) S((t+δ)/(2δ))
```

`S` 是在区间外钳位为 0/1 的平滑阶跃；可采用五次 `S(z)=6z⁵−15z⁴+10z³`。`δ>0` 令上下不同伸缩率在唇缝邻域平滑接合，避免直接拼接两条斜率不同的线。`W_s` 控制沿唇宽的收束；`W_t` 把内部伸缩连到上下随动皮肤，并在外支撑边界平滑回零。两者应是连续可微的包络，而非红唇二值蒙版。

`b_up`、`b_down`、`δ`、两组包络及 `A(u)` 均为待标定设计量。端点轮廓差与相对高度比只能约束成对映射，不能直接作为 `b_up/b_down` 或拆成对称单端参数。`A(0)=0` 是实现的中性定义；中性图未被本组提供。对称响应、线性滑杆和严格固定唇缝都是设计假设，不能列为参考事实。

## 从证据约束参数

优先使同一源图生成的低、高端映射满足：上外缘向上、下外缘向下；下唇可靠纹理竖向外移明显；中部强于两侧；唇缝邻域弱于上下外缘。用独立对应与原像素轮廓检查拟合、留出验证，稠密 DIS 只提供衰减位置的候选范围。

首轮先检验线性内核 `b(t)t` 是否足够；若下唇纹理对应与外缘轮廓之间留下稳定的深度相关残差，再以单调的分段函数替换内核。轮廓是形状约束，不得当成带已知 dx 的材质点强行回归。上唇证据不足时保留幅度范围，不用密集场峰值补齐。

## 局部 Jacobian 与逆映射

记 `H=W_t(s,t)b(t)t`，则在固定源 `(s,y)` 下：

```text
∂y D_y = A W_s [ (∂t W_t) b t + W_t (b + t b′) ]
∂s D_y = A [ W_s′ H + W_s (∂s H|t − m′(s) ∂t H) ]
J_F = [[1, 0], [∂s D_y, 1+∂y D_y]]
```

必须计入包络、上下接合与唇缝斜率的导数。边缘回零可能造成压缩；只检查内部 `1+A b>0` 不够。要求完整竖向导数在全支撑中留有正裕量，并检查剪切与逆残差。若仍采用保持 s 不变的该候选，每列严格单调、外部恒等，可用有界一维求根得到唯一源 y；若后续加入 dx，则重新核验完整二维场与全局无重叠。

渲染求 `F_u(p)=q`，通过验收的逆映射从原图采样一次。保护窗口、边界、退化嘴角跨度、唇缝断裂与逆解失败按公共约定处理；不能通过反复变形上次结果或混合错位原图掩盖接缝。

## 验收能够推翻什么

- 独立源纹理留出点同时检查 dx/dy；单列活动点与静止点。若可靠下唇水平残差持续有结构，推翻纯竖直候选。
- 上下外缘轮廓、唇缝与唇周皮肤分开核验。若线性内核不能同时解释纹理和外缘，推翻常斜率扩张。
- 检查外围完整回零与眼、鼻、下巴、外侧面颊的实际像素；本组有限保护窗不能替代新输入测试。
- 检查局部伸缩、边缘压缩、逆残差与最终单次采样输出。公式自洽、变形安全和画面发生变化均不等于复现合格。

需要实际实施时，应另外取得共同零态与若干中间档来约束响应，并在不同嘴形上重测尺度迁移。本次分析不启动 SDK 改造或算法执行计划。
