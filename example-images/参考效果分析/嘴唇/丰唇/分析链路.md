# 丰唇：分析链路

分析日期：2026-10-16。公共坐标、端点资格与采样数学见[嘴唇入口](../README.md)和[实现公共约定](../实现公共约定.md)。

## 输入与问题

`IMG_1971` 为本组源端点，`IMG_1972` 为目标端点，界面选中“丰唇”。二者均为 1170×2532 截图，滑杆分别位于左、右端；没有显示数值或中间档。照片共同区域裁为 `[0,142,1170,1750)`，得到 1170×1608 网格，排除上方状态栏与下方覆盖层。坐标 x 向右、y 向下，单位为对齐截图像素。

先检验：变化是整块位移、水平/竖直伸缩、围绕唇缝的增厚，还是光流误配？重点观察上下唇、唇缝、嘴角、唇周皮肤；眼、鼻、下巴、外侧面颊分别作为独立保护观察窗口。没有用唇区拟合配准。

这组可辨识的是源端点→目标端点，不是原始照片→单端效果。相邻功能截图是否重置其他参数未被记录，不能把本组源端点称为全功能共同零态。

## 对齐

在中央下半脸之外、分布于照片不同方位的稳定纹理上，以 SIFT 对应拟合相似变换。2048 个匹配中，1365 个参与拟合，683 个留出；留出残差中位数/P95/最大值均为 0 px。尺度与 1、转角与 0 的偏差仅为数值舍入，稳定区 RGB 原字节完全相同。因此采用恒等网格，不重采样原图。

## 稠密场的适用边界

DIS 前向场与反向场用于找方向、平台与衰减线索。唇部前后向闭合中位数为 2.06 px，P95 为 20.31 px；上、下唇分别达到 22.30 与 24.05 px。半尺度与全尺度在部分唇纹区域亦明显分歧。该结果说明大变形、窄唇缝与弱纹理已使本方法失稳。

基础固定尺度 NCC 在 750 个网格候选中接受 215 点，但只有 2 个活动点，下唇纹理没有被可靠覆盖。不能以 213 个静止点的低差异宣称唇核心准确。热图仍展示 dx、dy，但将不闭合区标成低可靠估计；不采用稠密峰值标定丰唇幅度。

## 独立的缩放模板对应

在源图固定空间分区中，各取最强 Shi–Tomasi 角点，形成 264 个候选；不按稠密场选择或剔除。21×21 源模板通过横向 0.9–1.1、竖向 0.4–3.5 的尺度库匹配；位置搜索半径为 90 px。接受条件为 NCC≥0.93、排除峰附近 13×13 后的峰值差≥0.015、反向模板满足同样质量条件且往返中心差≤1.5 px。缩放模板只是一种对应估计器，其最优缩放参数不自动等于整片唇的几何倍率。

| 结果 | 数量 |
| --- | ---: |
| 接受 | 67 |
| 弱纹理拒绝 | 89 |
| 峰值不足 | 9 |
| 非唯一峰 | 74 |
| 反向质量/闭合不足 | 23 |
| 初始搜索触边 | 2 |

两个触边候选扩大到 140 px 后均不再触边，但峰值唯一性仍不足，保持拒绝。接受点中活动 20、静止 47；活动点与 DIS 的差异中位数为 1.82 px、P95 为 13.57 px，静止点 P95 为 0.36 px。差异是两种方法的分歧，不能称任何一方的真值误差；接受模板仍可能在重复纹理上出错。

为避免弯曲唇缝导致水平矩形把上下唇混在一起，依据源图局部暗线定位唇缝，再按相对唇缝的上下位置汇总。下唇十个纹理对应全部向下，dy 为 +8.28…+26.70 px，中位数 +16.33 px；dx 为 +0.12…+1.95 px。近唇缝六点 dy 为 −1.45…+0.93 px，明显弱于下唇外部。上唇内部只有两个通过判据的对应，dy 分别处在 −9.30…−2.87 px；最外上缘没有完整纹理覆盖，不能由它们宣称整片上唇刚性上移。部分上方/下方皮肤也随动，支撑域不能等同于红唇二值范围。

## 独立唇缘形状检查

为补足外缘弱纹理，另外在七条固定列上定位上下外唇缘：Lab a 通道仅作为图像边缘定位信号，不分析颜色处理；取竖向梯度极值并在原像素上逐处审阅。分别用 7、9、15 px 水平窄带与两种平滑复测。该检查比较同列轮廓形状，给出近似法向偏移；它不提供完整 dx，也不证明同列就是同一材质点。

| 轮廓量 | 中位数 | 范围 |
| --- | ---: | ---: |
| 上外缘同列偏移 | −18 px | −24…−15 px |
| 下外缘同列偏移 | +40 px | +17…+42 px |
| 上下外缘间高度比 | 2.24 | 1.79…2.38 |

带宽/平滑改变造成的边缘位置变化最大为 3 px，中位数为 0；这只是定位方法敏感性，不是闭源效果或真实材质对应的精度。下外缘增幅在中部较大、两侧减弱；上外缘变化较小。轮廓高度比属于这组端点与这些剖面，不能用于新的照片或中性拆分。

## 事实到候选

1. 上外缘向上、下外缘向下且唇缝附近较弱，排除单一平移；下唇多个纹理点距离唇缝更远，支持增厚而非整块抬升。
2. 下唇纹理的竖直位移明显大于水平位移，且唇宽两侧衰减，优先检验带横向包络的竖直扩张。它尚未证明 dx 严格为零。
3. 上下外缘扩张不等，且不同列高度比不同，简单统一等比放大不足。最小候选先用上下不对称竖向伸缩，只有独立留出残差稳定要求时才增加非线性。
4. 眼、鼻、下巴、外侧面颊观察窗原像素均保持一致，支持作用较局部；这些窗口不证明整张脸或完整鼻部轮廓绝对固定。

未知量包括真实中性状态、单端幅度、响应曲线、上唇弱纹理的完整对应、唇缝是否严格固定、外围精确支撑与低纹理区 dx。最有价值的新增证据是本控制的共同零态和中间档，以及更高分辨率上唇纹理；不能用增加候选场自由度消除这些未知量。
