# 微笑候选实现方案

2026-10-17 实施更新：本页保留原候选推导；当前 SDK 实现、幅度/支撑设计与限制统一见[SDK改造记录](../SDK改造记录.md)，实际验证和待所有者验收项见[人工验收](../人工验收.md)。下文“未实施”指原测量阶段。

当前 SDK 进一步用源上唇中央的 C1 平台，将角部尾连续过渡到弱下移向量。实图复核表明，下述普通中央 bell 的直接加性形式不足以同时覆盖中央两侧并控制中间幅度；新公式与排除依据见[SDK 改造记录的微笑修正](../SDK改造记录.md)。

状态：**候选，未实施或验收**。依据[端点观测](分析链路.md)，用双侧二维局部峰解释角部上提/外展，增加一个有观测支持的弱中央反向峰；数学与渲染共用[公共约定](../实现公共约定.md)。

以源嘴部局部轴和嘴宽W建立坐标z=(s,t)，分别给左右源口角连续局部峰B_L、B_R，并给源上唇中央弱峰B_C。可选C1紧支撑函数 `b(r)=(1-r²)²`（|r|<1，外为0），用独立横/纵半宽构造 `B_i=b((s-s_i)/r_i)b((t-t_i)/h_i)`；这是初版设计函数，不是测得的闭源公式。

```text
v_i(u) = a_i(u)e_h + c_i(u)e_v
D(p,u) = w(p)[B_L(p)v_L(u) + B_C(p)v_C(u) + B_R(p)v_R(u)]
F_u(p) = p + D(p,u)
```

高端相对低端的主方向约束为 `a_L<0、a_R>0、c_L<0、c_R<0、c_C>0`。各a/c是局部坐标系中的候选幅度，不直接填入屏幕像素中位数；须按同源点端点映射拟合。本批左角约(−15.73,−28.20)、右角约(+14.28,−28.02) px提供当前分区的初始化量级，右角样本仅7，不当作准确峰值。

内部峰B与连接静止外围的w分开。角部峰的尾部允许中央重叠，但仅两个上提向量的非负bump不能生成正dy。中央11个独立NCC点的正dy在两尺度光流上均获同号支持，故增加一个较弱的中央正峰是当前证据要求的最低修正，不是任意增参。中央幅度需同时抵消角部尾部的负分量后匹配观测，不能直接令c_C等于+2.30 px。a_C可先取0作为设计简化，检验实测小dx残差；不能宣称完全无横向中央运动。

中央与下唇仍可能有不同的纵向分布，先使用一个中央峰和独立纵向宽度；只有残差跨方法稳定要求时才继续加层。嘴角外侧皮肤有随动，支撑不能截在唇红边缘。

`∇D`须含w、B_L、B_C、B_R的全部导数；重叠峰可能使梯度叠加，不能只检查峰中心。保护眼、外颊、参考中静止颏窗，并独立观察鼻底；保护边界与峰支撑应连续衔接。几何退化、遮挡/露齿条件不符、完整导数超预算、逆残差或边界覆盖失败时缩幅或恒等，不能把安全回退当作复现证明。

实现验证顺序：可靠几何及支撑→同源点两端标定→完整梯度/全局映射→逆解→原图一次采样。独立检查两嘴角dx异号且dy同负、中央有较弱反向下移且非严格固定、横纵剖面及保护窗。反例包括整嘴上移、只有加宽、仅两个同向上提峰、单一旋转、把中央强制不动或两侧无证据地完全镜像。中性拆分、滑杆线性、跨脸尺度及多控制组合都尚未验证。
