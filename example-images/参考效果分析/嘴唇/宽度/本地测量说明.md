# 宽度（整体）：本地测量说明

输入为 `IMG_1961.PNG → IMG_1962.PNG`，界面显示“整体”模式，原件只读。见[分析链路](分析链路.md)和[证据图](证据/位移证据.png)。

本部位被忽略的 `本地测量/` 保存主 `measure.py`、补充 `secondary.py`，以及本项 `summary.json`、`secondary.json`、`fields.npz`；`simple_qc/` 保存等比/分轴候选对比和局部查看材料。像素、实际采点、蒙版与逐像素场只留本地，不加入源码或持久日志；本文不依赖会话临时绝对路径。

复测先确认输入同网格和稳定留出残差；保持独立 NCC 的源纹理采点、半径裕量、歧义与闭合判据，不以光流一致性筛点。补充源色素子集可帮助区分主方向，但它不是精确语义嘴唇，也不替代全点统计。剖面中稠密曲线是窄带聚合估计，可靠邻近纹理点另标。

每轮分别记录移动与静止点、主要拒绝原因和方法差异；不把对齐、闭合或重建合格自动升级为算法识别或参考复现。新增中性或其他子模式时另建配对并保留输入身份。

实际验证限于本组端点分析、候选公式和文档链接；未运行 SDK、模拟器或全功能回归。
