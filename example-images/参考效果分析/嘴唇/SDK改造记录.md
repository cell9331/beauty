# 八项嘴唇功能的 SDK 改造

日期：2026-10-17。分支：`codex/mouth-displacement-analysis-20261016`。用户授权范围为大小、宽度、上下、倾斜、左右、M唇、丰唇、微笑；白牙保持原状。参考测量见[入口](README.md)和各项分析链路。本记录描述当前候选实现，最终外观由所有者验收。

## 逐项模型变更

| 功能 | 原实现与文档的主要差异 | 当前接入的模型 |
| --- | --- | --- |
| 大小 | 固定等比缩放，把尚未证实的等比关系写死 | 局部嘴轴上的横纵独立伸缩；初始横向强于纵向 |
| 宽度 | 横向模型基本相符，幅度和外围仍需复核 | 保留横向伸缩，重新核对端点倍率及二维支撑；源纵坐标不变 |
| 上下 | 沿局部法线移动，不能覆盖参考中很小的屏幕水平分量 | 以正向照片坐标定义二维平台平移，再转入源嘴局部轴；保留 UI 正负方向 |
| 倾斜 | 有限旋转位移乘衰减，在过渡区会附带径向收缩 | 衰减旋转角 `F(p)=c+R_(uθw(p))(p-c)`；过渡区也保持到旋转中心的距离 |
| 左右 | 屏幕纵向位移硬置零 | 用屏幕二维平台向量保留可检验的小正交分量 |
| M唇 | 下唇/口腔带固定，负向另用削峰分支 | 源唇缝曲线坐标中的中央正峰、两侧负峰及局部下缘反向峰；两端共用连续模型 |
| 丰唇 | 固定水平内唇带、上下共享幅度 | 曲线唇缝 `t=y-m(s)`，上下独立增厚率，缝附近平滑连接；不再把整个内唇带冻结 |
| 微笑 | 只有嘴角上提，缺少有独立对应支持的中央正 dy | 左右上提/外展峰，加源上唇中央弱下移区域；中央过渡与下唇尾部分开 |

这些是以参考事实约束的自行实现，不声称识别出美图秀秀内部算法。源嘴宽用于尺度归一化，源轮廓用于嘴轴、唇缝、厚度和支撑；没有将本批照片的实际点位或截图像素半径写入生产代码。

## 标定与作用范围

参考提供的是两端总差，没有确认的共同零态或中间档。SDK 选择围绕零态对称的名义响应作为设计起点；这是设计假设，不是把端点总差除二后称为实测单端。安全准入可能对两端产生不同缩幅，因此必须比较实际映射。

对每个参考低端纹理点 `q_low`，实际 Swift 求 `p=F_low⁻¹(q_low)`，再比较 `F_high(p)-F_low(p)` 与独立对应；保留移动点和近静止点的独立统计以及所有失败点。未用 Python 另造一个替代模型冒充 SDK 输出。

本地低端照片本身也已受参考效果影响。直接把其检测几何当作设计源，会混入未知零态造成的中心和厚度偏差，尤其影响较大左右平移的外围范围。因此，当前真实图残差用于发现反号、平台不足和支撑泄漏，不自动等于生产中性原片上的普适误差。原生检测和手工近似几何的结果分开保存。

M 唇实施前补查显示，下缘中央四个可靠对应具有约 −1.3…−2.4 px 的总上移，并得到两尺度同号支持；它们与上唇中央的正 dy 相反，支持一个局部独立下缘峰，不能据此移动整片下唇。下唇中段的近静止对应又约束上层 profile 提前归零。

微笑的实际 Swift 复核推翻了“宽角峰直接叠加一个普通中央 bell 即足够”的简化：中央两侧仍反号，而继续加幅会把中央推得过强。当前采用源上唇中央的 C1 平台权重 B，将角部尾 A 连续过渡到弱下移向量 vC：

```text
A = B_L vL + B_R vR
V = (1-B) A + B vC
D(p,u) = u w(p) V(p)
∇V = (1-B) ∇A + (vC-A)(∇B)ᵀ
```

B 的上下边界取自本次源上唇与唇缝，横向边界按源嘴宽归一化。中央平台保留弱正 dy，下唇超出 B 的范围继续接受角部尾。这里混合的是同一个前向向量场，没有混合两张错位图像；完整导数、连续证书及最终单次采样不变。原加性公式作为被实际残差限制的早期候选保留，不再冒充当前 SDK 公式。

外围采用连续矩形和椭圆支撑的乘积，允许下唇以下较弱皮肤随动，外颊归零。眼和鼻的源观测区域加连续过渡后置于支撑外；这些保护来自本次请求的源几何。M 唇上层与下缘局部峰分开限制纵向范围，避免一条长尾把下唇中段一起带动。微笑中央峰按独立对应重新核对覆盖及净位移，不能仅比较未叠加角部尾部的单峰高度。

## 可逆性与组合

实现由四部分组成：`BeautyMouthReferenceGeometry` 负责可靠源几何与归一化配置，`BeautyMouthReferenceModel` 负责八种前向场及完整导数，`BeautyMouthReferenceCertificate` 负责连续区域的保守上/下界，`BeautyContinuousMouthMap` 负责准入、复合、逆解及采样。

- 平移用完整方向导数下界证明沿平移直线的单调性；M 唇和丰唇保持源横坐标，证明整列纵向单调；倾斜保持半径，证明整圆角度单调。
- 大小、宽度、微笑对从恒等到端点的整个线性同伦给出行列式下界。倾斜和线性同伦的界采用连续区域自适应细分；停止用的点区间只提供未知最优值的另一侧界，不能代替整块支撑的安全证书。所有场在紧支撑外为恒等；连续区域上的局部可逆与适当映射条件共同提供全局可逆性，不以少量采样点 `det>0` 代替证明。
- 每项先独立准入，再按既有固定顺序复合：大小、宽度、微笑、上下、倾斜、左右、M 唇、丰唇。逆解反序进行，最后只从原始 RGBA 采样一次。新增一个无穷小控制不会重新缩小已有项的预算。
- 逐组件逆解容差依据后续场的前向 Lipschitz 上界分配，最后回代检查整个复合场。失效几何或逆残差不合格时保持安全回退，不把回退当作效果合格。

缺少内唇只拒绝 M 唇和丰唇；其余六项仍可使用可靠外唇。有真实唇观测而准入失败时不恢复旧点场。没有真实唇观测的原有粗几何兼容路径仍保留。透明度、输出范围、颜色空间和请求隔离继续由直接受影响的测试检查。

## 闭嘴真机准入修正

所有者在 iPhone 13 Pro 使用本批闭嘴参考时发现 M 唇、丰唇完全无效。实际生产 MediaPipe 两图均得到 478 点及 20 个唯一内唇点，有限值、面积、跨度与外唇包含检查都通过，唯内唇简单多边形检查失败。原实现把闭嘴内唇上下轮廓的接触/轻微交叉等同于缺失证据，准入掩码为 `63`，resolver 将两项请求强度 `±0.25` 清零，CPU/Metal 两端均为零像素变化。此前 macOS Vision 实图验证没有覆盖这条 iOS 原生检测路径，静态拓扑核对也不足以发现坐标交叉。

修正保留原简单多边形路径，在其失败时另外验证实际闭嘴唇缝：按原轮廓顺序从左右极点拆出两条 x 严格单调的观测曲线，只合并单条曲线内相邻完全重复的坐标；每条至少三个不同 x，覆盖中央及共同跨度。仍要求原有范围、外唇顶点包含和最小跨度。两条分段线性曲线在全部原始断点处的最大间隙不得超过 `0.025` 倍源嘴宽，因此允许接触或有界的微交叉，拒绝折返、竖段、大交叉及缺失观测。

九节点 C1 唇缝取两条实际观测曲线的中线。其解析极值须位于外唇整体上下范围的原容差内；在裁切后的拟合跨度内，进一步检查三次曲线与原分段线性中线之差的全部极值，误差不得超过 `0.025` 倍源嘴宽，防止漏采尖峰和插值过冲。两端常量延伸沿用原设计；不据此声明整条曲线均位于同 x 的局部外唇边界内。这两个容差是准入设计界限，不是参考图片测量出的闭嘴阈值。

未放宽共享 `simplePolygon`，未修改八项场公式、标称系数、包络构造及保护、可逆、采样或白牙逻辑；新获准的闭嘴观测改用实际唇缝，其派生中心与厚度随观测更新，也会影响其他六项使用的源几何，因此回归范围包含直接依赖嘴部几何的八项测试。修后同两图真机准入为 `255`，两项均产生实际输出，详细范围见[人工验收](人工验收.md)。参考外观仍由所有者确认。
