参考为 `IMG_1969 → IMG_1970`，界面选中“M 唇”，滑杆左端→右端，未显示端点数值。没有共同零态或中间档，本组只约束两个截图之间的位移差。

**主要结论：变化是上唇中部向下、左右邻近区向上的局部波形，不能用整块上下移动解释。** 独立源纹理对应中，上唇中部 9 点向下 +1.90…+4.72 px；左、右邻近波瓣分别 3/4 点向上约 −2 px。对应的水平分量明显较小。下唇 41 点位移模长中位数约 0.25 px，但仍有局部 2.41 px，不能把下唇全域设为绝对静止。

强化 NCC 在 264 个源图分区候选中接受 136 点，其中活动 53、静止 83；活动点与 DIS 的差异 P95 为 0.61 px。最小候选为具有上下独立包络的竖直三波瓣场；波峰位置、支撑范围、中性强度与滑杆响应均需另行标定。
