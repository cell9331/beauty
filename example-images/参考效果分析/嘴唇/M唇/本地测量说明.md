# M 唇：本地测量说明

分析日期：2026-10-16。聚合文档可跟踪；原像素、实际点位、逐像素场和中间脚本保存在被忽略的本地材料中。

## 材料与追溯

原参考为既有嘴巴目录中的 `IMG_1969 → IMG_1970`，原件未修改。部位级本地测量目录的 `M唇/fields.npz` 与 `summary.json` 保存公共配准、DIS 前后向场、半尺度场和基础网格 NCC。

`fullness_special` 目录中 `special.py` 保存两项共用的源图空间分区选点方法；`M唇-ncc.npz` 保存强化对应，配套 `M唇-summary.json`、`groups.json` 记录汇总，`checks.py` 与 `checks.json` 记录边界扩大和零变化控制。原像素匹配审阅图亦只留在本地目录。[位移证据图](证据/位移证据.png)沿用项目图片忽略规则。

脚本依赖相邻公共测量脚本、同批输入以及 OpenCV/NumPy；复跑前检查目录与环境。固定剖面与截图网格只属于这批输入，不是新照片的默认位置或支撑参数。

## 实际验证范围

- 配准留出 683 点，残差均为 0，稳定区原像素一致，保留恒等网格。
- 强化对应在 264 个源图纹理候选中接受 136；弱纹理拒绝 102、非唯一峰 23、反向闭合 1、初始触边 2。触边扩到 140 px 后均因非唯一峰维持拒绝。
- 接受活动点 53、静止点 83，活动点与 DIS 差异中位数 0.20 px、P95 0.61 px；该数为方法间差异，非真值误差。对应模板有重叠，未把点数等同统计独立性。
- 零变化 NCC 控制使用同批源图选点，264 个候选接受 127，返回位移模长中位数约 0.024 px、P95 0.071 px、最大 0.104 px；只核验亚像素拟合与歧义基线，不能外推为真实变形精度。
- 审阅上唇正负交替、下唇弱运动和外围保护；鼻部观察窗口有少量像素变化，未宣称绝对静止。
- 候选链式导数在 100 组光滑合成位置上与中心差分比较，最大差异约 8.5×10⁻¹²；只核对公式代数，不代替具体几何、全域安全或外观验证。

未验证真实中性图、中间档、单端幅度、闭源内部机制、其他照片或 SDK 实际输出。仅运行本次图像测量、局部控制与文档核对，没有 SDK 全量测试、Xcode 构建或模拟器回归。
