# 左右候选实现方案

2026-10-17 实施更新：本页保留原候选推导；当前 SDK 实现、幅度/支撑设计与限制统一见[SDK改造记录](../SDK改造记录.md)，实际验证和待所有者验收项见[人工验收](../人工验收.md)。下文“未实施”指原测量阶段。

状态：**候选，未实施、未通过参考效果验收**。依据[当前端点测量](分析链路.md)提出；公共坐标、完整Jacobian、逆解与从原图单次采样遵循[公共约定](../实现公共约定.md)。

以可靠源嘴部几何给出中心、局部轴及嘴宽W，设置包含口唇核心的内核和连接外围皮肤的二维C1支撑w。候选前向场：

```text
F_u(p) = p + w(p)[a_h(u)e_h + a_v(u)e_v]
a_h(0) = a_v(0) = 0
∇D = [a_h e_h + a_v e_v](∇w)ᵀ
```

局部轴是从新输入几何得到的，不能直接等同于本次屏幕横轴。本轮屏幕核心端点总差约(+54.53,+0.28) px，只约束同一源点的低→高映射。先拟合端点平台与过渡，再按W归一化；不能把该像素向量作为所有照片常量。令a_v=0可作简化设计，但不是“测得严格水平”。中性拆分、响应线性或对称性均待新增输入；自行选择时注明设计假设。

支撑先采用左右、上下独立过渡宽的平顶包络；测得10%→90%宽仅用于初始化比较，不直接当支持半径。保护窗与核心间连续衰减，避免把参考中随动颏部强行固定。只当独立纹理显示稳定残差规律时增加参数，当前无需把平台改成局部拉伸来贴合错误匹配。

实现顺序是可靠几何准备→源域核心/保护/支撑→端点标定→完整场梯度及全局边界检查→求逆→从原图单次采样。退化嘴宽、遮挡导致几何不可用、支撑侵入保护区、导数或逆解失败时缩幅或恒等；不得以恒等通过代替效果验收。

验证要在同一源点比较两端映射：下唇核心独立点的平台、成对距离及小dy；外围左右/上下衰减；鼻/眼/外颊保护和颏部随动。用“嘴变宽但中心未横移”“整脸平移”“只抹平边界”作为反例。核心残差好但外围折叠，或保护合格但平台位移不对，都不合格。其他人脸、张嘴、侧脸、组合控制仍需独立验证，当前未执行。
