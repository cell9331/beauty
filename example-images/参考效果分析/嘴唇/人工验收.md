## 实际验证范围

仅运行直接受影响的嘴部模型、连续映射、参数方向、接线、CPU/Metal、typed/legacy 包装器测试。构建复用本分支的增量缓存；一次内部结构变化后定位并重编三个含旧复制辅助函数的测试对象，没有清空整个缓存。

定向命令：

```sh
swift test --package-path BeautySDK --filter 'BeautyMouthReferenceModelTests|BeautyMouthReferenceIntegrationTests|MouthContinuousMapTests|BeautyEngineMouthReferenceTests|BeautyEngineMouthNegativeTests|MouthNegativeFieldTests|MouthWarpProviderTests|BeautyMouthSliderTests'
```

最终构建后运行上述筛选（复用已建二进制时加 `--skip-build`），**86 项测试通过，0 失败**。本机 Metal 可用，16 个正负端点的实际 Metal/CPU 一致性测试已执行。真实图 opt-in 另运行 **30 项（29 项模型数学测试及 1 项本地图测试），0 失败**；不将重复模型测试相加为新的覆盖数。

覆盖完整链式导数与有限差分、连续区域保守界、同伦中间档、组合正行列式、正反映射闭合、各项 UI 方向、缺内唇局部拒绝、无穷小新控制的连续性、原图单次采样、重复/归零、透明度、颜色/范围、EXIF/镜像及实际 Metal/CPU 一致性。粗几何兼容测试保留 20 次真实 typed/legacy/repeat 返回图；它的保护观察区不冒充真实唇连续模型的保护资格。

所有者本地图另用实际生产 `BeautyFaceDetector.production()`、adapter/resolver 和 `BeautyCPUBackend` 运行。macOS 使用 Apple Vision，8 次 fresh 检测、24 次 CPU 请求（每图零态及两端）、16 个有效非恒等端点。每端输出必须与导出映射对应的实际像素完全一致，零态与输入原字节一致；没有回退手工几何。

同源比较查询包括 2,718 个独立纹理对应及 39,528 个网格位置。所有查询都有成功或明确失败状态，不按 SDK 残差删点；移动点与近静止点分开统计。图中稠密显示是实际 Swift 查询后的插值，不能看作新增独立观测。

最终真实图 42,246 个同源查询全部成功，低端逆解最大回代残差为 `9.983×10⁻⁵ px`。8 项的眼、鼻与左右外颊**预先选择的观察窗**在实际输出中均保持 100% 字节一致；该结论只覆盖这些有限窗口和当前图片。

## 按项验收关注点

| 功能 | 优先检查 |
| --- | --- |
| 大小 | 两轴均缩放，横纵比例自然，唇形与周围皮肤平滑连接 |
| 宽度 | 左右展开/内收，唇厚不被误改，嘴角外侧过渡自然 |
| 上下 | 整体上下移动，唇内部形状保持，鼻下与下唇皮肤无断层 |
| 倾斜 | 顺/逆时针正确，过渡不收缩半径；重点看两端幅度与鼻下衔接 |
| 左右 | 整体平移、核心不拉伸；重点看两侧外围与脸轮廓，注意未知零态的支撑偏移 |
| M唇 | 上唇中央与两侧反向，局部下缘可反向，下唇中段没有被整片拖走 |
| 丰唇 | 沿源曲线唇缝增厚，上下幅度自然，唇缝/口腔纹理不冻结、不复制 |
| 微笑 | 双角上提/外展，上唇中央弱下移，下唇仍有上提尾；中央过渡无台阶 |

另检查中间档、重复同一参数、归零、八项组合和自己的其他输入。白牙不属于本轮验收。

没有确认的共同零态、中间档和跨控制重置证据，因而没有证明单端对称或滑杆线性。当前一张肖像上的聚合幅度/作用范围检查不能替代跨脸资格。
