# 鼻翼候选实现方案

状态：**候选，未实施、未验证复现**。依据是[当前分析链路](分析链路.md)，不是既有 SDK 参数或功能名称。

[测量约定](../测量约定.md)定义输入、坐标、方法与零态限制；[公共实现约定](../实现公共约定.md)定义前向场、符号和逆采样。本项只在此补充差异。

## 最小模型

目标为：“整体”模式下以下鼻为主的横向收窄，作用延至下鼻梁和两侧随动皮肤。

最小可靠几何：两侧鼻翼、鼻底中点及下鼻梁定位强区，眼周与嘴唇作为独立观察区。 依公共约定冻结局部轴及尺度，公式为前向位移：

```text
D(p,u)=−ρ(u) κ W P(p) E_a(s,t) s e_x
F_u(p)=p+D(p,u)
```

E_a 的纵向部分在上鼻根减弱、下鼻梁增强、下鼻形成宽强区，再向鼻底外连续回零；横向部分连接相向内收核心与静止外围。κ 是待拟合横向强度，不能直接把端点总位移除二。第一候选只设一个共同强度；左右独立参数必须由更广样本的稳定残差支持。

## 标定与保护

本批实测范围见分析链路，全部是截图端点间 px 聚合；公式系数、响应、支持边界及归一化幅度尚未拟合。要么先在 L 网格拟合端点间映射，要么取得共同零态后按 `F_R∘F_L⁻¹` 比较；不能以逐点减场或端点除二替代。

保护权重独立于内部运动，作用边界至少连续，一阶平滑须连同导数匹配。当前检查窗的静止/随动结论仅属于该批观察，不升级为完整区域保护。退化几何、权重冲突、Jacobian或逆解失败按公共约定收缩强度或恒等返回；不能让弱纹理填充决定安全性。

## 从几何到像素的候选流程

定位并核对可靠几何 → 在统一源域生成候选场 → 与有效独立对应及纵横剖面比较 → 检查全部权重导数、完整 Jacobian 与全局无重叠条件 → 求逆并检验残差 → 对原始输入单次采样。该流程是可审阅设计，不代表本轮已经运行了候选输出或数学安全验证。

## 可推翻的验收

同时比对鼻翼横剖面和同侧鼻梁至鼻翼纵剖面，确认中央、侧翼及外围的位置关系。拒绝只缩窄两个鼻孔边缘、两块刚性内推或把上鼻根一并明显收窄的候选。当前保护窗均无 >1 px 的独立接受运动点，不可外推成整脸静止。

下鼻核心是否存在可近似线性的压缩段、鼻梁至鼻翼的过渡和左右差异仍需标定。折叠菜单未展开，只分析整体模式，其他子模式未确认。 仅有公式一致、输出变化、调用链成功或局部测试数量都不构成效果合格。本轮没有更改 SDK 或创建实施计划。
