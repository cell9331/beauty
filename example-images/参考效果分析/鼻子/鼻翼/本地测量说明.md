# 鼻翼本地材料与复测边界

[返回本项](README.md)。输入是既有目录中的 `IMG_2109.PNG` 与 `IMG_2110.PNG`，原件未改动。当前可测的是 L→R，不是相对共同零态。

共享脚本、先验定义、配准记录、正反向场、半尺度场、实际对应和汇总留在鼻子部位的 `本地测量/` 本批目录；本项证据位于 `证据/`。两者均按现有规则保持本地，不在聚合文档嵌入像素、点位、蒙版、逐像素场或环境私有路径。

测量使用已存在的 Python、Pillow/NumPy 与缓存 OpenCV/Matplotlib，无模型或依赖下载。脚本保留当前环境适配，本轮实际执行成功；其他环境复测需先检查依赖，不承诺无适配可复跑。对应统计的主模板、补模板及筛选定义见[测量约定](../测量约定.md)。

可审阅输出：[位移证据](证据/位移证据.png)、[位移剖面](证据/位移剖面.png)。PNG 为本地忽略证据，不强制加入 Git；在其他机器单独取得 Markdown 时，不保证图片随文档存在。

本项实际运行图像对齐检查、正反向测场、独立模板对应及尺度/模板敏感性检查；未实施候选算法、未运行 SDK/Xcode/模拟器或全功能回归。验证范围与不可靠估计见[本轮验证记录](../验证记录.md)。
