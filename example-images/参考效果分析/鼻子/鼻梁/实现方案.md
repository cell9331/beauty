# 鼻梁候选实现方案

状态：**鼻梁独立支撑及下段衰减已修正并定向验证，完整复现未验证**。当前范围和参考拟合代价见[作用范围修正与验证](../作用范围修正与验证.md)。本页其余公式仍为候选，依据是[当前分析链路](分析链路.md)，不是既有 SDK 参数或功能名称。

[测量约定](../测量约定.md)定义输入、坐标、方法与零态限制；[公共实现约定](../实现公共约定.md)定义前向场、符号和逆采样。本项只在此补充差异。

## 最小模型

目标为：中鼻段为主的横向收窄，沿鼻长变化，范围明显长于山根。

最小可靠几何：鼻中轴、鼻根、鼻底及两侧鼻翼，保留中鼻宽度和上下过渡的几何尺度。 依公共约定冻结局部轴及尺度，公式为前向位移：

```text
D(p,u)=−ρ(u) κ_b W P(p) E_b(s,t) s e_x
F_u(p)=p+D(p,u)
```

E_b 的强区在中鼻段，向上、向下分别衰减；端点范围比山根长，但不能仅复制大小的包络。首选只有横向主项；不为坏 dy 峰增加竖直压缩或旋转自由度。若有效新增对应出现稳定 dy，再审阅正交残差。

## 标定与保护

本批实测范围见分析链路，全部是截图端点间 px 聚合；公式系数、响应、支持边界及归一化幅度尚未拟合。要么先在 L 网格拟合端点间映射，要么取得共同零态后按 `F_R∘F_L⁻¹` 比较；不能以逐点减场或端点除二替代。

保护权重独立于内部运动，作用边界至少连续，一阶平滑须连同导数匹配。当前检查窗的静止/随动结论仅属于该批观察，不升级为完整区域保护。退化几何、权重冲突、Jacobian或逆解失败按公共约定收缩强度或恒等返回；不能让弱纹理填充决定安全性。

## 从几何到像素的候选流程

定位并核对可靠几何 → 在统一源域生成候选场 → 与有效独立对应及纵横剖面比较 → 检查全部权重导数、完整 Jacobian 与全局无重叠条件 → 求逆并检验残差 → 对原始输入单次采样。该流程是可审阅设计，不代表本轮已经运行了候选输出或数学安全验证。

## 可推翻的验收

以有效鼻梁两侧对应、上/下过渡及未参与拟合的中轴小模板点验收。数十像素坏 dy 峰必须留在无效区，不参与峰幅/拟合/支持范围；也不能以静止背景点的低误差说明中轴合格。

中轴弱纹理、最大横向收缩幅度、核心倍率和上下过渡仍有空白。主鼻区被拒绝点主要因峰不唯一和闭合失败，不能将其填充曲线当独立证据。仅有公式一致、输出变化、调用链成功或局部测试数量都不构成效果合格。原分析阶段未改 SDK，后续实施以修正记录为准。
