# 山根、鼻梁与大小的作用范围修正

2026-10-17。[返回入口](README.md)。接续[首轮纵向修正](代码修正与参考验证.md)，本次处理真机反馈中的山根不明显、鼻梁近似整鼻变化及大小带动鼻周过多。

**已调整三项独立作用范围，22 项鼻部定向测试通过。参考图条件回放证实山根位置和外围保护改善，同时暴露部分参考幅形残差增加；不声明完整复现。**

以上结论及下列范围表格属于范围修正冻结批。用户随后确认位置正确，并要求山根、鼻梁更加明显；当前幅度增强及单独验证记录见本页末节。

## 改动与依据

- **山根**：原场以鼻脊首点为基准，又乘公共顶部衰减，主要作用在偏低位置。补测的双模板共同运动在眉间至内眼角之间，主要位于原基准上方。现以可靠眉头和内眼角确定局部中心，使用独立上下包络，向下快速回零。扩展顶部网格，同时保留其他鼻项原有格点。
- **鼻梁**：原纵向尾部未在鼻底前充分归零，横向肩部也过宽。现保留鼻背核心，向下减弱，并加强下段外侧的衰减，至鼻底归零。参考下段确有较弱随动；本次按用户反馈进一步保护鼻头、外鼻翼，是产品作用范围的选择，不把参考解读成整个下鼻严格不动。
- **大小**：原横向项在鼻外仍随离轴距离增长，外围皮肤可能比鼻内动得更多。现增加紧凑横向包络，鼻边连续过渡、远颊严格保护；保留首轮有参考依据的小幅双侧纵向随动。不能把所有紧邻鼻子的皮肤设为硬边界，也不能据最大变化矩形扩大整块活动域。

生产修改集中在 [BeautyContinuousNoseMap.swift](../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousNoseMap.swift)。未增加公开参数。沿用原图一次逆采样、完整分量梯度上限 0.45、模长上限 `faceSpan×0.06`、姿态缩放及眼、眉、完整外唇和 alpha 保护。山根新增几何关系只约束山根分量；锚点无效时，其他有效鼻项仍可输出。异常眉头值和不合理上下关系均局部拒绝，下界另有限制。

## 实际参考验证

大小、山根、鼻梁和鼻头均由实际 Swift map 及照片 stage 输出 PNG。沿用首轮同一份人工注册几何、原尺寸照片网格及独立 sRGB 解码；修改前后几何未改。共同中性图和参考滑杆数值仍未知，SDK ±cap 与参考端点的对应只作条件假设。

按同一源点求 `H = B_high⁻¹ ∘ B_low`，没有逐点减去不同坐标网格的场。另对实际输出 PNG 做独立 NCC，保留全部参考接受点、输出拒绝和移动/静止分组。新增上鼻根、下鼻及外围对应由源纹理和固定空间格选取，双模板交叉检查；没有按与实现一致程度筛点。分区已反复审阅，不称盲验；相关纹理块也不称独立样本。

## 后续：保留位置及边界，增强山根和鼻梁

用户确认位置和范围后，本批只增强山根与鼻梁的可见幅度。大小、鼻头、鼻翼和提升的公式保留；眉眼鼻的锚点、上下包络、严格零边界和保护框不变。鼻梁宽度系数从 0.105 调至 0.16，实际幅度仍由逆坐标转换及完整预算决定，不能把系数差直接当作图像增幅。

山根原满档已接近梯度上限，整体加系数会被重新缩回。现为原场增加紧凑内部响应，额外增益在鼻宽的 0.10–0.35 范围内平滑消失；该范围是实现的归一化设计，不是原照片点位。山根请求先乘原横向及完整保护权重，再以最近保护框距离决定局部软限幅：`b×tanh(request/b)`，`b=0.33×distance`，距离为零时恒等。正/负宽度系数分别为 0.11/0.16，用于平衡两种方向的可见变化；额外内部增益为 `1+1.5×(1−smoothstep)`。实际、对应符号 cap 和组合场仍全部经过原 0.45 梯度及模长预算，没有放宽安全阈值。

先乘保护、再做软限幅，避免眉头旁一个窄过渡消耗整片山根的梯度额度。多轮仅整体加系数或软限幅顺序不当的候选，未达到事先设定的真实像素幅度门槛；失败日志和精确合成模型探索结果保留本地，最终没有降低测试门槛。
