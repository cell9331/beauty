# 提升候选实现方案

状态：**候选，未实施、未验证复现**。依据是[当前分析链路](分析链路.md)，不是既有 SDK 参数或功能名称。

[测量约定](../测量约定.md)定义输入、坐标、方法与零态限制；[公共实现约定](../实现公共约定.md)定义前向场、符号和逆采样。本项只在此补充差异。

## 最小模型

目标为：以向上为主的局部位移场，中央和下鼻更强，上方及外围较弱。

最小可靠几何：鼻根、鼻底与鼻中轴定义方向、长度及峰区；保护下眼缘、鼻外颊和嘴唇。 依公共约定冻结局部轴及尺度，公式为前向位移：

```text
D(p,u)=−ρ(u) A H P(p) E_s(s) B(t)e_y
F_u(p)=p+D(p,u)
```

A≥0 是归一化峰幅待拟合量，B(t) 是上侧较缓升、下侧较快回零的平滑峰形；E_s 在中央较强，向两侧衰减。单峰是最小候选，不预设平顶，也不把观察上端当严格固定锚点。横向残差必须用独立点复核，未证明需要时不增旋转项。

## 标定与保护

本批实测范围见分析链路，全部是截图端点间 px 聚合；公式系数、响应、支持边界及归一化幅度尚未拟合。要么先在 L 网格拟合端点间映射，要么取得共同零态后按 `F_R∘F_L⁻¹` 比较；不能以逐点减场或端点除二替代。

保护权重独立于内部运动，作用边界至少连续，一阶平滑须连同导数匹配。当前检查窗的静止/随动结论仅属于该批观察，不升级为完整区域保护。退化几何、权重冲突、Jacobian或逆解失败按公共约定收缩强度或恒等返回；不能让弱纹理填充决定安全性。

## 从几何到像素的候选流程

定位并核对可靠几何 → 在统一源域生成候选场 → 与有效独立对应及纵横剖面比较 → 检查全部权重导数、完整 Jacobian 与全局无重叠条件 → 求逆并检验残差 → 对原始输入单次采样。该流程是可审阅设计，不代表本轮已经运行了候选输出或数学安全验证。

## 可推翻的验收

用不同鼻长高度和左右距离的上移剖面同时验收；整鼻等幅上移即使鼻尖对上也应拒绝。独立点最大上移约 25.42 px，不是全域峰值。部分下眼缘接受点向上约 1.09–3.19 px，不能把整个眼周写成静止。嘴唇检查窗两端同字节，仅约束该窗。

峰区位置、上下不对称过渡、侧向权重和中间滑杆响应未知；稀疏匹配中少数 dx 与主场不一致，未删去这些点。 仅有公式一致、输出变化、调用链成功或局部测试数量都不构成效果合格。本轮没有更改 SDK 或创建实施计划。
