# 鼻头候选实现方案

状态：**新增纵向项已实施并完成针对性验证，完整复现未验证**。具体生产表达、人工注册条件及残差见[代码修正与参考验证](../代码修正与参考验证.md)。本页其余公式仍为候选。依据是[当前分析链路](分析链路.md)，不是既有 SDK 参数或功能名称。

[测量约定](../测量约定.md)定义输入、坐标、方法与零态限制；[公共实现约定](../实现公共约定.md)定义前向场、符号和逆采样。本项只在此补充差异。

## 最小模型

目标为：鼻头局部横向内收，并存在上部向下、下部向上的纵向收拢分量；两轴比例尚未识别。

最小可靠几何：鼻头中心候选、鼻底和两侧鼻翼，以及上接鼻梁的局部范围；鼻根、眼睛和嘴唇用于独立保护观察。 依公共约定冻结局部轴及尺度，公式为前向位移：

```text
D(p,u)=−ρ(u) P(p) E_h(r,τ) [κ_x W r e_x + κ_y H τ e_y],  r=s−s_h, τ=t−t_h
F_u(p)=p+D(p,u)
```

κ_x、κ_y≥0 分别控制两轴收拢，s_h/t_h 是待拟合的局部中心，E_h 是鼻头局部连续支撑。先允许两轴独立，禁止预设 κ_x=κ_y；固定中心零位移是候选的可证伪性质，不是已经测得的事实。若中心纹理对应推翻线性核心，先收窄核心再判断是否需要更复杂模型。

## 标定与保护

本批实测范围见分析链路，全部是截图端点间 px 聚合；公式系数、响应、支持边界及归一化幅度尚未拟合。要么先在 L 网格拟合端点间映射，要么取得共同零态后按 `F_R∘F_L⁻¹` 比较；不能以逐点减场或端点除二替代。

保护权重独立于内部运动，作用边界至少连续，一阶平滑须连同导数匹配。当前检查窗的静止/随动结论仅属于该批观察，不升级为完整区域保护。退化几何、权重冲突、Jacobian或逆解失败按公共约定收缩强度或恒等返回；不能让弱纹理填充决定安全性。

## 从几何到像素的候选流程

定位并核对可靠几何 → 在统一源域生成候选场 → 与有效独立对应及纵横剖面比较 → 检查全部权重导数、完整 Jacobian 与全局无重叠条件 → 求逆并检验残差 → 对原始输入单次采样。该流程是可审阅设计，不代表本轮已经运行了候选输出或数学安全验证。

## 可推翻的验收

必须同时验证左右内收、上半向下及下半向上，并单列中央未覆盖区。只让鼻底上移、仅横向变窄或按等比缩小套用均不足。完整输出仍需看过渡和中轴；小模板共同接受只说明局部对应，不能证明整个鼻头场正确。

两轴倍率、压缩中心、中央强变形段的真实剖面及横向峰值仍未知；不把鼻头菜单解释成三维前突/后缩。r5 单模板有异常大位移，仅保留为方法不稳定记录，不当作峰值。 仅有公式一致、输出变化、调用链成功或局部测试数量都不构成效果合格。原始参考分析阶段未改 SDK；后续纵向修正的实际范围以上述验证记录为准。
