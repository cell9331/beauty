# 大小外围随动、鼻头纵向收拢：代码修正与参考验证

2026-10-17。[返回鼻子入口](README.md)。本页为首轮纵向修正的历史记录；后续山根、鼻梁及大小的当前作用范围见[作用范围修正与验证](作用范围修正与验证.md)。下文“保留其他四项”仅描述首轮，不代表后续未修改。

**结论：两项纵向修正已接入 dense 照片路线，16 项定向测试通过。本批固定人工注册几何的条件端点比较支持目标纵向规律得到改善，尚未证明完整参考复现、生产检测资格或跨照片泛化。**

## 实际改动

生产修改集中在 [BeautyContinuousNoseMap.swift](../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousNoseMap.swift)。其他四项鼻部场、原有横向系数、保护框和安全限幅保留。

- **鼻头**：将“下段单方向抬升”替换为围绕局部中心的纵向收拢。正向时上部向下、下部向上，负向反向。纵向强度独立于横向强度，支撑延续至鼻底，并分别限定上部宽度与下部衰减。
- **大小**：增加两侧皮肤肩部同向纵向随动，中轴和鼻内高度保持；上端及外侧尾部收紧，避免把整块鼻周皮肤一起推移。
- 新增内部逆采样坐标查询，与 `applyRGBA` 共用双线性位移插值，用于按同一源点比较端点；没有新增公开参数或输出原始几何的日志。

当前仍使用双眼连线确定的既有局部轴。鼻头中心沿用现有几何派生位置，属于本次初版设计，并非本批测出了唯一压缩中心。新增强度、范围和响应是实现选择，不能写成闭源产品参数；参考单端零态仍未知。

## 数学与保护复核

当前实现直接定义逆采样 `B_u(q)=q−d_u(q)`。鼻头纵向项与距局部中心的带符号距离相乘，大小纵向项使用双侧肩部权重，两项各自具有连续过渡。实际网格的全部分量、保护权重及过渡均纳入原有单元梯度和模长预算，包含实际强度、对应符号的 cap 及组合情形。

保留梯度上限 0.45、位移上限 `faceSpan×0.06`、pose 缩放、眼/眉/完整外唇保护、alpha 门禁和退化几何拒绝。独立只读审阅未发现新增方向、量纲、连续性或预算遗漏。网格上界约束实际双线性逆映射，不能扩大为完整前向候选、图像边缘 clamp 或所有跨阶段复合已获证明。

## 参考验证怎样进行

输入仍为大小 `IMG_2105→IMG_2106`、鼻头 `IMG_2115→IMG_2116`。照片同区域裁切为 1170×1670，保留 ICC，没有空间缩放或局部回正。人工在照片上注册眼、眉、鼻脊、鼻轮廓和嘴唇几何，修改前后固定同一几何；这只验证受控的真实照片渲染，不冒称生产检测成功。

测试直接调用实际 Swift 鼻部 map，并核对实际照片 stage 与 map 像素一致。两个 SDK 端点同用一份几何，比较采用：

```text
相对前向 H = B_high⁻¹ ∘ B_low
相对逆向 H⁻¹ = B_low⁻¹ ∘ B_high
```

因此按源对应求端点差，没有逐点相减不同网格场，也没有将参考端点差除二。参考左端仅为照片承载，不授予中性或 SDK 低端身份；SDK ±cap 与美图滑杆端点的物理对应仍是条件假设。数值闭合只检查相对求解器，不作照片拟合精度。

保留原先按源纹理选择的全部候选、接受和拒绝点。初先固定左侧标定、右侧复核；迭代期间两侧均已审阅，所以结果属于复阅数据，**不称独立盲验**。模板半径变化也只算方法交叉检查。未覆盖中段和拒绝区域继续保持未知。

真实输出 PNG 另用独立 NCC 匹配复查，搜索和接受规则沿用原测量，没有用 Swift 场初始化或按实现一致性筛点。鼻头上部 7 个参考块中，两轮均仅相同 4 块在输出 PNG 中接受，另 3 块拒绝；下部 19 块全部接受。块相关性保持原分析说明。

## 定向数值结果

单位为本批原尺寸截图 px。下表为同一批接受参考对应上的绝对纵向残差 P95；是相对参考对应的方法差异，不是真值误差。

| 定向组 | 实际 Swift 场：原实现 → 修改后 | 实际 PNG 独立 NCC：原实现 → 修改后 |
| --- | --- | --- |
| 大小双模板共同 5 点 | 2.193 → **0.729** | 2.231 → **0.951**，5/5 接受 |
| 鼻头上部 7 个相关块 | 3.226 → **0.903** | 1.820 → **0.550**，相同 4/7 接受，3 块拒绝 |
| 鼻头下部 19 个相关块 | 1.563 → **1.340** | 1.616 → **0.873**，19/19 接受 |

大小 5 点的场纵向方向均正确且超过 1 px；输出 NCC 五点方向均正确，其中四点超过 1 px。鼻头全部 121 个双小模板共同块的纵向残差 P95 从 1.341 降至 0.766；该汇总包含静止和移动块，不能代替上/下组。

### 静止区、正交残差及未解决问题

- 大小鼻区 ≤1 px 参考组 163 点，纵向残差 P95/max 从 **0.083/0.190** 变为 **0.116/0.400**，仍有小幅退步；没有超过 0.5 px 的残差。鼻内核心 13 点保持原来的 P50/P95 约 0.081/0.187。
- 鼻头鼻区静止组 225 点，纵向残差 P95 从约 0.078 降至 0.054。双眼、嘴唇、双颊和头发的原观察窗纵向结果与原实现一致；眉部保护由合成像素断言检查，没有另设真实照片眉部 NCC 窗。
- 同源点横向变化 P95：大小主鼻区约 0.001 px，鼻头主鼻区约 0.00045 px、定向区约 0.055 px。逆映射与限幅会产生小幅耦合，不能声称横向数学上完全不变。
- **旧横向幅形残差没有解决**：大小目标五点的全向残差 P95 仍约 10 px；鼻头旧横向差异也保留。目标纵向改善不等于整体二维复现合格。

首版曾明显带动参考近静止纹理，已因此收紧支撑。首版、低幅度版及较宽肩部版证据保留本地，未用最终结果覆盖失败调查；正文采用最后冻结版本。
