# 下颌线入口与发际线侧缘修正

2026-10-17；在 `codex/face-five-displacement-analysis-20261016` 当前工作区继续修正两项反馈。新版已覆盖安装到 iPhone 13 Pro，保留应用数据，外观待用户验收。此前三项改造见[历史交付记录](后三项SDK改造记录.md)。

## 下颌线入口

偏浅有两个来源：原模型以自然阴影下降到 90% 的位置作为新增阴影起点，并叠加材质羽化；单一脸部肤色族又把部分暖暗颈肤排除，在入口留下浅区。单独调整起点只使固定入口误差减少约 5.3%，因此继续修正材质依据，没有提高全局 gain。

当前将源下降的 50% 位置用于入口，90% 位置仍用于光照证据与长尾退出；使用真实 native patch 中心注册，进入宽度为 `.006S`，`S` 为源脸宽。几何安全边界和源亮侧约束共同限制进入距离，完整像素足迹通过后才着色。材质羽化只表达材质、连通和歧义边界，不再把阴影场自身的零权重重复当作进入边界。量化形成的多个高分对比窗口只作诊断；真实下降—恢复—再下降仍以三条源上下文轨迹判断并拒绝。

左右颈肤 patch 各自先通过原脸部族的逐 native 样本资格，再检查双侧一致性。编辑材质允许原脸部族，或同时匹配两侧已核验的颈肤族；原 `.035` 色度距离与脸部亮度上下界保留。源光照判断仍使用原脸部族。连通只从颌内锚授权，颈肤不能自行越过完整异物横带复活区域；细丝自身、源亮侧、alpha 与逐通道 18% 预算继续保护。

相同源观察窗、同一参考 ICC 转 sRGB、无新增配准下，实际公共 SDK 满档结果如下。数值是编码亮度变化，单位 `/255`，负值表示变暗。

| --- | ---: | ---: | ---: |
| 约 2.5 px | 0.00 | −8.08 | −12.86 |
| 约 7.5 px | −0.79 | −11.65 | −14.94 |
| 约 12.5 px | −8.08 | −12.58 | −15.94 |

四个固定分箱的中位值与参考的平均绝对差由 **9.484 降至 3.605，减少 62.0%**。这是纵向剖面指标，不是逐像素误差或精确法向距离。总变化像素由 60254 增至 **66100**；指定源观察域中条件参考变化低于 −3/255 的像素覆盖由 82.88% 升至 **89.65%**，不作为语义 IoU。

下颌下中央中位变化由 −9.08 到 **−10.86**，参考 −11.51。四分档逐通道无反向变化；衣服、头发、眼核心、额头、鼻、唇、背景观察区仍为零改变。比条件参考额外变暗超过 3/255 的像素从 425 增至 **664/66100**，超过 5/255 为 12，最大额外变暗仍为 7.50；改善入口没有消除全部局部色调残差。完整材质不足的浅区仍可保留。

## 发际线侧缘

原三个运动窗的外侧尾部覆盖了少量背景。新增相对源轮廓的左右保护，在轮廓外 `.15… .40` 倍眼距平滑释放，到 `.40` 倍眼距起精确固定；保护平坦区完整覆盖原运动窗的外侧及高度。使用既有 C² 窗，并将保护乘积的完整导数计入证书。额前/侧发运动窗、`.046` 幅度、来源资格和眉眼核心保持。

沿用原左右背景窗，各 **99750 像素**；修正前低端改变 320/620、高端 300/580 像素，修正后两端左右窗均 **0 改变，最大通道变化 0**。眉眼、发顶和鼻口观察窗也均零改变。这只证明声明的源观察窗，不能扩称任意照片的语义背景分割。

两端总变化像素为 **276490/276436**。原 r20 移动 40 点的向量差 P50/P95 为 **1.759/4.553 px**，14 个空间留出移动点为 **1.928/5.023 px**；修正前 P95 分别为 4.554/5.030 px。完整梯度证书 **0.431531**、幅度缩放 1，主要位移保留。固定的 273 条源查询在最终两轮逐值一致，未更换对应点或观察窗。
