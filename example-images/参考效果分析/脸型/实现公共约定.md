# 脸型候选实现的公共约定

本文件保留测量阶段供[脸型归档](README.md)各项候选方案共用的数学与采样边界；其中“本轮”“待标定”描述该阶段，不描述美图秀秀内部实现，也不覆盖后续生产状态。当前分批实现、定向验证和已知残差分别见[前三项记录](SDK改造记录.md)、[后五项记录](后五项SDK改造记录.md)、[后三项记录](后三项SDK改造记录.md)。实际照片外观仍待审核，不能因代码接入认定参考复现。

## 证据与端点资格

脸宽、小脸、太阳穴、颧骨、下巴长短、尖下巴当前能识别的是“左端截图作为源 → 右端截图作为目标”的总对应。面部流畅、V脸只有“配准原图 → 右端截图”的条件性差异。相同照片内容不证明共同零态；两端总差不能除以二解释单端强度。各批次测量的配准与交叉检查分别记录，不能混作同一统计集合；后五项见[五项测量约定](五项测量约定.md)。

下文首先定义可在当前源图上拟合的对应场。未来若要对中性照片开放滑杆，必须另取同一编辑状态的中性及中间档，分别标定端点映射与响应。令中性源点为 r，端点映射为 E₋、E₊，当前观察场应满足：

`D_obs(E₋(r)) = E₊(r) − E₋(r)`。

不能直接相减定义在两个端点网格上的场，也不能把当前左端几何当作已知中性几何。文中的线性倍率 t 只表示对候选对应场的设计性插值 `F_t(p)=p+tD(p)`，t=0 为当前源、t=1 为当前目标假设；不代表产品中间档规律，也不支持自动外推到负端。

## 坐标、局部轴与几何

全局源坐标 p=(x,y)，x 向右、y 向下，单位为源网格像素；当前测量的源网格是对齐后的截图网格。前向位移和映射为：

`D(p)=p_target−p_source`，`F(p)=p+D(p)`。

为迁移到新图，候选设计使用左右眼中心连线确定单位水平轴 eₕ，朝图中右侧；与之正交、朝下巴的单位轴为 eᵥ。R=[eₕ eᵥ] 为正交矩阵，c 为双眼中心中点，L 为眼中心距：

`z=(h,v)=Rᵀ(p−c)/L`，`D(p)=L R d(z)`。

眼中心距只是本方案选择的归一化长度，**本轮尚未测量 L，未得到任何实测无量纲幅度**。必须在实际源图上测量后，才能换算截图像素与模型系数。局部轴按源图固定，不随待求像素或迭代位置重新估计。下颌、下巴、脸缘及可靠观察区也来自源图；这里不保存实际点位。

眼中心缺失、L 退化、轮廓与五官关系不可信、遮挡导致支撑无法可靠定位时，拒绝该项并返回原图。大侧脸、强透视、张嘴等未验证输入不能靠放大支撑范围补救。

## 内部规律、紧支撑与独立保护

各项分别定义内部运动 d₀ 与支持它的空间窗，不能把皮肤支撑等同于五官二值蒙版。可选的 C² 紧支撑基函数为：

`b(s)=(1−s²)³`（|s|<1），否则为 0；

`B(h,v)=b((h−h₀)/rₕ) b((v−v₀)/rᵥ)`，其中 rₕ、rᵥ>0。

b 的值、一阶及二阶导数在支撑边界连续归零。若证据要求内部平台，可用 C² 过渡 `S(t)=6t⁵−15t⁴+10t³`（0<t<1，两侧延拓为 0/1）拼成有平台的紧支撑窗。支撑位置、内部峰形、平台宽度和回零宽度是不同参数，均须标定；不得把这张图的半径当通用常量。

对独立指定的保护核心使用 C² 函数 Pⱼ∈[0,1]：核心内 Pⱼ=1，外围平滑回零。总保护因子 `G=∏ⱼ(1−Pⱼ)`，最终场 `d=G d₀`。保护核心的选取先于拟合，不按“恰好与模型一致”筛选。保护过渡本身会增加梯度，须纳入安全界；不能只把位移清零后跳过边缘检查。严格保护是候选设计约束，不自动成为参考产品已采用的机制。

## 完整导数与无折叠资格

所有空间权重的导数必须保留。对一般形式 `d₀=Σₖ wₖ(z)mₖ(z)`，其完整导数为：

`∇z d₀ = Σₖ [mₖ (∇wₖ)ᵀ + wₖ ∇mₖ]`；

`∇z d = d₀ (∇G)ᵀ + G ∇z d₀`；

`∇p D = R (∇z d) Rᵀ`，`J_F=I+∇p D`。

这里向量导数按“输出分量为行、输入坐标为列”。b 在内部的导数为 `b′(s)=−6s(1−s²)²`；还要乘上 1/r 的链式因子。多项保护相乘时使用完整乘积求导，不用含除以 `(1−Pⱼ)` 的写法，以免核心内除零。

一个保守、足以保证全局单射并支持可靠逆解的准入条件是：场在整个平面连续可微、紧支撑，且有**全域上界** `supₚ ||∇pD||₂ ≤ κ < 1`。由此 `||F(p)−F(r)|| ≥ (1−κ)||p−r||`；结合紧支撑外恒等，F 是全平面的双射，且 Jacobian 不退化、行列式为正。κ 与安全余量属于待确定的工程预算，不是本轮测得的常数。

可通过各多项式基函数的解析极值界、覆盖整个支撑的区间界以及乘积/求和上界作保守认证。稀疏采样的最大梯度只可用于发现问题，不能当作全域上界；仅检测 det(J)>0 也不独立证明全局一一映射。认证失败时先扩大有证据支持的过渡或降低整项幅度；若参考所需幅度与安全/保护约束不相容，应报告候选不合格，不能把降低后的外观宣称为复现。

## 逆映射与单次采样

渲染目标 q 时求唯一源点 p，使 `F(p)=q`。在上述 κ<1 条件下，可用固定点迭代：

`p₀=q`，`pₙ₊₁=q−D(pₙ)`。

迭代是收缩映射；每个像素核验实际逆残差 `||F(pₙ)−q||`，并可用后验界 `||pₙ−p*||≤||pₙ₊₁−pₙ||/(1−κ)` 控制精度。容差与迭代上限按最终采样质量明确制定，尚未标定。一次 `q−D(q)` 通常只是近似，不可直接当作真实逆映射。

支撑必须完整落在有效图像内部，边界邻域保持恒等，并验证变形域覆盖目标域。不可裁掉支撑后仍使用原有导数保证。逆解不收敛、几何失效、越界或安全认证失败时，拒绝整项渲染并返回原图；逐像素回退恒等会制造拼接边界，不作为通过方式。保护核心处 D=0 且全局唯一时，其逆点也是自身。

从同一张原始输入按最终逆映射采样一次；固定零位移区域可保留原字节。不要反复变形上一次输出，也不要混合两张错位图掩盖边界。本文只覆盖各项独立场；若未来合并多个功能，须重新认证总映射及保护，不能把单项资格直接相加。

## 实施与验收边界

候选的可审阅流程是：取得可靠源几何 → 用拟合集确定低自由度参数 → 全域导数认证 → 求逆并检查残差 → 原图单次采样 → 用未参与拟合的对应和实际输出核验。这里只定义流程，未创建 SDK 执行计划。

各项验收须分别报告移动区域、保护核心、过渡区域与背景，给出接受点数、拒绝原因及方法间差异；保留不同尺度或方法的不一致。已知平移、局部合成场及零变化控制可以核对数学/符号/逆解，但不证明真实参考外观。几何安全与软件调用成功均不能代替独立效果验收。
