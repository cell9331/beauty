# 下颌线本地测量说明

本轮本地批次位于同一脸型分析目录的 ignored `本地测量/后三项-20261017/jawline/`。原始截图、裁图、源点、蒙版、逐像素场和脚本仅保留于本地，不加入持久 Markdown。

复跑顺序：

1. 使用本项目已存在的 Python 图像计算环境，不下载模型。`measure.py` 复用原图一次配准字节，按共同照片边界裁出 2032/2033/2034。
2. `protocol.json` 固定坐标、条件源、观察区、待检验机制和光度域；不能把原图升级为已证实零态。
3. `measure.py` 生成 source-only NCC 两尺度、独立接受/拒绝、稳定区拟合/留出、DIS 前后向与半尺度字段；NCC 不由光流初始化或一致性筛选。
4. `photometry.py` 读取源确定的皮肤/颈/衣服/头发/核心/背景区域；参考 ICC Display P3 转 sRGB，原图按无标记 sRGB 假设。编码量与解码线性光分开，且无光流变形对齐。
5. 独立零变化与 `(5,−3)` px 平移控制只验证该类纹理匹配能力；色调共同 gain 检查在作用区及控制区分别计算残差。
6. `render.py` 生成合成证据图。图中热图是估计字段或条件光度差，曲线注明窄带/聚合方式；图中的源图边缘不是通用生产参数。
7. 主协调任务的 `probe/output/` 提供当前分支公开照片 SDK 中性和右端、源资格聚合和 CPU/实际 Metal/direct-apply 一致性回执；`sdk_compare.py` 只读取实际输出，在相同源观察域统计变化与条件参考差，`render_sdk.py` 制作实际对比证据。

本次实际生产结果：源资格通过，effective strength 0.25，eligible 2845、最终变化 2136 像素，CPU/实际 Metal/direct apply 均逐字节一致；中性与一次配准原图一致。此回执证明的是本图 macOS Vision 照片路径，不能扩大为真机检测器、其他照片或实时路径验收。

外部专项比较补充：同批次 `jawline-report-review/color_space_audit.py` 导入既有 `jawline/photometry.py` 的读取、源观察区与亮度定义，不触发其主流程；在同一源像素观察区分别比较原始 P3 字节和 ICC 转 sRGB 后的参考，生成 `color-space-audit.json`。无新增配准或重采样；仍保留无标记源图按 sRGB 处理的假设。编码域共同增益残差以 0…255 RGB 向量长度计，线性域残差以 0…1 RGB 向量长度计，不能把两种残差数值直接相除或比较大小。公开结论见 [外部专项对比](外部专项对比.md)。

验收本轮分析应检查 NCC 接受数和拒绝原因、两尺度差、保护/背景传输误差、色域说明、零态限制、实际资格与理论上限的区别、对生产与历史试验的区分，以及引用能否打开。仅分析和文档不运行 SDK 全量测试、模拟器或设备回归。
