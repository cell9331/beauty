## ① 中央缺口：代码如何把皮肤留白

关键判断，当前 217–231 行中的核心片段：

```swift
return samples.allSatisfy { c in
    skin(c) || (c.luma >= max(18, palette.luma * 0.58) &&
        c.luma <= min(250, palette.luma * 1.30 + 8) &&
        neckPalettes.allSatisfy {
            hypot(c.chroma.x - $0.chroma.x,
                  c.chroma.y - $0.chroma.y) <= 0.035
        })
}
```

这里有两层“全部满足”：每个 native 样本必须匹配**两组颈肤参照**，而一个目标像素的完整 3×3 又必须**每个样本均通过**。中央自然光照下的颈肤颜色超出已有参照；本图亮度上下限并没有拒绝该区，因此主因是色度资格。

随后 591 行 `guard material[j] else { continue }` 不再计算该像素权重，534 行初始化的零值被保留。621–624 行又把材质拒绝域放入距离场的零边界，636–638 行沿边缘降低阴影，形成“浅洞＋周围浅边”。最终 `apply` 的 45 行只处理正权重，洞内没有着色机会。

**对应修复责任：目标材质模型及其边界处理。** 不能只加 gain，也不能只取消 3×3；原生材质阶段已经拒绝约 72%，完整足迹额外扩大约 9.15 个百分点。应保留发丝/衣领保护所需的完整足迹，补足独立颈肤依据。

注意 188–190 行的 `neck.allSatisfy(skin)` 是**整项源证据门禁**，失败会拒绝整项效果。本图该门禁通过，不能将它直接当成局部缺口的触发点。

## ② 左入口：共同预算压缩了仍有余量的通道

当前 48、51–55 行：

```swift
let cap = sourceDecrement * Double(weights[j])
var budget = 1.0
for channel in 0..<3 where cap[channel] > 0 {
    budget = min(budget, rgb[channel] * 0.18 / cap[channel])
}
let shaded = rgb - cap * (max(0, budget) * fraction)
```

三个通道最后使用同一个 `budget`。209–211 行选择的源族减量方向与当前像素的通道余量不一致时，蓝通道限制会连带缩小红、绿减量。这里不能简化成“18% 上限太低”：离线只改成各通道分别限额，仍守 18%，就能独立改善左入口。

![当前正式 SDK、仅改变预算投影的离线候选与美图参考](../本地测量/下颌线缺口重分析-20261017/profile/budget-only-current-material-comparison.png)

该候选保持原材质、羽化、幅度和尾型：中央 +14.37 不变，左入口 +3.92→+1.56，下缘 +2.72 不变。原 11 个保护窗及原所有权外没有变化，四档单调、alpha 和 18% 预算通过离线核对；原四个颈肤域过深超过 3/255 的像素也由 305 增至 368，需要保留这个代价。

**对应修复责任：`Evidence.apply` 的预算投影。** `sourceDecrement` 的颜色方向还存在残差，不能把亮度改善认定为全部 RGB 复现。候选尚未合入或安装。

## ③ 尾部：预设形状需要校准，不能先认定硬截断

当前 605–608 行：

```swift
let entering = smooth(safeEntryDistance / (f.span * 0.006))
let exiting = 1 - smooth((r.exitDistance / f.span - 0.02) / 0.22)
let lateral = smooth((0.40 - abs(q.x) / f.span) / 0.10)
weights[j] = Float(entering * exiting * lateral)
```

退出权重从法向距离约 `.02S` 开始减弱，在 `.24S` 自然回零；支撑检查也在 `.24S` 截止。因此不能只看到 588 行的范围检查，就说“代码硬切出一条浅边”。当前下缘残差位于已拥有、预算未饱和的材质上，但究竟该改内部衰减、局部颜色还是支撑长度，尚需分离。

仅增加一个尾型参数时，左侧拟合改善，右侧留出误差反而恶化约 12.6%。**对应修复责任：材质及预算稳定后的空间/光度标定**，不是立即统一加长或加深。

## 当前不能误指的路径

- 241–277、442–518 行的光照注册，以及 547–578 行的连通保护，当前没有被证明是中央主因；固定这些算法，仅改变材质资格即可在离线本图关闭缺口。
- 连通失败可能是前面材质被排除后的结果，不能直接通过新增颈部连通种子跨过异物。
- 只靠相邻颜色连续扩张的离线方案虽能补洞，但已被渐变异物反例推翻，**不属于当前生产代码，也不是可直接采用的修复**。
