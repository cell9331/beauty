# 下颌线：实施与校准

2026-10-17；参考与色域核对见 [分析链路](分析链路.md)、[外部专项对比](外部专项对比.md)，改造前生产基线见 [代码差异](代码差异.md)。首次交付见 [后三项 SDK 改造记录](../后三项SDK改造记录.md)，当前入口反馈修正与重新安装见[两项修正记录](../入口与侧缘修正记录.md)。

继续采用不改变几何的源固定照片光度层。`BeautyJawlineShadow` 将源光照注册与新增阴影支撑分开：保留双侧皮肤、原自然下颌对比、局部亮侧上包络、完整 native 3×3 材质足迹；新增双侧颈部源族作为材质佐证，支持约 0.24 倍源脸宽的连续尾部。

完整材质域按四邻接连接，只从已经核验的颌内锚授权。目标 native 样本须符合原脸部族，或同时符合左右已通过原脸部资格和双侧一致性核验的颈肤族；保留原色度阈值及脸部亮度界限。有限细丝可沿真实皮肤路径绕过，细丝本身不改变；整条 foreign 横带必须阻断。颈部种子不能自行复活与脸部分离的区域。仍是基于源证据的照片候选，不是颈部语义分割；同色无边界衣物等不可识别输入没有获得普遍保护保证。

令 `S` 为源轮廓横向跨度，`x` 为源眼轴横坐标。当前入口与退出分开：源光照下降 50% 位置注册进入距离，另受 `.005S` 几何边界约束，中心及四角取最保守值后用 `smooth(dEntry/.006S)` 进入；源 90% 暗侧距离 `dDark` 保留长尾退出 `1−smooth((dDark/S−.02)/.22)`，横向为 `smooth((.40−|x|/S)/.10)`。缺失局部 profile 分别使用粗 50% 位置加 `.0025S`、粗 90% 位置加 `.005S`，两者均限于原 `.025S` 界。`smooth` 是截断到 0…1 的三次平滑步；材质羽化不再重复使用阴影自身零权重作为入口。真实竞争光照仍拒绝，native 量化造成的多个高分窗口只作诊断。

色调不再把当前编码 RGB 同乘统一 gain。由源皮肤族尺度 `P` 与 `warm=max(0,Pr−Pb)` 构造低自由度减量 `C=.105×[max(.25Pr,Pr−1.25warm),Pg,Pb+.25warm]`；冷/中性来源不强行套固定暖肤色。当前颜色基线上 `V=C×W`，统一预算 `k=min(1,min_c(.18×RGBcurrent[c]/V[c]))`，输出 `RGBcurrent−fraction×k×V`。各通道最多减少 18%，保持 alpha 和四分档单调。

这是按本轮 sRGB 同域数据选择的工程模型，不是已识别的美图混合模式。约 15/255 的实际峰值预算接近参考峰减去整体传输差，因此没有为中央中位不足而统一加深两侧。参考原图的共同零态仍未确认。

当前本图编辑 **66100 像素、429 列**，每列变化数中位 **170**；首次三项交付为 60254 像素、157.5，更早旧版为 2136 像素、16。指定源观察域中，条件参考编码差 <−3/255 的像素覆盖由首次交付 **82.88% 增至 89.65%**；这不是语义真值 IoU。

本图衣服、头发、眼核心、额头、鼻、唇和背景观察域无改变；alpha、无增亮、逐通道预算、四分档单调均通过。比条件参考额外变暗 >3/255 的像素为 **664/66100**，首次交付为 425/60254；最大额外变暗保持 7.50。CPU/实际 Metal/direct 一致。可与本轮下颌角、发际线在源着色后单次逆采样；其他几何/纹理组合仍拒绝。新版已重新安装真机，最终效果待用户验收。
