# 下颌线分析链路

## 输入资格与坐标

源为此前一次重采样到共同照片网格的原图，目标为 `IMG_2034` 下颌线右端。共同照片区域为 1170 × 1570 截图像素，已排除状态栏、工具栏、滑杆和覆盖层。`D(p)=p_target-p_source`，x 向右为正，y 向下为正。没有重新按局部变形对齐，也未借光流吞掉明暗差。

这一条件比较不构成“已证实零态 → 右端”。相邻 `IMG_2032/2033` 是另一控制的端点，只有作为输入污染检查的意义，不能给本项补出左端或共同零点。

测量前固定了观察区：下颌下中央与双侧皮肤、较低颈部、衣物、左右头发、额头、双眼、鼻和嘴核心、上方及双侧远背景。观察区域由源图和空间分区确定，不按目标差值大小或光流一致性筛选。

## 同网格检验及其他项残留

独立 source-only NCC 在预定网格、源纹理和源轮廓条带上选择 336 点；使用半径 14、20 px 两套模板，搜索半径从 128 px 开始，遇边界再扩大到 256、384 px。接受要求为源模板标准差 ≥3、双向 NCC ≥0.72、峰值与邻近候选差 ≥0.025、双向闭合 ≤1.4 px；并不要求与稠密光流一致。

分布于多方位稳定区的半径 14 对应接受 35 点，交替分为拟合 18 点、留出 17 点。全局相似变换的留出误差 P50/P95 为 0.11/0.23 px；留出原网格位移 P50/P95 为 0.10/0.19 px。相似变换所需位移远小于一个像素，因此本轮保留原网格与原字节，不新增空间重采样。

同一批源点核对相邻截图：原图 → 2032 有 11 个 >2 px 接受点，模长 P95 4.77 px；原图 → 2033 有 17 个，P95 7.24 px；原图 → 2034 没有 >2 px 接受点。该比较能区分前两幅的下颌角几何变化，2034 未呈现这些端点的几何残留。它不能证明所有可能的其他调整都已清零。

## 几何证据和不确定性

| 方法 | 接受/选择数 | 位移模长 P50/P95 | >2 px 移动点 |
| --- | --- | --- | --- |
| NCC 半径 14 | 196/336 | 0.09/0.23 px | 0 |
| NCC 半径 20 | 204/336 | 0.08/0.24 px | 0 |
| 两尺度共同接受 | 181 | 方法间差 P50/P95 为 0.07/0.20 px | 无可供单列的移动点 |

半径 14 拒绝的主要原因为弱纹理 76 次、前向峰不唯一 60 次、反向峰不唯一 64 次、闭合超限 3 次；原因可重叠，不能加总当作人数。半径 14 的下颌/颈部加密源点接受 34 个，模长 P95 0.23 px；下脸轮廓条带接受 15 个，P95 0.67 px，最大 1 px。**无 >2 px 点不等于全域严格零位移**，尤其不能用大量静止背景替弱纹理皮肤担保。

完整尺度 DIS 的下颌下中央估计模长 P95 0.41 px，前后向闭合 P95 0.08 px；但与半尺度估计差 P95 1.74 px。右侧边界局部完整尺度模长 P95 1.77 px，半尺度差 P95 1.72 px，且 NCC 不支持同量级移动。因此这些局部稠密箭头保留为亮度变化/弱纹理下的不稳定估计，不解释为几何模型证据。

34 点子集的零变化和已知 `(5,−3)` px 平移控制各接受 21 点；控制误差 P50/P95/最大为 0.02/0.07/0.10 px。它检查符号和此量级纹理匹配能力，不能外推成弱纹理皮肤的像素级真值精度。

## 色域、幅度与范围

目标截图带 Display P3 ICC，原图不带 ICC。先按 ICC 将目标转换到 sRGB，原图按 sRGB 假设，不进行空间采样。若直接把原编码通道相减，会在全脸产生红减蓝增的色域差，不能归为本控制。

本轮分别报告编码量 `Y'=0.2126R'+0.7152G'+0.0722B'`（0…255）与 sRGB 解码后的线性光亮度 `Y`。编码亮度差取 `Y'_target−Y'_source`；百分比分别除以同域源亮度。下颌下观察区像素分布如下，P5/P95 是区内分布，既不是置信区间也不是独立样本数。

眼部锐边编码差 P5/P95 可达约 ±5…6/255，而独立几何对应保持亚像素；这些边缘变化不足以证明保护核心本身被下颌线改色。背景和衣物近似 −1/255 的传输差作为基线不确定性保留，未做局部光度拟合，也未从每个像素强行减掉它。

剖面按源图手工辨识的下颌边缘索引，在中央宽带内取每 5 px 的中位数，属于源样本的近似竖直偏移，不冒充精确法线距离。它在边缘附近快速变暗：偏移约 +12.5 px 时 −15.94/255；+47.5 px 时 −11.94；+97.5 px 时 −8.87；+157.5 px 时 −2.29；+177.5 px 接近背景基线 −1。以 −1/255 仅作共同传输基线估算，变暗一侧 10%→90% 的进入约 17 px，退出 90%→10% 约 127 px。边缘定义、窄带和色域假设使这些宽度只能作约数，不能写成其他照片的固定参数。

中央并非无变化点，双侧也不能用左右完全相同的幅度代替。横向统计中的“侧强中弱”同时受源皮肤亮度、遮挡和可观察区域影响，不足以唯一确定双峰函数。

## 最小可证伪判断

事实：同网格独立纹理保持静止；下颌下有跨双侧和中央的宽明暗尾；通道相对减益不同。最小假设是源坐标下、靠近下颌的局部色调场，不需要先引入下颌几何收缩。

对于每个中央皮肤像素，即使允许独立拟合最佳共同编码 RGB 增益 `g`，`||RGB_target−g RGB_source||₂` 的 P50/P95 仍为 8.31/11.97；左侧为 6.15/8.10，右侧为 9.14/12.00。相同计算在额头、鼻和衣物的 P50 约 0.74…0.90、P95 约 1.52…1.79。故共同编码 gain 不能充分解释局部色调，不能以整体 ICC 差解释这一残差。候选可包括非线性色调或颜色耦合，但本样本不能唯一识别闭源公式。

仍未知：已证实零态、左右端跨度、单端绝对量、中间档响应、组合策略以及精确材质授权方式。补充该控制零/左态将比提高光流自由度更能消除这些未知。

## 本图实际生产 SDK 核对

使用同一工程中性原图、单次 macOS 生产 Vision 观测冻结源几何，公开参数 `jawlineShadow=0.25` 分别执行 CPU 和实际 Metal 照片路径；二者逐字节一致。中性输出与本次一次配准原图逐 RGB 字节一致，直接生产 `Evidence.apply` 也与公共 CPU 输出一致，因此下表没有重建一套 Python 近似来冒充生产输出。

源资格通过，没有 refusal：双侧皮肤 family 2、源对比射线 10，局部源 profile 列 628，合格编辑域 2845 像素。源域候选 6834 像素中还受完整 native texel、材质连通和局部 profile 等约束；最终实际 RGB 改变 2136 像素。`maximumSourceGainPermille=180` 仍只是源上界，不能把它解释为所有像素降低 18%。

部分源观察区相交，上表计数不能相加当作全域 2136 像素。源下颌下和颈部四区取并集为 62288 像素；其中参考条件编码差 <−3/255 的像素有 48148，SDK 只改变其中 1607，占 3.34%。阈值高于约 −1 的整体传输基线，但仍是条件差的观察量，不是语义真值、准确率或对已证实中性的召回率。

实际 SDK 仅 136 个源列有非零像素，单列变化像素数 P5/P50/P95 为 12/16/18、最大 19；这些列在横向存在明显资格断口。即使区域中位为 0，不能称完全 noop。只在 SDK 改过的相同像素上看幅度，左/中央/右 SDK 中位分别 −5.28/−15.09/−8.63，对应参考为 −16.71/−15.51/−14.86；中央中位接近也不能掩盖 SDK 极窄范围和幅度分散。SDK 所有已改像素编码差 P5/P50/P95 为 −23.76/−7.42/−0.93，最深 −27.83，存在局部过深点。

本图实际输出支持的差异因此是：**源资格通过但编辑薄且断，参考有宽尾；部分薄带可过深，同时两侧已改像素仍欠幅；共同编码 gain 与参考通道响应不一致。** 这些结果只覆盖本源、本分支、macOS Vision 静态照片路径，不证明真机其他检测器或实时视频同样表现。
