# 下颌线残留：重新归因与修复方案

2026-10-17；使用 `reference-displacement-analysis` 重查当前真机版本对应的公共 SDK 输出。**本轮仅分析、离线消融与方案，未修改 SDK、构建或安装。** 当前代码与上轮交付状态不变，见[实施说明](实施说明.md)和[两项修正记录](../入口与侧缘修正记录.md)。

结论：中央缺口是原图材质被拒绝，左入口还受整条颜色向量预算约束，下缘是独立的衰减差。三处不能统一当作幅度不足。应先建立可信的中央颈肤所有权，并独立验证逐通道预算，最后重新标定尾部。

## 输入、口径与可辨识量

继续使用已一次对齐的原图、IMG_2034 右端，以及上轮最终 `output-r2`；参考按 ICC Display P3 转 sRGB，源图按无标记 sRGB 假设处理。不新增配准或重采样。此前两尺度独立 NCC 没有支持可辨认的几何收缩，本轮不重新拟合几何；下颌线单项保持 `F(p)=p`。

亮度差使用编码 sRGB 的 `/255` 单位。这里的正残差表示 SDK 比条件参考更浅，不是线性光百分比。参考共同零态仍未确认。

三个标注多边形分别与原下颌左/中/右及下颈四个源观察域的并集取交，冻结为 **3037 / 719 / 5158 像素**；没有按目标残差筛点。最初全多边形辅助统计与这个交集不是同一口径，最终表格只用固定交集。数值转写与当前实际公共满档 RGB 全像素一致，预算消融另与 25/50/75/100 四档实际 RGBA 一致。

## 中央：哪些材料路线已被排除

在冻结源资格、几何、颜色减量、羽化和预算的条件下比较；参考及手画区域只用于候选冻结后的评估。

| 离线材质模型 | 中央完整 3×3 通过率 | 中央残差中位 | 判断 |
| --- | ---: | ---: | --- |
| 当前脸部族或双侧颈肤族 | 18.67% | +14.37 | 已部署基线 |
| 已验证来源族并集／族间线段走廊 | 21.93% | +14.36 | 改善很小，不能填平缺口 |
| 仅由现有来源拟合亮度条件色度曲线 | 22.85% | +14.30 | 单一亮度变化不足以解释 |
| 只约束相邻颜色跳变的源图连通 | 100% | +1.86 | 本图明显改善，**未通过泛化反例，不能直接采用** |
| 冻结已核验 native 参照包络＋严格邻接 | 40.14% | +13.58 | 阻止累计漂移，但仍不足以修复 |

无界连通候选只从原颌内种子出发，没有读取目标残差授权，也保留了完整 3×3；但独立反例证明，连续小色差能累计漂移到远冷色端点，仍被 100% 纳入。原已合格节点的无条件连边还会穿过明显的近肤色硬边。黑丝和明显异色横带控制通过，不能抵消这两项失败。

有界候选改用四个原已核验 patch 的全部 native 色度点作为冻结参照，保留原 `.035` 半径及亮度界，每条新增边都须过原图邻差约束。它阻断了远色渐变，并消除了借旧节点硬边继续扩张的通路；但中央原生参照覆盖仍只有 55.48%。这说明均值丢失了部分源变化，**现有来源证据本身也不够**。不得继续用参考缺口反向扩大色度半径。

推荐的新材质模型应补充独立的原图颈肤范围证据，将颈肤、头发、衣领和未知区域区分开，再在有限源参照内利用颜色连续性。可研究独立颈肤分区，或由上下方向的原图材质轨迹、左右独立来源和阻挡边界共同佐证；这些是待验证路线，本轮没有选择、下载或接入分割模型。

可以先定义三态所有权：独立确认的颈肤、明确异物、未知。色度只在已有独立颈肤范围内作辅助置信度；明确异物不能靠羽化或图扩张跨过，未知不能自动成为新的颜色学习来源。验证标签应来自原图的独立颈肤/发丝/衣领标注，不能将参考变暗的区域直接当作生产材质标签。若新证据仍不足，应保留未解决结论。

实现边界应明确：

- 新来源必须从原图独立确认，不能从目标暗化区或已扩张节点反复更新参照。
- 新增区域同时满足有限来源包络、局部连续、颌内连通和完整 native 足迹；保留源亮侧、特征区及 alpha 保护。
- 近肤色硬边、渐变异物、完整横带、发丝及其绕行均需独立控制，不能仅检查当前图的衣服窗口。
- 与皮肤同 RGB、同连续性的布料仍不可由颜色图识别；没有额外证据的区域不能宣称语义安全。

这部分需要更好的所有权依据，当前并不存在一个已同时证明“补全中央”和“通过新增反例”的源色度参数。

## 左入口：先改预算投影，不统一加深

设当前源颜色基线为 `I`、原权重为 `w`、源族减量向量为 `C`、归一化滑杆为 `s`。现有方法为：

```text
d = w C
b = min(1, min_i(0.18 I_i / d_i))
I'_i = I_i − s b d_i
```

一个通道先到预算，就同比缩小整个 RGB 向量。更值得验证的零拟合参数候选为：

```text
v_i = min(w C_i, 0.18 I_i)
I'_i = I_i − s v_i
```

它保留 18% 上限、原 gain、原尾型及滑杆单调性，只允许仍有余量的通道继续完成原减量。使用**当前正式材质**的干净消融结果：

| 固定标区 | 当前正式版本 | 仅改逐通道预算 |
| --- | ---: | ---: |
| 中央缺口 | +14.37 | +14.37 |
| 左入口 | +3.92 | +1.56 |
| 下缘尾部 | +2.72 | +2.72 |

左右已拥有域的 RGB MAE 均未恶化，亮度 MAE 左侧 2.029→1.814、右侧 1.622→1.620。原 11 个保护观察窗、原所有权外变化、alpha、增亮及 18% 违规均为 0，四分档反向变化为 0。四个源颈肤观察域内比参考过深超过 3/255 的像素 **305→368**，超过 5/255 为 **3→8**；颜色方向也会改变，仍需视觉与不同来源控制，不能用亮度误差代替完整颜色验收。

在未通过泛化的源图连通候选上叠加该投影，中央残差可到 −0.07、左入口到 +1.56。该组合只证明两类原因可以分开解释，不是可直接部署的完整修复。

不建议统一增 gain：1.25 倍会使原四个颈肤域过深超过 3/255 的像素从 **305 增至 11570**，中央零权重缺口仍在。把颜色方向全局混向源肤色的拟合也未通过空间留出，不能替代局部归因。

## 下缘：等前两项稳定后再标定

保持当前材质时，仅增加一个尾型参数，左半拟合能使训练 MAE 2.029→1.779，右半留出却由 1.622→1.826，恶化约 12.6%；反向拟合参数也不稳定。该实验不能支持通用加长或加深。

后续应冻结已验证材质与预算，按源下颌局部法向距离归一化，分开比较峰值、10%→90% 过渡与尾部回零；左右空间留出分别报告。先检查“内部衰减太快”与“支撑截断过早”，再决定是否新增一个形状参数；不要同时调 gain、色向、尾长和横向窗去追同一张图。

## 验证与交付边界

本轮验证是实际输出的逐像素复刻、冻结源观察域统计、离线候选、空间留出、阈值敏感性及独立反例。**未执行 SDK/App 单元测试、Xcode 构建、模拟器或真机部署**，也未将候选标为生产资格。

建议实施次序：先补足中央独立所有权证据；逐通道预算可作为独立小改验证；两项固定后重测尾部。每步保留原固定标区、完整 RGB 与亮度残差、过深计数和负例。单张条件参考不能识别共同零点、滑杆中间档或闭源内部算法。
