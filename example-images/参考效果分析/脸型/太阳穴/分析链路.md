# 太阳穴：分析链路

2026-10-16；只测几何。源 IMG_2024（左端），目标 IMG_2023（右端）。坐标、输入配准、接受判据及控制见[本批测量约定](../五项测量约定.md)。以下单位均为截图像素，x 右、y 下。

## 从输入到观察

两张均选太阳穴；没有可读数值，不标成 ±100。共同稳定纹理为同一网格，保留截图原字节。原图只作为对齐内容参照，未当作已证实共同零态；直接可识别的是左端到右端总对应。

| 观测 | 当前证据 | 限制 |
| --- | --- | --- |
| 双侧局部外扩，同时上移 | 主场横分量约 −29～+30，竖分量最低约 −14 | 主场峰值是估计，不能称全域真实极值 |
| 强运动存在独立纹理支持 | r14 左侧对应最低 dx≈−28.5、dy≈−11.3；全部移动点最大模长约 30.6 | 右侧已接受点只覆盖较弱区域，未独立验证 +30 峰 |
| 方向随上下位置变化 | 上段上移相对外扩更强，下段竖分量较快减弱 | 不支持整个局部恒定斜向平移 |
| 核心五官与远区保持 | 眼、鼻、口中心、中央颏尖、上方头发及远背景观察窗逐像素相同 | 仅限这些窗；外眼角或眉尾邻域不可由此整体宣布固定 |

## 交叉检查

源纹理 NCC r14 接受 **152/219**，拒绝 67；其中移动 8、其余 144。主要拒绝为峰不唯一、弱纹理与闭合失败。移动点与主场差 P95 **0.65 px**，其余点 **0.10 px**，不可把背景较好的结果扩展到峰区。

r20 接受 147，移动 6；移动点与主场差 P95 **1.57 px**。两尺度共同移动点仅 6，差 P95 **0.99 px**。主场移动区半尺度差 P95 **3.09 px**，因此峰形边界只给范围，不报小数级确定支持半径。没有接受点触及搜索边界；完整拒绝与异常保留在本地。

只由主场拟合中央共享锚点，再用未参与拟合的 8 个 NCC 移动点检验：外向符号 **8/8**；垂直射线残差 RMS **0.36 px**，每侧固定斜方向为 **1.60 px**。大模板对应为 0.45/1.17 px。这里只支持方向结构，未验证幅度包络。

## 事实 → 候选 → 可推翻点

局部两侧反向横移、都向上且方向随位置变化，优先检验**局部紧支撑包络乘外向射线场**。这同时表达两个分量，比纯水平填充或每侧固定斜平移更符合目前证据。中央和下脸保持，排除了全脸统一横向缩放；强度向外围衰减，也不符合整个太阳穴区域刚性平移。

尚不能确定锚点是否对应产品实际控制点、左右是否对称、包络是否圆/椭圆、平台是否存在及中间档响应。下一项最有区分力的补充是右侧峰区更多可辨纹理、同一状态中性和中间档。若独立点显示系统性切向位移，或不同方位需要不同锚点，该最小射线候选应被否定或收窄，不能继续加任意自由控制点掩盖差异。
