# 下颌角、发际线、下颌线：参考与当前代码差异

> 本页为本轮改造前的差异快照。当前三项已实施并安装真机，见[后三项 SDK 改造记录](后三项SDK改造记录.md)。

日期：2026-10-17。当前分支为 `codex/face-five-displacement-analysis-20261016`，比较包含此前八项未提交修改的工作区源码。本轮仅分析、测量与执行当前代码的本地输出，没有修改 SDK/App，也没有更新真机安装包。

## 结论

三项都有参考与现有模型或作用范围的差异，**不能一并归结为强度系数偏小**。下颌角的方向与支撑错位，发际线存在二维模型差异且本图被源曲线资格拒绝，下颌线则是宽色调场与薄中性增益条带的差异。

| 项目 | 参考模型证据 | 当前照片代码 | 本图实际幅度与作用范围差异 |
| --- | --- | --- | --- |
| 下颌角 | 两侧局部向内、向上，近固定斜方向；上提/内收约左 1.34、右 1.37；中央颏尖、颈部观察窗保持 | `jawSlim` 仍走旧连续轮廓带；局部种子为内收 `0.030S`、上提 `0.008S`，比值仅 0.267，负端响应为正端 0.4 倍，再经保护/限幅 | 参考 r14 已匹配点最大模长 18.4 px；17 个同材质移动点中 15 个在 SDK 两端差 ≤2 px，r20 为 17/18。采样范围明显遗漏；条件剖面还显示局部横向偏强、上提不足，不能统一增幅 |
| 发际线 | 额前头发向下约 34 px、两侧内收约 17～18 px；头顶和核心近稳。共享向内径向候选有留出方向支持 | `HairlineBoundaryRefiner` 是逐列纯 y 采样，限定源发肤边界窄带；存在 hard/soft/coherent 三路资格与细枝保护 | 本图请求保留为 ±0.25，源几何资格通过，但像素源曲线不通过：两端改变像素 **0**，采样场严格恒等。参考中央 10%剖面宽约 268～274 px，不能由当前局部 y 带调幅补齐 |
| 下颌线 | 独立纹理没有 >2 px 移动点；主要为下颌下局部明暗与色调变化，中央和两侧都有宽尾 | 生产 `jawlineShadow` 用编码 RGB 三通道共同乘 `1−0.18fW`，限制在源下颌边缘下 `0.005S…0.045S` 的薄域，再作材质/连通/足迹资格 | 本图源资格通过，实际改 2136 像素、136 列；每列变化像素 P5/P50/P95 为 12/16/18、最大 19。参考在下颌下约 100 px 仍明显变暗。SDK 可局部过深，并非全域单纯欠幅 |

`S` 为当前代码观测脸轮廓横向跨度，不是截图宽度。所有参考 px 均为统一照片网格像素；源图、配准、色域、点选与条件限制见[后三项测量约定](后三项测量约定.md)。

## 幅度与范围的独立核对

### 下颌角

参考两端稳定区字节完全相同，无需再次配准。NCC r14/r20 接受 181/175 个点，其中移动点 17/18；移动点与主场差 P95 为 0.60/2.52 px，未用主场筛点。主场方向拟合在独立 r14 点上的正交残差 P95 为 0.81 px；当前种子方向即使允许逐点任意调幅，残差仍为 10.36 px，支持方向结构差异。

独立建立参考低端→工程原图的同材质对应后，178/174 个三元组通过，包含全部 17/18 个移动点。分别求当前 SDK 两端的输出位置，在这些移动点上的二维向量差 P50/P95 为 r14 **5.20/13.27 px**、r20 **4.07/12.00 px**。这是有条件的同材质比较，没有把参考低端坐标直接当作 SDK 低端坐标。

当前 SDK 地图确实准入，低/高端最大采样偏移为 8.35/20.04 px。这个全局数看似接近参考，不代表目标位置达标：同材质 r14 移动点上 SDK 最大两端向量仅 8.40 px，右侧八个移动点最大约 0.29 px。对后向采样网格反演的残差小于 0.00001 px，仅说明找到的插值分支数值闭合，不能宣布 SDK 场全域唯一可逆。

### 发际线

参考 r14/r20 接受 146/129 个源纹理点，移动点 59/40；与主场差 P95 为 2.07/1.73 px。另有 r14 异常假峰保留，不能把所有接受点都视作真值。强运动点的共享径向方向由 16 点拟合、12 点空间留出，留出正交残差 P95 0.83 px；统一平移的残差 P95 约 19.7 px，因此不是整个头发刚性下移。

当前公开两端及中性输出均逐字节相同，所有采样坐标均为恒等。参考低端→原图独立对应链 r14/r20 通过 145/128 点，其中移动 58/40；对这些同材质移动点，SDK 零向量与参考差 P95 为 **33.70/33.68 px**。

本图失败位于像素源曲线阶段：`sourceCurveFound=0`、coherent `completePath=0`，240 列中 169 列没有合格未保护峰，`missingColorColumns=0`。这不表示规划没有下发，也不等于所有照片都不会生效；即使另一图通过，纯竖直带仍不能表达本次参考的横向内收与宽区域。

### 下颌线

只有右端，原图作为中性源仍属条件假设。参考 ICC 转至 sRGB 后，左/中央/右下颌下区域的编码亮度变化中位为 **−12.93/−11.51/−11.94 /255**，线性光亮度相对变化中位约 **−21.07%/−13.96%/−14.86%**。远背景及衣物约 −1/255 的传输差单独保留，未当作局部效果。

参考中央 R/G/B 的相对变化中位约 −3.64%/−8.44%/−12.75%；即使逐像素拟合最佳共同编码 gain，RGB 向量残差 P50/P95 仍为 8.31/11.97，而保护/控制区域约 0.74～0.90/1.52～1.79。当前三通道共同乘 gain 不足以解释这一局部色调，但不能凭该样本识别闭源色彩公式。

SDK 源资格通过且强度为 0.25；在上述完整区域的亮度变化中位均为 0，因为绝大多数像素没有被编辑。在 SDK 已改的同域像素内，左/中央/右编码差中位为 −5.28/−15.09/−8.63，对应参考为 −16.71/−15.51/−14.86；SDK 全部已改像素最深达 −27.83。同坐标核对还有 468/2136 个 SDK 改色像素比条件参考额外变暗超过 3/255，最大额外变暗约 13.10/255，因此“局部过深”不是比较不同位置的极值。中央局部接近不能掩盖薄带、横向断口与这些过深位置。

源皮肤观察并集里，参考条件差 <−3/255 的 48148 像素中，SDK 改变 1607（3.34%）。这是明确阈值与条件源下的覆盖观察，不是语义 IoU、准确率或对已证实零态的召回率。历史 `BeautyWideJawlineShadowTrial` 未接生产，不能算当前 App 已具有宽域能力。

## 本轮执行范围

参考测量包含稳定区配准留出、全/半尺度场、前后向闭合、源纹理独立对应、零变化/已知平移控制、模型方向或色调反例，以及图表目检。

实际代码核对复用既有 SwiftPM 编译对象，在忽略目录编译一次本地分析辅助，没有改动 SDK/App 或增加测试目标。使用同一张工程中性原图、一次 macOS 生产 Vision 观测，执行下颌角两端、发际线两端和下颌线右端共五个实际公共输出；中性保持原字节，五端点 CPU/实际 Metal 输出逐字节一致。

为读取实际采样坐标，辅助只在当前源码副本添加观察回调。副本、原模块直接执行、公共 CPU 输出全部逐字节相同，再检查同材质坐标求解与实际端点纹理。原始场、点位、执行回执和脚本仅保存在本地忽略资料。这证明该源与该观测下的当前输出，不代替 iOS MediaPipe、其他照片、实时路径或用户真机验收。

本轮未运行全 SDK/宿主测试、模拟器或设备回归，未重开算法实施计划。下颌线仍缺已确认零态，三项中间档响应及更多姿态/遮挡迁移均未由这些截图确认。
