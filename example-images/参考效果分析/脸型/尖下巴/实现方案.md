# 尖下巴：两侧局部内上峰形候选

> 实施更新（2026-10-17）：本方案已接入照片路径；集中参数、参考核对和实际验证见[后五项 SDK 改造记录](../后五项SDK改造记录.md)。以下正文保留 2026-10-16 测量阶段的候选与未知量，“本轮”均指该分析阶段。

本方案对应当前左端到右端的总观察场，参数尚未标定；不描述美图秀秀的内部算法。实测与不确定性见[分析链路](分析链路.md)，坐标和资格见[五项测量约定](../五项测量约定.md)，归一化、保护、完整梯度与采样沿用[实现公共约定](../实现公共约定.md)。本轮未改动或验证 SDK。

## 事实 → 候选 → 可推翻条件

双侧下缘几何变化强于中央，轮廓最下点仍上移约 10 截图像素。主场在双侧峰区的闭合和尺度一致性不足，真实峰高及分量比例未确定。优先检验两个局部向内、向上的峰形：中央水平分量相消、竖向尾部叠加，不添加“尖端固定”的约束。

这是对空间规律的低自由度解释；纯纵向双峰加小水平量仍未排除。若新的可靠对应表明双侧峰区主要为纵向，则应让横向幅度退至零；若中央需独立方向或宽平台，或两峰支撑无法同时满足形状和保护，再修改模型。不能为追随不可靠光流峰而堆控制点。

## 最小几何与前向场

采用公共归一化坐标 `z=(h,v)` 和源几何尺度 L。需要源图可靠的下巴中线、下缘两侧肩部、下唇下方与颈部的静止观察区。初版把峰心放在源图两侧下缘附近；峰心是待拟合的几何参数，不固定为本次截图坐标。

以 h_c 为局部中线，峰心横向间距的一半 δ>0，共享纵坐标 v_b，横纵支撑尺度 r_h、r_v>0。b 为公共 C² 紧支撑函数：

```text
B_L(z) = b((h−h_c+δ)/r_h) b((v−v_b)/r_v)
B_R(z) = b((h−h_c−δ)/r_h) b((v−v_b)/r_v)
m_L = ( a_h, −a_v)
m_R = (−a_h, −a_v)
d₀(z) = B_L(z) m_L + B_R(z) m_R
d(z) = G(z) d₀(z)
D(p) = L R d(z)
F_t(p) = p + t D(p)
```

a_v>0 给出向上分量，a_h≥0 给出两侧向内分量；**所有幅度、峰位、宽度均待拟合**。左右相同幅度、纵坐标和支撑是减少初版自由度的设计假设，并非实测对称性。a_h=0 是必须保留的竞争基线。

为了允许中央竖向尾部叠加，初版要求 r_h>δ 且中央下缘落在纵向支撑内。对 h=h_c，有：

```text
d₀,h = 0
d₀,v = −2 a_v b(δ/r_h) b((v−v_b)/r_v)
```

因此横向相消不意味着尖端固定。δ/r_h 同时影响两峰是否可分辨与中央尾部强度，不能任意选择后宣称复现。对本文所选 b，在未乘保护的固定纵向剖面内，`1/√5 < δ/r_h < 1` 可使中心为两峰和的局部低谷，同时保持非零尾部：该条件由 `b″(s)=−6(1−s²)(1−5s²)` 推得，只是候选函数的形状约束，**不是实测宽度比**。完整场乘 G 后还须重新核对侧强中弱的剖面。严格保护 G 不能在尖端核心强制归零，否则会消掉已观察到的中央上移。

## 标定与仍未知的量

轮廓最下点约 10 像素上移是几何约束，双侧固定 x 边界差约 21～30 像素也只是几何约束；二者不直接等于材质点的 a_v L。先用可靠材质对应拟合可识别的分量，再将候选完整映射后的轮廓与目标边界比较。不能单靠边界解出切向位移，也不能将光流异常水平极值作为 a_h 的标定值。

本轮未测 L，没有实测无量纲系数；端点总差不能除以二作为单端幅度。中央额外可靠纹理仅有 1 点，与约 10 像素级上移相容，约束范围有限；双侧峰部仍需可追踪纹理输入，才能标定 a_h/a_v、峰高和宽度。只有新增独立残差支持稳定左右差异，才解除共享幅度或支撑的设计假设。

中性拆分、真实滑杆响应、尺度迁移、非正脸和不同表情均未知。两端截图只用来标定当前对应场；以后若定义中性滑杆，应按公共约定对同一中性源点生成端点映射，再转到观察场的源网格比较。

## 完整梯度、保护与失败处理

内部方向向量 m_L、m_R 为常量，故：

```text
∇z d₀ = m_L (∇B_L)ᵀ + m_R (∇B_R)ᵀ
∇z d = d₀ (∇G)ᵀ + G ∇z d₀
```

每个 B 的导数都包含 h/v 两个基函数与 1/r_h、1/r_v 的链式项；两峰交叠和保护过渡的完整导数必须共同计入。按公共约定认证全域梯度界及完整 Jacobian，核验唯一逆映射与实际逆残差，并从同一原始输入采样一次。峰内局部收缩安全不能代表整个叠加场安全。

眼鼻、上侧口部核心、较远颈部与背景先独立指定保护观察区。参考支撑在口部边缘和下缘过渡可能有小幅随动，严格保护的具体范围需与可靠对应共同核对；不能把所有语义区域整块固定。支撑太窄导致梯度过大时，只能在证据允许的范围内调整过渡或降低整项幅度；降低后的外观不等于通过参考验收。

眼轴、L、下缘或遮挡关系退化，支撑无法可靠定位，保护与所需场冲突，安全认证或逆解失败时，拒绝整项并返回原图。不能用逐像素恒等回退制造拼接边界。

## 必要独立验收

必须分别检验左右峰区、中央尖端、上侧渐入、下方释放与保护核心。中央需要允许约 10 像素级上移；两侧形状改变应强于中央，但峰值分量须由新增独立纹理约束，不能用不可靠光流极值设验收门槛。

同样的数据分别检验 a_h=0 与 a_h>0，使用未参与拟合的材质对应和完整变形后的边界形状比较。若两者现有证据下无法区分，应保留不确定性，不把更复杂模型称为已确认。移动点数量、拒绝原因与跨尺度差异单列，不能用大批静止点给峰区背书。

合成双峰、零变化及保护窗口只核对符号、连续性、导数和逆解；真实输入的留出对应与实际输出才检验候选效果。本轮只交付方案与验证方法，不创建 SDK 执行计划。
