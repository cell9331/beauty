# 尖下巴：本地资料说明

[证据目录](证据/)保存对齐端点、带符号位移场、横纵剖面和独立轮廓核对图。[共享本地测量资料](../本地测量/)保存本批截图裁区、稳定区配准、双向与半尺度场、独立纹理对应、局部轮廓、脚本及数值汇总。原始参考输入保留在既有输入目录。

主独立检查和额外 21×21 下巴局部检查分别保存，二者点数和误差分位数不合并。主检查移动点少，额外检查也未覆盖双侧最大变化处；原始拒绝记录和跨尺度不一致应保留，不能只留下与光流相符的对应。

轮廓资料保存两端独立提取的下缘和三种平滑尺度复测，约束边界几何与最下点变化。轮廓位置差不自动等于同材质前向向量；中央弱纹理对应不足和双侧峰区闭合失败仍是当前限制。

持久 Markdown 仅保留允许的汇总、候选公式与适用范围。原像素、实际对应点、采样位置、蒙版、逐像素场和包含运行路径的脚本只在 Git 忽略的本地资料中保存。重跑前按当前环境适配脚本，并重新核验[五项测量约定](../五项测量约定.md)中的输入、端点、配准和控制。

本轮完成参考分析，未完成候选参考标定或 SDK/照片效果验收。文件与低方法间差异不构成双侧峰区精度证明。
