# 下巴长短：渐入、平台与下侧释放候选

> 实施更新（2026-10-17）：本方案已接入照片路径；集中参数、参考核对和实际验证见[后五项 SDK 改造记录](../后五项SDK改造记录.md)。以下正文保留 2026-10-16 测量阶段的候选与未知量，“本轮”均指该分析阶段。

本方案只为本轮左端到右端的总对应提供可审阅候选。直接证据及限制见[分析链路](分析链路.md)；数学、失败处理和采样沿用[实现公共约定](../实现公共约定.md)，测量资格见[五项测量约定](../五项测量约定.md)。参数尚未标定，本轮未改动或验证 SDK。

## 事实 → 候选 → 可推翻条件

下缘中央有独立纹理支持约 38～39 截图像素上移，轮廓近似恒定竖移；上侧运动较弱，下方颈部随动后释放。最小候选是以纵向位移为主的局部平台场，上侧通过渐变产生纵向压缩，下侧通过释放连接静止区域。弱横向收敛作为可关闭的附加项，只在独立对应支持时保留。

若可靠对应证明下缘核心持续线性变化而无平台，或需要明显水平主运动，此候选应被推翻。不能把“轮廓近似平移”升级为下巴整块材质刚性，也不能将口部和颈部全部硬保护后称为复现。

## 最小几何与前向场

使用公共归一化坐标 `z=(h,v)`、尺度 L 和固定局部轴 R；c、L 的定义见公共约定。需可靠源图的下巴中心、下缘、下唇下方过渡与可随动颈部边界。这里只定义几何关系，不保存实际点位，也不把本张图的像素位置设为通用常量。

以 h_c 为下巴局部中心横坐标，r_h>0 为横向支撑尺度。使用公共 C² 基函数 b 和过渡 S，定义有平台的纵窗：

```text
a < b_v ≤ c_v < d
T(v) = S((v−a)/(b_v−a)) · [1−S((v−c_v)/(d−c_v))]
H(h) = b((h−h_c)/r_h)
W(h,v) = H(h) T(v)
m(h,v) = (−k(h−h_c), −A)
d₀(z) = W(z) m(z)
d(z) = G(z) d₀(z)
D(p) = L R d(z)
F_t(p) = p + t D(p)
```

A>0 给出当前端点方向的向上运动；k≥0 为弱横向收敛候选，k=0 是最小纵向基线。A、k、支撑与过渡参数全部待拟合。`b_v≤v≤c_v` 为纵向平台；平台外的渐入和释放分别拟合，不要求上下对称。t 仅为公共约定中的候选场设计插值，不代表产品真实中间档，也不自动允许负向外推。

在未受保护和横向包络明显影响的中央，上侧 T′>0 使 `∂d_v/∂v=−A T′<0`，对应端点间局部纵向压缩；下侧 T′<0 时逐渐释放。平台在 v 方向近恒定，但横向 H、收敛项与保护 G 仍可造成二维空间变化。

## 幅度与作用范围标定

约 39 像素是当前下缘核心的端点观察量，不能直接除以二；本轮未测 L，不能写成固定无量纲 A。先测源图几何与 L，再将可靠同材质前向对应转入局部轴，用拟合集标定 A、横向支撑和上下过渡；留出另一组对应及轮廓作检验。

独立轮廓约束候选输出的边界形状与最下点变化；它的固定 x 几何差不直接作为 d_v 拟合真值。下缘恒定竖移 RMSE 约 1.65 只说明简单核心值得优先检验，不是候选验收容差。现有单个较下方颈部对应也不足以标定整段释放。

k 初始可设为零作为对照，再检查可靠双侧对应是否残留稳定的内收方向；存在可重复的水平残差时才拟合 k。若左右残差差异稳定，应先核对源几何、遮挡与对应质量，再决定是否解除设计性对称，而不是立即增加局部峰。

共同中性状态、左右端强度拆分和真实响应曲线未知。未来若面向中性照片提供控制，需要同一编辑状态的中性及中间档输入，按公共约定在同一源点比较端点映射。

## 完整梯度、保护与失败处理

本项内部 m 随 h 变化，故除窗导数外还必须计入：

```text
∇z d₀ = m (∇W)ᵀ + W · diag(−k, 0)
∇W = (H′ T, H T′)
∇z d = d₀ (∇G)ᵀ + G ∇z d₀
```

T′ 包含两个过渡的完整乘积求导，H′ 包含 1/r_h；不能只检查平台内的导数。之后按公共约定认证完整 Jacobian、全域梯度上界、全局单射及逆残差，从同一原始输入采样一次。

眼、鼻、远侧背景和图像边界应先独立指定保护核心。口部下缘与颈部有参考随动，不能按语义标签整块固定；严格保护范围与参考所需场冲突时，应报告候选不合格。几何退化、遮挡使支撑无法定位、安全界失败或逆解失败时拒绝整项并返回原图，不逐像素拼接回退。

## 必要独立验收

分别检验上侧渐入、下缘核心、下方释放、双侧水平残差和保护窗口。核心需有可靠纹理对应支持幅度及平台范围；轮廓需保持约 39 像素级上移的方向与边界形状。不得以静止背景占多数的总误差取代移动区结果。

用零变化和合成局部平台场核对符号、完整导数、逆映射与单次采样；这些仅核对候选数学。真实效果须检查未参与拟合的同材质对应及实际输出，与测量交叉方法的不一致分别报告。本轮到此方案和验证方法为止，不创建 SDK 执行计划。
