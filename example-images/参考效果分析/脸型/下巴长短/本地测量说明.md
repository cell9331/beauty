# 下巴长短：本地资料说明

[证据目录](证据/)保存本轮对齐端点、带符号位移场、横纵剖面和独立轮廓核对图。[共享本地测量资料](../本地测量/)保存本批截图裁区、配准、双向与半尺度场、独立纹理对应、局部轮廓、测量脚本及数值汇总；原始参考输入保留在既有输入目录。

本项包含两类独立对应：共享源纹理分区检查，以及额外的 21×21 下巴局部格网检查。两者采样范围和接受条件不同，不能合并点数或分位数。轮廓检查单独保存三种平滑尺度的提取结果，约束轮廓几何变化，不等同于同材质前向位移。

持久 Markdown 仅保留允许的汇总、候选公式和适用范围。原像素、实际对应点、采样位置、蒙版、逐像素场及带运行路径的脚本只在 Git 忽略的本地资料中保存，不进入版本化文本。

重跑时需按当前输入和环境适配脚本，并重新核验[五项测量约定](../五项测量约定.md)中的端点资格、配准和控制。文件存在及跨方法吻合只证明当前参考分析的部分依据；候选尚未参考标定，未通过 SDK 或实际照片效果验收。
