## 共同执行与边界

八项参考场在源图眼距坐标内相加，各组件独立保护。保护只约束自己的场；眼鼻口使用核心与平滑过渡，太阳穴/颧骨另保护中央下巴。下巴长短允许下唇外围和颈部过渡参与，邻近头发也可随局部几何移动。

使用 C² 紧支撑与五次平台函数，完整导数包含窗口、仿射项和所有保护乘积。后五项参与时，将完整支撑盒分为固定区间，使用一维函数及导数的解析极值包住每块的完整梯度，再取全域最大上界；不是用采样 Jacobian 充当证明。安全预算仍小于一，必要时统一减幅。仅首批三项参与时保留原有认证数值路径。

对每个目标像素实际迭代求逆，检查前向残差，再从不可变输入采样一次。组合求逆失败则返回该几何阶段原输入；精确恒等区域保留原字节。拒绝新模型时，不恢复这五项旧连续场或旧拉点；其他合格脸型功能保留。

五项要求新鲜、可靠的观测脸缘、成对眼、外唇和鼻部，不借脸框猜测缺失支撑。源图还须有完整窗口边距，pose 合格，采样输入全不透明。当前窗口属于基于观测几何的工程定位，未增加太阳穴、颧骨或真实颈部边界检测器。

实施只覆盖静态照片及其预览使用的共同阶段。实时 `pixelBuffer` 仍使用旧点采样，尚未迁移到新场；共享规划器的新观测准入也会影响实时请求，本次未验证该输入种类。其他部位仍按既有阶段执行；八项之间的一次采样保证不扩展为全 SDK 所有功能的一次采样。

## 幅度与作用范围核对

以原图作为工程中性源构造左右端点，再按同一源点进行 `low.inverse → high` 比较。参考产品的共同零态与中间档响应未被证实；不能把端点差简单除二当成单端实测。

本次已使用真实源图眼距校准窗口与工程幅度，并分开检查移动、过渡及静止观察区。独立纹理对应来自不同测量方法，但其汇总已用于迭代观察，因此不称最终盲测。尖下巴峰区证据较弱，保留纯纵向双峰的竞争解释；V脸只有右端与原图的条件比较。

本图实际眼距约 291.08 px。最终五项均无需额外减幅，认证梯度上界依次为 0.388、0.200、0.219、0.351、0.380，均低于 0.80 预算。初版过度限幅已消除；下巴长短端点总上提从初版约 58 px 收回到约 40 px；尖下巴窗口下移，减小上侧颌部牵动。

以下误差为同源端点的二维位移残差，单位是统一截图网格像素。r14/r20 表示两个独立纹理模板半径；括号内为该分组接受点数。移动点和其他点使用原测量的预先分组，不把大量静止背景混进移动误差。

| 功能 | r14 移动 P95（n） | r20 移动 P95（n） | r14 其他点 P95 / 最大值（n） |
| --- | ---: | ---: | ---: |
| 太阳穴 | 1.86（8） | 1.56（6） | 0.19 / 0.91（144） |
| 颧骨 | 3.74（19） | 4.05（19） | 0.14 / 0.72（144） |
| 下巴长短 | 5.93（7） | 4.11（5） | 0.17 / 8.03（153） |
| 尖下巴 | 8.98（2） | 2.26（1） | 0.07 / 0.22（159） |
| V脸 | 7.91（4） | 8.11（3） | 1.06 / 9.59（156） |

尖下巴与 V脸的移动点数很少，P95 接近少数点的最大误差，不能当成稳定的泛化精度。独立方法的原始接受/拒绝依据见[五项测量约定](五项测量约定.md)；上述结果来自已接受对应，没有按候选误差再次筛点。

额外细核保留了与大模板统计不同的证据：

- 下巴长短：43 个细核移动对应 P95 为 8.64 px；另 1 个其他点残差为 8.39 px。实际映射后的轮廓最下点上移 40.52 px，参考为 38.65 px；57 个轮廓几何点纵向残差 P95 为 9.75 px。左下颈部部分区域偏强，双侧肩部及下方中央部分区域偏弱；统一降幅虽改善尖端，却使这些范围与整段轮廓残差更差，因此保留当前幅度。肩部已有双侧细核纹理对应支持约 3–6 px 弱水平内收，但较大模板的双侧复核不足，下方释放段又有不收拢的对应；统一水平系数及其随高度释放仍未确定。当前保留水平系数为零，明确留下这部分横向残差。
- 尖下巴：6 个细核移动对应 P95 为 3.42 px；66 个其他点 P95 为 3.28 px、最大 7.90 px。轮廓最下点上移 11.47 px，参考为 10.51 px；57 点轮廓几何残差 P95 为 6.30 px。大模板中仍有一个下颈部对应与当前下缘范围不一致，没有将其排除后宣称达标。
- V脸：源图颏尖前向上移 2.26 px，条件参考估计为 2.22 px；双侧峰区接近参考，但右外侧有对应预测上移约 10.59 px、参考约 2.60 px。当前较宽窗口为保留中央弱尾部的折衷，不能称外围完全复现。

轮廓数据描述实际变形后边界的几何差异，不冒充同材质点的前向位移。五项全部查询的最大逆残差小于 0.0001 px；这是求逆数值精度，不能抵消上表的参考模型误差。
