## 交叉检查与误差

| 方法 | 接受 / 候选 | 移动 / 其余接受点 | 移动点与主场差 P95 | 其余点与主场差 P95 |
| --- | ---: | ---: | ---: | ---: |
| NCC r14 | 181 / 269 | 17 / 164 | 0.60 px | 0.16 px |
| NCC r20 | 175 / 269 | 18 / 157 | 2.52 px | 0.24 px |

NCC 仅由源纹理及预先空间格选点，搜索 ±128 px 起，触边扩大；没有用主场初始化或一致性筛选。r14 拒绝 88 个，主要原因弱纹理 49、正向峰不唯一 39、反向峰不唯一 38、闭合失败 12，原因可重叠；r20 拒绝 94 个，主要为反向峰不唯一 51、正向峰不唯一 48、弱纹理 44、闭合失败 22。没有接受点贴最终搜索边界。

两模板共同接受 169 点，其中共同移动 15 点，两模板位移差 P95 为 1.54 px，最大差 3.16 px。主场移动估计区前后向闭合 P95 为 0.57 px；全/半尺度差 P95 为 **4.49 px**。因此全场局部尖峰及精确支持边界不作为确定测量。

源图固定竖窄带的全/半尺度估计：进入 10–90% 约 **87–108 px**，退出 90–10% 约 **84–126 px**；强区峰位漂移至多 **28 px**。归一到工程眼线至颏尖距离，峰约处于 0.59–0.65；这个比例只是本样本取线的统计，不是新输入默认常数。大致作用区和候选峰形可辨，精确峰/边界待更多强区纹理或中间档核实。

零变化和已知 (+37,−23) 平移控制各 34 候选；r14 接受 24、控制误差 P95 0.11 px，r20 接受 23、P95 0.05 px。控制核对符号和本方法能力，不外推为真实局部变形精度。

## 事实 → 候选 → 可推翻点

两侧近固定斜方向、幅度局部达峰、中央和远区保持，优先解释为**两侧局部包络乘上内斜向量**。只由主场拟合每侧方向，再用不参与拟合的 NCC 移动点检验，正交残差 RMS/P95 为 r14 **0.41/0.81 px**、r20 **0.70/1.33 px**。作为对照，当前种子方向即使允许逐点任意调幅，残差 RMS/P95 仍为 r14 **5.16/10.36 px**、r20 **4.38/7.81 px**。这支持“当前方向偏浅”的差异判断。

本候选只约束方向与局部性，没有识别闭源网格、衰减函数、共同锚点、左右对称性或端点中性拆分。全脸统一缩放不符合核心及颏尖保持；纯水平内收不符合可靠上移。单一共享径向锚点目前没有比固定斜方向更直接的证据，不沿用其他功能的机制结论。若强区新增纹理出现系统性方向旋转，或中间档出现不同支撑/非线性响应，应推翻或收窄当前候选。

本轮未拟合替代 SDK 参数，没有 SDK 实施计划、全项目测试或设备回归。

## 当前 SDK 实际端点核对

使用同内容、已一次配准的工程原图，冻结一次 macOS 生产 Vision 观测，分别运行公共 SDK 下颌角滑杆 0/1。工程中性 PNG 与该输入逐字节相同；两个端点的 CPU/Metal RGBA 逐字节一致。分析副本只在当前真实 sampler 通过全部保护、来源足迹及 admission 后记录源采样坐标，输出同时与原模块 map、公共 SDK RGBA 逐字节一致。没有修改生产代码。

为比较同一材质，在参考低端已接受点上独立搜索其工程原图对应，再对同一个原图点分别反演 SDK 低/高端采样网格，计算 `F_high(p)−F_low(p)`。r14 的 181 个参考接受点中 178 个也通过低端→原图 NCC，全部 17 个移动点保留；r20 为 174/175，全部 18 个移动点保留。所有这些查询均收敛，最大采样网格逆解残差小于 0.00001 px。这个残差只说明找到了插值 backmap 的数值解分支，不证明源码具有全域唯一逆；原图对应也不证明共同零态。

| 同材质分组 | 比较点数 | 向量差 P50 / P95 | 参考移动但 SDK ≤2 px |
| --- | ---: | ---: | ---: |
| r14 移动 | 17 | **5.20 / 13.27 px** | **15 / 17** |
| r14 其余 | 161 | 0.03 / 1.24 px | 不适用 |
| r20 移动 | 18 | **4.07 / 12.00 px** | **17 / 18** |
| r20 其余 | 156 | 0.02 / 0.75 px | 不适用 |

r14 参考移动点的模长 P95/最大值为 17.20/18.41 px，同一组的 SDK 为 4.14/8.40 px；右侧 8 个移动点 SDK 最大仅 0.29 px。该结果说明多数可辨移动纹理没有落入当前有效范围，不能据此说 SDK 全域强度都偏小。[实际对照图](证据/当前SDK对照.png)显示 SDK 自己的强区横向反而偏强，竖向则明显不足。

对采样反演分支另用实际 SDK 低→高图的独立 NCC 核对：r14 接受 173/178，原参考移动点接受 15/17，采样预测与这些移动点的图像 NCC 差 P95/最大为 0.20/0.35 px；r20 接受 171/174，移动 18/18，差 P95 0.52 px，保留 **2.43 px** 最大不一致。大模板可能混合相邻动/静区域，不能据此把该点删去；这一局部差异也不缩小为采样逆解的数值残差。

相同低端显示网格上的窄带条件比较中，SDK 强峰水平内收约 22 px、上移约 6 px；参考全尺度同带约内收 12–14、上移 17–18 px，半尺度上移峰更高且有漂移。SDK 进入 10–90% 约 59/96 px，退出约 **29/33 px**；参考进入约 87–108、退出约 **84–126 px**。SDK 峰比全尺度参考偏下约 11–22 px；不能把两低端不同状态的这组显示剖面冒充精确同材质点比较。

保护观察方面，眼、鼻、内唇、颈部窗口两者都逐像素保持；参考唇角旁窗口有对应支持的移动，SDK 两侧窗口均 100% 不变。参考颏尖窗口 100% 同字节，SDK 仅 70.3% 同字节，SDK 该低端网格区域端点位移模 P95 约 1.09 px；这是额外的小幅范围尾部，不与双侧主峰混称。

当前 SDK map 报告低/高端最大采样偏移约 8.35/20.04 px，梯度约 0.404/0.45，二者都已正常 admission。未出现“未生效所以误以为模型不匹配”的情况。所有输出都是当前模型的分析基线，没有调幅、替换函数或视觉验收。
