# 下颌角：本地测量说明

本轮本地批次位于脸型目录下 `本地测量/后三项-20261017/jaw_angle/`，仅供所有者在本机复核，受忽略规则保护。原图、截图原像素、实际点位、轮廓、蒙版、逐像素场、脚本和运行日志不进入持久 Markdown；文档只保留聚合数与相对链接。

资料包含：测量前声明、全局相似配准及留出残差、主/反/半尺度场、源纹理 NCC r14/r20 的逐点资格与拒绝理由、零变化和平移控制、两模板/主场差异、方向辨别及窄带剖面。SDK 实际端点对照使用同一工程中性图和一次生产观测，不能用不同网格的场直接相减。

复核顺序：

1. 先核对 `IMG_2032` 左端与 `IMG_2033` 右端，及本批输入指纹；截图共同裁切不再重采样。
2. 检查稳定区留出和同字节资格，再看两个分量、FB 拒绝与半尺度漂移。
3. 查看独立 NCC 的候选/接受/移动点数、拒绝原因和边界扩搜，不按主场一致性删点。
4. 区分“沿方向最佳拟合的残差”“独立方法差异”与“当前 SDK 实际位移误差”，不把它们都称为真值误差。
5. 复看[证据图](证据/位移证据.png)与[横向剖面](证据/横向剖面.png)，确认缩略图尺度没有改变像素单位。

实际 SDK 分析另保留：同材质三元组、原样 sampler 观察所得 backmap、逐点数值反演及残差、SDK 图像 NCC 复查、同网格条件范围/剖面。r14/r20 同材质候选 178/174，全部查询通过残差门槛；这不证明全域一一映射。图像 NCC 大模板的 2.43 px 不一致点完整保留。包含照片的[当前 SDK 对照图](证据/当前SDK对照.png)同样属于本地忽略资产，不随 Markdown 单独分发。

实际验证仅覆盖本项本地测量、输入、对应、方向、当前单项公共 SDK CPU/Metal 输出及文档；没有修改或回归全 SDK，没有运行模拟器/真机验收，也没有把候选包络拟合成新实现。
