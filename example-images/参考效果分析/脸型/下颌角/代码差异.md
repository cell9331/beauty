# 下颌角：当前代码差异

> 改造前历史快照；当前模型、幅度与范围见[实施说明](实施说明.md)。

2026-10-17 的 worktree 源码快照。只统计参考与当前照片路径的模型、幅度和作用范围；未修改生产代码。源码指纹由本批本地基线记录保存。

## 当前路径与模型

宿主 [BeautyFaceShapeSlider.swift](../../../../BeautySDK/Sources/BeautyCore/Models/BeautyFaceShapeSlider.swift#L30) 把下颌角位置映射为 `jawSlim=(2p−1)×0.45`，`p=0.5` 为工程中性；resolver 使用 signed cap 0.45。端点 ±0.45 与参考左/右端方向一致，但 0.5 中性及中间档线性仅是工程约定。

[BeautyStillImageGeometryStage.swift](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyStillImageGeometryStage.swift#L100) 先清除新八项由新模型接管的键，再让 `jawSlim` 进入旧 `BeautyContinuousFaceMap`。不能用前五项的新 C²/精确逆模型描述本项。

设 `S` 为观测轮廓横向跨度，`C` 为眼线至颏尖距离，`y=v/C`，`l=min(1,|h|/(0.30S))`，`b(y)=(1−((y−0.72)/0.35)²)²`（支持内，支持外为零），`j=jawSlim/0.45`。当前[种子公式](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousFaceMap.swift#L286)为：

```text
d_seed = S × (−side×0.030, −0.008) × j × b(y) × l × response(j)
response(j) = 0.4 (j<0), 1 (j>=0)
```

种子不是最终前向场：它在最近 Hermite 轮廓点求值，乘内/外距离带、五官与附件保护，再由 [boundedField](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousFaceMap.swift#L414) 投影到梯度 0.45、位移 0.06S 的约束，仍有姿态和最终公共限幅。最终[采样](../../../../BeautySDK/Sources/BeautyEffects/Render/BeautyContinuousFaceMap.swift#L549)是双线性格点偏移后 `source=q−d(q)`，没有对声明的源前向场做残差受控的真正逆解。

## 备用点路径也不等同

[FaceShapeWarpProvider.swift](../../../../BeautySDK/Sources/BeautyEffects/Warp/FaceShapeWarpProvider.swift#L351) 的下颌角只生成两侧 `lowerFacePoints`，水平位移是 `bounds.width×0.07×strength/cap`，竖直为零，半径为 `bounds.width×0.24`。负值须有 continuous observed support 才能反转 planning points；否则空发射后被清零。这条路径不能当作真实照片默认模型，也不能说明实时像素缓冲路径已具备参考的上移。

参考共同零态、单端拆分、连续档位响应仍未确认。上述差异不等于已完成替代模型或视觉验收。

## 实际输出资格

本次公共 SDK 与 CPU/Metal 对照均使用一次冻结的 macOS 生产 Vision 观测。仅记录实际 sampler 来源坐标的分析副本与原 map、公共输出均逐字节一致；工程中性输入同字节，map 也确已 admission。参考点通过独立低端→原图 NCC 后，比较同一个原图材质点的 SDK 端点总向量。r14 比较 17 移动点有 15 点 SDK 位移 ≤2 px；r20 为 17/18，P95 向量差 12.00 px，支持范围遗漏结论。

逆解是对记录采样网格的插值反演；通过残差不证明 guard 边缘或全域唯一逆。另做实际 SDK 端点图 NCC，主模板移动点与采样预测差 P95 0.20 px；大模板 P95 0.52 px，保留单点 2.43 px 不一致。完整资格、计数和实际对照见[分析链路](分析链路.md)。
