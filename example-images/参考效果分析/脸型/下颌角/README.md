# 下颌角：参考与当前代码差异

> 最新状态：本项已按本轮证据改造并安装真机，见[实施说明](实施说明.md)。以下保留改造前取证与代码比较，不能视作当前实现。

本轮分析日期：2026-10-17。比较 **IMG_2032 左端 → IMG_2033 右端**；只做取证与差异统计，没有修改 SDK 或宿主。

参考呈现双侧下脸的**向内、向上局部推拉**。可靠纹理的上移约为内收的 1.3 倍，中央颏尖、颈部和核心五官保持。当前照片路径的下颌角仍采用轮廓带场，种子方向的上移/内收仅 0.267；这个方向差不能靠统一缩放强度消除。

| 维度 | 参考证据 | 当前代码 | 差异资格 |
| --- | --- | --- | --- |
| 模型方向 | 两侧近似固定的上内斜方向；r14 独立移动点 17 个 | 轮廓最近点决定包络；每侧固定浅斜方向，上移/内收 0.267 | 明确方向差；参考斜方向候选仍非闭源机制识别 |
| 幅度 | r14 可靠点最大模长 18.4 px；该点内收 10.8、上移 14.9 px | 同材质移动点最大仅 8.4 px，然而当前强区窄带水平分量又高于参考、垂直分量偏小 | r14 移动点向量差 P95 **13.27 px**；不能概括为全域统一偏小 |
| 峰与过渡 | 两尺度竖剖面峰位有 28 px 漂移；进入 10–90% 约 87–108 px，退出约 84–126 px | 实际输出相同显示窄带退出约 29–33 px，峰较参考偏下 | 当前下降更陡；这是低端网格条件剖面对照 |
| 范围与保护 | 侧邻头发有对应支持；眼、鼻、内唇、颏尖、颈部观察窗逐像素相同 | r14 参考 17 个移动点中 15 个在 SDK 内位移 ≤2 px；唇角旁观察窗全部静止，颏尖窗又有少量额外改变 | **明确范围差异**；整块外唇保护和窄外带未覆盖参考分布 |
| 端点响应 | 只有左右两个端点，未确认共同零态和中间档 | 宿主左右端映射 ±0.45；代码负端响应为正端的 0.4 | 0.4 不可由这两个端点验证，也不能把参考总差除二 |

单位为共同裁切照片网格的截图像素，x 向右、y 向下。原图只作为工程中性输入，未证实为参考共同零态。

实际输出取现有公共 SDK 的单项左右端点，冻结同一次 macOS 生产 Vision 观测；CPU/Metal 与添加采样观察器的分析副本逐字节一致。r20 复查的 18 个移动点差 P95 为 **12.00 px**，其中 17 点 SDK 位移 ≤2 px。源码、实际采样坐标和图像对应的资格均在链路中分别列明，未用全场背景稀释移动差异。
