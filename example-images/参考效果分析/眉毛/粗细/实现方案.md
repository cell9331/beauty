# 眉毛粗细：以眉脊为锚的纵向扩张

归档说明：本篇迁移既有候选方案，测量来自 2026-10-15，方案编写于 2026-10-16。本次归档未新增测量或实施。证据与推理见[分析链路](分析链路.md)。


本文仅依据参考截图位移测量提出实现方案，尚未实现或验证。
不参考现有 SDK 实现，只解释几何；公共约定见 [README](../README.md)。

## 1. 测量事实与实现假设

从较细端到较粗端，眉脊上方纹理向上、下方纹理向下，形成纵向扩张。
本图上、下侧代表纹理的端点差各约 **5–9 px**。
这些值是局部位移，不是整眉厚度的统一增量，也不能直接换算成统一缩放倍率。
当前汇总未给出每个纹理点到眉脊的距离，亦未给出两个端点相对原图的完整幅度。

可证伪假设：眉脊近似固定，周围纹理的垂直位移随离眉脊距离增加。
上、下侧允许不同扩张强度，但在眉脊附近平滑连接。
先检验最简单的核心线性扩张，只有独立残差要求时才增加非线性参数。
若同侧位移与距眉脊距离无关、接近整片平移，则该假设应被拒绝。

## 2. 所需几何输入

- 源图方向与面部正交轴，眉头 `H`、眉尾 `T` 和投影眉长 `L`。
- 眉脊曲线 `c(r)` 以及对应的上、下核心高度。
- 眉头/眉尾衰减范围、周围可变形皮肤带、眼睛保护域。
- 眉脊上下两侧的独立纹理匹配和置信度，且需覆盖多个离脊距离。

不以颜色阈值定义粗细变化；毛发纹理只用于几何测量。
缺少可靠眉脊时不能用任意水平线代替，需明确失败或保持该眉原样。

## 3. 前向场与参数方向

公共坐标 `d=(p-H)·e_y-c(r)` 向下为正，眉脊为 `d=0`。
`m(t,d)` 为核心 1、外围平滑归零的支持与保护包络。
令 `q(t)` 为可选的沿眉身强度调制，初始设为 1；端点衰减交由 `m` 承担。
正参数 `u` 增粗，负参数变细，`u=0` 恒等。

```text
k_i(u) = b_i_plus · u      , u >= 0
       = b_i_minus · u     , u < 0         (i = upper, lower)
w(d)   = S((d + epsilon) / (2 · epsilon))
k(d,u) = (1 - w(d)) · k_upper(u) + w(d) · k_lower(u)
D(p,u) = q(t) · m(t,d) · k(d,u) · d · e_y
F_u(p) = p + D(p,u)
```

四个 `b_i_plus/b_i_minus` 均非负，表示两方向、上下两侧各自的强度。
`epsilon>0` 为眉脊附近混合宽度，`S` 是公共钳制三次 smoothstep。
因此 `d=0` 始终无位移，上下扩张不在脊线上形成导数断裂。
当 `k_upper=k_lower=k` 且核心 `m=q=1` 时，`d_out=(1+k)·d`。
这是候选机制的含义，不是声称参考产品采用统一倍率。
当前测量支持以 `e_y` 为作用方向，不预设沿弯曲眉脊法线扩张。

## 4. 幅度如何从 5–9 px 标定

在同一源点上，两端的核心位移差近似为：

```text
Delta D_y(p) = [k(d,+1) - k(d,-1)] · d
```

先在临时参考输入中估计 `d`，再回归上下两侧的位移差与距离关系。
不能把 5–9 px 除以未测量的“典型眉高”，输出一个看似确定的比例。
只有端点匹配时，即使在线性核心，也不能直接辨识原图归一化的强度之和。
同一侧、远离上下混合带且 `m=q=1` 时，以原图距离 `d` 表示两个端点：

```text
d_low  = (1 - b_minus) · d
d_high = (1 + b_plus) · d
lambda = d_high / d_low = (1 + b_plus) / (1 - b_minus)
```

端点线性对应能约束的是相对比例 `lambda`；必须有共同原图的眉脊和点对应，
才能确定 `b_plus+b_minus` 及正负端拆分。不能把 `lambda-1` 当作这个强度和。
上下 `k` 混合带或非恒定支撑内不再适用上述单一比例，须从同源点生成两端映射，
以逆投影求得低端位置后拟合公共端点差场，不能从两端位移直接指定 `b` 的和。
选择对称 `b_plus=b_minus` 只是额外的待验证设计；在线性核心可据此初始化
`b=(lambda-1)/(lambda+1)`，不能写成实测的中性→端点幅度。

核心线性模型拟合步骤：先令上下强度相同，再比较独立检查点残差。
只有上下残差系统不同，才启用 `k_upper/k_lower` 分离。
只有沿眉身仍有系统残差，才让 `q(t)` 成为低自由度平滑曲线。
不得为追每个噪声点增加局部控制点，掩盖错误机制。
扩张系数无量纲；上下核心高度、`epsilon` 和支撑宽度随 `L` 缩放。

## 5. 支持区、保护与无折叠

核心必须覆盖实际毛发上下沿，外围再接回静止皮肤。
不能只移动深色毛发像素，否则会在原毛发位置留下重复轮廓。
变细与增粗都从源图直接映射，不对上一张输出继续缩放。
眉下支撑在眼睛保护域前平滑归零，禁止靠移动眼睑换取粗细幅度。
眉尾支撑随源眉形收窄，避免厚度变化把细眉尾吹成块状。

令 `v=q·m·k·d` 为垂直标量场，则：

```text
det(J_F) = 1 + grad(v) · e_y
```

核心中变细要求比例保持正；但只检查 `1+k>0` 远远不够。
外围 `m` 的导数及上下混合 `k` 的导数同样可能造成局部压缩。
应对完整场检查正 Jacobian 下界、梯度和逆解残差，再确定可用极值。
若保护间隙不足，限幅或拒绝该眉，不越过保护域扩大可变形区。

## 6. 实现伪代码

```text
1. 校验输入几何，拟合源眉脊、上下核心和眼睛保护域。
2. 构造紧支撑 m 与眉脊混合宽度 epsilon，初始化 q(t)=1。
3. 从已标定的上下强度计算 k(d,u)，生成前向垂直扩张场 D。
4. 检查脊线固定、支持边界、保护域、梯度及 Jacobian；异常则限幅或退出。
5. 对每个目标像素求 F_u(p)=q 的逆解，并检查残差与有效采样域。
6. 原图单次采样；u=0 使用恒等路径，保持画布与元数据约定。
7. 汇总上下位移、厚度变化、拟合残差和保护结果，不保存逐点资料。
```

## 7. 拟合与像素/几何验证

拟合目标先用置信度加权纹理点误差，并用独立点检查离脊距离关系。
位移小或低纹理点不能用于稳定除法估计 `k`，应在回归中处理。
脊线本身有误差时，要报告锚点不确定性，不能让位移场弥补错误脊线。

- 正例：上侧向上、下侧向下，代表纹理的两端差符合 5–9 px 的测量范围。
- 锚定：眉脊位移接近零，粗细变化不会变成眉毛整体上下移动。
- 形状：横向尺寸保持，眉尾仍连续，上下扩张无硬接缝或双轮廓。
- 保护：眼睛和支持区外实际像素与原图比较；上侧运动不能被误判为整体提眉。
- 负例：平坦纹理、遮挡、脊线退化、保护间隙不足时安全退出或原样。
- 数值：正负极值、零值、重复与逆映射残差；整个支持区没有折叠。
- 图像契约：单次重采样后的尺寸、extent、方向/镜像、alpha 与采样边界符合公共规则。

尚需拟合：原图到正负端的幅度分配、上下非对称强度、`epsilon`、核心边界、
外围支撑以及是否需要 `q(t)`；当前没有确定的统一增粗倍率。
本文不表示新算法已接入或上述验收已运行。
