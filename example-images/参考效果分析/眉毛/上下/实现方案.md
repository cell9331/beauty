# 眉毛上下：沿眉形的平台位移

归档说明：本篇迁移既有候选方案，测量来自 2026-10-15，方案编写于 2026-10-16。本次归档未新增测量或实施。证据与推理见[分析链路](分析链路.md)。


本文是依据参考截图位移测量提出的实现方案，尚未实现或验证。
不依赖当前 SDK 代码；只处理几何位移，不拟合颜色。
公共坐标、包络、逆映射和证据边界见 [README](../README.md)。

## 1. 测量事实与实现假设

同一肖像的滑杆低端→高端，眉体主体向上移动约 **15.7 px**。
分别相对对齐原图测量，低端向下约 **7.8 px**，高端向上约 **7.9 px**。
这些像素属于本轮截图照片坐标，不能直接用于任意分辨率。
横向位移很小，两眉主体的垂直位移接近等量平台。
上侧 10%→90% 过渡约 **50–60 px**；下侧 90%→10% 约 **10–13 px**。
上述范围来自光流估计，不是完整支持区宽度，也不是精确边界定位。
横剖面有两个平台，眉间收窄；选定眼睛窗口在两个端点之间保持原样。

可证伪假设：每眉内部作近似恒定垂直平移，外围用沿眉形的非对称包络连接原图。
额头侧过渡宽，眼睛侧过渡窄；内部不以多个圆形点力叠出平台。
若独立纹理匹配显示平台内有持续缩放或弯曲，此平移假设需要扩展。
眼睛端点之间相同不能单独证明它们分别与原图相同，仍须单独核验。

## 2. 所需几何输入

- 校正方向后的源图、面部轴 `e_x`、`e_y`，以及左右眉身份。
- 每眉的眉头 `H`、眉尾 `T`、投影长度 `L` 和眉脊曲线 `c(r)`。
- 沿眉形的上、下核心边界，眉头与眉尾的水平过渡宽度。
- 上眼睑/眼睛保护域及其到眉下缘的可用间隙。
- 可用于拟合的纹理匹配置信度；低纹理位置不伪造精确边界。

只要求几何抽象，不预定检测器、模型或 landmark 编号。
几何退化、两眉混淆或保护间隙不足时，返回明确失败或该眉原样。

## 3. 前向场与参数方向

沿用公共源坐标 `t=r/L`、`d=(p-H)·e_y-c(r)`，`d>0` 为眉脊下方。
令 `m(t,d)` 为公共 `C1` 紧支撑包络，眉体核心为 1，眼睛保护域为 0。
定义 `u∈[-1,1]`，正值使眉毛上移，`u=0` 精确保持原图。

```text
a(u) = A_up · u       , u >= 0
     = A_down · u     , u < 0
D(p,u) = -a(u) · m(t,d) · e_y
F_u(p) = p + D(p,u)
```

`A_up`、`A_down` 均为非负长度；核心中没有水平分量或位置相关缩放。
每眉分别构造包络；眉间重叠采用公共有界组合规则，不能叠成双倍幅度。
两眉幅度可先共享一个归一化系数，不能因此强制抹掉源图的不对称。

## 4. 用测量标定幅度与边界

在本参考图尺度，初始目标取 `A_up≈7.9 px`、`A_down≈7.8 px`。
这两个半幅来自分别对原图的测量，不是把 15.7 随意除以二。
推广尺寸时，用参考与新输入的眉长比例缩放长度量：

```text
A_up(input)   = alpha_up · L_input
A_down(input) = alpha_down · L_input
alpha_up     = 7.9 / L_reference
alpha_down   = 7.8 / L_reference
```

`L_reference` 须在临时测量中求得；当前汇总未给出，不能编造归一化数值。
随后保存拟合后的无量纲系数及残差汇总，不保存实际点位。
视角明显不同、眉长投影不稳定时，缩放规则需另行验证。

对于完整的单段三次 `smoothstep`，10%→90% 跨度约为全过渡宽度的 `0.6084`。
因此若采用该特定曲线，50–60 px 对应全上侧宽度约 **82–99 px**；
10–13 px 对应全下侧宽度约 **16–21 px**，仅作为初始化。
不能把测得的 10%–90% 跨度直接当 `smoothstep` 的完整支持半径。
这只是曲线宽度换算；端点差场须回到共同源坐标后再确定实际源图包络。
保护包络相乘会改变剖面，最终须在合成后的场上重新拟合过渡宽度。

## 5. 支持区、保护与无折叠

眉头内侧支撑应快速收窄，让眉间低位移带由测量决定。
外侧支撑允许超过眉尾，以平滑接回原图；不能在毛发边缘硬截断。
眉下侧窄过渡必须留出足够空间，不能直接裁成保护域上的阶跃。
上移和下移共用几何包络是初始假设，残差不支持时分别拟合。

本单轴场的 Jacobian 行列式为：

```text
det(J_F) = 1 - a(u) · (grad(m) · e_y)
```

须检查全支持区而非只检查眉体；下移时窄下侧过渡尤其可能压缩。
要求 `det(J_F)` 大于预先确定的正阈值，并约束最大位移梯度。
阈值属于安全设计参数，不能冒充参考产品测量；不满足时扩大可用过渡或限幅。
扩大过渡若侵入眼睛保护域，不能牺牲保护来满足数值条件。

## 6. 实现伪代码

```text
1. 校正输入方向，校验每眉几何、原图域和眼睛保护间隙。
2. 在源图坐标拟合眉脊与上下核心，构造非对称紧支撑包络 m。
3. 从归一化系数和 L 得到 A_up/A_down，按 u 生成前向场 D。
4. 检查保护区、支持边界、位移梯度与 Jacobian；失败则限幅或明确退出。
5. 为目标像素 q 求解 F_u(p)=q，检查逆解残差及源图采样范围。
6. 从原图单次采样生成结果；u=0 直接使用原图恒等路径。
7. 只记录参数版本、汇总残差与验证计数，不持久化逐点场或图像。
```

直接取 `p=q-D(q,u)` 只是一次近似，不能作为精确逆映射。

## 7. 拟合与验证

先用独立纹理点拟合 `A_up/A_down`，再拟合包络，避免用边界补偿幅度错误。
目标函数包含置信度加权位移残差、平台内方差和剖面宽度残差。
拟合点与检查点分开；弱纹理区的光流只作辅助，不能独立决定支持边界。
端点比较须从同一源点生成 `F_low/F_high`，再将差值放到低端坐标。
不能直接相减分别定义在两张输出坐标中的光流值。

- 正例：两眉核心位移方向正确，端点差接近 15.7 px，原图半幅分别符合测量。
- 形状：平台内眉头、眉中、眉尾相对距离基本保持；横向残差无系统偏移。
- 剖面：上缓下陡、眉间收窄同时成立，容差由独立测量噪声预先确定。
- 保护：实际输出中的眼睛及支持区外窗口与各自原图比较，不能只比端点。
- 负例：`u=0` 恒等、无眉/遮挡/退化几何安全退出，极值不折叠、不越界。
- 像素与元数据：纹理单次重采样无双影，尺寸、extent、方向、alpha 按公共规则验证。

尚需拟合：归一化幅度、核心上下界、水平支撑、保护过渡、正负端是否共用包络。
当前只完成技术推导，未据此生成新输出、跑像素验收或提升任何效果状态。
