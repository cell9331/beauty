# 眉毛·上下：分析链路

本篇整理 2026-10-15 的历史测量及 2026-10-16 的既有推导。本次仅迁移证据和资料，没有重新运行测量、拟合候选输出或提升效果资格。

## 1. 输入、方向与问题

输入为同一肖像原图及滑杆左端 `IMG_2037`、右端 `IMG_2038`。可审阅的对齐原图和端点已包含于[证据图](证据/位移证据.png)，完整对齐输入保留在本功能的本地测量目录。
这组输入用于回答左端→右端的二维位移规律；除上下外，不把端点差等分为已经测得的单端幅度。

统一照片网格、前向场正方向、稳定区与保护区见[眉毛公共约定](../README.md)。原始场 `dx` 向右、`dy` 向下为正；本功能主证据展示垂直分量，图上向上为正。两个分量同时见[七项总览](../证据/位移总览.png)。

## 2. 历史测量步骤

1. 排除界面覆盖，仅在眉区外的头发、侧部和下半脸稳定纹理拟合全局相似变换，并用空间留出点与分区拟合交叉核对。原图只重采样一次；截图间漂移小于 0.001 px，保持同网格。
2. 左端→右端计算 DIS 前向二维场，并计算反向闭合、Farnebäck 方法差异与半尺度复测；后者换算回统一截图像素。弱纹理的光流填充值属于估计。
3. 在源图纹理上按空间格选角点，独立进行 NCC 模板匹配。历史搜索裕量为每轴 ±48 px，接受时检查匹配分数、多解和反向闭合，不按“符合稠密场”筛点。
4. 以原尺度与半尺度曲线、邻近独立对应和功能所需的局部纹理/刚性核对约束空间规律，再提出低自由度候选机制。图中纵剖面采用 7 px 窄带中位数，横剖面采用 5 px 窄带中位数；橙点来自邻近位置，并非每个剖面坐标都有实际对应。

原图留出配准残差 P95 约 0.684 px 是历史稳定区统计，不能外推为所有眉区点的真实位移精度。零变化控制得到 P99 0 px；已知局部上移 8 px 控制的纹理区误差 P95 约 0.062 px，亦不能代替本功能精度。

## 4. 从观测到候选机制

同一肖像的滑杆低端→高端，眉体主体向上移动约 **15.7 px**。
分别相对对齐原图测量，低端向下约 **7.8 px**，高端向上约 **7.9 px**。
这些像素属于本轮截图照片坐标，不能直接用于任意分辨率。
横向位移很小，两眉主体的垂直位移接近等量平台。
上侧 10%→90% 过渡约 **50–60 px**；下侧 90%→10% 约 **10–13 px**。
上述范围来自光流估计，不是完整支持区宽度，也不是精确边界定位。
横剖面有两个平台，眉间收窄；选定眼睛窗口在两个端点之间保持原样。

可证伪假设：每眉内部作近似恒定垂直平移，外围用沿眉形的非对称包络连接原图。
额头侧过渡宽，眼睛侧过渡窄；内部不以多个圆形点力叠出平台。
若独立纹理匹配显示平台内有持续缩放或弯曲，此平移假设需要扩展。
眼睛端点之间相同不能单独证明它们分别与原图相同，仍须单独核验。


## 5. 未知量与下一项辨别测量

参考眉长的统一测量值、归一化幅度、准确核心上下界、横向支撑、保护过渡及正负端是否共用包络。眼睛端点间不变，还需分别对原图核对。

中间滑杆档位、跨眉形/姿态和组合顺序没有由本组端点图确定。具体候选场、完整 Jacobian、保护、逆映射与单次采样要求见[实现方案](实现方案.md)及[公共约定](../README.md)。本次没有实施这些候选设计。
