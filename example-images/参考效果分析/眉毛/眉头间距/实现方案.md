# 眉头间距：内侧局部水平形变，眉尾固定

归档说明：本篇迁移既有候选方案，测量来自 2026-10-15，方案编写于 2026-10-16。本次归档未新增测量或实施。证据与推理见[分析链路](分析链路.md)。


本篇仅根据参考截图的位移测量提出实现方案，未参考现有 SDK 实现。
坐标、形变方向、支撑域与逆映射遵循[公共约定](../README.md)。
本文只设计几何变形，不设计亮度、颜色或眉毛重绘。

## 1. 测量告诉了什么

- 两个滑杆端点之间，单侧眉头向外移动约 **29–33 px**。
- 运动集中在内侧眉头，经过眉中段衰减，眉尾接近零位移。
- 独立 SIFT 核对的眉尾纹理点，画面左侧 **38 点**、右侧 **36 点**均为零位移。
- 上述数字属于同一肖像的端点总差，没有独立确认相对中性状态的对称性。

像素量统一属于公共约定的 **1170 × 1749 px** 照片网格，不能混用原始截图坐标。

因此，这一控制应当采用眉头局部支撑，并在到达眉尾之前变为严格零。
它与[整眉间距](../间距/实现方案.md)的区别首先是作用域与剖面，不能只换强度。
“内侧平台接平滑衰减”是便于拟合的候选模型，不是已识别出参考产品内部公式。

## 2. 输入几何与符号

每侧需要源图眉头 `H`、眉尾 `T`、眉脊曲线 `c(r)` 和眼部保护区域。
使用公共约定的 `L`、`t`、`d`、`e_out`；`t=0` 为眉头，`t=1` 为眉尾。
眉毛内部使用 `m(t,d)=1` 的支撑平台，周边皮肤以 C1 过渡回到恒等。
眉尾固定域必须覆盖被参考验证为不动的外段，而非仅固定尾尖一个点。
支撑参数由本次眉形决定，不将截图中的绝对坐标固化到通用输入。

新增拟合量：

| 参数 | 含义 | 约束 |
| --- | --- | --- |
| `h0` | 内侧满幅平台终点 | `0 ≤ h0 < h1` |
| `h1` | 完全停止水平运动的位置 | `h1 < 1`，留出眉尾固定域 |
| `A+`、`A−` | 中性到向外、向内端点的幅度 | 非负、按眉长归一化 |
| `m` 的边界宽度 | 眉区向皮肤的过渡 | C1 连续、眼部保护核为 0 |

`h0`、`h1` 需由剖面拟合；不能先指定“内侧三分之一”再把测量往上套。

## 3. 位移场

令 `S` 为公共约定的夹紧 smoothstep，定义：

```text
g_head(t) = 1                                      当 t ≤ h0
            1 − S((t − h0)/(h1 − h0))              当 h0 < t < h1
            0                                      当 t ≥ h1
f(p) = g_head(t(p)) m(t(p), d(p))
a(u) = A+ u                 当 u ≥ 0
       A− u                 当 u < 0
D(p;u) = a(u) f(p) e_out
F(p;u) = p + D(p;u)
```

`u>0` 表示眉头分开，`u<0` 表示眉头靠拢；左右侧用 `e_out` 自动取得相反方向。
`t≥h1` 时，`D` 严格为 0，无须依赖接近零的数值尾巴保护眉尾。
眉头之前的皮肤由公共支撑 `m` 归零，`g_head=1` 不意味着无限向鼻梁延伸。
纵向支撑随眉形展开，眼部保护归零必须带平滑过渡，不能硬切掩码。

初版只设面部水平分量，垂直残差单独核对。
若内侧不是平台，可用保端点与固定尾段的单调样条替换 `g_head`。
仍然保留由独立证据支持的严格零外侧区，不以整眉间距较宽的参与范围替代。

## 4. 幅度与尺度标定

参考尺度下，眉头平台的端点总差 `ΔA=A+ + A−` 约为 **29–33 px**。
按公共约定，将低端场映回同一原图点后比较端点差，不能直接逐点相减不同网格。
先联合拟合 `ΔA`、`h0` 与 `h1`，同时覆盖眉头大位移、中段衰减和眉尾零位移。
只把眉头幅度拟合正确，却拖动眉尾，仍不符合这一参考控制。
幅度保存成 `k=ΔA/L_ref`，新输入以 `ΔA_new=k L_new` 作为尺度迁移起点。
`h0`、`h1` 为归一化眉长参数，可按可用空间及保护条件调整并重新验收。

两个端点不足以独立确定 `A+`、`A−`。
对称拆分只能作为明确标注的初版假设；中性参考齐全后应分别拟合。
单个人脸截图不能证明不同眉长、眉间距、姿态与遮挡下仍有相同参数。

## 5. 支撑、保护与无折叠

- 固定外侧眉段；在目标保护窗口中验证纹理实际不动，不能只检查尾尖参数。
- 眉间是左右相反运动的会合处，必须遵守公共归属规则并检查鼻梁不被牵扯。
- 眼睑与眼球保护核为恒等，保护过渡需兼顾强度和可用距离。
- 若固定尾段、眼部保护与目标眉头幅度不能同时满足无折叠，则限制或拒绝强度。

令 `f=g_head m`，检查：

```text
det(J_F) = 1 + a(u) [e_out · ∇f(p)] > ε_J > 0
```

衰减段越短，负斜率越大；眉头向外时会压缩眉头与固定外段之间的纹理。
因此不能在看到眉尾被拖动后，一味把 `h1−h0` 压窄。
应结合参考允许的作用范围、梯度裕量与眼部空间选择参数。
连续场无折叠检查之外，还要验证逆映射残差与保护区域的实际像素对应。
同时遵守公共梯度预算 `||∇D||_2≤kappa<1`，超预算不能假定固定点逆解仍收敛。

## 6. 实现顺序

```text
1. 获取当前眉头、眉尾与眉脊，建立 t、d，确定眼部保护核和眉尾固定域。
2. 用参考内侧/中段/外侧纹理拟合 ΔA、h0、h1，而非只对齐最大位移。
3. 按本次眉长缩放幅度；将未测中性拆分明确标记为假设。
4. 在源空间求 D=a·g_head·m·e_out；t≥h1 的整个外段保持 D=0。
5. 核对左右相反方向、眉间过渡、眼部恒等、梯度与 Jacobian 正裕量。
6. 求 F 的逆并从原图单次采样，逆求解不收敛时返回明确失败。
7. 独立匹配复核眉头运动与眉尾不动，保存聚合误差和失败原因。
```

`p=q−D(q)` 只能作为逆求解初值，不能作为精确逆映射使用。

## 7. 怎样验收这一个调整

沿眉脊比较端点到端点的 `D·e_out`：内侧最大、中段衰减、外段为零。
独立匹配眉头、中段和外段纹理，同时报告位移误差和固定区偏差。
眉尾固定检验要复用独立纹理或固定像素窗口，不能用候选 `g_head=0` 自证。
弱纹理的过渡范围记录为估计，不用插值网格数量代替独立匹配数量。

实际输出正例检查眉头向外/向内正确、内侧纹理连续、眉尾形状与位置不变。
负例检查 `u=0` 原样、支撑外不动、鼻梁及眼部保护核不动、镜像方向正确。
极值重点检查衰减段压扁、眉间重影、固定域边缘折痕与逆解残差。
重复性、尺寸、方向、alpha 与色彩元数据遵循公共验收；不将颜色差当作位移证据。
本篇是候选方案，尚未产生该候选场的实际输出通过结论。
