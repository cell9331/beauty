# 眉毛·眉头间距：本地测量资料说明

下列资料保存在本功能的 `本地测量/` 中，供所有者本地核对，受总目录 Git 忽略规则保护。它们来自历史运行；本次归档未执行这些脚本或重算结果。

| 子路径 | 内容与用途 |
| --- | --- |
| `aligned/` | 已对齐原图、本功能两张端点截图及原图有效域；对应主证据中的原图与端点 |
| `fields/head_spacing.npz` | 端点前向场、闭合/方法差异、纹理有效标记、稀疏对应和半尺度场 |
| `fields/head_spacing_low.npz`、`fields/head_spacing_high.npz` | 历史原图到左右端点的场；其存在不等于全部通过共同中性标定 |
| `fields/head_spacing_ncc_independent.npz` | 独立 NCC 对应、置信度、闭合及与稠密场的差异 |
| `registration.json` | 公共配准记录和稳定区留出汇总 |
| `summary.json`、`measurements.json` | 本功能既有聚合测量记录 |
| `independent-template-summary.json` | 本功能 NCC 接受数、拒绝原因和分组差异 |
| `mechanism-summary.json` | 本功能历史纹理、分区及刚性检查，含实际对应，仅限本地 |
| `controls.json` | 历史零变化与已知局部运动控制结果 |
| `历史脚本/` | 历史配准、测场、NCC、汇总、机制检查和绘图脚本原件，供流程审计 |
| `归档校验.json` | 本次复制的图像、场与脚本 SHA-256，便于确认材料完整性 |

历史脚本沿用原运行的路径与输入布局，含七项共享参数；归档没有改写为可直接在新目录运行的工具。需要复测时，应先按当前输入与共享坐标规则改为明确的本次配置，再检验路径、搜索裕量和输出位置。不要把旧脚本重新运行成功视为候选实现通过。

公开链路只使用[分析链路](分析链路.md)中的聚合量。实际点位、逐像素场、蒙版、图像及脚本里的私有路径不复制到 Markdown。
