# 眉毛倾斜：眉区内部有限旋转，周边连续过渡

归档说明：本篇迁移既有候选方案，测量来自 2026-10-15，方案编写于 2026-10-16。本次归档未新增测量或实施。证据与推理见[分析链路](分析链路.md)。


本篇仅根据参考截图的位移测量提出实现方案，未参考现有 SDK 实现。
坐标、形变方向、支撑域与逆映射遵循[公共约定](../README.md)。
本文只设计几何变形，不设计亮度、颜色或眉毛重绘。

## 1. 测量告诉了什么

- 眉头与眉尾反向升降，同时存在水平位移分量。
- 两个端点之间，每眉约旋转 **9°**，左右方向相反，眉内纹理接近刚性运动。
- 独立 SIFT 拟合：画面左眉 **113 点、−9.153°**，右眉 **104 点、+9.130°**。
- 上述拟合的残差中位数分别为 **0.315 px**、**0.349 px**。
- 旋转中心接近眉中外侧是待进一步拟合的线索，尚不是已确定通用位置。

这支持“眉区内部有限旋转”的首个模型，不能只用两端反向竖直推拉代替。
拟合误差小支持该截图的近刚性解释，不等于已识别出参考产品的内部算法。
测得角度是端点总差，不能直接当成中性到任一端点的角度。
拟合像素和残差统一属于公共约定的 **1170 × 1749 px** 照片网格。

## 2. 输入几何与符号

每侧需要源图眉头 `H`、眉尾 `T`、眉脊曲线、眼部保护区域和旋转中心 `C`。
在公共面部正交基 `(e_x,e_y)` 中，`e_y` 向下。
有限旋转矩阵定义为：

```text
R(θ) = [ cosθ  −sinθ ]
       [ sinθ   cosθ ]
```

在该坐标系内，正角度表现为画面顺时针旋转。
以 `σ=sigma` 表示公共侧别：画面左眉 `σ=−1`，右眉 `σ=+1`，取 `θ_side(u)=σ θ(u)`。
本文规定 `u>0` 为眉头上抬、眉尾下沉；左右侧应分别得到负、正角度。
姿态与镜像转换必须在坐标统一后完成，不能按人的解剖左/右直接套图像符号。

支撑 `m(p)` 在眉内完整纹理区为 1，向外围皮肤 C1 归零。
旋转中心属于源图几何参数，不跟随滑杆重新漂移。

## 3. 位移场

令 `x(p)=((p−C)·e_x, (p−C)·e_y)`，定义：

```text
θ(u) = Θ+ u                 当 u ≥ 0
       Θ− u                 当 u < 0
δ_local = [R(σ θ(u)) − I] x(p)
D(p;u) = m(p) [δ_local.x e_x + δ_local.y e_y]
F(p;u) = p + D(p;u)
```

在 `m=1` 的内部，`F` 是绕 `C` 的完整有限旋转，保留眉内长度和厚度。
在 `0<m<1` 的外圈，旋转逐步退为恒等，允许周围皮肤连续跟随。
在 `m=0` 的保护核和支撑域外，源点保持原位。
必须同时保留 `δ_local.x` 与 `δ_local.y`；小角度竖直近似不是完整实现。

不要逐点用不同 pivot 旋转同一条眉毛，也不要让 `m` 在眉内快速起伏。
否则会把应当近似刚性的眉体变成局部弯曲或拉伸。

## 4. 旋转中心、角度与尺度标定

先在眉内独立匹配点上稳健拟合 `p_b = R_delta p_a + t_delta`。
在统一坐标中，由 `C=(I−R_delta)⁻¹ t_delta` 得到端点间刚性模型的中心估计。
拟合时同时检查残差的空间分布；单个中位数不能排除一端系统性偏差。
角度较小时中心估计会变得不稳定，应报告中心置信范围并拒绝无依据的远处 pivot。

将 `C` 转成相对眉头/眉尾和眉长的无量纲位置，供新输入建立候选中心。
不能固定到截图的某个像素，也不能把“眉中外侧”直接硬编码成某个比例。
角度本身无须随图片尺寸缩放，中心位置、支撑宽度与过渡距离需要随几何缩放。

两端总角度满足 `Θ+ + Θ− ≈ 9°`，左右分别使用对应拟合值作参考。
比较端点场时遵守公共网格对应关系，不能把不同端点坐标上的分量直接相减。
当前没有独立中性角度，`Θ+=Θ−` 只是可选初版假设，不能称实测 ±4.5°。
有中性与中间档后，再分别拟合两个方向的响应曲线与可能的非线性。

## 5. 支撑、保护与无折叠

- 支撑平台应覆盖整条眉毛及其内部纹理，外围旋转过渡要避开眼睑保护核。
- 按旋转后的扫掠范围检查画布、相邻眉和保护区，不能只看源眉包围盒。
- 内部刚性旋转的行列式为 1；混合外圈可能压缩甚至折叠，仍须完整检查。
- 若纹理平台、眼部保护与目标角度之间没有足够过渡空间，应限制角度或返回失败。

记 `δ(p)=(R−I)(p−C)`，则：

```text
J_F = I + m(p)(R−I) + δ(p) ⊗ ∇m(p)
```

旋转矩阵与向量在同一面部基中计算，梯度转换回同一二维坐标再检查。
对平台、过渡和保护边缘检查 `det(J_F)>ε_J>0`、梯度预算与逆解残差。
公共充分条件为 `||∇D||_2≤kappa<1`；超预算时不能假定固定点逆解仍收敛。
不要由内部旋转安全推断外圈安全，也不要只检查稀疏眉点的位移。

## 6. 实现顺序

```text
1. 对齐参考的眉外稳定区域，在眉内匹配点上拟合有限刚性变换与残差。
2. 估计 pivot 及不确定性，转为眉几何归一化位置；不固定截图绝对坐标。
3. 为当前源图建立 C 与完整眉内平台 m，外围加入保护和紧支撑过渡。
4. 由滑杆得 θ_side，计算完整 (R−I)(p−C) 的水平、垂直两个分量。
5. 检查平台刚性、保护核、扫掠范围、过渡 Jacobian 与方向符号。
6. 对 F 求逆，验证求解残差后从原图单次采样；失败时限制或拒绝该强度。
7. 以独立纹理刚性拟合、分量剖面及保护像素复核输出。
```

只有平台内部可以直接使用精确旋转逆；整个混合场仍需解 `F⁻¹`。
`p=q−D(q)` 不是该混合场的精确逆。

## 7. 怎样验收这一个调整

先比较端点相对旋转的符号、角度与拟合残差，保留水平和垂直两个分量。
沿眉脊抽取两个分量，眉头/眉尾应呈相反升降，不能只检查总变化像素数。
独立纹理点的成对距离与局部厚度在眉内应近似保留，偏差受重采样容差约束。
旋转中心拟合要有稳定性核对；中心变化大而角度稳定时，应保留中心未知结论。

实际输出正例检查两侧方向正确、眉内不弯折、眉头眉尾随同一旋转运动。
负例检查 `u=0` 原样、眼部及支撑外不动、镜像与整体面部旋转后的符号一致。
极值检查外圈折痕、眼睑牵扯、边界采样与逆解残差，并核对确定性与输出元数据。
本篇没有实际渲染该候选场，测量对近刚性的支持不能冒充候选实现已经通过。
