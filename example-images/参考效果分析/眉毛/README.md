## 1. 测量依据与可辨识范围

输入为同一肖像的一张原图和七组、十四张滑杆端点截图。截图照片裁切后的统一网格为
**1170 × 1749 px**。下表均为滑杆左端到右端的总差，长度单位属于这一个网格。

| 调整 | 测得的主要位移 |
| --- | --- |
| 上下 | 两眉主体上移约 15.7 px；相对原图分别下移约 7.8 px、上移约 7.9 px |
| 粗细 | 上下侧纹理反向移动，代表量级各约 5–9 px |
| 长短 | 中外段水平位移约 15–18 px，眉头基本固定 |
| 间距 | 单侧眉头向外约 23–27 px，沿眉身向外逐步减弱 |
| 眉头间距 | 单侧眉头向外约 29–33 px，眉尾保持接近零 |
| 倾斜 | 每眉约 9° 的反向旋转；眉内纹理近似刚性 |
| 眉峰 | 眉中外段局部上抬约 14–16 px，向两端减弱 |

配准只使用眉区外的稳定纹理。原图到截图的独立留出配准残差 P95 约 0.684 px，
截图之间稳定区的全局漂移小于 0.001 px。稠密场经过两种光流方法及尺度复测；
独立局部匹配在七项合计接受 341 个移动纹理点，每项移动点的方法间差异 P95
为 0.46–1.05 px。这是测量方法之间的差异，不能当作真值精度或候选实现的达标阈值。

这些观测约束位移方向、空间分布和端点跨度，没有确定对方的内部公式。
除上下外，中性到两个端点的幅度分配仍需独立标定；中间档响应、跨眉形和组合效果亦未测定。
文中的函数形状、几何输入和安全规则是据此提出的设计，须用实际输出验证。
仅上下测得的上下过渡宽度不能直接套到其余六项。

## 2. 源坐标和沿眉形的二维坐标

在完成方向与镜像校正的源图上，建立面部正交轴 `e_x`、`e_y`：
`e_x` 指向画面右，`e_y` 指向画面下。整体面部旋转由这组轴表达，计算完位移后再投回图像坐标。
画面左眉取 `sigma=-1`，画面右眉取 `sigma=+1`，定义 `e_out=sigma·e_x`，始终朝眉尾外侧。
计算中的像素中心使用整数索引 `(i,j)`，左上首个中心为 `(0,0)`。
转换到以纹理边界为 0/1 的归一化采样坐标时，使用 `((i+0.5)/W,(j+0.5)/H)`，
不能把中心与边界坐标混用；输入 extent 有偏移时，先显式换到局部坐标，输出时保留该偏移。

每侧需要眉头 `H`、眉尾 `T`、平滑眉脊及上下核心包络；不预定检测器或点位编号。
这些几何可以由可靠图像测量或人工标注提供。先用可靠几何检验变形模型，再单独检验自动几何的误差。

```text
L = (T-H) · e_out > 0
r = (p-H) · e_out
t = r / L                         # 眉头为 0，眉尾为 1
d = (p-H) · e_y - c(r)             # 相对眉脊，向下为正
```

`p` 是源点，`c(r)` 是眉脊在该坐标中的垂直位置。`L` 为投影眉长，不是曲线弧长。
上、下核心厚度记为正函数 `h_u(r)`、`h_d(r)`；核心满足 `-h_u ≤ d ≤ h_d`。
有限外围支撑需要眉脊延拓时，延拓须保持一阶连续，不能在眉头/尾端简单夹紧后留下斜率断点。
眉脊不能稳定表示为此坐标中的单值曲线、眉长退化或左右归属不清时，不套用该模型。

## 3. 平台、紧支撑和保护包络

位移作用区包含眉毛与邻近皮肤，是连续变形的支撑域，不是毛发的二值分割。
取夹紧的三次过渡函数：

```text
z = clamp(z, 0, 1)
S(z) = z*z*(3-2*z)
```

一个可直接计算的平台包络为：

```text
m_vertical = S((d+h_u+R_u)/R_u) * [1-S((d-h_d)/R_d)]
m_ends     = S((r+R_H)/R_H) * [1-S((r-L)/R_T)]
m_support  = m_vertical * m_ends
```

`R_u,R_d,R_H,R_T` 均为正长度，分别控制上、下、眉头外、眉尾外的过渡距离。
核心中包络为 1，外围在有限距离归零，外边界的一阶导数也为零。
宽度和核心曲线本身须平滑；不同调整可采用独立拟合的包络，不能只共享一个固定半径。

再引入平滑保护因子 `P(p)`：眼睛保护核内为 0，离开保护核经过正宽度过渡才到 1。
每眉最终 `m=m_support·P·w_owner`；`w_owner` 负责两眉外围支撑的归属。
两眉核心应互不重叠且各自保持满幅；外围可用平滑分区，使权重和不超过 1，防止眉间双倍叠加。
无法同时保留两个核心、保护核和连续过渡时，应拒绝该几何或限制幅度，不能强行归一化核心。
保护、归属处理后须重新检查整个场的剖面和梯度。

眼睛保护范围由独立几何和源图检查确定，不能从候选场的零位移区倒推。
保护核上的源映射恒等，还必须与全局一一映射和实际输出保护检查一起成立。

## 4. 强度、尺度与端点拟合

每项设计 `u∈[-1,1]`，`u=0` 使用精确恒等路径。位移长度以眉长归一化，角度和扩张比例无量纲。
例如 `A=alpha·L`，其中 `alpha` 必须先由参考眉长及实测位移标定。
当前汇总未测定参考眉长的统一定义数值，因此不编造 `alpha`；投影长度的测量定义须始终一致。

把滑杆正负两端设成对称，是一种可验证的初版设计，不是端点差天然证明的事实。
上下已经分别对原图测量，可用对应的两个半幅初始化；其他调整应拟合原图到各端的对应关系。
相同参数在不同形态上的尺度迁移是下一项验证对象，不能把本图像素常数写成全局参数。

所有公式定义前向映射 `F_u(p)=p+D(p,u)`。对于同一原图点 `p`：

```text
p_low  = F_-1(p)
p_high = F_+1(p)
V_pair(p_low) = p_high - p_low
```

测得的端点差场以低端图像为源坐标，因此应比较 `V_pair(F_-1(p))` 与 `F_+1(p)-F_-1(p)`。
不能把定义在原图、低端和高端三个网格上的值直接逐点相减。
单项中的 `A+ + A-` 等关系只在同一源点、相同空间权重的模型内成立；仍须按此坐标规则比较。

## 5. 连续性、无折叠和逆映射

完整映射的 Jacobian 为 `J_F=I+∇D`。必须检查平台、上下过渡、眉头/尾过渡和保护边缘，
不能只检查若干眉点，也不能只检查内部刚性或缩放系数。
设计的默认充分条件为整个支撑上 `||∇D||_2 ≤ kappa < 1`，并保留正的行列式和逆解残差裕量。
`kappa`、最小行列式、迭代残差与位移预算是待确定的数值设计参数，不是参考测量结果。
仅有 `det(J_F)>0` 不足以独立证明全局没有重叠。
连续场的全域导数预算应由解析界或保守数值上界保证；稀疏取样的最大梯度只是检查结果，
不能充当全域上界。若采用网格，则另检查完整覆盖、所有变形三角的方向和全局无重叠。

当导数预算成立且场在外围连续归零时，可从目标像素 `q` 迭代求源坐标：

```text
p_0 = q
p_(k+1) = q - D(p_k,u)
accept only if ||p_k + D(p_k,u) - q|| <= epsilon_inverse
```

该固定点法的收敛依赖上述梯度条件。预算不成立时不能继续假定它收敛；应限幅、调整允许的过渡，
或为另一种逆解与全局有效性证明建立独立验证。也可以用带源坐标的有效网格表达映射并作逆向查询。
直接使用一次 `p=q-D(q,u)` 只是近似，不能当精确逆。

采样目标区域需包含源支撑及其完整运动扫掠范围。画布、边界和越界处理须显式定义。
从未修改的原图按最终逆映射采样一次；不以上一帧编辑结果作为新的纹理源，
也不在位移边缘混合两份未对齐图像来掩盖接缝。零参数直接保留原图，避免无意义的重采样。
尺寸、extent、方向、镜像及 alpha 仍按输入输出契约核验。

## 6. 从测量到最小实现

先给可靠几何，用每篇定义的低自由度场拟合独立纹理对应：先确定方向、幅度和必要空间规律，
再拟合外围过渡；只有独立残差有系统结构时才增加自由度。
拟合目标可采用置信度加权的稳健位移误差，再加入该项的平台、单调、峰形或刚性约束。
剖面必须同时保留水平与垂直分量，低纹理段标为估计；拟合点和检查点分开。

容差应结合独立测量噪声和目标可见差异，在观察候选输出前确定。
先验证候选字段，再验证实际输入/输出中的纹理对应、轮廓、双影、保护与元数据。
安全原样返回不算正例效果通过；变化像素数也不代替位移方向和空间规律。
正负强度、零值、重复、旋转/镜像、尺度改变、遮挡及退化输入均按声明的输入范围检查。

七项先独立复现。组合时须在明确坐标中合成总映射并检查总梯度，最后仍只采样原图一次。
有限旋转与伸缩不能默认以简单位移相加获得精确组合；组合顺序和相互影响需要独立比较。
单次采样不等于简单相加，本轮独立截图也没有确定参考产品的组合顺序。
