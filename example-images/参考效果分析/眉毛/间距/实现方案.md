# 眉毛间距：沿整条眉身递减的水平位移

归档说明：本篇迁移既有候选方案，测量来自 2026-10-15，方案编写于 2026-10-16。本次归档未新增测量或实施。证据与推理见[分析链路](分析链路.md)。


本篇仅根据参考截图的位移测量提出实现方案，未参考现有 SDK 实现。
坐标、形变方向、支撑域与逆映射遵循[公共约定](../README.md)。
本文只设计几何变形，不设计亮度、颜色或眉毛重绘。

## 1. 测量告诉了什么

- 同一肖像的两个滑杆端点之间，单侧眉头向外移动约 **23–27 px**。
- 位移沿眉身向眉尾减弱；眉尾明显小于眉头，不能解释为整眉等量平移。
- 两侧移动方向相反，主要分量为面部水平方向。
- 这些像素是对齐后的参考截图尺度，表示两个端点的总差。
- 未独立确认两个端点相对中性状态对称，因此不能把一半写成实测单端幅度。

像素量统一属于公共约定的 **1170 × 1749 px** 照片网格，不能混用原始截图坐标。

由此选择“眉头强、眉尾弱的连续水平场”。整眉刚性平移不能满足该剖面。
下面的平滑函数、尾端比例与滑杆映射属于候选参数化，仍需拟合参考数据。

## 2. 输入几何与符号

每侧需要源图眉头 `H`、眉尾 `T`、眉脊曲线 `c(r)` 和保护区域。
使用公共约定的 `L`、`t`、`d`、`e_out`；`t=0` 为眉头，`t=1` 为眉尾。
眉毛内部的支撑权重 `m(t,d)` 为 1，外部平滑归零。
纵向支撑贴合眉脊，额头侧过渡可以较宽，眼睛侧必须受到保护边界约束。
横向支撑要在眉头和眉尾之外留出过渡，不能在眉毛端点直接截断。

新增拟合量：

| 参数 | 含义 | 约束 |
| --- | --- | --- |
| `ρ` | 眉尾相对眉头的水平幅度 | `0 ≤ ρ < 1`，由参考剖面拟合 |
| `A+`、`A−` | 中性到向外、向内端点的幅度 | 非负、按眉长归一化 |
| `m` 的边界宽度 | 向周围皮肤传递运动的范围 | C1 连续、保护区内为 0 |

是否 `ρ=0` 应由独立尾部匹配及测量噪声界判断，不能预定尾尖一定移动或固定。
与眉头间距的区别以眉中外段是否参与、沿眉身的衰减和归零位置为主。

## 3. 位移场

令 `S` 为公共约定的夹紧 smoothstep，定义：

```text
g(t) = 1 − (1 − ρ) S(t)
f(p) = g(t(p)) m(t(p), d(p))
a(u) = A+ u                 当 u ≥ 0
       A− u                 当 u < 0
D(p;u) = a(u) f(p) e_out
F(p;u) = p + D(p;u)
```

`u>0` 表示两眉分开，`u<0` 表示靠拢；画面左眉向左为正，右眉向右为正。
在支撑平台上，眉头位移为 `a(u)`，眉尾位移为 `ρ a(u)`。
`g` 在眉身内连续递减，周围皮肤通过 `m` 跟随并在外缘归零。
该最小模型的垂直分量为 0；若独立匹配发现稳定垂直分量，再增加对应项。
不能通过放大二维位移模长来掩盖水平分量不匹配。

参考剖面若不能被这一条 smoothstep 解释，可改用有单调约束的样条 `g(t)`。
保留 `g(0)=1`、`0≤g(1)<1`，且不凭少数噪声点引入局部反向位移。

## 4. 幅度与尺度标定

先在参考尺度拟合 `ΔA=A+ + A−`，其眉头目标约为 **23–27 px**。
按公共约定，将低端场映回同一原图点后比较端点差，不能直接逐点相减不同网格。
左右分别拟合，不把区间两端解释成左右两眉的固定数值。
同时以中段、尾段的匹配点约束 `ρ` 和整条 `g(t)`，不能只拟合眉头峰值。
把拟合幅度记录成 `k=ΔA/L_ref`，新输入使用 `ΔA_new=k L_new`。
这只是尺度迁移，不能由同一肖像推导跨人脸和侧脸泛化已经成立。

若只有两端参考，`A+` 与 `A−` 的拆分仍不可识别。
初版可明确采用对称映射作待验证假设；有中性参考后再分别拟合两侧曲线。
不要用端点总差直接设成中性到单端的幅度。

## 5. 支撑、保护与无折叠

- 支撑覆盖眉身及周围过渡皮肤；眼球、眼睑保护核与支撑域外保持恒等。
- 眼睛侧的窄过渡需要随幅度检查，不能单靠压窄权重避让眼睑。
- 两眉内侧支撑重叠时，使用公共约定的归属与组合规则，避免相反位移直接叠加。
- 每次在源空间生成完整场，输出从原图单次采样，不能逐次变形已变形结果。

记 `f=g m`，本模型的 Jacobian 行列式为：

```text
det(J_F) = 1 + a(u) [e_out · ∇f(p)]
```

这里的梯度包含眉脊曲率、`t` 尺度和支撑边界的全部贡献。
向外移动时，眉头位移大于眉尾，眉身会发生局部压缩，因此必须检查梯度。
若最小行列式不满足预定正裕量，减小幅度或扩大可用过渡；无空间则拒绝该强度。
同时遵守公共梯度预算 `||∇D||_2≤kappa<1`，超预算不能假定固定点逆解仍收敛。
仅有正行列式不足以覆盖全部全局问题，还要检查边界、逆求解与保护区对应关系。

## 6. 实现顺序

```text
1. 读取本次源图几何，确认 L>0、眉脊有效，建立 t、d 和保护支撑 m。
2. 从参考的眉头/中段/尾段剖面拟合 ΔA、ρ 或单调样条 g。
3. 按本次眉长缩放幅度；由明确的滑杆假设或中性测量得到 a(u)。
4. 在源坐标计算 D=a·g·m·e_out；分别处理左右眉符号与归属。
5. 检查方向、支撑边界、保护核、梯度和 Jacobian；必要时限制强度。
6. 求 F 的逆，验证残差后从原图单次采样；逆失败时返回明确失败。
7. 以独立匹配与剖面核对输出，记录聚合误差和失败项。
```

`p=q−D(q)` 仅可作为逆求解初值，不能当作精确逆映射。

## 7. 怎样验收这一个调整

参考复现先比较端点到端点的水平场，避免未测中性拆分污染结论。
沿眉脊抽取 `D·e_out`，应当眉头最大、沿眉身递减，并复现眉中外段的参与范围。
尾部较小或归零以独立对应和噪声界判断，不以预定的非零尾尖制造两项区别。
以独立局部纹理对应核对眉头、中段、尾段，分别报告位置误差与方向误差。
将位移正交分量单独报告；不把纹理稀疏处的平滑插值当成独立观测。

实际输出的正例检查两眉分开/靠拢方向正确、纹理连续、作用范围匹配。
负例检查 `u=0` 原样、支撑外与眼部保护核不动、左右镜像后方向仍正确。
极值检查眉头挤压、眉尾拉扯、边界双影与逆解残差；重复执行应得到相同结果。
尺寸、方向、alpha 与色彩元数据按公共约定验收，像素变化本身不能代替位移正确。
这里只提出实现与验收方法，尚未产生该候选场的实际输出通过结论。
