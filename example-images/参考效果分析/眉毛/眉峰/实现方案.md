# 眉峰：眉中外段局部抬升的紧支撑位移

归档说明：本篇迁移既有候选方案，测量来自 2026-10-15，方案编写于 2026-10-16。本次归档未新增测量或实施。证据与推理见[分析链路](分析链路.md)。


本篇仅根据参考截图的位移测量提出实现方案，未参考现有 SDK 实现。
坐标、形变方向、支撑域与逆映射遵循[公共约定](../README.md)。
本文只设计几何变形，不设计亮度、颜色或眉毛重绘。

## 1. 测量告诉了什么

- 两个滑杆端点之间，眉中外段局部上抬约 **14–16 px**。
- 内侧位移较小，向外侧减弱并在外围回零，作用不是整眉平移。
- 峰位来自本次参考的位移观察，不能直接等同某个固定通用解剖点。
- 这些是同一肖像两个端点的总差，未独立确认相对中性状态对称。

像素量统一属于公共约定的 **1170 × 1749 px** 照片网格，不能混用原始截图坐标。
汇总没有确认眉尾严格不动；固定区域须由独立对应确认，不能从候选公式倒推。

据此采用沿眉长的局部 bump，推动眉峰附近及周边皮肤连续运动。
峰位、内外侧过渡长度和中性拆分仍需拟合，不能靠功能名称直接确定。
不采用整眉刚性旋转，因为它不能独立解释局部峰值和两端衰减。

## 2. 输入几何与符号

每侧需要源图眉头 `H`、眉尾 `T`、眉脊曲线 `c(r)` 和眼部保护区域。
使用公共约定的 `L`、`t`、`d`；`e_y` 向下，因此上抬位移带负号。
支撑平台 `m(t,d)=1` 应覆盖受影响眉体及相邻纹理，周围皮肤 C1 归零。
在眉长方向再定义局部 bump，不能靠径向圆形衰减代替眉形剖面。

新增拟合量：

| 参数 | 含义 | 约束 |
| --- | --- | --- |
| `t_a` | 内侧开始产生局部运动的位置 | `t_a < t_p`，由观察范围拟合 |
| `t_p` | 最大抬升位置 | 在本次眉中外段内拟合，不固定通用比例 |
| `t_b` | 外侧局部运动完全停止的位置 | `t_p < t_b`，可大于 1，须在有限支撑内 |
| `A+`、`A−` | 中性到抬高、压低端点的幅度 | 非负、按眉长归一化 |

允许 `t_a<0`，以表达眉头少量跟随；是否需要由独立内侧匹配判断。
`t_b` 可在眉尾前或眉尾外，由外侧位移剖面与纹理匹配拟合。
候选约束为 `t_b≤1+R_T/L`，使它位于公共眉尾外围支撑内；不强制 `b(1)=0`。

## 3. 位移场

令 `S` 为公共约定的夹紧 smoothstep，定义不对称 bump：

```text
b(t) = 0                                     当 t ≤ t_a
       S((t−t_a)/(t_p−t_a))                  当 t_a < t < t_p
       1 − S((t−t_p)/(t_b−t_p))              当 t_p ≤ t < t_b
       0                                     当 t ≥ t_b
f(p) = b(t(p)) m(t(p), d(p))
a(u) = A+ u                 当 u ≥ 0
       A− u                 当 u < 0
D(p;u) = −a(u) f(p) e_y
F(p;u) = p + D(p;u)
```

`u>0` 抬高局部眉峰，`u<0` 压低；两眉共同遵守同一竖直方向。
`b(t_p)=1`，左右两段可有不同宽度，连接点和支撑外缘的一阶导数均连续。
`m=1` 的眉体内，抬升沿眉长由 `b(t)` 决定，不强行做整眉平顶。
额头和眼睛两侧的过渡由 `m` 决定，与沿眉长的 bump 分开拟合。

这个最小模型不加入水平位移；水平匹配残差必须单独报告。
若后续发现稳定的水平分量，需要有独立证据再增加，不能用斜向力预先混入。

## 4. 幅度、峰位与尺度标定

在参考尺度联合拟合 `ΔA=A+ + A−`、`t_a`、`t_p` 与 `t_b`。
按公共约定，将低端场映回同一原图点后比较端点差，不能直接逐点相减不同网格。
峰值目标约 **14–16 px**，同时匹配内侧小位移和外侧回零的位置。
峰值一致而支撑太宽，会变成眉毛上下；支撑过窄则会形成尖折，均不算复现。
用 `k=ΔA/L_ref` 保存尺度关系，新输入取 `ΔA_new=k L_new` 作为候选幅度。
峰位与左右宽度使用归一化眉长，不固化截图的绝对像素位置。

当前不能证明不同眉形的 `t_p` 相同，也不能由局部最高的原眉毛纹理直接推定它。
先用参考位移峰位拟合，再建立跨眉形的几何映射；新形态需要独立验证。
端点不提供中性拆分：若采用 `A+=A−`，应明确记录为初版假设。
不能把 **14–16 px** 除以二后称作已经测得的单端最大幅度。

## 5. 支撑、保护与无折叠

- 独立测定的固定域、支撑域外和眼部保护核保持恒等；不预定整段眉尾固定。
- 下侧靠近眼睑时，保护过渡不能在眉体内部把局部峰形截断。
- 若窄支撑与强幅度导致折叠，应限制幅度或采用参考允许的更宽过渡。
- 抬高与压低对上下侧空间要求不同，两个方向应分别检查，不能只测正端点。

记 `f=b m`，本模型的 Jacobian 行列式为：

```text
det(J_F) = 1 − a(u) [e_y · ∇f(p)]
```

检查完整二维梯度，包括眉脊 `c(r)` 引入的交叉分量。
除 `det(J_F)>ε_J>0`，还要限制沿眉长的剪切与位移梯度，避免眉峰变成尖角。
同时遵守公共梯度预算 `||∇D||_2≤kappa<1`，超预算不能假定固定点逆解仍收敛。
正行列式不能代替轮廓与纹理验收；眉体局部过度拉伸仍可能形成错误外观。
两侧支撑独立建立，不能跨眉间把两个局部峰连成同一片大范围抬升。

## 6. 实现顺序

```text
1. 在源图建立每侧 t、d、眉体平台与眼部保护支撑 m。
2. 用参考位移峰值和内外侧剖面拟合 ΔA、t_a、t_p、t_b。
3. 按本次眉长迁移尺度；中性拆分使用已测响应或明确标记的假设。
4. 在源空间计算 D=−a·b·m·e_y，保留局部不对称过渡与独立测定的固定域。
5. 检查两方向的保护核、梯度、Jacobian、峰形与可用过渡空间。
6. 对 F 求逆，验证残差后从原图单次采样；无安全解时限制或拒绝强度。
7. 独立匹配复核峰位、两侧衰减和固定区，记录聚合误差与失败项。
```

`p=q−D(q)` 只可作为逆求解初值，不能当作实际逆采样公式。

## 7. 怎样验收这一个调整

沿眉脊比较端点到端点的 `−D·e_y`，分别报告峰值、峰位和内外侧半高宽。
同时比较外侧归零位置与内侧残余，避免只对一个最大值调参。
用独立纹理匹配核对内侧、峰区和外段，水平分量作为模型残差单独统计。
纹理稀疏处的 bump 形状属于估计，不把候选公式生成的网格当成测量证据。

实际输出正例检查局部抬高/压低方向正确、眉脊连续、邻近皮肤没有尖折。
负例检查 `u=0` 原样、眼部与支撑外不动、实测固定域不动、镜像后的峰位关系正确。
极值检查眉体纵向拉伸、眼睑牵扯、外侧折痕和逆解残差，并核对重复性与元数据。
本篇仅提供候选实现与验收方法，尚未产生候选场实际输出通过的结论。
