# 眉毛长短：眉头锚定的水平伸缩

归档说明：本篇迁移既有候选方案，测量来自 2026-10-15，方案编写于 2026-10-16。本次归档未新增测量或实施。证据与推理见[分析链路](分析链路.md)。


本文根据参考截图的位移分析提出可实现假设，尚未实现或验证。
不参考现有 SDK 代码，不涉及颜色；公共数学见 [README](../README.md)。

## 1. 测量事实与实现假设

短端→长端的位移主要沿水平向外，眉头基本不动。
代表幅度集中在眉中外段，本图局部两端差约 **15–18 px**。
更外侧的位移再衰减回零，因此作用域不等于一条单调伸长的无限射线。
当前汇总未确定两个端点各自相对原图的幅度，也未确定精确的上升曲线。

可证伪假设：以内侧眉头为锚，沿眉身增加水平向外位移，外侧皮肤带再接回原图。
核心中的中外段可接近平移平台；不用整眉围绕几何中心等比缩放。
若独立匹配显示眉头明显移动或垂直分量持续显著，则该最小模型不足。

## 2. 所需几何输入

- 源图面部轴、画面左右眉身份、眉头 `H`、眉尾 `T` 与眉脊 `c(r)`。
- 公共投影长度 `L=(T-H)·e_out>0`，其中 `e_out=sigma·e_x`。
- 眉体核心上下界、眉头固定区、眉外侧可用支撑区与眼睛保护域。
- 眉头、眉中、眉尾、外侧皮肤各区的独立纹理匹配与置信度。

`e_out` 始终从眉头指向外侧，不能按 landmark 列表顺序猜正负。
眉头尾投影接近零、曲线自交或左右身份不确定时，不生成该眉变形。

## 3. 前向场与参数方向

`t=r/L`，`d` 为相对源眉脊的向下距离，公共包络 `m(t,d)` 核心为 1。
定义眉头锚定函数 `g(t)`，让位移从内侧零值上升到中外段平台：

```text
g(t) = S((t - t_anchor) / (t_plateau - t_anchor))
0 <= t_anchor < t_plateau <= 1
a(u) = A_extend · u       , u >= 0
     = A_shorten · u      , u < 0
D(p,u) = a(u) · g(t) · m(t,d) · e_out
F_u(p) = p + D(p,u)
```

`A_extend/A_shorten>=0`，正 `u` 拉长，负 `u` 缩短，零值恒等。
上述 `g` 将平台延续到眉尾，是可证伪的初始候选，不是中外段峰值观测的必然结论。
仅在眉尾确实满幅、`m(T)=g(1)=1` 且眉头固定时，投影端点距离才变为 `L+a(u)`。
这也不表示真实曲线弧长恰好增加 `a`，弧长须由输出曲线另算。
若独立剖面显示眉尾前已经衰减，应为强度增加尾侧门函数：

```text
g_tail(t) = 1 - S((t - t_decay) / (t_zero - t_decay))
g_local(t) = g(t) · g_tail(t)
t_plateau <= t_decay < t_zero
```

用 `g_local` 替换前向场中的 `g`；`t_zero` 可按测量落在尾前或尾外。
后文的 `g` 表示最终选用的有效剖面，包含需要的尾侧门函数。
此时尾部可以部分衰减或归零，端点距离应由 `F_u(H)`、`F_u(T)` 实算。
允许缩窄尾侧作用包络，但不得为了匹配峰值而预设眉尾一定移动或一定固定。
两种候选共同保留眉头固定、中外段为主、外围回零三条已观察规律。
初始模型没有 `e_y` 位移，不把“沿眉脊切线伸长”当已测定事实。

## 4. 从端点差标定幅度与尺度

在实际存在的平台 `g=m=1` 的同一源点上，端点差满足：

```text
Delta D_out = A_extend + A_shorten
```

本图 15–18 px 可初始化这个总量；它不是两个单端幅度。
只有原图→短端、原图→长端均测到后，才能分别确定两个 `A`。
先用对称半幅只是待验证的初始设计，不得写为实测 ±7.5–9 px。
目标尺度用 `A=alpha·L`；参考眉长尚需在临时输入上测量后取得 `alpha`。
左右眉分别拟合后比较无量纲幅度；不能把像素差直接归咎于天然不对称。

标定顺序为：先拟合平台总幅度，再拟合 `t_anchor/t_plateau`，最后拟合外侧衰减。
眉头是否需要严格固定区由测量噪声和独立检查点决定。
最简单的 smoothstep 若无法解释中外段剖面，再改成少量结点的单调 `C1` 曲线。
只允许由有置信度的残差增加自由度，不能直接拟合每个稠密光流值。

## 5. 支持区、保护与无折叠

上、下支撑沿眉形分布，避免水平伸缩把整片额头拉向两侧。
眉头邻近鼻梁区由 `g=0` 和内侧包络双重约束。
尾侧何时衰减由独立剖面决定，不能因功能名称而强制满幅平台覆盖眉尾。
平台到外侧固定区之间，正向外拉会压缩下降过渡带；该处是重点风险区。
增大中外段位移不能靠把外侧过渡削得更窄实现。
眼睛保护域内场为零，并确保眉下连接带平滑、无局部横向挤折。

令 `h=g·m`，本单轴场有：

```text
det(J_F) = 1 + a(u) · (grad(h) · e_out)
```

导数须在源图固定面部垂直坐标上求值，包含 `d` 随曲线 `c(r)` 变化的项。
只沿眉脊对 `g` 求一维导数，会漏掉上下包络造成的梯度。
短端在上升带压缩，长端在外侧下降带压缩，两个极值必须分别检查。
正 Jacobian 下界、梯度上限及逆解残差由公共安全规则约束。
没有足够可用支撑时限幅或明确退出，不能移动保护域补空间。

## 6. 实现伪代码

```text
1. 校验方向、左右身份与源眉几何，取得 L、眉脊及可用支撑。
2. 构造眉头锚定 g(t)，并沿眉形构造含眼睛保护的紧支撑 m。
3. 按 u 和归一化幅度生成水平前向场 D=a·g·m·e_out。
4. 检查眉头固定、尾部实测剖面、外围归零、完整梯度与 Jacobian。
5. 为目标坐标 q 求解 F_u(p)=q，校验逆残差和源图采样边界。
6. 原图单次采样输出；零参数走恒等路径，保留公共图像契约。
7. 记录幅度/剖面/保护的聚合残差与失败计数，不保存点位或逐像素位移。
```

## 7. 拟合与像素/几何验证

纹理检查点必须覆盖固定区、上升区、平台和外侧回零区。
只测最大位移不能区分整眉平移、中心缩放和眉头锚定伸缩。
端点相对场须从共同源点的 `F_low/F_high` 生成，再放到低端坐标比较。
拟合目标包含外向位移残差、垂直残差、眉头固定误差与外侧剖面误差。
保留独立检查点和左右眉分项，防止单个均值掩盖一侧方向反了。

- 正例：短→长的中外段外向差接近 15–18 px，眉头位移接近测量噪声。
- 机制：中外段强、内侧弱、外侧归零同时成立，眉脊无系统垂直漂移。
- 形状：眉尾连续，端点长度变化符合独立测量，眉厚不因支持区过窄明显挤薄。
- 保护：眼睛、眉间固定窗与支持区外输出像素分别对原图检查。
- 负例：镜像后两侧仍正确向外，零值恒等，遮挡/退化几何安全处理。
- 数值：正负极值均无折叠、无逆解发散；重复结果稳定。
- 图像契约：尺寸、extent、方向、alpha 和边界采样按公共规则验证。

尚需拟合：原图到两端的幅度分配、归一化系数、锚定区、平台起点与终点、
尾内是否衰减、上下与外侧支持宽度，以及是否存在需要建模的稳定垂直分量。
本文提供待验证技术路线，不表示参考内部公式已被确定或效果已合格。
