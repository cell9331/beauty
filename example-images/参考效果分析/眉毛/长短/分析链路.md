# 眉毛·长短：分析链路

本篇整理 2026-10-15 的历史测量及 2026-10-16 的既有推导。本次仅迁移证据和资料，没有重新运行测量、拟合候选输出或提升效果资格。

## 1. 输入、方向与问题

输入为同一肖像原图及滑杆左端 `IMG_2041`、右端 `IMG_2042`。可审阅的对齐原图和端点已包含于[证据图](证据/位移证据.png)，完整对齐输入保留在本功能的本地测量目录。
这组输入用于回答左端→右端的二维位移规律；除上下外，不把端点差等分为已经测得的单端幅度。

统一照片网格、前向场正方向、稳定区与保护区见[眉毛公共约定](../README.md)。原始场 `dx` 向右、`dy` 向下为正；本功能主证据展示水平分量，图上向右为正。两个分量同时见[七项总览](../证据/位移总览.png)。

## 2. 历史测量步骤

1. 排除界面覆盖，仅在眉区外的头发、侧部和下半脸稳定纹理拟合全局相似变换，并用空间留出点与分区拟合交叉核对。原图只重采样一次；截图间漂移小于 0.001 px，保持同网格。
2. 左端→右端计算 DIS 前向二维场，并计算反向闭合、Farnebäck 方法差异与半尺度复测；后者换算回统一截图像素。弱纹理的光流填充值属于估计。
3. 在源图纹理上按空间格选角点，独立进行 NCC 模板匹配。历史搜索裕量为每轴 ±48 px，接受时检查匹配分数、多解和反向闭合，不按“符合稠密场”筛点。
4. 以原尺度与半尺度曲线、邻近独立对应和功能所需的局部纹理/刚性核对约束空间规律，再提出低自由度候选机制。图中纵剖面采用 7 px 窄带中位数，横剖面采用 5 px 窄带中位数；橙点来自邻近位置，并非每个剖面坐标都有实际对应。

原图留出配准残差 P95 约 0.684 px 是历史稳定区统计，不能外推为所有眉区点的真实位移精度。零变化控制得到 P99 0 px；已知局部上移 8 px 控制的纹理区误差 P95 约 0.062 px，亦不能代替本功能精度。

## 4. 从观测到候选机制

短端→长端的位移主要沿水平向外，眉头基本不动。
代表幅度集中在眉中外段，本图局部两端差约 **15–18 px**。
更外侧的位移再衰减回零，因此作用域不等于一条单调伸长的无限射线。
当前汇总未确定两个端点各自相对原图的幅度，也未确定精确的上升曲线。

可证伪假设：以内侧眉头为锚，沿眉身增加水平向外位移，外侧皮肤带再接回原图。
核心中的中外段可接近平移平台；不用整眉围绕几何中心等比缩放。
若独立匹配显示眉头明显移动或垂直分量持续显著，则该最小模型不足。
