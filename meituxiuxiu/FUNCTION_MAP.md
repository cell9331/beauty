# Meitu Xiuxiu Reference Function Map

**整理日期:** 2026-06-23
**来源目录:** `meituxiuxiu/`
**图片数量:** 15 张 PNG，均为 1170x2532 手机截图

## 结论

这批截图不是 App 首页，而是美图秀秀编辑器内的「美型 / 五官」调节界面。所有截图共用同一个编辑器框架，只是底部一级分类和二级功能横向滚动位置不同。

首页参考已单独整理在 `meituxiuxiu/HOME_MAP.md`。

整理时不删除原始 PNG 文件；只在本文档中合并重复功能，保留唯一功能分类和必要的补充截图引用。

## 共同界面结构

- 顶部黑色系统栏，中间是「美图秀秀」品牌胶囊。
- 主区域是全屏人像预览，图片铺满到白色工具面板上方。
- 预览底部有「背景保护」开关，右侧有一个小的对比/预览按钮。
- 底部是白色工具面板：
  - 顶部一条强度滑杆，圆形滑块。
  - 右侧有「整体」胶囊按钮。
  - 中间是二级功能横向列表：线性图标 + 中文名称；选中项为粉红色。
  - 底部是一级分类横向列表；选中项黑字加粉红短下划线。
  - 左下是取消 `X`，右下是确认勾选。
- 限免 / Pro / OFF 状态以小徽标或图标内文字展示，属于功能状态的一部分。

## 一级分类导航顺序

截图中能看到的一级分类顺序大致为：

`表情管理` -> `3D塑颜` -> `比例` -> `脸型` -> `眼睛` -> `嘴唇` -> `鼻子` -> `眉毛`

部分截图左侧还能看到被截断的 `青管理` 文案，可能是更靠左的一级分类；但本目录没有对应完整功能面板截图，暂不纳入唯一功能分类。

## 设计提取要点

- 编辑器第一屏应优先像参考图一样：大预览 + 下方白色工具面板，而不是信息卡片式 SDK 控制台。
- 一级分类是底部主导航，不是左侧列表或普通表单。
- 二级功能是横向滚动 icon rail，选中状态用粉红色。
- 具体参数调节统一通过顶部 slider 完成，而不是每个功能都展开一个独立 slider 表单。
- 取消和确认是编辑器级动作，应固定在底部左右两端。
- `整体` 是二级调节区域右侧的快捷入口，不应做成独立页面。
- `限免`、`Pro`、`OFF` 是功能状态标记，后续 Demo 可以先用静态徽标表达，不必立刻实现会员逻辑。

## 未被这批截图覆盖的范围

- App 首页 / 图片导入首页。
- 相机拍摄入口。
- 图片选择器或相册入口。
- 美颜肤质、滤镜、妆容、贴纸、背景、风格等其他一级模块。
- 保存、分享、导出流程。

因此，若要重做首页，需要另外参考首页截图；若要重做当前编辑器，则本目录足以定义「美型 / 五官」工具面板的结构和分类。
